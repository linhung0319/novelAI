# 角色塑造素材 — 索引

## 這個資料夾是什麼

`Data/角色塑造/` 專收**角色設計與塑造**的跨語言、跨媒介素材。開這個資料夾的理由：

- `技巧知識庫/` 目前的角色技法只有兩本主檔（`角色塑造.md` 管「塑造與呈現」、`需求四象限.md` 管「需求與弧線」），而**兩檔的來源幾乎全部集中在單一繁中作者（洛克老師）** 的 `Data/【人物】.txt`＋`Data/【獨門密技】.txt`。
- `Data/跨語言技巧/人物與角色弧線.md` 雖已做過一輪跨語言補充，但只有 80 行、四個生態各 1–2 條，且軸線集中在「弧線」。
- 角色塑造不限於小說：遊戲、動畫、二次元手遊的角色設計方法論（辨識度、記憶點、屬性組合、分階段揭露）有大量小說界沒有的可操作手法，值得單獨開一個資料夾承接。

**主題檔的內部標記慣例**：
- 標「**僅搜尋摘要，未取全文**」＝該條只取得搜尋結果摘要（知乎 403／JS 牆／憑證錯誤等），**提煉時不可當成已核實原文使用**。
- `二次元遊戲角色設計.md` 額外標【可轉譯】／【需改寫】／【不可搬】＝該手法對小說的可用度。
- 標「（策展者判斷，非原文）」＝該段是策展時的推論，不是來源作者的主張。

## 每檔內部格式

沿用 `Data/跨語言技巧/*.md` 的既有慣例：

H1 標題（跨語言）→ `>` 引言三行檔頭（性質／涵蓋語言＋對映知識庫技法／抓取日期）→ 依語言生態分節（`## 英文 craft` / `## 日文` / `## 簡中` / `## 韓文` / `## 遊戲・二次元`）→ 每個技巧 `### 方法名稱（作者/出處）`＋繁中提煉＋保留原文術語＋1–3 句原文金句＋`> 來源：URL｜作者/站台｜語言` → 結尾「跨語言對照」表。

**不用 frontmatter**（Data/ 全資料夾慣例）。

## 提煉時的一句話導引

同一件「怎麼讓角色立起來」，四個生態的切入點截然不同：
- **英文 craft** 擅長**結構化與關係化**——角色不是單獨設計的，而是靠對立網（Truby character web）互相定義；並把典型學（Enneagram 健康層級）接上弧線引擎。
- **日文** 擅長**落到句子與記號**——語尾×一人称的書き分け、萌え要素的組合論、「憧れ×感情移入」的二軸調校。
- **簡中網文** 擅長**記憶點工程**——極致標籤＋反差＋生存規則，追求「3 秒立住一個人設」。
- **二次元手遊** 擅長**多感官與分階段**——矛盾標籤的外顯/內化、視覺聽覺動作三路記憶點、角色故事分批釋出以養情感。
- **韓文 웹소설** 擅長**把角色綁進連載節奏**——魅力＝每次危機都能給讀者情緒回報。

提煉時可對照取用，互補為佳；刻意讓各生態貢獻**不同**切面，不重複灌水。
