# 角色關係網與群像

> **用途**：本檔承載「方法」，管**角色之間如何互相定義**——對手怎麼找、角色網怎麼配、多角色的戲份與記憶負荷怎麼管。供 `organize`／`develop` 配置角色群、`expand` 診斷「缺的是哪一種角色」、`beat-sheet` 排群像戲份與反派升級、`beat-test`／`character` 檢查新角色是否與既有角色構成真對立引用。
> **三檔分工**：`角色塑造.md` 管**單一角色是什麼樣的人**（塑造與呈現）；`需求四象限.md` 管**單一角色要什麼**（需求與弧線）；本檔管**角色之間**。`write`／`revise` 通常不需要本檔（句子層級不處理角色配置）。
> **核心命題**：沒有角色能在真空中被創造出來——角色是靠一張互相關聯的網被定義的。
> 本檔內容提煉自 `Data/角色塑造/角色關係網與群像.md`（**跨語言策展筆記**，非洛克老師逐字原文）；核實狀態見檔尾。

## 一、對手論：對手＝爭同一個東西的人

Truby 對「對手（opponent）」的定義比「反派」嚴格得多：對手不只是**阻止**主角達成目標的人，而是**與主角競爭同一個目標**的人。判準是**結構功能，不是道德善惡**——好人也可以是對手（`Data/角色塑造/角色關係網與群像.md`「對手論」）。

- **找對手的方法**：從主角的**具體目標**出發，誰想阻止他得到它，誰就是對手。目標愈模糊，對手愈找不出來。
- **「主角的對手是他自己」是結構性錯誤**：那描述的是角色的內在弱點（屬 `需求四象限.md` 的落差／`角色塑造.md` 六的 FLBW），不是真正的對立。真對手必須是外部、且爭奪同一目標。
- **深層對立**：表面看目標不同（偵探抓兇手／兇手逃脫），底下其實在爭同一件事。《唐人街》表面是傑克抓兇，底層在爭「**大家最後會相信哪一個版本的現實**」。找到這一層，衝突才不只是動作。

> 「A true opponent not only wants to prevent the hero from achieving his desire but is competing with the hero for the same goal.」（英）

## 二、四角對立：一個主角配三個對手

好故事很少停在「主角 vs 主對手」的二元線。Truby 的配置法是 **1 主角＋1 主對手＋至少 2 個次對手**，四人推到四個角落（同上「角色網與四角對立」）；四人要彼此拉開多遠，靠第三節的六參數表逐項比出來。四條設計律：

| 律 | 內容 |
|---|---|
| **同弱點、不同攻法** | 每個對手都攻擊主角**同一個大弱點**，但用**不同的方式**攻。這是四角對立最可操作的一條——不是湊四個敵人，是讓同一道傷口被四種手法反覆按 |
| **把價值觀擺進衝突** | 四個角色各自代表一整套價值系統，且彼此對撞。賭上的是「整套活法」，情緒衝擊才大 |
| **每人是主題的一個變奏** | 同一個道德難題，四人各給一種回應。主題因此是**從角色長出來的**，不是外加的說教 |
| **主角透過對手學習** | 對手握有鑰匙——主角的成長是被對手逼出來的，不是自己想通的 |

為什麼不能只做兩人對立：善對惡的二元結構會讓整個道德論證流於簡陋，**只有一張道德對立的網**才能讓讀者感受到現實人生的道德複雜度——要的是網，不是線。

> 「Each opponent should attack the hero's great weakness in a different way.」／「Your moral argument will always be simplistic if you use a two-part opposition, like good versus evil.」（英）

## 三、六參數個體化比較表

角色要「不一樣」，靠的不是各自設定，是**放進同一張表逐項對照**（同上「六參數比較表」）：

| 參數 | 原文 |
|---|---|
| 弱點 | Weakness |
| 心理需求與道德需求 | Psychological and moral need |
| 慾望 | Desire |
| 價值觀 | Values |
| 權力・地位・能力 | Power, status, and ability |
| 面對核心道德難題的方式 | How each faces the central moral problem |

**比較順序**：先做主角↔主對手 → 再擴及其他對手與盟友 → 最後做**對手之間／盟友之間**互比。最後這一步最常被跳過，也最容易抓出「兩個配角其實是同一個人」。

《窈窕淑男》案例：核心道德難題是「男人怎麼對待女人」，每個角色是一個變奏——Ron 為保護女人而合理化欺騙／Julie 明明有才華卻容忍被虧待／John 用權力換取性好處／Michael 假扮 Dorothy 後反而幫女人爭取尊重。

## 四、Mirror 與 Foil：兩種不同的功能，不是「對比工具」

把配角當「拿來對比主角的道具」是誤用；兩者是**功能性架構**，作用方向不同（同上「Foil 與 Mirror 的分工」）：

| | Mirror（鏡像） | Foil（對照） |
|---|---|---|
| 關係 | **共享**同一個傷口／缺陷／目標，在**選擇的那一點**分岔 | 處在同一敘事空間，但跑**另一套內在邏輯** |
| 他向主角展示什麼 | 「你可能變成的樣子」（治癒的，或崩壞的） | 挑戰主角的世界觀，製造意識形態阻力 |
| 作用 | **加劇內在衝突** | **複雜化外部選擇**，暴露決策底下的「軟邏輯」 |
| 診斷測試 | 他是否共享同一傷口、用不同方式解決它、並逼主角面對清算？ | 他是否在同一框架內運作、挑戰主角的倫理或策略、暴露其推理破綻？ |

兩者可並存於同一部作品（不是二選一）。`需求四象限.md` 五「兩極呼應」是 mirror 的雛形，本節是它的操作化版本。

> 「What should create narrative tension ends up as decoration.」／「Don't build contrast. Build tension.」（英）

## 五、群像的配額與記憶負荷

群像的本質不是「人多」，是**命運交會**——不是「很多人各自有故事」，而是「很多人的命運在某個點被打結」（同上「群像的戲份管理」「記憶負荷上限」「戲份配額」）。

**兩種結構**：**平行式**（如《冰與火之歌》，每條線都要能獨立成立，難度極高）／**鏈式**（A 帶 B 帶 C，把難度轉移到劇情編排，相對可控）。另一種切法是以時間線為主（角色眾多的單元劇）vs 以故事線為主（5 人以內的緊密團隊）。

**硬上限**：大事件中的**活躍角色控制在 3–5 人**，依據是人類工作記憶容量約 7±2 個組塊；超過 5 人讀者就開始吃力。

**配額四法**：

- **戲份格**：把每個角色在各章的出場畫成表格看失衡。原則不是平均，是**刻意**。
- **錯開情緒里程碑**：把各角色的弧線轉折畫在同一張圖上，確保**沒有兩個角色在同一場戲踩到轉折點**。
- **中央樞紐**：群像必須有一個共享的地點、處境或問題，把所有支線拉進同一軌道（與 `世界觀與背景.md` 六「綑綁抗衡」同原理）。
- **輪換配對**：讓不同角色兩兩組合輪替，每種組合照出角色的不同面；別讓誰長期卡在固定二人組裡。

**紅線與坑**：「群像戲份比重嚴禁超過讀者可控角色」——主線是經脈、配角故事是枝葉，且要讓主角參與配角故事的發展。三個常見坑：莫名出現的人物→人設突兀；過度側重配角→劇情阻塞以至卡文；視角切換不當→劇情割裂。

> 「Screen time distribution in an ensemble story isn't about being equal — it's about being purposeful.」（英）
> 「人類工作記憶的容量約為 7±2 個組塊。當大事件中活躍角色超過 5 人，讀者就開始吃力」（繁中）

## 六、配角功能化與反派的分層升級

**配角功能不重疊＝網文版的角色網**：給每個配角設計獨立的功能與性格，避免工具人。例：女主的三個閨蜜分別是毒舌擔當（吐槽搞笑）／知心姐姐（情緒價值）／理性軍師（分析建議）——**功能不重疊**是最低要求，人設也不該重疊（同上「配角獨立功能化 & 反派分層金字塔」）。

**反派三層金字塔**：底層**認知型**反派（練手，建立規則）→ 中層**勢力型**反派（多次交鋒）→ 頂層**終極**反派（貫穿全篇）。分層設計讓反派隨故事推進逐步升級，避免「開場最強、後面沒得打」。

> **反派設計的完整鏈**（三檔接力）：`需求四象限.md` 四「反派也有正當需求」（他為什麼問心無愧）＋ 本檔一「爭同一目標」（他為什麼是對手）＋ 本檔六「三層升級」（他何時出場、強度怎麼排）。

## 供哪些 skill 參照

- `develop`／`organize`：配置角色群時用六參數表逐項互比，確保配角不撞人設；群像作品先選結構兩型並定活躍角色上限。
- `expand`：診斷「這段缺什麼」時，先判缺的是**爭同一目標的對手**（缺衝突）、還是 **mirror／foil**（缺內在張力或世界觀阻力）——兩者要新增的角色完全不同。
- `beat-sheet`：排幕時用戲份格與情緒里程碑錯開檢查，並依三層金字塔排反派的出場與升級。
- `beat-test`：檢查群像戲份是否失衡、是否有兩個角色在同一場戲搶轉折、反派是否隨故事升級。
- `character`：新角色拍板前，用一「爭同一目標」與四「mirror／foil 測試」確認他在網中有位置，而非又一個功能重疊的配角。
