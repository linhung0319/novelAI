# 約束

> ⚠️ **尚未產出**——本檔是空骨架，只是先把位置佔好。實際內容由 `character`／`worldbuild`／`beat-sheet`／`write-test` 在**作者拍板後**寫入。
>
> 依 `結構定義/事實流.schema.md`：**下游不得寫成 X 的負向排除線**。**一條約束一列、欄位就地編輯**——它是規則登記表，不是事件流。
>
> **`.co.md` 的意思**（`共同約定.md` 零）：AI 寫、**你可以改、改動會留著**、格式由檢查器守。正因為沒有東西會覆蓋你，你改壞了也沒人幫你修——所以它有格式要遵守。
>
> **為什麼約束單獨一支檔**：它是**作者拍板的意圖**，正文裡沒有這句話、重讀一萬遍也生不出來——所以它不可重生，不能住進會被重生的 `.ai.md`。相對地，`狀態` 與 `錨` 是該章正文的函數，住在 `chapters/chNNNN.ai.md` 的「## 本章事實」，作者改了正文 `derived-sync check` 就報 stale、重生即修正。
>
> **為什麼是表不是 log**：約束一生會變的只有射程與是否解除。做成 append log 的話，「延長射程」只能再追加一行同名的去覆蓋，舊行從此不再被讀到卻永遠不會消失；而且「拍板點」會被綁成「生效點」，表達不出回溯生效。
>
> **逐欄**：
> - `生效自`＝`全書` 或 `幕NNN（arcAA）`。**寫「全書」就是回溯生效**——不必為了立一條約束而偽造一個拍板幕號。
> - `解除於`＝`—`（尚未解除）或 `幕NNN（arcAA）`。**延長射程＝改這一格**，不新增列。
> - 刻意**沒有「狀態」欄**：狀態可由「解除於」導出。手動維護的狀態欄正是「射程欄沒人讀」那個坑的來源。
>
> **指向還沒排幕的 arc 是合法的**——約束天生領先幕綱（替反派立排除線時那個 arc 常還沒拆幕）。投影會印一行資訊，不會報錯。
>
> **查詢不要整檔讀**：`uv run --project <套件根>/tools/fact_projection fact-project --book <你的書> --for-beat 幕NNN`（由幕綱的角色欄自動導出實體，別讓 LLM 自己填）
>
> **落檔後驗格式**：`uv run --project <套件根>/tools/fact_projection fact-lint --book <你的書>`（本檔只住約束；狀態與錨屬章 delta）
>
> **「為什麼這樣定」不寫在這裡**，那屬 `裁決流.co.md`。
