# 約束

> ⚠️ **尚未產出**——本檔是空骨架，只是先把位置佔好。實際內容由 `character`／`worldbuild`／`write`／`write-test` 在**作者拍板後**追加。
>
> 依 `結構定義/事實流.schema.md`：**下游不得寫成 X 的負向排除線**，append-only、一行一條、只增不重生。作者可審可改，投影程式（`tools/fact_projection`）唯讀。
>
> **為什麼約束單獨一支檔**：它是**作者拍板的意圖**，正文裡沒有這句話、重讀一萬遍也生不出來——所以它不可重生，不能住進會被重生的 `.ai.md`。相對地，`狀態` 與 `錨` 是該章正文的函數，住在 `chapters/chNNNN.ai.md` 的「## 本章事實」，作者改了正文 `derived-sync check` 就報 stale、重生即修正。
>
> **固定 4 欄信封**：`- 幕NNN（arcAA）· <實體> · 約束〔<名>〕：<內容>`（前三欄以 `·` 分隔，token 與內容以 `：` 分隔）
>
> **退場靠顯式解除**：發一行同名、內容以 `（解除）` 起頭的事件；投影 `--active-only` 時會濾掉。不刪舊列。
>
> **查詢不要整檔讀**：`uv run --project <套件根>/tools/fact_projection fact-project --book <你的書> --as-of 幕NNN（arcAA） --kinds 約束 --active-only`
>
> **落檔後驗格式**：`uv run --project <套件根>/tools/fact_projection fact-lint --book <你的書>`（本檔只住 `約束`；混進狀態或錨會報錯）
>
> **「為什麼這樣定」不寫在這裡**，那屬 `裁決流.md`。
