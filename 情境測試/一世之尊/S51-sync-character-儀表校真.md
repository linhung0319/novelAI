## 摩擦與缺口

1. ⭐⭐**新料·「機器事實在衍生檔、源檔不動就永遠不 stale」＝ derived_sync 的定義級盲點第二次發作**（第一次＝2026-07-23「源檔有、衍生檔不存在」）。`所屬arc`／`弧線類型`／`影響力`／`伏筆.收` 這類**隨正文長出的機器事實**寫在衍生檔 front-matter，源檔不動 → hash 不變 → 永遠 fresh → **無聲腐爛**。9 支角色標了整整兩卷的錯。作者的處方是**人眼巡檢項**（已落 `就緒儀表.md` 盲點③），但根因在工具：`derived_sync` 沒有「衍生檔內容 vs 正文事實」這一軸。**系統套件級候選功能，留真人作者。**
2. ⭐⭐**新料·「宣告式檔的狀態格會說假話，而且是結構在生產它」**。本 session 一口氣抓到 **4 格假話**（L9 三支角色檔／L11 大綱欄／L12 大綱欄／L12 正文欄）＋1 格狀態值錯（L11 幕綱欄），全部同型＝**儀表抄到了舊裁決、沒抄到後來那次**。作者的診斷比修法重要：「這張表 282KB、單格上千字，狀態與事件日誌塞在同一個 cell 裡……**假標籤會反覆長出來，是結構在生產它**」。已登記，本輪明令不做。
3. **系統對「作者利器」邊界拿捏正確但偏保守**：`大綱/arc11.md` 檔案本身的 working title 措辭它抓到了、**不代動**（比照 arc10 前例）——判斷對；但同一輪它又主動改了 `大綱/_index.md` 的 arc09／arc10 條與 `結構.md` 的 arc11 標題（同屬作者授權範圍的延伸）。邊界是對的，只是**兩者都在「作者利器」這一側，處置卻不同**——值得下次觀察它靠什麼分。
4. **自報精度**：Stage A 說真德／空聞「維持不動」，實際兩檔各 +7 行核對註（值未動、檔有動）。同 S45「自報就地改 4 檔實為 3」族，**非 over-reach**，但自報數字不可全信、須 git diff 複驗（誡條已有）。
5. **導演擋下一筆系統套件級改動**（第 3 次）：作者要把 🧊 標法「`已揭＠<arc/幕>（<正文章>）`」寫進 `結構定義/` 當通例——屬規格層，不由故事側 oracle 拍板。系統**照擋令執行並主動在檔內記明「屬規格層、本輪不裁」**。同輪第二筆同型＝schema 五欄 vs 書內六欄漂移（只登記不修）。**兩筆皆留真人作者。**
