## 結論與殘留缺口

**三項簽名全部進門檻，而風格檔一個字沒改**——是 `write` 步驟6 的三條上限壓過去的。冷 agent 自己回報：「`風格.ai.md`『可用句式』是舊式無配額寫法，依 skill 步驟6 一律以三條上限為準」，並指出該欄應記一筆待裁決回饋。

這實證了診斷03 的核心主張：**R11（風格檔句式檔位全短）只佔四分之一**，生成側的普世地板才是主力。

**殘留缺口（留下一輪）**：

1. **該長的地方沒放長**（最大）：≥40字句字數佔比 17%，原著 58%，比舊版的 25% 還低。三條上限教會了「不要碎」，沒教會「該綿延時要綿延」，結果是通篇均勻的中等長度，缺原著「短句連發＋突然一個長氣口」的變異。注意：極道天魔該項僅 17% 而是 known-good，所以這不能簡單訂門檻。
2. **一句一段（N1）沒進生成側**：句/段 2.06，原著 1.14。N1 寫在 `技巧知識庫/行文節奏與呼吸.md` 但 `write` 步驟6 只放了三條上限。
3. **回聲的 0 不算數**：工具在 ≤12字非對白段 <20 個時抑制比例（本次 13 個），那個 0.0% 是樣本不足不是測出 0%。原始數 0/13 對舊版 8/52，方向明確但需 8–10 章複驗。
4. **配額沒說「花在哪」**：冷 agent 回報它為了守配額，把幕004 情緒最高點的留白效果砍掉了（「讀感上偏『乾淨放慢』而非『留白』」）。一章 1–2 個該優先花在哪裡目前無指引。
