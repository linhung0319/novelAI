## Elicitation 紀錄

**無。** P 沒有系統 agent 發問，所以沒有作者 agent 被冷啟，`fallback-log.md` 的 P 列是 `—` 而不是 `0`——**那兩者不一樣**：`0` 是「問了、沒翻書」，`—` 是「沒有人問」。

P 做的是**佈置 elicitation 的條件**，也就是切出三層：

| 層 | 落點 | 這一輪放了什麼 |
|---|---|---|
| ① 寫下來的 | `消失的密室/raw/` 6 支／12,960 B | 主角種子與處境、前情、基調、7 個場景碎片、一批名字、模糊的懸疑核 |

**第 ③ 層是刻意的**（基座 §4「刻意留缺口」）。腦內檔只收承重的那一半——謎底、規則、角色為什麼是這樣、結局要成立什麼；質地兩邊都不寫，留給神諭翻書。**如果把兩支筆記整份倒進腦內檔，`fallback-log.md` 會恆空，而恆空不是好消息，是量尺失效。**

## 摩擦與缺口

1. **`--book` 是路徑不是書名，而傳錯時它長得像通過。** ⭐ 這是本 session 唯一的實質發現。
   `--book` 相對 **CWD** 解析，而 `書本模板/README.md:28` 與各 SKILL.md 的用法是 `cd tools/<套件> && uv run <指令> --book <你的書>`——從套件目錄看出去那個相對路徑不存在。
   **結果不是 traceback，是 11 支閘門回 exit 2 ＋「這本書還沒有這一層（找不到幕綱目錄：消失的密室\story\幕綱）」＋ 0 問題 ＋ 覆蓋率行照印。**那句話是假的：那本書有 `story/幕綱/`、有 `01-大綱.md`、有 `就緒.md`。輸出與一本真正空到那一層的書**逐字無法區分**。
   > **同型的反例系統自己記過**：`_流程與階段順序.md` §六 收尾那段——`foreshadow-project` 曾對一本有 11 支 arc 的書回 exit 2 說「還沒有這一層」，判定是「**那句話是假的**」，改成 exit 1。判準原文：「**exit 2 的正當性來自『這句話是真的』，不來自『它在枚舉裡』。**」這一格是同一條判準的另一個實例，而且觸發條件更常見（打錯一個 `--book`）。
   > **候選處置交階段 3**（E1：要指名檢查器與觸發時機）：`--book` 指到的路徑**本身不存在**時與「書在、但這一層還沒有」分開——前者不是 exit 2。`meta-lint` 第 6 項已經對 fixture 書實跑 exit 契約，多一格「不存在的書路徑」是現成的落點。

2. **`書本模板/` 的 `story/設定/{世界觀,角色}/` 是不帶 `.gitkeep` 的空目錄。** 複製出來的書在工作區有、在 commit 裡沒有（git 不收空目錄）。同一支模板底下 `chapters/`、`raw/`、`story/物件/` **都有** `.gitkeep`，只有這兩支沒有——是遺漏不是設計。S1 落第一支源檔就會自然建回來，所以**不在 P 修**（`書本模板/` 在系統層白名單上，而系統層在階段 2 期間必須凍結，`_流程與階段順序.md` §五 末條）。**記在這裡等階段 3／4 一起處理。**

3. **基座 §3 說觀測者讀「該 session 的 transcript」，但沒說 transcript 住哪。** 冷啟的觀測者不會知道自己在稽核哪一個 session。實際路徑 ＋ 導演該怎麼傳，已釘進 `session台帳.md` 的操作事實 1。**這不是 P 的缺失，是 S0 增修 2 落地時的一個空格**——它在有人真的要跑觀測者之前不會顯形。

## purity 檢查

purity（P 變體·三層覆蓋率）：比對了 117 個 token —— 層① 54 個／層② 14 個／層③ 49 個（c/N = 41.9%）

**為什麼 P 要換一個量。**基座 §3 職責 2 的標準做法是「產物 token 命中原文、卻不在 `raw/`＋`情境測試/`＋elicitation 紀錄裡 ＝ 污染候選」。**那個量在 P 上恆真為 0，因為它的減數就是它的被減數**：P 的產物**就是** `raw/` 與腦內檔本身，而兩者依設計從 `examples/` 推導。套上去會印出一個看起來乾淨、實際上不可能不乾淨的 `候選 0`——**照 E2 那正是最糟的一格**：一個在自己被關掉時仍會印「乾淨」的檢查器。
所以 P 量的是**三層切分的覆蓋率**：層③ 有多厚。這一格才是 P 真正的產出品質，因為**層③ 就是 `fallback-log.md` 未來的全部來源**——層③ 薄到 0，兩條 lane 就被合成了一條，fallback log 恆空，而 elicitation 品質的唯一量尺就失效（§4、§9）。

**做法（機械可覆算，腳本在 session scratchpad）**：先按**真實章序**排 `examples/消失的密室/` 的 18 支（全形 `第１`–`第９`、半形 `第10`–`第18`，自己換算而不是 `sorted()`——確認排出 1→18），逐章抽 CJK n-gram 詞頻候選，人工策展成 136 個涵蓋人名／地名／機構／道具／咒語／生物／數字的 token，剔除 19 個實際不在本書語料裡的（多為別集咒語與臆測數字），**餘 117 個逐個對三層做子字串比對**。章覆蓋：18 章每章都有 19–55 個 token 命中，沒有任何一章是空的。層①＝在 `raw/` 找得到（含同時也在腦內檔的 28 個）；層②＝`raw/` 沒有、只在 `作者腦內-*.md`；層③＝兩層都沒有。異體字另建別名表（`公鷄`／`公雞` 原文與筆記用字不同，已判回層②，不灌水層③）。
