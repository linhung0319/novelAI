## 摩擦與缺口

### 1. ⭐ 口頭拍板不落檔 → 下一輪就查無此句（機制缺口的活體實例）

第 2 輪系統引用「作者在題旨那段寫瑞斗**最後真的分成了好幾塊**」，據此判定分叉三的訂金已付掉一半。作者（**冷啟、只有檔**）查遍 raw 與腦內檔，回：「**這句話不在我的檔案裡。**」

**兩邊都沒錯。** 那句話確實是作者第 1 輪**在對話裡**親口說的——但它從未落進任何檔。系統 agent 記得（同一條 transcript），作者 agent 不記得（每輪冷啟）。

這正是 `CLAUDE.md` 標為最危險的那一格：**共創問答問出來的具體事實是③（真正的新資訊），看起來像分析、住在分析區，直到某次重生吃掉它而沒有人會發現。** 這裡的版本更早一階——它**連 `.ai.md` 都沒進去，只活在對話裡**，於是下一輪就地蒸發，還誘發了一次誤判。

**而系統的處置是對的**：它沒有硬拗，`裁決流.md` append 了一列更正（「分叉三兩案皆未定，不得記成已定案」），理由欄記下區分。**但這是事後補救，不是機制。** 缺的是「本輪對話中拍板但尚未落檔的事實」有沒有一個落點——目前 0 個。這一列該進 `需求機制帳`。

> **測試設計上的附帶價值**：作者 agent 每輪冷啟，反而讓這個缺口**可被觀測**。若作者 agent 是暖的（記得自己說過什麼），這一格會被記憶蓋掉，永遠不會露出來。

### 2. `develop` 階段就需要質地層答案，而流程圖假設它晚一階

`fallback-log.md` 的兩條 lane 是照「承重進腦內／質地留 fallback」切的，並預期 fallback 出現在 `beat-sheet`／`write`。實際**提前到 S1**——因為 `develop` 要落 `風格.md`，而 `style-lint` 的 `可用句式` 欄天然要求可數的顆粒度（「碎在分句／句／段＋數字」），讀感描述過不了。

**這不是缺口設計失準，是「質地何時被需要」畫錯了一階。** 詳細判讀在 `fallback-log.md`。

### 3. 水下存取控制不擋 `.ai.md`（系統自己撞出來，已落 `待裁決.md`）

`settings-select` 的水下存取控制擋的是**源檔切面**，不擋 `<名>.ai.md`。系統第一版 `湯姆瑞斗.ai.md` 把「他挑替罪羊的理由」「鄧不利多五十年前就不信他」寫進對衝關係節——**那兩條正是作者要求關進水下的內容，等於繞過存取控制**。系統自己發現並改成只留指標，連帶刻意不生成 `金妮.ai.md` 與 `鄧不利多.ai.md`（四象限本體就是水下內容）。

**這是本 session 唯一一個系統自己抓到的系統級缺口**，形狀值得階段 3 看：**衍生層沒有繼承源層的存取控制**。而它現在的補救是「AI 自律不要寫進去」——`CLAUDE.md` 對這個形狀的判準是「規勸不會被執行，工具會」。

另有一筆同源的待裁決：`哈利.ai.md` 的「落差」欄是作者親筆給的四象限，內容就是「分帽子那天」——**同一件事同時是公開的四象限與水下的秘密**。系統採「對筆下公開、對讀者水下」並掛起待作者裁決。

### 4. 「刻意的紅」與「真的紅」在 exit code 上無法區分

`char-lint` exit 1，而系統說這是正確訊號、不該消掉。**若它說的是對的，那麼從現在起這本書的 `char-lint` 恆紅**——直到 13 支配角全部補完四象限為止（可能好幾個 session）。於是往後任何一次**真正的**角色格式違例，會落在一個已經紅著的閘門上，而「紅」與「更紅」在 exit code 上一模一樣。

這和 `設計原則.md` E2 守的是同一件事的反面：E2 要求「0 也印」是怕檢查器被關掉時印「乾淨」；這裡是**檢查器恆紅時，新問題印不出來**。可能的方向（交階段 3，本 session 不動）：把「源檔有、衍生檔尚未生成」與「衍生檔格式錯」分成兩個 exit 級別，或讓覆蓋率行帶「其中 N 支是已知待補」。

### 5. 系統要「一行正當需求」，作者給的是「這個角色在結構裡負責哪一格」

問配角時系統要的是四象限／正當需求（角色軸的 schema 欄位）。作者答的形狀不同——麥朵是「『答案一直在場沒人去撿』的活示範」、阿辣哥是「證詞成立、但給證詞的人不救你」那一格、飛七是題旨四格表缺的第五格。**那是功能位置，不是需求。**

兩者都真、都該留，但**只有前者有欄位**。目前這些「結構功能」被寫進角色源檔的自由散文裡（因為沒有別的家），而它們其實是會被 `beat-sheet` 拿去排幕的東西。這一格交 `需求機制帳` 數落點。

### 6. 作者反向推動系統的三次，系統都接住了（正面）

`魔法物品與規則.md` 從「不承重」被作者改判為「扛四個計時器」、`地理.md` 被否掉、`權力與程序.md` 是作者自己加的（系統完全沒想到，而它扛著海格被帶走／校長被停職／結尾奪席位三件事）。系統三次都沒有堅持自己的分類，也沒有為了顯得周全而兩邊都建。**「AI＝共創＋審稿、非門檻」在這三次裡是成立的。**
