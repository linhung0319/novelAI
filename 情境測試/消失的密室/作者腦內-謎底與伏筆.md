# 作者腦內 · 謎底與伏筆

給我自己看的答案。寫下來是因為我開始忘記自己埋過什麼，然後在後面寫出對不上的東西。

## 一、兇手鏈（從上游往下游）

1. **魯休斯馬份**在斜角巷的書店裡跟衛斯理先生打起來。混亂中他撿起金妮那本被打翻在地的舊變形課本，把一本黑色的日記夾了進去，再塞回她手裡。**全書最重要的動作，發生在一場所有人都在看別處的鬧劇中間。**主角就在現場，眼睛甚至掃過那個動作。他沒懂。
2. **金妮**以為那是舊書裡夾著的東西，開始在上面寫：哥哥們取笑她、袍子是舊的、書是二手的、她喜歡的那個男生永遠不會喜歡她。
3. **日記回信。**它扮演一個溫柔、有耐心、記得每件小事、從來不笑她的朋友——她一整年唯一被聽見的地方。
4. 它吸走她的秘密、恐懼與生命力，同時把裡面那個人的一部分灌回她身上。控制是**漸進的**：先是失眠與臉色，再是整段失憶的空白。
5. 在那些空白裡她做了所有的事：掐死看守家的公雞（雞啼對那個東西致命，得先清掉）、用顏料在牆上寫字、用借來的能力打開密室、放出那個東西。她起初完全不知情。
6. **她自己起疑**：袍子上有雞毛、萬聖節那晚想不起來去過哪、胸口沾滿顏料、哥哥說她臉色不對。她慌了，把日記丟進那間故障盥洗室的馬桶。
7. **主角撿到它**——對日記裡的那個人來說是天上掉下來的禮物，他真正想見的人本來就是他。
8. 金妮驚慌，翻遍主角的宿舍把它偷回去。（主角只會發現有人翻過箱子、只有那本本子不見了，然後把懷疑指向錯的人。）
9. 日記發現主角在追查，逼金妮在牆上寫下最後一行字、把她帶進密室，用她剩下的生命讓自己顯形，坐在那裡等他下來。

**兩個動機分開寫：**

- **魯休斯要的是脫手與奪權**：魔法部正在查抄私宅，這件舊物必須離開他家；災難重演可以逼走現任校長；萬一敗露，第一個倒的是那個正在推麻瓜保護法的小職員。他不知道日記會自己行動——他是丟火柴的人，不是縱火犯。
- **日記裡的那個人要的是主角本人**。清洗麻瓜家庭出身的學生只是招牌事業。他真正想弄明白的是：一個什麼都不會的嬰兒怎麼會毀掉他的力量。

## 二、那本日記

- **外觀**：小、薄、黑色破皮封面，五十年前的東西，封底印著麻瓜文具店的地址（所以主角會推論寫日記的人是麻瓜——錯的推論，但推得合理）。
- **內頁全空白，但會吸墨水**：寫進去的字被吸收，然後浮出回話。
- **做得到**：對話、扮演人格、把人拉進它保存的記憶場景（訪客像幽靈一樣不可見不可聞，只能跟著看）、竊取書寫者的意志與生命、吸夠之後脫離本體現形。
- **做不到／代價**：**必須有人持續寫**才會變強，沒人理它就只是一本空白的本子；現形要幾乎耗盡一個人的性命；而且它**不沾外來的物質**——滿房間的書被紅墨水潑到，唯獨它乾乾淨淨。這是它最早的破綻，比任何台詞都早。
- **摧毀**：那個東西的毒牙刺穿它，墨水噴出、紙頁灼穿冒黑煙、裡面的人尖叫著散掉。同一秒，指控魯休斯的唯一物證也毀了。**我要主角贏得徹底而證據上一無所有**，並且要有人在最後把這件事說破。

## 三、那個東西

- 一條蛇。極大，能活好幾百年，由癩蛤蟆孵公雞蛋生出來的（這個來歷寫在一頁舊書上，不要由角色講——唯一一次我允許用文獻交代，因為那頁紙本身是道具）。
- **直視致人於死；隔著東西看到牠只會石化。**這是整本推理的鑰匙，也是「出了這麼多事卻沒有人真的死」的答案。中介物決定結果：貓看到的是地上積水的倒影；那個一年級的孩子隔著相機鏡頭（所以底片被燒熔）；赫夫帕夫那男孩透過一個幽靈看到（幽靈已經死了、不能再死一次，所以牠變黑、煙霧化）；兩個女生用鏡子照轉角，因為其中一個已經想通了、正在防著。
- **公雞的啼叫對牠致命**，所以看守家的雞被殺是清障，不是虐待動物。
- **蜘蛛見牠就逃**。那一列從窗縫排隊擠出去的蜘蛛是全書最早的物證。
- **牠靠城堡的水管系統移動**，所以牠能在牆裡走、能被會蛇語的人聽見，卻從來沒有人看見過牠。「管子」這兩個字就是解答本身。

## 四、密室

- **入口**在那間掛著故障牌子的女生盥洗室——第一次案發地點的隔壁。**全書最大的一個玩笑**：三個人在那裡熬藥、開會、待了好幾個月，就坐在入口上面。
- **開法**：其中一個水池的銅龍頭側面刻著一條小蛇，那個龍頭從來不出水（住在那裡的鬼一直抱怨，沒人聽）。對著刻紋用蛇語說「打開」——但**得先讓自己相信那條刻出來的蛇是活的**。這讓開門變成一個意志的動作，不是一句咒語。
- **內部**：陡降的粗水管；潮濕的石隧道，滿地小動物骨頭；中途一張空掉的蛇蛻；盡頭一堵刻著兩條纏繞巨蛇的石門，蛇眼鑲綠寶石。
- **主廳**：長、昏暗、綠光，兩排刻著盤蛇的石柱，盡頭是與房間等高的創辦人石像。**那個東西的巢在石像嘴裡**，對石像說蛇語，巨口就會張開。深度比地下教室還深，很可能在湖底下——所以沒有人聽得見底下發生的事。

## 五、五十年前那一次

- 開密室的是那個少年自己，他花了五年才找到入口。
- 死掉的女孩就是現在住在那間廁所裡的鬼。她那天被人嘲笑戴眼鏡，躲進去哭；她聽見一個男孩在講一種她聽不懂的語言，開門去罵他，然後看見一雙巨大的黃眼睛。
- 學校差點關閉。少年不想回麻瓜孤兒院過暑假，所以他找了一個現成的替罪羊——那個在城堡裡偷養怪物的大塊頭學生。那孩子被開除、魔杖被折斷，少年拿到一面「對學校的特殊貢獻獎」。**那面獎牌要在很前面、在一個完全無關的場合出現一次**（有人被罰擦銀器），然後整本不再提。
- 只有一位變形課老師從頭到尾不信，替那孩子求情、讓他留下來當看守。那位老師現在是校長，從那時起就一直盯著那個少年。

## 六、誤導線清單

| 讀者會懷疑誰／什麼 | 我用什麼把他們送過去 | 什麼時候拆掉 |
|---|---|---|
| 那個死對頭同學 | 他公開說那個髒話、樂見有人出事、父親是舊黨、喊「下一個就是你」 | 中段。主角冒充別人混進去審問，他自己什麼都不知道，還說他也希望能幫忙 |
| 那個死對頭動了球場上的手腳 | 兩個朋友一口咬定是他 | 當晚就拆：真兇在床邊自己承認了，而兩個朋友從頭到尾不知道 |
| **主角自己** | 他會說蛇語、每次第一個到現場、跟看門人吵完架貓就出事、被拍照後拍照的人出事 | 分三次拆：校長當面表態、被冤枉的人事後道歉、真兇揭曉 |
| 那個看守＝五十年前的兇手 | 一段看起來無可辯駁的「記憶錄影」：他蹲在箱子旁哄一個東西、被當場指認 | 森林裡那頭巨蛛否認，並指出真正的東西是蜘蛛最怕的古代生物 |
| 森林裡那頭巨蛛＝密室的怪物 | 記憶裡牠從門後衝出來，時間也對得上 | 同上。牠從沒傷過人，因為牠敬重養牠的孩子 |
| 那個新來的老師＝可依靠的專家 | 整本鋪他的獎項與自吹 | 結尾前他打包逃跑時自己說破 |
| 朋友的哥哥深夜鬼鬼祟祟 | 他在地下層遊蕩、被妹妹撞見某件事、臉色慘白、阻止妹妹說話 | 最後揭曉那是私人戀愛。**功能是證明「異常」不等於「有罪」，對照真的有罪的那個孩子** |
| 「事情已經過去了」 | 四個月風平浪靜、解藥快好、那個老師到處宣告危險已過 | 一次雙重襲擊打掉，倒下的是查得最深的那個人 |
| 「跟那個不能提名字的人無關」 | 開場那個小精靈親口說的 | 結尾拆：字面遊戲，那個人改名字之前的名字是可以提的 |

## 七、伏筆帳（還沒分章，先記相對位置）

**解謎那一場一次全收**（密度就是爽感，不准分批）：牆裡往上跑的聲音、排隊逃走的蜘蛛、被殺的公雞、熔掉的底片與那面小鏡子、案發現場那攤水。

**揭底那一場收**：獎牌（獎是嫁禍成功的產物，不是破案的功績）、被翻的箱子、那個女孩整年的異常。

**其他**：月台通道自己封上→中段由小精靈自承；「跟著蜘蛛」→森林那一場；「請求幫助的人總能得到幫助」→結尾，那是使用說明不是安慰；朋友那根壞魔杖→同時拆掉假專家、炸塌隧道；「主人給一件衣服就自由」→最後一頁，用一隻髒襪子完成；帽子說主角適合另外一邊→最後一場對話兌現主題；伸進大釜的那隻手→最後一場才揭曉。

## 八、提醒自己

- 那個關鍵動作之後，**整本不准有任何角色回頭提起它**。讀者要在最後才想起自己看過。
- 那個女孩的異常一直放在畫面邊緣，但**永遠不要給她特寫**。單一視角在這裡是我的武器。
- 揭底時那個少年必須**自己**得意地把一切講出來。他忍不住要讓人知道他有多聰明——這是他輸掉的原因。
