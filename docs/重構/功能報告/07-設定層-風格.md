## 〇、一句話結論

**這一軸的方向是對的（A1／A2 前向，源→衍生分權乾淨，`check` 從未報錯過），病全部集中在一個地方：`風格.ai.md` 的五個 front-matter 欄是本軸唯一的產物，schema 稱它們是「`write-test` 的機讀核對基準」，而那個「基準」在一世之尊上是空的——`可用句式` 4/4 檔位違反 schema 自己列的三條 ❌、0/4 宣告顆粒度級別、0/4 給出可數的數字，而它已經封章、`check` 報 fresh、五輪重生沒有任何守衛吭過聲。**

## 一、六問

這個功能含**三筆**性質不同的內容，分別跑：

- **筆 A**：`風格.md` 的一節散文（「這本書該用什麼腔調寫」）
- **筆 B**：`風格.ai.md` front-matter 的**一個欄**（`禁用詞表`／`稱謂系統`／`可用句式`／`語域`／`基調參照`）
- **筆 C**：`風格.ai.md` 本體的一節分析（`## 腔調`／`## 時代・文化色`／`## 句式與節奏偏好`／`## 修辭天花板`）

- **筆 A**：作者。A1 成立（無 inbound 重算規則）。**乾淨。**
- **筆 B**：AI 從 A 抽取、作者確認後封章。A2 成立。**但實測混了第三種決定權**——`基調參照` 的真實決定權在 `00-摘要.md`（另一支源檔），它在這裡只是一份拷貝（見 Q4）。
- **筆 C**：AI。A2 成立。**但實測 `風格.ai.md` 的 6 個節裡有 2 個不是 C**：
  - `## 待裁決回饋`（1,824 字元，**36.9%**）＝ AI 的觀察 ＋ 人的裁決，04 已裁定它該住 `story/參照/待裁決.md`；
  - `## 三場語感範例參照`（360 字元）＝ 從 `raw/場景碎片.md` 搬來的素材，**不是從源檔重算出來的**（實測：`舉頭望明月`／`左二` 兩個關鍵詞 raw 命中、`風格.md` 查無）。

  **合計無家內容 2,118 字元 ＝ 全檔 42.8%。** 這是 05 的「衍生檔變成無家內容收容所」在第三軸上復發，而且三個家 04／05 都已經蓋好。

### 「壞了永遠不會發現」的項目

**六項，其中三項屬 E2 最後一格（守衛回報正常的假陰性）：**

**① `可用句式` 的三條 ❌ 全部違反且順利封章。**
schema `風格.schema.md:70-73` 的表格逐格禁止的東西，實測 4/4 檔位全中：

| 檔位 | 實測值 | 違反哪一格 |
|---|---|---|
| 日常吐槽 | `短句快節奏＋破折號省略號承接跳躍念頭` | ❌ 讀感形容詞（「短、碎、跳」是讀感不是形式）＋❌ **重拍裝置的授權**（破折號） |
| 武道宏大 | `沉緩留白＋單一準確意象` | ❌ 讀感形容詞 |
| 動作生死戰 | `短促碎句動詞驅動` | ❌ 讀感形容詞 |
| 安靜扎心 | `乾淨放慢收掉吐槽` | ❌ 讀感形容詞 |

**0/4 宣告顆粒度級別（分句／句／段）、0/4 給出可數的數字。**
後果是一條完整的斷鏈：`prose-metrics` 對 11 個 arc 印四項輔助量（句長中位／≥40字句佔比／逗號:句號／分句均長）＝ **44 個數字**，工具自己在輸出末尾寫「供對照 `可用句式` 宣告用」——**而那個宣告是空的，44 個數字全部無從對照**。`write-test` 測試5 要求的「實測顆粒度對不對得上宣告」在這本書上執行不了，而報告會印得完全正常。

而 `破折號` 這個**被 schema 明文禁止的空頭授權**，實測代價可量：**11/11 個 arc 的破折號密度 6.42–9.76／千字，門檻 ≤0.5，六本 known-good 語料 max 0.38——是 known-good 上限的 16.9×–25.7×。** schema:75 說空頭授權「實測被用到語料的 20–160 倍」，這本書給了它第一個逐 arc 的數字。

## 六、原則的問題

### A · **A4 的位元分不出「零讀者」與「只有 LLM 讀者」，而這一軸整個落在後者**

A4 說：「檔的第二個位元是**程式會不會解析它**……會被解析的檔必須有一支 lint；沒有 lint 的檔，程式只能整檔讀」，可執行判準是「一支檔若被任何**程式**逐行／逐欄解析，就去找它的 lint。找不到，那支檔現在不配被解析」。

**在風格上，這條原則導出的答案是錯的。** 五個欄：

| | 05 世界觀四欄 | 06 角色三欄 | **07 風格五欄** |
|---|---|---|---|
| 程式解析器 | 0 | 0 | **0** |
| 消費者（指得出行號） | **0**（`升格哨兵` 寫「供 beat-test/sync 盯」，兩支 skill 零次提及） | **0**（`弧線類型` 連假消費者都沒宣稱） | **有**：`write/SKILL.md:109`、`write-test/SKILL.md:29,34`、`revise/SKILL.md:24` 逐欄指名 |
| A4 的答案 | 刪欄 ✅ | 刪欄 ✅ | **刪欄 ❌——那會刪掉本軸唯一的產物** |

**問題出在「程式」這個字。** LLM 逐欄取值是解析，只是解析器不會 raise。而**這正好讓 lint 更必要不是更不必要**：程式讀壞格式會當場炸（E2 第二格），LLM 讀壞格式會**安靜地讀錯**（E2 最後一格）。實測就是這樣——`可用句式` 的值格式合法、消費者存在、`write` 每次都讀，而它讀到的是不可執行的讀感形容詞，五輪重生無人吭聲。

**建議改寫**（不加註解，改條文本身）：

> **A4　檔的第二個位元是「有沒有人逐欄／逐行取值」。這個位元不由副檔名承擔，由「有沒有檢查器」承擔**——會被逐欄取值的檔**必須有一支 lint**，**取值者是程式或 LLM 都算**；沒有 lint 的檔，只能整檔讀。
> **LLM 取值者比程式取值者更需要 lint**：程式讀壞格式會當場炸，LLM 讀壞格式會安靜地讀錯，而錯的那一格會直接進正文。

這個改寫不影響 04／05／06 的既有結論（那三軸的欄位是**零取值者**，兩種判準下答案相同），只是補上第三格。

### B · **E1 的消費者推論只管「有沒有人讀」，不管「讀到的能不能用」**

05 立的推論是：「凡 schema 寫『供 X 用／供 X 盯』，X 那一側要指得出讀它的那一行」。風格五欄**全部通過這一關**——而通過得沒有意義：`write-test` 測試5 確實有一格寫著「段落性質是否套了對應 `可用句式` 檔位」，而它讀到的值是 `短句快節奏＋破折號省略號承接跳躍念頭`。

這與 06 為 E2 補的推論（「覆蓋率行要能回答命中的裡面幾筆是空的」）**是同一個縫的兩半**：06 補在**選取側**（selector 印空殼數），風格暴露的是**schema 側**——一個欄可以有消費者、有合法格式、而值本身不可核對。

**建議新增 E1 的第四條推論**：

> **凡 schema 宣稱某欄「供 X 核對」，那個欄必須同時定義「什麼樣的值算可核對」，且該判準要是機械可判的。**
> 「有人讀」（05 的推論）與「讀到的能用」是兩個承諾。`風格.schema.md` 是**唯一一支把後者寫出來的 schema**（`可用句式` 的 ✅/❌ 表 ＋「值寫得可數」），而它零實作——**規格寫對了、閘門沒接上**，這比沒寫規格更接近 E2 最後一格：讀 schema 的人會以為有人在守。

判準必須是**結構判準不是語意判準**（顆粒度 token ＋阿拉伯數字），理由見已駁回清單的 `prose-metrics` 關鍵詞分類與世界觀別名表兩條。

### C · **D2 漏了一個成長軸：不隨書長成長、但隨編輯輪次成長**

D2 的資格條款是「有選擇器 **且** 查詢成本不隨全書長度線性成長」。`共同約定.md:286` 據此把風格檔列為「本來就是單檔且有界」而豁免選擇器——**照 D2 字面它合格**（風格檔確實不隨章數長）。

實測它 **5 次重生從 611 B 長到 12,247 B（20.04×）、已越過 12,000 的哨兵門檻**，成長軸是**裁決輪次**。這與 05 診斷 `_總覽.ai.md`（成長來自寄居內容）、06 診斷角色衍生檔（9/22 支源檔一次沒改而衍生長了 1.30–2.08×）**是同一個軸的三個實例**，而 D2 的字面判準對這個軸完全不設防。

**這一條我不提案改寫**——三個實例的直接病因都是「無家內容寄居」，而那個病 A3 第 0 條已經在管。但值得記下：**「不隨書長成長」不等於「有界」**，D2 若要在功能 14 重新表述成本函數，這個軸要進去。

### 與提案的出入

- **`style-lint` 第 4 項的判準比提案嚴一格，因為提案那一版實測是假陰性。** §三 寫的是「值必須含顆粒度 token（`分句`／`句`／`段` 其一）」，照字面實作＝「值裡有沒有這個字」——而 `短句快節奏＋破折號…` 與 `短促碎句動詞驅動` **都含「句」字**，於是 4/4 讀感形容詞裡有 2 個被判成「已宣告句層」，**首跑只報 4 筆、閘門對著它誕生要抓的那一格報乾淨**（E2 最後一格，在它自己身上重演了一次）。收緊成**位置判準**：token 要出現在**值的開頭或緊接 `碎在` 之後**——那是 `風格.schema.md` 兩個 ✅ 範例一直在用的正規形，不是新語法，仍然機械可判、仍然不是詞表。收緊後首跑 5 筆。`test_granularity_rejects_readfeel_adjectives` 就是為了不讓它退回去。
- **schema 自己的範例原本過不了自己的閘門**：`恐怖高潮: 碎在句（一句一分句）` 沒有阿拉伯數字（「一句一分句」是中文數字）。**沒有放寬判準去遷就範例**（中文數字在散文裡到處都是，認它等於讓「短句為主、一律放慢」也過關），而是把範例改成 `碎在句（句號前 0–2 個逗號）`——與 `write/SKILL.md:109` 早就在寫的換算一致。
- **第 4c 項「全檔位同級」的未宣告怎麼算**：實作成**未宣告＝最粗的一級**。這不是新判準，是 `風格.schema.md` 自己那條實測結論（「不指定顆粒度時，LLM 一律在最粗的一級實現讀感」）；不這樣算的話，0/4 宣告的書會因為「可判的檔位不足」而靜默跳過這一項——**規則的前提不成立時靜默通過，正是本輪在抓的形狀**。
- **`書本模板` 還有一處 `待裁決回饋` 殘留沒改**：在 `story/00-摘要.ai.md` 的骨架頭註裡。那是**功能 08 的檔**，依「只動本功能範圍」的紀律不順手改，**記進 08 的已知疑點**。
- **正文掃描在多檔形態下取所有風格檔字面 entry 的聯集**，不逐章依 `風格` 欄分派。0 本書拆過多檔（那條路徑本身就標著「零實作的行為承諾」），現在做等於憑空設計；`ch-lint` 已經在守那一欄指向的檔存在，真的有書拆多檔時這裡跟著改。**這一條寫進了 `scan_chapters` 的 docstring**。
