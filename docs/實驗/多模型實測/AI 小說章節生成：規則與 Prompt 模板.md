# AI 小說章節生成：規則與 Prompt 模板

Nov 1, 2026 · @Hung Lin

## 設計原則

核心假設：模型會模仿 context 裡的文字語氣，所以 prompt 裡的每一段都要長得像「好的正文」，而不是像規格書。

1. **形式比內容更會傳染**。設定表、條列規則、壓縮的提要都是電報體，正文會跟著變硬、變跳。所以設定和提要都改寫成敘事散文。
2. **越靠近寫作指令的文字，影響越大**。順序固定為：角色與世界 → 前情提要 → 本章要發生的事 → 寫法說明 → 風格範文 → 前一章結尾原文 → 「請接著寫」。模型最後讀到的是一段順暢的正文，下筆時就直接接上那個語感。
3. **只放這一章用得到的東西**。不出場的角色、用不到的能力不放，避免模型覺得每句都要「塞進設定」。
4. **用範例取代形容詞**。「節奏緊湊」「張力強」這類抽象要求，容易被理解成短句加重動詞；給一段範文比十條規則有效。
5. **寫法說明用編輯跟作者說話的語氣**，不用「必須／禁止」的條列。少用否定句，多說要怎麼寫。

## 規則：每個區塊放什麼、怎麼寫

| 區塊 | 要放什麼 | 怎麼寫 | 避免 |
| --- | --- | --- | --- |
| 1. 角色與世界 | 只放本章出場的角色、本章會用到的設定 | 每個角色一小段敘事文字，把特質寫成「他會怎麼做」 | 「性格：冷靜、記仇」這類標籤；整份世界觀百科 |
| 2. 前情提要 | 到目前為止的主線、本章需要記得的伏筆 | 像書背文案或朋友轉述，句子完整、有過程，300–500 字 | 「A 擊敗 B 後得知真相」這種只有結果的壓縮句 |
| 3. 本章要發生的事 | 4–7 個事件、本章的情緒重心、章末停在哪裡 | 用一段話講「發生什麼」，不規定「怎麼寫」；說清楚哪些事本章不要解決 | 把大綱寫成逐條指令；要求每個特質都要表現 |
| 4. 寫法說明 | 鏡頭跟誰、篇幅、少數幾個寫法重點 | 編輯對作者說話的口吻，短短一段 | 「必須／禁止」清單；「緊湊」「張力」「震撼」等抽象詞 |
| 5. 風格範文 | 一段你喜歡的人類作家正文，500–800 字 | 原文照貼，標明「參考語感，不要模仿內容」 | AI 寫的段落；跟本章題材完全相同的段落（會被抄情節） |
| 6. 前一章結尾 | 前一章最後 500–1500 字原文 | 原文照貼，最好是你修改過、讀起來順的版本 | 只放提要；放一段本來就卡頓的 AI 原文 |

補充兩點：

- 如果前一章就是你滿意的文字，區塊 5 可以省略，讓區塊 6 兼任風格參考。
- 「約三千字」模型常寫不足。可以寫「約三千字，寧可多一點」，或分成上下兩半各寫一次。

## Prompt 模板

複製後把【】裡的內容換掉。建議貼進一個全新的對話，不要接在討論設定的對話後面。

```
我們正在合寫一部長篇小說，目前寫到第【N】章。這次請你寫第【N+1】章。下面依序是會出場的人物、到目前為止的故事、這一章要發生的事，以及一些寫法上的想法，最後附上一段參考文字和上一章的結尾。

先介紹這一章會出場的人。

【角色A】【用一小段話寫他是什麼樣的人：他平常怎麼說話、遇到事會怎麼反應、有什麼習慣或舊傷、他現在最在意什麼。】

【角色B】【同上。】

【需要的話，用一兩段話交代這一章會用到的世界設定，例如地點、季節、這趟任務的規矩。用不到的不必寫。】

故事到目前為止是這樣的：

【用三五百字、完整的句子，像跟朋友轉述一樣講前面幾章發生了什麼。重要的轉折要講到「怎麼發生的」，不要只講結果。最後點出這一章開始前，主角心裡最放不下的事。】

這一章要發生的事：

【用一段話講本章的經過，大約四到七件事，按順序講。說明這一章的情緒重心是什麼，章末停在哪個畫面。再說明哪些事這一章先不要解決。】

關於寫法，我的想法是這樣的：

這一章請把鏡頭跟著【主角】，他看到、聽到、想到什麼，讀者就知道什麼。每到一個新場景，先讓讀者知道人在哪裡、朝著哪邊、身邊有誰，動作之間要接得上，讀者讀每一句都能從上一句的畫面接過來。動作用平實準確的詞就好，推門就寫推門。句子裡該有的「了、著、便、卻、還是」都留著，讀起來要能一口氣順下去。段落以敘事段落為主，對話照常分行。人物的心情可以直接說出來，也可以從他做的事看出來，交替著用。故事的意思留給讀者自己體會，章末停在畫面上就好，不用總結。篇幅大約三千字，寧可多一點。

下面這段文字是我喜歡的語感，請參考它的句子節奏和銜接方式，內容與這部小說無關，不要借用它的情節或人物：

【貼上一段你喜歡的人類作家正文，約五百到八百字。如果上一章的文字你已經很滿意，這段可以刪掉。】

最後是上一章的結尾：

【貼上上一章最後五百到一千五百字的原文。】

請從這裡接著寫第【N+1】章，直接開始正文。
```

## 填好的範例：可直接測試

以下是一部虛構的北地走鏢故事，假設已寫到第四章，要求寫第五章。範例省略了風格範文，讓「上一章結尾」兼任風格參考；想比較效果，可以在結尾前加入一段你喜歡的人類作家文字。

```
我們正在合寫一部長篇小說，目前寫到第四章。這次請你寫第五章。下面依序是會出場的人物、到目前為止的故事、這一章要發生的事，以及一些寫法上的想法，最後附上上一章的結尾。

先介紹這一章會出場的人。

林硯，二十八歲，在北方走了十年鏢。他話不多，進一個地方總是先看清楚門窗和人，再找位置坐下。五年前他信錯了一個同伴，整支鏢隊折在山裡，只有他活下來，左手腕也是那時候傷的，天一冷就隱隱作痛，他從不跟人提。他用刀，刀法不好看，但快。這趟鏢他接得勉強，是因為貨主開的價，夠他還清欠下的撫恤銀子。

沈舟，三十出頭，三個月前在驛站跟鏢隊搭上話，之後就一路同行。他愛說笑，跟掌櫃、馬夫、路邊小販都能聊上幾句，懂一點醫術，林硯的手腕就是他在照看。問起來歷，他總是一句帶過。他對林硯很好，好到林硯有時候不知道該怎麼回應。

阿禾，十七歲，鏢隊裡最年輕的趟子手，第一次出遠門，什麼都想問，夜裡睡得很沉。另外還有兩名鏢師老周和大牛，這一章戲份不多。

時值臘月，北地官道被大雪封了一半。這趟鏢要把一只上了銅鎖的木匣送到雁門關外一戶姓韓的人家，貨主只交代兩件事：匣子不能開，也不能離開鏢師的視線。

故事到目前為止是這樣的：

鏢隊從太原出發已經二十多天。第二章在黃崖口，他們夜裡遇上一夥人想搶匣子，對方進退整齊，不像普通山賊。混戰中林硯被逼到崖邊，是沈舟從側面撲過來替他擋了一刀，自己肩上也挨了一下。那一夜之後，林硯第一次跟沈舟喝了酒，話雖然還是不多，卻開始讓沈舟替他換藥。

第三章裡，阿禾無意間說起，出發前一晚，他看見沈舟在驛站後院跟一個騎黑馬的人說話。林硯去問，沈舟笑著說那是來討債的舊相識，已經打發走了。林硯沒再追問，但把這件事記下了。

第四章，鏢隊被大雪困在半路，老周染了風寒，沈舟熬藥照顧了兩天兩夜。雪勢稍停，林硯決定冒險抄小路，繞過已經封死的官道。上一章結束在他們黃昏時找到一座半埋在雪裡的村子，村口只有一家客棧還亮著燈。

這一章開始前，林硯心裡最放不下的，是他越來越想相信沈舟，而五年前，他也是這樣相信過一個人。

這一章要發生的事：

這一章從客棧裡的一夜寫到隔天清晨。掌櫃是個瘸腿的中年人，對他們很殷勤，卻好像早知道他們會來，灶上多備了五個人的飯。晚飯時沈舟照常跟掌櫃閒聊，林硯注意到兩人說起某個地名時，掌櫃斟酒的手停了一下。夜裡林硯被手腕的疼痛弄醒，發現睡在隔壁鋪的沈舟不在。他循著聲音走到後院，隔著柴堆看見沈舟和一個披斗篷的人低聲說話，那人遞給沈舟一個小布包。林硯聽不清內容，只聽見「雁門」兩個字。他沒有現身，回房躺下裝睡，沈舟不久也回來了。清晨，沈舟像往常一樣替他換藥，林硯聞出藥的氣味跟平常不太一樣，他沒有說破，換完照常道了謝。這一章的情緒重心，是林硯的懷疑一點一點長出來，以及他不願意讓它長出來的那種拉扯。章末停在林硯趁大家去後院餵馬時，獨自把木匣從行李裡取出，藏到另一個地方。這一章先不要揭露沈舟到底在做什麼，布包裡是什麼、藥有沒有問題都先不交代，林硯和沈舟之間也還不要起正面衝突。

關於寫法，我的想法是這樣的：

這一章請把鏡頭跟著林硯，他看到、聽到、想到什麼，讀者就知道什麼。每到一個新場景，先讓讀者知道人在哪裡、朝著哪邊、身邊有誰，動作之間要接得上，讀者讀每一句都能從上一句的畫面接過來。動作用平實準確的詞就好，推門就寫推門。句子裡該有的「了、著、便、卻、還是」都留著，讀起來要能一口氣順下去。段落以敘事段落為主，對話照常分行。人物的心情可以直接說出來，也可以從他做的事看出來，交替著用。故事的意思留給讀者自己體會，章末停在畫面上就好，不用總結。篇幅大約三千字，寧可多一點。

上一章的文字語感是我想要的，請延續它的句子節奏和銜接方式。以下是上一章的結尾：

天黑得比林硯預想的快。雪雖然停了，風卻沒停，一陣一陣從山坳裡捲下來，把馬背上的積雪又吹起一層，打在臉上像細沙。

走在最前面的大牛忽然勒住了馬，回頭喊了一聲：「有燈！」

林硯抬眼望過去。山坡底下果然有一片黑壓壓的屋頂，大半都埋在雪裡，看不出還有沒有人住，只有靠近路口的一棟兩層樓房，窗紙透出一點昏黃的光，在一片白裡顯得特別扎眼。

「這種地方還有客棧？」阿禾縮著脖子，聲音裡帶著掩不住的高興。

老周咳了兩聲，沒力氣說話，只是把身上的皮襖又裹緊了些。他這兩天燒是退了，人卻還虛著，要是再在雪地裡過一夜，怕是撐不住。

林硯沒有馬上下令。他盯著那點燈光看了一會兒，又看了看四周的山勢。村子坐在山坳最低的地方，三面是坡，只有他們來的這條路能進出。要是有人想在這裡堵他們，一點也不費事。

沈舟策馬靠過來，跟他並排停下。「看出什麼了？」

「沒有。」林硯說，「就是覺得太巧。」

「這一路上，不巧的事我們遇得還不夠多嗎？」沈舟笑了笑，朝老周那邊偏了偏頭，「老周等不起。」

林硯知道他說得對。他回頭看了一眼綁在自己馬鞍後的木匣，匣子用油布包了兩層，銅鎖上結了一層薄霜。

「進村。」他說，「今晚我守前半夜。」

沈舟應了一聲，先一步策馬往坡下走去。林硯跟在後面，看著他的背影被風雪吹得有些模糊。走到村口時，那扇亮著燈的門忽然從裡面開了，一個人提著燈籠站在門檻上，像是已經在那裡等了很久。

請從這裡接著寫第五章，直接開始正文。
```

## 修訂 prompt 與使用建議

初稿出來後，在同一個對話接著貼下面這段，讓模型做一輪「鏡頭連續性」修訂：

```
請把剛才這一章從頭順一遍，像編輯看稿那樣修改，劇情不要動。

逐段讀下來，留意這幾件事：讀者讀到每一句時，能不能想像出畫面，而且跟上一句的畫面接得上；人物在哪裡、朝哪邊、手上拿著什麼，有沒有突然跳掉；有沒有哪個動詞用得比實際動作更重，例如明明是推卻寫成撞；有沒有哪裡把句子之間的「了、著、便、卻」省掉，讀起來一頓一頓的；有沒有單獨一句話自成一段、其實可以併回前後段落的地方。

改完請直接給我完整的修訂版正文。
```

使用建議：

1. **先做 A/B 測試**。同一章用兩種 prompt 各生成一次：你原本的設定表寫法，和這份模板的寫法，對照讀哪個順。這能直接驗證「context 語氣會傳染」的假設。
2. **前一章結尾用你改過的版本**。它是模型最後讀到的文字，對文風影響最大。
3. **規劃和寫作分開**。設定、大綱在一個對話討論，寫正文時開新對話，只貼這份 prompt。
4. **字數不足就分段寫**。可以把「這一章要發生的事」切成前後兩半，先寫前半，再請它接著寫後半。
5. **還是卡頓時，先換範文**。在上一章結尾前加入一段人類作家的正文，通常比再加規則有效。
