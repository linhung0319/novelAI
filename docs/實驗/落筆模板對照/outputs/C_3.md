提燈籠的是個中年人，身子往一邊歪著，右腿像是短了一截。

「幾位辛苦，快進來，快進來。」他把燈籠抬高，光一張臉一張臉地照過去，最後落在馬背上。「馬從側門牽去後院，棚子和草料都有。」

林硯下了馬，先解下鞍後的木匣，夾在右臂底下，才跟著進門。

堂屋不大，擺了四張方桌。前門一道，櫃檯旁掛著布簾，後頭大概是灶房，布簾左邊是上二樓的木梯。窗子都釘了擋風的木板，只有門邊留著一扇糊紙的。他挑了靠牆那張桌子，背後是牆，抬眼就能看見前門和樓梯。木匣放在腳邊，靴子貼著。

他們才坐下，飯就上來了。一大盆羊肉燉蘿蔔，一籠饃，五碗粟米飯，熱氣騰騰。掌櫃一瘸一拐地來回端，腳步一輕一重，掀開布簾時，林硯看見灶上的大鍋還冒著白氣。

阿禾已經抓起了筷子。

「掌櫃的，今晚還有別的客人？」林硯問。

「沒有沒有，這種天，半個月沒見過生人了。」

「那這鍋飯是給誰煮的？」

掌櫃笑了，臉上的皺紋擠在一起。「雪停了嘛。山裡雪一停，困在路上的人就會往這邊走，多煮總比少煮好。」

林硯看著面前的五碗飯，沒有再問。

「你看他，飯都端來了還要審一審。」沈舟笑著搖頭，自己從盆裡夾了一塊肉放進嘴裡，慢慢嚼著，朝林硯抬了抬下巴，這才又夾一塊放進他碗裡。「趁熱。」

林硯吃飯前總要等別人先動筷，這習慣有五年了，他從沒跟人說過。沈舟也從沒問過，只是不知從哪天起，每頓飯都先吃第一口。

他低頭把那塊肉吃了。

沈舟吃得快，吃完就端著酒碗跟掌櫃聊開了，從雪勢聊到村裡還剩幾戶人家，又聊到掌櫃的腿。

「這腿是陰天才疼，還是晴天也疼？」

「老毛病了，早年摔的。」

「我看像傷過筋。這種傷光揉沒用，得用熱酒化開藥力。」沈舟把空碗推過去，「我前幾年路過白草坡，那邊有個老馬醫，治這個很有一手。」

掌櫃正提著壺往碗裡倒酒，酒線斷了一下。

只有一下，短得像人眨了個眼。壺嘴隨即穩住，酒倒到碗沿，一滴也沒灑。

「白草坡，」掌櫃說，「那可遠了。客官走得真遠。」

「混飯吃嘛。」沈舟端起碗喝了一口，又問起桌上的醬菜是不是自家醃的。

林硯看著他的側臉，什麼也沒看出來。沈舟還是那副樣子，笑得眼角彎彎的，阿禾在旁邊聽得直樂。

他把「白草坡」三個字記下了，跟驛站後院那個騎黑馬的人放在一起。他替沈舟記下的事到今天也才兩件。他有時候希望自己的記性差一點。

二樓只有一間大房，五張木板鋪挨著排開。炭盆早就生好了，屋裡是暖的，被褥摸上去也不潮。林硯把木匣連著油布塞進自己的行李，擺在鋪頭，然後下樓，守了前半夜。

他坐在火盆邊，背靠櫃檯，聽了很久的風。趁著沒事，他把上二樓的木梯來回走了兩趟，發現靠牆那一側踩上去不會響。掌櫃早早回了後面的小屋，再也沒出來。到了子時，大牛下來換他，他才上樓躺下。

沈舟在隔壁鋪翻了個身，含含糊糊地說：「睡吧，天亮給你換藥。」

林硯嗯了一聲。

把他弄醒的是左手腕。

那種疼他很熟，像有根鈍釘子慢慢往骨頭縫裡擰，天越冷擰得越深。他睜開眼，先伸手往鋪頭摸，隔著行李摸到匣子硬硬的一角，才把右手移過來按住手腕。

屋裡炭火快熄了，只剩一點暗紅。他躺著等那陣疼過去，等著等著，覺得哪裡不對。

少了一個聲音。

沈舟睡覺時鼻息有點重，不到打鼾的地步，這三個月他已經聽慣了。林硯偏過頭，伸手往隔壁鋪探了探，被窩是涼的。

角落裡有人咳了一聲。老周半靠在牆上，眼睛在暗處微微發亮。

「他說藥該續火了，」老周的嗓子啞得厲害，「下去看看。」

林硯坐起來，披上皮襖，拿了刀。他把行李往老周鋪邊推了推：「替我看一下。」

老周看了他一眼，又看了看隔壁那張空鋪，點了點頭，什麼也沒問。

這一路上，那只匣子還是第一次離開他手邊。

他踩著靠牆那一側下了樓。大牛坐在火盆邊，面朝前門，背影一動不動，也不知是醒是睡。換作平常，他會過去踢一腳凳子。今晚他從大牛背後走過，輕輕掀開了布簾。

灶房裡沒有人。灶膛留著火，火是新添的，柴才燒掉一半。藥罐坐在灶邊，蓋子輕輕跳動，滿屋都是老周那帖藥的苦味。

林硯站在那裡，心裡竟鬆了一下。

他確實來看過火，話沒有錯。現在回去，躺下，天亮以後什麼事都沒有。

這時他覺得腳邊有風。通往後院的門虛掩著，留了一條縫，門閂靠在牆邊。風聲裡夾著一點別的聲音，很低，斷斷續續，是人在說話。

他在門邊站了一會兒，才側身出去。

雪停了，天上雲很薄，雪地把夜色映得發青。屋簷底下的積雪被風刮得很淺，他貼著牆走，一直走到柴堆後面，蹲下來。馬棚裡有匹馬打了個響鼻。

馬棚另一頭站著兩個人。

一個披著斗篷，帽子壓得很低，比另一個矮半頭，看不出是男是女。另一個背對著這邊，一邊的肩膀比另一邊低了一點點。林硯不用看臉就認得出來。黃崖口那一刀落在那個肩膀上，到現在還抬不太高。那一刀本來是他的。

風一陣一陣，把話都吹散了。他只聽得出沈舟也在說話，聲音平平的，沒有笑。他從沒聽過沈舟用這種聲音說話，像換了一個人站在那裡。

斗篷底下伸出一隻手，遞過來一個小布包，大約拳頭大小。沈舟接過去，在掌心掂了一下，收進懷裡。

風正好在這時停了一停。

「……雁門……」

只有這兩個字，也分不清是誰說的。接著風又起來了。

林硯發現自己的右手已經握在刀柄上。他慢慢把手指鬆開。

現在走出去，問一句，很簡單。上一回他也問了，沈舟笑著說是來討債的舊相識。今晚再問，沈舟也一定有話可答，而且答得合情合理，說不定還會把布包掏出來給他看。

他怕的就是這個。他怕沈舟一笑，自己就信了。

五年前那個人也對他好。進山的最後一夜，那人把火堆邊最暖的位置讓給他，還笑他年紀輕輕就睡不踏實。第二天下午，山道兩頭都站滿了人。

可是，這跟沈舟有什麼相干？沈舟替他擋過刀，替老周熬了兩天兩夜的藥。一個想害他的人，何必做這些？他在雪地裡蹲著，手腕疼得一跳一跳，替沈舟想了好幾個理由，每一個都說得通。他越想越覺得不對勁，自己這麼賣力，倒像在替人圓謊。

他沿著原路退回去，從灶房穿過堂屋，上了樓。

老周已經閉上了眼，呼吸粗重，看不出睡著了沒有。林硯摸了摸行李裡的匣子，又摸到銅鎖，才把行李拖回鋪頭，脫了皮襖，面朝裡躺下，把呼吸放長放慢。

他等了大約一炷香的工夫。

他沒聽見樓梯響。門輕輕開了，才知道有人上來了。林硯今晚試了兩趟才知道哪一側不響，沈舟不知道是什麼時候知道的。

腳步先往角落去了。瓷碗輕輕擱下，有人壓著嗓子說：「老周，醒醒，這一服得趁熱喝。」接著是老周含糊的咕噥聲，吹氣聲，吞嚥聲。「慢點，燙。」沈舟低聲笑了一下，聲音還是平常那個聲音。

過了一會兒，腳步朝這邊來了，在兩張鋪之間停住。

林硯的呼吸沒有變。

他的左手剛才露在被子外面。一隻手碰到他的手背，冰得像剛從雪裡拿出來，輕輕托起他的手腕，塞回被子裡，又把被角往上拉了拉。

然後隔壁鋪板響了一聲，沈舟躺下了。沒多久，那點略重的鼻息又響了起來。

林硯睜著眼看牆，一直看到牆上有了灰白的顏色。

天亮以後，沈舟端著一盆熱水上來，袖子捲到手肘，精神很好。

「手。」

林硯把左手伸過去。沈舟解開舊布，用熱布巾擦淨，拿拇指按了按腕骨旁邊：「昨晚疼了吧？這天氣，不疼才怪。」

「還好。」

沈舟打開藥盒，用竹片挑出藥膏。林硯聞慣了這個味道，當歸混著艾草，又苦又沖，這三個月他袖口上總留著一點。

今天那股苦味底下還有別的味道。很淡，有點甜，又有點澀，像受了潮的木頭。

他的鼻翼動了一下，又馬上定住，沒有再吸第二口氣。

藥膏敷上來，和平常一樣先涼後熱。沈舟的手很穩，一圈一圈纏著布，嘴裡說著阿禾半夜說夢話，喊的是他娘做的棗糕。阿禾在對面抗議，說他才沒有。大牛哈哈大笑。

林硯看著那隻手。他想起它昨夜有多冰。

「藥，」他開口，停了一下，「還夠嗎？」

「夠。」沈舟低頭打結，沒有抬眼，「到雁門都夠。」

他把結收緊，在上面輕輕拍了兩下，每回都是這樣。「好了，別沾雪。」

「多謝。」林硯說。

這兩個字他說得跟昨天一樣，跟前天也一樣，他很確定。

他把袖子放下來，蓋住那圈布。手腕一陣一陣地發熱。他可以找個沒人的地方把藥刮掉，可是他沒有動，說不上來是怕沈舟發現，還是別的什麼。

吃過早飯，掌櫃在樓下喊，豆料煮好了，天冷，馬要吃熱的。林硯對大牛說：「今天要趕路，馬餵足些，蹄子也都看一遍。都去，老周也去走動走動，別老窩著。」

大牛扛起料袋就下了樓，阿禾扶著老周跟在後面。沈舟走到門口回過頭：「你不來？」

「收拾一下就來。」

「那隻手別提重的。」沈舟說完，下樓去了。

林硯站著沒動。他聽見樓梯響，聽見布簾掀動，聽見掌櫃一輕一重的腳步穿過灶房，往後院去了。過了一會兒，阿禾的笑聲隔著後牆傳了上來。

他走回鋪頭，解開行李，把木匣拿了出來。

油布的結是他自己打的，解開時左手腕使不上勁，他用牙咬住繩頭，一點一點鬆開。木匣露出來，銅鎖上的霜已經化了，留著一點水痕。他把匣子放在一邊，從炭盆旁的柴筐裡挑了兩截硬木，在手裡掂了掂，又換掉一截，才用油布原樣包好，一層，兩層，再打上原來的結。

沈舟看他打過這種結，看過很多次。

他把油布包塞回行李，擺在原處，隔著行李摸上去，也是硬硬的一角。

然後他轉過身，看向牆角。大牛的鋪蓋卷歪在那裡，繩子亂七八糟捆了兩道。這人的鋪蓋從來都是自己往馬背上一甩，從不讓人碰，到了地方往地上一攤，倒頭就睡，再多幾斤重也不會多想。再說他是老鏢師，匣子跟著他，也不算離了鏢師的視線。

林硯解開繩子，把鋪蓋攤開，木匣用自己一件舊棉衣裹了，放進去，再捲起來。捲到一半他停了手，聽了聽，後院有人在喊馬的名字，沒有人上樓。他繼續捲，照大牛的手法把繩子亂捆兩道，打了個難看的死結。

他對自己說，這是防那個掌櫃。那五碗飯，那扇釘了板的窗，這個只有一條路能進出的村子，樣樣都該防。防人的事，本來就不必跟誰商量。

他又對自己說了一遍。

他把鋪蓋卷放回牆角，擺成原來歪著的樣子。

「林硯！」樓下有人喊他，是沈舟，聲音裡帶著笑，「你那匹馬不肯吃，只認你，下來看看！」

「來了。」

他走到門口，又回頭看了一眼。從這裡看過去，屋裡什麼也沒有變。
