# 跨媒介技巧整理（2026-11-08）

作者要求：注意力、畫面感這類技巧不只屬於小說，到電影、短影音等領域搜尋，原始紀錄放 `Data/`，再把可以用上的整理出來，之後再決定怎麼萃取進 novel-desk。

原始筆記在 `Data/跨媒介技巧/`，共四份 109 條。這份只整理，不改 novel-desk，也不替作者選要萃取哪些。

## 先知道

- 四份由四個 subagent 搜尋寫成，我讀過全文，但**沒有逐條回頭核對網頁**。認知那份有 8 篇論文是從 PDF 文字層逐字取的，可信度最高；其餘多是頁面摘錄或讀書筆記，萃取成卡之前，要用的那幾句應該再核一次。
- 證據強弱差很多。下面每個原則標了最強的證據是什麼：**實驗**（受控實驗或統合分析，但幾乎都不是小說，多是兩三句的短文或說明文）、**量測**（語料量測）、**經驗**（從業者說法）。
- 「對小說」全是推論。作者的判斷優先。
- 出處代號：`認`＝認知心理與閱讀研究、`影`＝電影剪輯與鏡頭、`編`＝編劇與口說故事、`短`＝短影音漫畫與遊戲，數字是條號。

## 一、跨領域收斂的原則

**對小說：**

- 連接詞（才、便、結果）的好處在「讀起來順」（認 12），正是作者在意的。

- 「狀態轉換給過渡」對應認 2：下一句的原因最好就在讀者手上那一句。
- 附條件：連接詞的線上效果研究不一致（認 13）；背景知識多的讀者，低連貫的文字反而學得好（認 4，測的是說明文）。所以不是越多越好，用在讀者自己推不出來的地方最划算。

### P4. 省主語、代名詞、名字：看情境，不是看規則 → 技巧 2，候選 B

這是這次最具體、可以直接改卡的發現，解決了 03 指出的 `唸起來卡.md` 反向問題。

| 情境 | 該用 | 依據 |
|---|---|---|
| 1. 同一個焦點人物，上一句是主語，這句繼續當主語 | 省略或代名詞；重複名字反而慢 | 認 15、16、22（含中文） |
| 2. 換主語、換焦點、指不顯著的人、新人物出場 | 寫出來；省略會變慢，名字沒有懲罰 | 認 16、17、21（中文實驗：換人時省主語明顯變慢） |
| 3. 場上有同性別的另一個人 | 名字；同性別代名詞最弱，讀者要到句末才排除另一人 | 認 18、19、20、25 |

- 中文語料：九成零形回指出現在沒有競爭者的語境（認 23）。
- 中文寫作書（`Data/【創作技巧】.txt:625`、`技巧知識庫/字詞句法與抗生硬.md:69`）的省主語例子，都是情境 1。
- 作者的老赫姆、莫甘改寫，補的多半是情境 2、3。這是推論，要拿作者實際改的句子逐句對過才算數。
- 用「那個年輕人」這類描述語代替名字，場上有相似人物時可能更糟（認 24）。這也支持 `唸起來卡.md` 現有的「叫名字就好」。

- `唸起來卡.md` 那題可以改成按情境問，而不是單向教省主語。
- `/draft` 修正段的「句子保留主語」照字面做到底，會在情境 1 撞上重複名字懲罰。`/draft` SKILL 已經把「該用代名詞的地方硬用名字」列為修正段做過頭的例子，研究支持這個擔心。

### P7. 高點拿注意力：篇幅加在揭曉之前，前面壓縮，強調點要少 → 技巧 5，候選 E

| 領域 | 說法 | 證據 |
|---|---|---|
| 口說故事 | 沙漏：在最重要的五秒之前把時間拉慢；其他地方刪不相干的細節（編 16，讀書筆記） | 經驗 |
| 認知 | 延後結果幾乎沒有上限地提高懸疑，懸疑和沉浸、欣賞正相關（認 29） | 實驗（電影觀眾） |

**對小說：** 這補上了 03 的擔心。事件形狀實驗發現，標輕重只會讓 Claude 把重事件拉長，但讀者的緊張感沒有更集中。這幾個領域都說高點的力道來自三樣東西，問句可以從這三樣出：

- 結果被延後（認 29、編 16）。
- 前面有壓縮來對比（短 14）。
- 其他地方沒有在搶注意力（短 14 的 1–2 個注目點）。

這和 `重音放哪.md` 的「先拿掉前面裝飾用的，留下真正的高點」同方向，可以互相連結。

### P8. 事件密度：事件之間要有「所以／但是」，平淡處一句帶過 → 技巧 6，候選 F

| 領域 | 說法 | 證據 |
|---|---|---|
| 編劇 | Trey Parker：兩個 beat 之間填得進「然後」就出問題，要填「所以」或「但是」（編 7，轉載報導） | 經驗 |
| 編劇 | 大多數場景不超過三頁；寫到第三頁就停下來問為什麼這麼長；最晚從哪進場、最早從哪離場（編 10） | 經驗 |
| 短影音 | crazy progression：好幾天的平淡日常壓進前三分鐘，不要一天一天演（短 2） | 經驗 |
| 電視劇 | A／B／C 線按重要性分篇幅，runner 只有一兩場（編 15） | 經驗 |
| 評書 | 有話便長，無話便短（編 23） | 慣例 |

**對小說：** 這是幕綱轉章那一步可以用的檢查，而且不用數字：

- 列出這章的事件，每兩件之間填「所以／但是」，填成「然後」的段落大概就是作者說的「繞」（編 7）。
- 每件事問最晚從哪進場、最早從哪離場（編 10）。

可以和 `Data/【小說】.txt:329–340`（一幕一事件、光靠擴寫細節只會虛胖）放在一起用。

## 三、不要搬，或搬了有副作用

收斂自三份筆記的檔尾：

- **固定間隔的鉤子或轉折**（「每 N 秒一個 pattern interrupt」，數字全部出處未證實，短 10）：違反「普通劇情直接說」，L4D 自己也寫「Constant, unchanging combat is fatiguing」。
- **平台與電影的數字**（3 秒、30 秒、三分鐘張力、三頁、鏡頭秒數、網頁只讀 20–28%）：換算到小說字數沒有根據。搬遷文件的精煉規則已經要求用量寫成文字描述。
- **closure 越大越好、讓讀者自己拼**（短 11、編 5 的後半）：只適用懸疑和情感高點，否則和作者的判斷相反。
- **刪一半字、迎合 F 形掃讀**（短 21、23、24）：那是找資訊的網頁。讀者在掃讀，代表已經不投入了。
- **結尾突然收**（短 5）：小說大事件後仍要一點喘息，L4D 也有 Relax。
- **好東西全塞開頭**（短 1、2）：MrBeast 是單集挑戰，長篇連載中段會沒東西給。
- **慢動作、特寫的生理效果**（影 23、24）：實驗量的是影片，文字沒有對應證據。
