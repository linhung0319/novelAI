# B 臂：照 novel-desk draft skill 的 prompt 模板組

組法依 `novel-desk/.claude/skills/draft/SKILL.md`：不寫行文指令，事件只寫發生什麼，對白只寫意圖，角色寫會做什麼、在意什麼。第 1 章沒有前文，所以刪掉「故事到目前為止」和「上一章的結尾」兩段。第 2 章的前情由 Claude 寫，「上一章的結尾」由寫手貼自己寫的第 1 章最後 500–1500 字。

---

## 第 1 章 prompt

我們正在合寫一部長篇小說，這次請你寫第 1 章。下面依序是會出場的人物、這一章用得到的世界設定、這一章要發生的事。

先介紹這一章會出場的人。

奧倫·維斯，十五歲。父親死後，他以三等雜役的身分在謄抄司抵父親的債，期限三年，沒有工錢。他瘦小，穿父親留下的灰袍，袖子太長，挽了三折。右手食指第二節有握筆磨出的繭，想事情時會用拇指指甲刮那圈繭。他話很少，凡事要自己核對過才信。他從小看得見一件別人看不見的事：紙上寫錯的規則，在他眼裡是黑的，符文、藥方、條文、告示都一樣；它只告訴他哪裡錯了，不告訴他對的是什麼。小時候他問過父親，父親說紙上什麼都沒有，從此他沒對任何人說過。

賈里德·維斯，奧倫的父親，已經死了。他做了十九年二等抄寫員，從沒出過錯。抄書時會把紙轉四十五度，說這樣手腕順著走，墨不會拖，奧倫從小跟著這樣抄。四十一天前，淨誤庭說他抄《正典》第七卷第 214 頁時抄錯了字，判他污損典籍，當場處死。

老赫姆，謄抄司的司務長，六十多歲。他跛左腳，腰上掛一串銅鑰匙，走一步響一聲，司裡的人聽聲音就知道他走到哪裡。他暗中護著奧倫，但說話從不說破。

莫甘，坐在奧倫隔壁桌的二等抄寫員，二十多歲。他話多，司裡的規矩背得比誰都熟，講規矩時會朝頭頂的原典架比一下。他不會幫奧倫，也不會告發他。

這一章用得到的世界設定：巫師的一切法術都照《符文正典》來做，大家相信《正典》是從世界的規則本身抄下來的，所以改動一個字就是污損世界，宣稱《正典》有錯是死罪；條文是「污損典籍者，罪同污損世界」。灰塔學院的謄抄司在地下三層，抄寫學院用的《正典》抄本。抄錯一個字就是污損典籍，由淨誤庭裁決，可以當場處死。抄本照架上的順序抄，每天三十頁。每頁抄完要在頁腳畫校字符。抄寫員核到拿不準的字，可以在那個字的左側點三個點，兩上一下，叫疑字符，意思是請下一手複核；它不改原典，登記簿不記，核點也不查。抄本一年裝訂一次，左側打孔穿線，裝訂線內側約兩分寬的一條會永遠壓在線底下，不拆線看不見。淨誤庭的巡查員入場會搖銅鈴，鈴一響，所有抄寫員停筆、雙手攤在桌上，直到巡查員離開。時間是灰曆 1147 年二月初七。

這一章要發生的事：奧倫在父親坐了十九年的第七排第三張桌前坐下，今天的份額是第七卷第 200 到 230 頁，照順序他今天會抄到第 214 頁。老赫姆巡到他桌邊，說旬末要核對抄本、這一卷也在裡面，又要他有些頁抄快一點。莫甘閒聊時講起抄錯一字是死罪、上個月院子裡處死了一個抄了快二十年的抄寫員，講到一半想起那是奧倫的父親，就不說了；同一段閒聊裡，莫甘照規矩在自己原典一處蟲蛀的地方點了疑字符，順口講了疑字符和裝訂線的規矩。奧倫抄到第 214 頁，看見原典第一行是黑的，他抄了四十一天《正典》，從沒在《正典》上看過黑。他取出縫在袍子內襯裡的父親殘抄本（行刑後發還的遺物，按規矩要燒，是老赫姆讓他留下的），父親那張正好抄到第 214 頁，他逐字比對，一字不差。章末停在走廊盡頭傳來銅鈴、全司停筆的時候，奧倫面前的第 214 頁還沒有抄。這一章先不要解決第 214 頁怎麼抄；不要寫父親為什麼照抄還被處死；不要讓奧倫在這章想到疑字符的用處；老赫姆那句話的真正意思不要揭；不要提《正典》有不止一個版本、奧倫的能力有更深的用法、父親是自願赴死，也不要出現「篡改」「編纂者」。

這一章的鏡頭跟著奧倫。篇幅大約三千字，寧可多一點。

## 第 2 章 prompt

我們正在合寫一部長篇小說，目前寫到第 1 章。這次請你寫第 2 章。下面依序是會出場的人物、到目前為止的故事、這一章要發生的事，最後附上上一章的結尾。

先介紹這一章會出場的人。

奧倫·維斯，十五歲，在謄抄司以三等雜役身分抵父債。話很少，凡事要自己核對過才信，想事情時會用拇指指甲刮食指的繭。他看得見紙上寫錯的規則，在他眼裡是黑的，只告訴他哪裡錯，不告訴他對的是什麼。他從沒對任何人說過。

老赫姆，謄抄司司務長，六十多歲，跛左腳，腰上的銅鑰匙走一步響一聲。他暗中護著奧倫，但不說破，也不讓奧倫看出他在幫忙。

塔洛·格林，淨誤庭巡查員，五十上下，灰袍。他核抄本時不看人，只看紙，只講條文和流程，不辯論。四十一天前當場處死賈里德·維斯的就是他。

這一章用得到的世界設定：淨誤庭核點時逐桌逐頁核本旬的抄本，抄到哪頁交到哪頁，沒抄的不算；抄本核完進檔，一年裝訂，往後有人會翻。改動原典一筆就是污損，當場處死。疑字符是在字的左側點三個點，兩上一下，請下一手複核，合規、登記簿不記、核點不查；裝訂線內側約兩分寬的一條，裝訂後會壓在線底下。

故事到目前為止是這樣的：奧倫的父親賈里德做了十九年抄寫員，四十一天前被淨誤庭以抄錯《正典》第七卷第 214 頁的罪名處死。奧倫接下父親的桌子和那一卷，今天照順序抄到第 214 頁。老赫姆巡場時要他有些頁抄快一點。隔壁的莫甘閒聊時照規矩點過一次疑字符，講過疑字符和裝訂線的規矩。奧倫在第 214 頁看見原典第一行是黑的，拿出父親的殘抄本逐字比對，父親抄的和原典一字不差，所以錯的是原典本身，而說出來就是死罪。這時走廊傳來淨誤庭的銅鈴，全司停筆，奧倫的第 214 頁還沒抄。

這一章要發生的事：塔洛·格林入場，要逐桌逐頁核點本旬抄本，老赫姆捧上登記簿，塔洛從第一排開始核，輪到奧倫大約還有一刻鐘，而他的第 214 頁一個字沒寫，原典攤在架上，誰都看得見他抄到哪頁。奧倫考慮三種做法：照原典抄，交上去的就和父親那張一模一樣，進了檔等於證明父親死得不冤；改成對的，他不知道對的是什麼，改原典一筆也是死罪；不交，他四十一天每天三十頁沒斷過，偏偏少這一頁一定會被追問。老赫姆把一疊要歸架的舊抄本放到第七排第一張桌上，讓那桌要核兩疊，多出大約一炷香，奧倫沒注意到這是有意的。奧倫想起莫甘點過的疑字符，決定照原典一字不改地抄完第 214 頁，再在裝訂線內側、第一行那個字的左邊點三個點；抄到第三筆時他想起父親也是這樣寫的。塔洛走到他桌前逐頁翻，翻到第 214 頁時手指在裝訂線那一側停了半秒，然後翻過去，判他過。塔洛轉身時沒回頭，對奧倫說了一句話，意思是他父親當時也是這樣低著頭，然後搖鈴離場。章末停在奧倫接著抄第 215 頁，第 214 頁上的三個點還沒乾。這一章不要寫父親為什麼照抄還被處死；不要寫塔洛對賈里德有什麼記憶或心思；疑字符將來會怎樣不要寫；不要提《正典》有不止一個版本、奧倫的能力有更深的用法、父親是自願赴死，也不要出現「篡改」「編纂者」。

這一章的鏡頭跟著奧倫。篇幅大約三千字，寧可多一點。
