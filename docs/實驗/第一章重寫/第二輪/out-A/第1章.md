# 第1章 父親抄錯了一個字

灰曆一一四七年二月初七，早鐘敲過以後，奧倫·維斯在謄抄司第九排第三張桌前坐了下來。這張桌子是他父親賈里德·維斯坐了十九年的位子，桌面左上角被手肘磨出一塊比別處淺的木色，筆架上有一道裂縫，是父親用細麻線一圈一圈纏起來的。四十一天過去了，那圈麻線還沒有鬆。

謄抄司在灰塔學院的地下三層，這裡沒有窗，四十多張長桌排成九排，每張桌上點著一盞油燈。每一排桌子的正前方都有一座高架，架上擺著《符文正典》的原典，大家平常簡稱它《正典》。灰塔學院的巫師施的每一道法術，都要照《正典》上寫的去做，而學院裡用的每一部《正典》抄本，都是從這間屋子裡一頁一頁抄出去的。抄寫員是學院裡最底層的工人，整天坐在地底下，一輩子也見不到幾次太陽。

四十一天前，淨誤庭說賈里德抄錯了字，判他污損典籍，在謄抄司後面的院子裡當場處死了他。賈里德死後留下一筆債，學院照規矩把債轉到兒子名下，於是十五歲的奧倫以三等雜役的身分進了謄抄司，要在這裡抄三年書來抵父親的債，三年裡沒有一文工錢。他身上穿的是父親留下的灰袍，父親的肩膀比他寬，手臂也比他長，所以他把袖口往上挽了三折，抄字的時候袖子才不會拖過未乾的墨。

抄本照架上的順序抄，每人每天抄三十頁。奧倫接的是父親那一卷，也就是第七卷。父親生前沒抄完的那份抄本，按規矩整份作廢，第七卷得從第一頁重新抄起。奧倫剛進司裡時，先被派去補別人留下的零頁，一直補到七天前，老赫姆才把第七卷交到他手上。

他把原典翻到今天的份額，第七卷第二百頁到第二百三十頁，然後用拇指把頁角一張一張撥過去數。數到第二百一十四頁時，他的拇指停在頁角上，沒有再往下撥。

第二百一十四頁就是父親被判罪的那一頁。淨誤庭貼在司門口的判決書上寫著：二等抄寫員賈里德·維斯，抄《正典》第七卷第二百一十四頁時抄錯了字，污損典籍，當場處死。判決書上沒有寫錯的是哪一個字。奧倫怕的就是這一點。父親抄了十九年書，從來沒有出過一次差錯，卻偏偏因為這一頁被處死；奧倫不知道父親到底錯在哪裡，所以也不知道自己今天照著原典抄下去，會不會抄出和父親一樣的錯，然後和父親一樣被拖到院子裡去。照他平常的速度，過了午飯，他就會抄到這一頁。

奧倫用右手拇指的指甲去刮食指第二節那圈繭。那圈繭是抄寫員握筆握出來的硬皮，他想事情的時候就會這樣一下一下地刮。他刮了好一會兒，才聽見身後傳來銅鑰匙碰撞的聲音。

老赫姆是謄抄司的司務長，六十多歲了。他跛著左腳，每走一步，腰上那串銅鑰匙便響一聲，所以全司的人不必回頭，也知道司務長走到了哪裡。老赫姆在奧倫桌邊站定，瞥了一眼攤開的原典：「旬末淨誤庭要來核對抄本，第七卷也在裡面。」

奧倫應了一聲是。老赫姆沒有馬上走開，他用指節在桌沿上敲了兩下，又說：「有些頁，抄快一點。」

奧倫以為司務長是在催進度。他在心裡算了一遍，到旬末還有三天，他要再抄九十頁，只要不出錯，時間是夠的；可是老赫姆特地走過來說這一句，說明上面盯得很緊，這一卷不能有任何閃失。他點頭說知道了，老赫姆便拖著左腳往下一排走，鑰匙聲一步一響地遠去。奧倫低頭看著那一疊頁角，覺得胸口比剛才更悶了。

他深吸一口氣，從紙堆裡抽出一張空白的抄頁，把它轉了四十五度，斜著擺在原典的右手邊。這是父親教他的。父親抄書時總把紙轉成這個角度，說「這樣手腕順著走，墨不會拖」。奧倫六歲時就坐在父親腿上看他抄字，後來自己學寫字，也跟著把紙斜著放，到現在已經改不過來了。他抄完第二百頁，照規矩從頭到尾核了一遍，在頁腳畫上校字符，表示這一頁已經核過，然後把它翻到一旁，接著抄第二百零一頁。

隔壁桌的莫甘是二等抄寫員，二十多歲，全司數他話最多。莫甘每抄完一頁都要停下來說幾句，今天也一樣。他擱下筆，朝頭頂的原典架比了一下：「你知道外頭那些巫師怎麼說這部書嗎？他們說《正典》不是人寫出來的，是從世界的規則本身抄下來的。世界怎麼轉，書上就怎麼寫，所以你在書上改一個字，就等於在世界身上動了一刀。條文寫得明明白白：『污損典籍者，罪同污損世界。』抄錯一個字就是污損，污損就是死罪，淨誤庭當場就能判，當場就能殺。」

奧倫沒有接話，這條條文他第一天進司裡就背熟了。莫甘也不需要別人接話，自己往下說：「所以說，抄得再久都沒用。上個月院子裡才處死一個，抄了快二十年的老手，聽說抄的就是第七卷的……」

莫甘說到第七卷，忽然想起死的人是誰，後半句話便噎在喉嚨裡。他看了奧倫一眼，又飛快地把眼睛轉回自己的原典上，乾咳了兩聲：「……反正，小心一點總沒錯。」

奧倫握筆的手停在紙面上方，筆尖懸了一會兒，才又落下去。莫甘說的那個老手就是他的父親，而父親被判罪的第二百一十四頁，他今天下午就要抄到。

莫甘大概覺得尷尬，安靜了好一陣子，手上抄得特別快。過了小半個時辰，他忽然「嘖」了一聲，把油燈往自己的原典那邊挪近：「蟲蛀了，這個字被咬掉一角，看不出是『衡』還是『衛』。」莫甘用筆尖蘸了一點墨，在抄頁上那個字的左邊點了三個點，兩個在上，一個在下。

莫甘發現奧倫在看，便順口解釋起來，口氣像在教剛進門的學徒：「這叫疑字符。核到拿不準的字，就在字的左邊點這三個點，意思是『這裡我不確定，請下一手複核』。它不改原典一筆，抄本上也不多出一個字，所以合規，登記簿不記它，淨誤庭核點也不查它。」他把抄頁轉過來給奧倫看，那個字剛好是一行的第一個字，三個點落在紙的最左邊，「你看，點在這裡，正好在裝訂線那一側。抄本一年裝訂一次，二十頁一疊，左邊打孔穿線，線的內側大概有兩分寬的一條，會永遠壓在線底下，不拆線誰也看不見。等明年一裝訂，這三個點就壓進去了，跟沒點一樣。」

莫甘說完，又朝原典架比了一下，好像這些規矩都是從架子上掉下來的，然後低頭繼續抄他的。奧倫看了那三個點一眼，便轉回自己的紙上，他手邊還有二十多頁沒抄。

午飯是一塊黑麥餅和一碗溫水，奧倫坐在桌前吃完，把餅屑撥進手心倒掉，又拿起筆。下午他抄得很穩，第二百零九頁、第二百一十頁、第二百一十二頁，每一頁抄完都核一遍，畫上校字符。抄完第二百一十三頁以後，他把那張紙翻到一旁，伸手翻開原典的下一頁，結果第二百一十四頁的第一行是黑的。

奧倫從小就看得見一件別人看不見的事：紙上寫錯的規則，在他眼裡是黑的。不管是符文、藥方、條文還是貼在牆上的告示，只要哪裡寫錯了，那裡就會發黑，像有人把一團墨按進紙裡，可是底下的字還讀得出來。他八歲那年，在街口藥鋪的牆上看見一張藥方，其中一行是黑的，半個月後他才聽說，照那張方子抓藥的人吐了三天，藥鋪回頭去查，發現那一行的分量寫錯了。黑只告訴他這裡錯了，不告訴他錯在哪一個字，也不告訴他對的應該是什麼。他小時候問過父親，父親拿起那張紙看了看，說紙上什麼都沒有。從那以後，奧倫就把這件事藏了起來，再也沒有跟任何人說過。

可是他在謄抄司抄了四十一天《正典》，從來沒有在《正典》上看見過黑。《正典》被當成世界本身的抄本，它應該是全天下唯一不會錯的一部書。

奧倫盯著那一行看了很久，黑色從行首一直延伸到行尾，把整行字都罩住了，每一筆都像浸在墨汁裡。他看完以後，把手伸進灰袍的內襯，摸出一疊對折的紙。這是父親沒抄完的殘抄本，行刑以後，司裡把它當作遺物發還給他。按規矩，死人留下的殘頁要燒掉，是老赫姆通融，才讓他留了下來。奧倫把它縫在內襯裡，四十一天沒有拿出來看過。

他把紙攤開，一張一張往後翻。父親的字微微往右斜，因為父親抄的時候紙轉了四十五度。殘抄本的最後一張，剛好是第二百一十四頁，那張紙的第一行也是黑的，黑得和原典一模一樣。

奧倫把父親那張抄頁放在原典旁邊，用左手食指按住原典的第一行，右手食指按住父親抄的第一行，一個字一個字地往下比。他比完一遍，又從頭比了第二遍，接著把整頁剩下的每一行也比完。父親抄的第二百一十四頁和原典一字不差，一筆都沒有多，一筆都沒有少。

奧倫這才明白過來：父親沒有抄錯，錯的是原典本身。父親照著一行寫錯的原典，一字不差地抄了下來，結果淨誤庭判他抄錯了字，把他處死了。可是這件事不能說出口。《正典》被當成從世界規則上抄下來的書，宣稱《正典》有錯就是死罪，誰說出來，誰就會被拖到同一個院子裡。

他的處境也跟著變了。現在他知道原典的這一行是錯的，他也知道父親就是照著這一行抄，才被處死的；而他自己手上的第二百一十四頁還沒有抄，那張轉了四十五度的抄頁上一個字也沒有。

奧倫把父親的殘抄本按在膝蓋上，還沒想好第一筆該怎麼落，走廊盡頭便傳來一聲銅鈴。

鈴聲在地下三層的石牆之間來回撞，全司四十多支筆在同一個時刻停了下來。莫甘把筆擱上筆架，雙手攤平放在桌面上，前後幾排的抄寫員也都一樣，誰都沒有出聲。奧倫認得這個鈴聲，那是淨誤庭巡查員入場時搖的銅鈴。鈴一響，所有抄寫員都要停筆，把雙手攤在桌上，一直攤到巡查員離開為止。淨誤庭的巡查員是來核點本旬的抄本的，比老赫姆說的旬末早了三天。

奧倫把殘抄本塞回內襯，然後把雙手攤在桌上。他的右手邊是抄好的第二百一十三頁，頁腳畫著校字符；他的正前方是原典的第二百一十四頁，第一行是黑的；原典旁邊那張轉了四十五度的抄頁，還是一張白紙。
