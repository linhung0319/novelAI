# 第2章 我沒抄錯，是書錯了

鈴聲停下來以後，謄抄司的門口走進來一個穿灰袍的人。他五十歲上下，左手提著那只銅鈴，右手空著，袍子上沒有一點裝飾。奧倫認得這個人，他是淨誤庭的巡查員塔洛·格林。四十一天前，在謄抄司後面的院子裡當場處死父親的，就是塔洛·格林。那天奧倫被擋在院門外，只從門縫裡看見一個灰袍的背影，聽見一聲鈴響，然後院子裡就安靜了。後來司裡有人告訴他，那個灰袍的人叫塔洛·格林，淨誤庭派來謄抄司的巡查員一直是他。奧倫看著那只銅鈴看了一會兒，才把眼睛垂回自己攤開的手上，他的十根手指平平地貼著桌面，指尖卻是冰的。

塔洛·格林站在門內，眼睛沒有看任何一個抄寫員，只看著最前排桌上的紙：「淨誤庭核點。本旬抄本，逐桌逐頁，抄到哪頁，交到哪頁。手上這一頁沒抄完的，准抄完這一頁，抄完停筆，手放回桌上。」

老赫姆拖著左腳從側門過來，鑰匙串一步一響，雙手捧著謄抄司的登記簿送到塔洛面前。塔洛接過登記簿，翻開第一頁，走到第一排第一張桌前，開始一頁一頁地翻那張桌上的抄本。塔洛核得很快，他翻一頁，眼睛從上到下掃一遍，手指在紙面上擦一下，再翻下一頁，翻完一疊就說一聲「過」，然後走向下一張桌子。坐在第一排第一張桌的老抄寫員一直到塔洛走開，肩膀才鬆下來，可是他的手還攤在桌上，一動也不敢動。

奧倫攤著雙手，眼睛盯著桌面，耳朵聽著前面翻紙的聲音。他在心裡數，塔洛核一張桌子大約只要二十幾次呼吸的工夫，前面還有八排，四十來張桌子。他算了兩遍，算出輪到第九排第三張桌，大約還有一刻鐘。

他的問題很清楚。核點交的是本旬已經抄好的部分，抄到哪頁就交到哪頁，而原典攤在他面前，翻在第二百一十四頁上，那張轉好角度的抄頁擺在原典旁邊，一個字都沒寫。原典就立在架上，誰走過來都看得見他抄到了哪裡，他交一張白紙上去，這張白紙本身就要解釋。塔洛剛才說了，手上這一頁沒抄完的准抄完，那麼他必須在這一刻鐘裡，把第二百一十四頁抄出來，可是怎麼抄，他想不出一條走得通的路。

第一條路是照原典抄。照原典抄，他交上去的就是一張和父親一模一樣的紙，連那一行黑都一模一樣。這張紙會和父親那張一起進檔，往後要是有人把兩張翻出來並排看，看見的就是父親那張被判了污損、兒子這張核點通過，兩張一個字都不差。那等於他親手替淨誤庭作證，證明父親死得不冤。奧倫很想站起來說一句：我父親沒抄錯，是書錯了。可是這句話一出口，他就是下一個被拖進院子的人。

第二條路是改成對的。他做不到。黑只告訴他這一行錯了，不告訴他錯在哪個字，也不告訴他對的該是什麼，他連該改哪一筆都不知道。就算他知道，改原典一筆就是污損典籍，塔洛·格林就站在幾排之外，當場就能處死他。

第三條路是不交。他可以把白紙收起來，把原典翻回去，只交到第二百一十三頁。可是登記簿上記著每個人每天抄了多少頁，他每天三十頁，四十一天一天都沒斷過，偏偏今天停在第二百一十四頁前面，塔洛一定會問他少的是哪一頁。他只要說出頁碼，塔洛就會知道這是誰的兒子，又是停在哪一頁上。

鑰匙聲在前面響了幾下，又在第七排停住。老赫姆抱著一疊要歸架的舊抄本，放在第七排第一張桌上，然後拖著左腳走回登記簿旁邊。奧倫沒有抬頭去看，他正盯著自己攤開的十根手指，把三條路從頭又想了一遍，結果三條路還是都走不通。

他的右手拇指想去刮那圈繭，可是手要攤在桌上，他只能讓拇指的指甲在桌面上輕輕壓了一下。他把眼睛從自己的手上移開，往左邊看過去，結果看見了莫甘的抄頁。

莫甘的雙手攤在桌上，兩隻手中間就是他上午抄的那一頁，紙的最左邊有三個小小的墨點，兩個在上，一個在下。奧倫看著那三個點，想起莫甘上午說過的話：核到拿不準的字，就在字的左邊點三個點，意思是「這裡我不確定，請下一手複核」；它不改原典一筆，抄本上也不多一個字，所以合規，登記簿不記，核點不查；點在一行第一個字的左邊，就正好落在裝訂線內側那兩分寬的一條裡，明年裝訂以後會永遠壓在線底下，不拆線誰也看不見。

奧倫盯著那三個點看了一會兒，慢慢想明白了這個做法為什麼行得通。他照原典一字不改地抄，抄出來的紙和原典一樣，所以過得了核點。然後他在第一行第一個字的左邊點上疑字符，這三個點合規，登記簿不記，核點不查，裝訂以後就壓進線底下。這樣做不能替父親翻案，父親已經死了，判決也不會改。可是將來如果有人拆開裝訂線，看見這三個點，就會知道有一個抄寫員在這一行上標過疑，就會回頭去核這一行。這是他現在唯一能在紙上留下來的東西。

他抬眼往前看。塔洛·格林還站在第七排第一張桌前，那張桌上擺著兩疊抄本，塔洛翻完一疊，又把另一疊拉到面前，從第一頁翻起。奧倫不知道那張桌子為什麼多出一疊，他只知道塔洛在那裡停得比別處久，久到他多出了大約一炷香的時間。

奧倫深吸一口氣，把手從桌面上收回來，拿起筆。塔洛准大家抄完手上這一頁，而他這一頁的原典早已翻開，紙也早已擺好，只是還沒落筆。他蘸了墨，讓手腕順著那張斜放的紙走，從第一行第一個字開始抄。

寫到第三筆時，他想起父親也是這樣寫的。父親的殘抄本上，這個字的第三筆也是這樣往右下拖出去，在紙轉了四十五度以後，那一筆看起來幾乎是平的。奧倫的筆尖在紙上停了一下，一滴墨在筆尖下慢慢暈開一點，他看著它不再擴大，才把這個字寫完。

接下來他沒有再停。他照著原典一字一字地抄，第一行抄完，第一行在他眼裡也黑了，和原典一樣黑，和父親那張一樣黑。抄到第五行時，他聽見前面的鑰匙聲往後挪了一排，翻紙的聲音也跟著近了，塔洛已經離開第七排第一張桌。奧倫沒有抬頭，他知道手一快字就會歪，字一歪就要重抄，所以他照著平常的速度，一筆接一筆地往下寫，抄完一行，再抄下一行，一直抄到最後一行，又照規矩從頭到尾核了一遍，在頁腳畫上校字符。最後他把筆尖移回第一行第一個字的左邊，在離紙緣不到兩分的地方，點了三個點，兩個在上，一個在下。點完以後，他把筆擱回筆架，雙手重新攤在桌上，這時塔洛·格林已經核到了第八排。

鑰匙聲跟在塔洛後面，一步一響。塔洛核完第九排第一張桌，接著走到第二張桌，也就是莫甘的桌前。奧倫用眼角看著塔洛一頁一頁翻莫甘的抄本，翻到上午那一頁時，塔洛的手指照樣從右往左擦過紙面，擦過最左邊那三個墨點，沒有停，也沒有問，翻過去以後說了一聲「過」。莫甘把攤著的手指微微蜷了一下，又趕緊攤平。塔洛·格林把莫甘的抄本推回去，往右走了一步，在奧倫的桌前停下來。他沒有看奧倫，只伸手把奧倫的抄本拿到面前，從本旬的第一頁開始翻，翻一頁，看一眼，再翻一頁。奧倫攤著雙手，聽著紙一張一張被翻過去，第二百零九頁，第二百一十頁，第二百一十三頁。

塔洛翻到第二百一十四頁時，手指從紙的右邊往左邊擦過去，擦過那一行黑，一直擦到裝訂線那一側，然後在那裡停了半秒。奧倫數著自己的呼吸，一，二，數到第三下時，他看見塔洛的手指底下就是那三個還帶著光的墨點。

塔洛把那一頁翻了過去：「過。」

他把抄本推回奧倫面前，在登記簿上寫了一筆，轉身要走。塔洛·格林走出一步，又停了一瞬，他沒有回頭，背對著奧倫說：「你父親也是這麼低著頭的。」

奧倫攤著的手指僵在桌面上，他盯著塔洛的灰袍下擺看，一直看到那道下擺又動起來。塔洛沒有再說第二句話，奧倫也不知道這句話是說給誰聽的，他只知道自己的頭此刻確實是低著的，低得只看得見桌上那張紙。接著，塔洛搖響銅鈴，走出了謄抄司的門。鈴聲在走廊裡越來越遠，老赫姆的鑰匙聲跟著響了一陣，也遠了。全司的抄寫員這才把手從桌面上收回去，有人揉手腕，有人重新蘸墨，莫甘長長地吐了一口氣。

奧倫坐在原處，看著自己的手看了一會兒，才伸手把原典翻到下一頁。他抽出一張新的抄頁，把它轉了四十五度，壓在剛抄好的那一張上面，開始抄第二百一十五頁。壓在下面的第二百一十四頁上，裝訂線那一側的三個點還沒有乾。
