# 第二輪：兩種 prompt 寫第 1–2 章

日期：2026-11-07

## 問題

同樣的劇情，兩種 prompt 寫出的第 1–2 章，作者讀起來哪個好讀、哪個懸念有效。

## 兩臂

| 臂 | prompt | 檔案 |
|---|---|---|
| A | Claude 的 brief：事實明列、從作者改寫歸納的句子規則、五段節奏結構、危機寫成明確的問題、第 1 章埋解法線索 | `A-brief.md` |
| B | novel-desk `draft` skill 的 `templates/prompt.md` 格式，照 SKILL.md 的組法：不寫行文指令、事件只寫發生什麼、對白只寫意圖 | `B-prompt.md` |

兩臂劇情相同，都依作者選的方案 A：第 1 章停在危機最高點（銅鈴），第 1 章過渡段埋疑字符線索，第 2 章帶出解法。

## 已知的差異（不是要比的，但會影響結果）

- A 臂給了幾句固定台詞（老赫姆、塔洛最後一句、條文），B 臂照 skill 只寫意圖。
- B 臂第 2 章照模板貼上一章結尾，用的是 B 自己寫的第 1 章；A 臂也接自己的第 1 章。
- 兩臂都用 subagent（作者同意）。draft skill 原本要求用 `send.py` 在乾淨環境生成；搬遷文件記錄 Claude Code 外殼對 AI 腔無差（H 對 A），所以這裡用 subagent 換方便。

## Claude 補的劇情邏輯（請作者確認）

- 第 1 章的危機：父親照原典一字不差地抄，還是被判抄錯處死，奧倫不知道為什麼。所以他怕自己照抄也會一樣。這個「為什麼」留作懸念，兩章都不解。
- 第 2 章的「逃過」：通過核點活下來；疑字符是額外留下的記錄，合規、登記簿不記。三條死路照原細綱。

## 判讀

作者盲讀，稿件編為甲、乙（對照在 `key.md`，作者讀完前不看）。作者記：讀到哪裡卡、有沒有哪裡講太多、結構看不看得出來、懸念有沒有效。
