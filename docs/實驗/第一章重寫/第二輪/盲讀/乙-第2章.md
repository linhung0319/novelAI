# 第2章 我沒抄錯，是書錯了

鐵包木的門被推開，門軸響了一聲。

進來的是一個穿灰袍的人，五十上下，個子不高，左手提著銅鈴，右手空著。他的灰袍和抄寫員的不一樣，領口滾了一道深灰的邊，下襬垂到腳背，走路的時候不晃。他在門口站定，搖了第三下鈴，然後把鈴收進袖子裡。

奧倫的雙手攤在桌上，眼睛看著自己面前的那張白紙。他不用抬頭也知道那是誰。四十一天前他在院子裡見過這個人，那天這個人也是這樣站著，手裡也是這個鈴。

塔洛·格林。

廳裡沒有人說話。

鑰匙聲從後面響起來，叮，叮，老赫姆從司務長的小間裡出來，懷裡捧著一本厚冊子，是登記簿。他走到塔洛面前，把冊子雙手遞上去。塔洛接過來，翻開，看了第一頁，又翻到最後寫字的那一頁，看了一會兒。

「本旬核點。」塔洛說。他的聲音不高，也不低，像在唸一張已經寫好的單子，「逐桌，逐頁。抄到哪頁，交到哪頁，未抄的不計。未核到的照常抄寫，核到你桌前，停筆，起身。」

他把登記簿合上，交回給老赫姆，走向第一排第一張桌。

廳裡又響起了筆聲，但比剛才稀，也比剛才輕。

奧倫把雙手從桌上收回來。

他算了一下。第一排五張桌，一張桌大概抄了七、八天的份額，塔洛一頁一頁翻，一張桌子少說也要翻兩百多頁。他看了一眼第一排，塔洛已經坐下了，左手按著抄本，右手翻，翻得不快，每一頁都停一下，看頁腳，看原典，再翻下一頁。

照這個速度，輪到第七排第三張桌，大約還有一刻鐘。

他看著面前那張紙。

右手邊，第七卷原典攤在斜架上，翻在第二一四頁，頁碼印在頁腳正中，誰走過都看得見。左手邊，十四張抄紙疊著，最上面那張是二一三，校字符畫在頁腳。

塔洛核到他桌前，會先數他交了幾頁，再看他的原典翻在哪裡。二一四開著，二一四沒有抄。

他拿起筆，蘸了墨，筆尖懸在紙上。

照原典抄。

一個字一個字照著抄，抄完二十二行，畫校字符，交上去。那就是一張和父親那張一模一樣的紙。一樣的十七個字，一樣的黑。它會被核過，進檔，年底裝訂，跟父親那張壓在同一個位置。往後有人翻到這一頁，會看見兒子抄的和父親抄的一字不差。父親抄的這一頁是罪證。他抄一樣的，交上去，核過了，那就等於在檔裡寫下：沒錯，就是這樣，他就是抄錯了，該死。

他的筆尖沒有落下去。

改成對的。

他看著原典的第一行。黑蓋在十七個字上面，整整一行，從第一個字到最後一個字。它只告訴他這一行是壞的，沒有告訴他是哪一個字壞，壞成什麼樣，該是什麼樣。他從小看見的黑都是這樣，只說錯，不說對。他不知道對的是什麼。就算他知道，改原典一筆就是污損，改抄本不照原典也是抄錯，抄錯一個字，就是院子。

他把筆放回筆架上。

不交。

他今天交到二一三，就停在這裡。未抄的不計。

可是他抄了四十一天，每天三十頁，一天都沒有斷過。登記簿上每一天的份額都是滿的，老赫姆的粉筆字寫在木牌上，二〇〇至二三〇，他交到二一三就停，原典翻在二一四。偏偏是二一四。塔洛會問。塔洛不用問第二句，只要問一句為什麼停在這裡，他就沒有話可以答。

他用拇指的指甲刮食指上的繭。

第一排第一張桌核完了。塔洛站起來，那張桌的抄寫員也站起來，等塔洛走到第二張桌，才坐下去。整個過程沒有人說話。

隔壁的莫甘在抄，抄得很慢，一筆一筆，好像怕手抖。

鑰匙聲又響了。

老赫姆抱著一疊東西從後面的架子那邊走過來，叮，叮，一直走到第七排，在第一張桌旁邊停下。那疊是舊抄本，用麻繩捆著，紙邊發黃，大約有兩指厚。他把那疊東西放在第七排第一張桌的桌角上。

「歸架的。」他對那桌的人說，聲音不大，「去年的第三卷，昨天才清出來，還沒核。」

那桌的人點了一下頭，沒說話。

老赫姆轉身往回走，經過奧倫的桌子，沒有停，鑰匙聲一路響到司務長的小間，門關上了。

奧倫看了一眼那疊舊抄本，又看回自己的紙。第七排第一張桌現在有兩疊要核。他沒有多想這件事。

他在想的是另一件事。

他想起中午莫甘點的那三個點。

兩個在上，一個在下，點在字的左邊。這個字我拿不準，請下一手的人複核。它不改原典，登記簿上不記，核點的時候也不查。第三十一條，合規的。

他把那幾句話在心裡又過了一遍，一字不差，和中午聽的時候一樣。

然後他又想起莫甘講的另一條。裝訂線靠裡面那一條，大概兩分寬，縫好以後就壓在線底下，永遠看不見，除非拆線。

他低頭看那張空白的抄紙。左邊的紙緣，留著一指寬的白，那是給裝訂打孔用的。白邊再往裡一點，靠近第一行第一個字的地方，就是那兩分。

他看著那兩分寬的白。

他把那張紙轉了一下，轉回斜斜的，大約四十五度。

他拿起筆，蘸墨。

第一行第一個字，他照原典抄。筆畫，筆序，右下角那一點是頓筆，他就頓。第二個字，第三個字。他抄得比平常慢，每抄一個字，眼睛就回到原典上，再回到紙上，對過一次才寫下一個。十七個字，一行。他抄完第一行，那一行在他的紙上也黑了，和原典一樣，和父親那張一樣，從第一個字黑到最後一個字。

他沒有停，接著抄第二行。

第二行是乾淨的。第三行乾淨。他照平常的速度抄下去，一行對一行，眼睛在兩張紙之間來回。第五排核完了，塔洛走到第六排。他抄到第十五行。第六排第二張桌。第十八行。第六排第四張桌。

第二十二行最後一個字寫完，他提起筆，對了最後一次，然後在頁腳畫校字符，一個圈，兩道斜線。

塔洛核到第六排第五張桌。

奧倫把筆尖在硯台邊上刮了刮，刮掉多的墨，只留筆尖上一點點。

他把筆移到第一行，第一個字的左邊，移到那兩分寬的白裡。

他點了第一下。很小，比墨點大不了多少。

第二下，在第一下的旁邊，和第一下齊平。

第三下要點在下面。他的手腕往下壓了一點，筆尖碰到紙的時候，他的手腕是順著走的，紙是斜的，那一點落下去，墨沒有拖。

他想起父親也是這樣寫的。紙斜斜擺著，手腕順著走。父親說這樣墨不會拖。

三個點。兩個在上，一個在下。

他把筆擱回筆架上，把那張紙移到左手邊，疊在二一三上面，錯開一點。

然後他把原典翻到第二一五頁。

第六排第五張桌的人站起來了。塔洛從第六排走出來，走進第七排，在第一張桌前坐下。那桌的人站在旁邊。塔洛翻完了那桌的抄本，看了一眼桌角那捆舊的，問了一句什麼，那桌的人答了，塔洛就把麻繩解開，一本一本翻下去。

翻得和剛才一樣慢。

奧倫看著第二一五頁的原典，沒有拿筆。

過了很久，比一刻鐘還要久一點，塔洛把那捆舊抄本重新疊好，站起來，走到第二張桌。又過了一會兒，第二張桌的人坐下了。

塔洛走到他桌前。

奧倫停筆，起身，站在凳子旁邊。

塔洛坐下來。他沒有看奧倫，他看的是桌上那疊抄紙，看的是斜架上的原典。他先把原典往回翻，翻到第二〇〇頁，然後拿起最底下那張抄紙，二〇〇，對著原典看，看頁腳的校字符，放下，拿起二〇一。

他的手指很乾，翻紙的時候不出聲。

二〇五。二〇六。二〇九。

奧倫站著，雙手垂在身側。他聽見隔壁莫甘的筆停了，莫甘沒有轉頭。

二一一。二一二。二一三。

塔洛拿起第二一四頁。

他把那張紙放在原典旁邊，原典翻到二一四。他的眼睛從第一行看下去，看到第二十二行，看頁腳的校字符。他的右手拇指和食指捏著那張紙的左緣，捏在裝訂線那一側，正好是第一行開頭的地方。

他的手指在那裡停了一下。

半秒，也許還不到。

然後他把那張紙翻過去，放在核過的那一疊上面，又往下看了一眼，沒有下一張了。

他把原典翻回第二一四頁，看了一眼頁碼，又往後翻了一頁，翻到奧倫剛剛翻開的二一五。

「過。」他說。

他站起來。

奧倫站在凳子旁邊，沒有動，等他走開。

塔洛轉身，往第四張桌走。他走了一步，背對著奧倫，沒有回頭。

「你父親那時候，」他說，「也是這樣低著頭。」

他走到第四張桌前，坐下，翻開莫甘的抄本。

奧倫坐回凳子上。

他把手放在桌上，看著原典第二一五頁的第一行，第一行是乾淨的。

塔洛核完了第七排，核完了第八排，第九排，第十排。廳裡的筆聲慢慢回來了，一開始很稀，後來就和平常一樣了。核到第十二排最後一張桌，塔洛站起來，走回門口，老赫姆捧著登記簿跟過去，塔洛在登記簿上寫了幾個字，把筆交還給他。

他從袖子裡取出銅鈴，搖了一下。

廳裡的筆聲又停了一次。所有人把雙手攤在桌上。

門軸響了一聲，門關上了。

過了一會兒，老赫姆的鑰匙聲響起來，叮，叮，往司務長的小間去了。

筆聲又回來了。

奧倫拿起筆，蘸墨。他把新的抄紙鋪好，用鎮紙壓住上緣，往左轉，轉到斜斜的，大約四十五度。

他開始抄第二一五頁的第一行。

左手邊那疊抄紙，最上面那張是二一四。第一行第一個字的左邊，那兩分寬的白裡，三個點還沒乾，在油盞底下有一點亮。
