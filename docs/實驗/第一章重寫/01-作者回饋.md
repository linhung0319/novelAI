# 第一輪重寫：作者回饋（2026-11-07）

作者讀 `重寫版.md`：「好了很多」。仍覺得怪的地方如下，原文照錄重點。

## 句子層

1. 「他昨晚睡前算過三遍。不管怎麼算，今天都會抄到第二百一十四頁……」：讀者隱約知道主角怕自己也被處死，但沒說出來，要用腦判斷。**讀者注意力有限；懸疑處讓讀者猜是樂趣，普通劇情應盡量減少讀者用腦。**
2. 老赫姆出場，作者改寫：
   > 是老赫姆，謄抄司的司務長，今年六十多歲了。他跛著左腳，每走一步，腰上的銅鑰匙便響動一聲。老赫姆撇了眼攤開的原典「旬末要核對的抄本，這一卷也在裡面。」
3. 轉紙四十五度，作者改寫：
   > 奧倫把新的一張紙轉了四十五度，斜壓在原典旁。這是父親的習慣，在小時候教給了奧倫，斜放著讓手腕順者走，就不會將墨拖紙上。
4. 莫甘噎住那段，作者改寫：
   > 「上個月院子裡不就處死了一個？」莫甘說，「也是個抄寫員，聽說抄了快二十年，結果一個字抄錯，就……」
   > 莫甘張了張嘴，喉嚨裡像卡了什麼東西，沒有再繼續說下去。
   > 過了一會兒，莫甘才小聲說了句「你接著繼續抄吧」，然後轉回自己的桌前，再也沒出聲。
   > 奧倫抄完了那行，才發現握得太用力，筆尖在紙上壓出個小坑。奧倫盯著那個小坑看了一會兒，才深吸了一口氣，拿出一張新的白紙，轉了四十五度，重新從那行的開頭開始抄。

## 整章層

作者：一直繞來繞去，沒有清晰的結構，讀起來不知所云。作者認為這章想做的是：

1. 介紹背景：父親作為抄寫員被處死，主角同樣是抄寫員
2. 接近危機：主角快抄到那一章，司長升高壓迫感，節奏往上
3. 過渡：抄寫日常，普通抄寫員視角，再次提醒危機；若給出解決危機的線索更好；節奏回落
4. 危機降臨：抄到父親被處死的那章，節奏到最高
5. 解決危機：主角用某種方式逃過處死。若放到下一章，要再演一次危機降臨時主角多做了什麼。目前主角沒有做任何逃過危機的動作（作者：這也是一種寫法，不算對錯）
