## 問題 1：每一項有沒有對應的卡

### 1. 讀者注意力有限：懸疑處才讓讀者猜，普通劇情直接說

**判斷：沒有。** 沒有一張卡寫「這裡不是懸疑處，該直接說」。有三張卡碰到「讀者要不要猜」，但說法都偏向藏，沒有反過來的提醒：

- `換個管道.md`：「心聲｜最確定，所以太清楚會減少張力。」
- `設定怎麼帶出來.md`：「先給現象和體驗，之後才給定義和名詞。」
- `是不是多說了.md`：「拿掉它，讀者從前面的事讀得出來嗎？讀得出來就是多說了。讀不出來，要補的可能是前面的動作和對白。」這題的方向是「能暗示就不要說」。第一輪「他昨晚睡前算過三遍」那段，讀者隱約讀得出來，照這題會判成不用說白，和作者的判斷相反。

最接近的是兩處，都只講一半：

- `是不是多說了.md`：「這句告訴讀者的是一件他還不知道的事，還是替他下的判斷？人類也常解釋，但多半在交代資訊」。這題替「交代資訊」留了位置，但沒有說普通劇情的資訊應該交代。
- `留一塊不說破.md`：「不說破的是作者刻意保留的，還是作者自己也沒想好？」這題問的是留白是不是刻意的，適用卻是「什麼都交代清楚了」，方向是教人多留。
- `開頭檢查.md`：「讀者知道他要什麼嗎？不知道目標，就無法判斷事件對他的意義。」只涵蓋「主角想做什麼」，不涵蓋背景和「主角怕什麼」，也只用在開頭。

**索引：** 作者的症狀是「讀者要用腦才判斷得出來」，索引沒有一行寫這種症狀。`是不是多說了` 的索引行寫的是相反的症狀（「有句子在解釋意義、像旁白」）。

**來源：**

| 說法 | 出處 |
|---|---|
| 直白就是簡單直接，「让读者把注意力集中在故事上，而不是用于理解文字含义」 | `Data/【mx-xz站-場景與敘事技巧】.txt:229`（對照表 §三也收了） |
| 「出場的角色必須讓讀者盡快知道它的目標……否則讀者無從判斷事件對角色的意義，自然容易感到無聊。」 | `Data/【編劇結構】.txt:1274–1280` |
| 心聲太明白會減弱張力，「所以懂得製造緊張的小說家，便要懂得何時遮蔽訊息，何時又該透漏訊息。」 | `Data/【人物】.txt:1818–1824`。卡片 `換個管道.md` 只收了前半句，後半句「何時該透露」沒收 |

### 3. 每件事只講一次；不寫用不到的場景細節

**前半「每件事只講一次」：部分。**

- `是不是多說了.md` 的適用寫了「把演過的事再講一遍」，對白段問「讀者剛看過的事，一句『他把剛才的事大略說了』夠不夠？」，內心戲段寫「不會漏，因為前面才演過：他在替讀者做筆記，可以考慮刪。」
- `重音放哪.md`：「單獨一行的短句，有新的事發生，還是把剛說過的話再說一次？」
- `放快或放慢.md`：「擴寫時只加這個人此刻真的有的東西，不把演過的意思再講一遍。」

缺的是第二輪甲那種重複：同一個事實（「今天會抄到第 214 頁」）在一章裡隔幾段用不同說法講三次，或下一章開頭整段重述上一章的處境。三張卡都是看一句或一段，沒有一題問「這件事這一章已經講過幾次」。`幕尾停在哪.md` 有「不要用『重述目前處境，再預告接下來』的總結段落收尾」，只管章尾，不管章首。

索引行 `是不是多說了：有句子在解釋意義、像旁白；對白像在交代資料、講給讀者聽；或內心戲看著多餘` 沒寫「同一件事換說法講好幾遍」，作者說「繞來繞去」時不容易對到這張。

**後半「不寫用不到的場景細節」：有。**

- `一件東西頂一段描寫.md`：「這個細節想告訴讀者什麼沒明說的事？說不出來，可能就不用補。」「大小、格局、擺設省掉，會少什麼？」
- `幕裡寫了什麼.md`：「人和物：和劇情有關才細寫。其他只點重點，讓讀者自己補。」
- `這段戲留不留.md`：「它對後面有什麼影響？影響很小，前因也可以不要。」

第二輪乙的「一百一十二級石階、十二排桌子」，拿這兩張卡都問得出來。

### 5. 危機段要給足篇幅和注意力

**判斷：部分，分散在四張卡。**

- `整段碎掉.md`：「篇幅有依張力分配嗎？高潮那幕有沒有比過場厚？過場能不能再薄？」最直接，但吃的是「連續幾章」，索引行是「發生很多事，每件都獨立……每章都等長等速」。
- `該演還是帶過.md`：「讀者一路等著看的那場通常還是要演。」
- `放快或放慢.md`：「放慢：他此刻有什麼念頭、想起什麼、周圍有什麼變了？」
- `心念插進動作.md`：「情緒最高的那一刻，能不能走進內心繞一圈（感受、回憶、想像），再回到同一個動作？」
- 句子層的 `重音放哪.md`：「如果要拿掉，先拿掉前面裝飾用的，留下真正的高點。」

缺的是一題直接問「這章最重要的是哪段？它拿到的篇幅和注意力，有比背景段多嗎？」，而且作者說「危機那段不夠突出」時，索引沒有一行對得到。

**來源：** `技巧知識庫/場景與情節推進.md:61`（高潮幕鋪成 set-piece，「遠比過場幕厚」）；對照表 §八「篇幅依張力分配」「重拍放在情緒最高點」；`Data/【創作技巧】.txt:800–806`（「在過場……『用說的』就好，等到重要的劇情再演給讀者看」）。

**一個要注意的實驗結果：** `docs/實驗/事件形狀/02-結果.md` 結論 2 和 5：brief 標了事件輕重，Claude 只把重事件拉長，形狀不變；Claude 給重事件的字數已經比原文多，但原文把讀者的緊張感更集中在重事件上（集中度原文 1.5–2.1，Claude 0.66–1.46）。所以「不夠突出」可能不是篇幅不夠，而是寫法（例如重事件之前沒蓄壓、或背景段也寫得一樣用力）。這張卡如果補，問句不能只問字數。

### 6. 事件量決定篇幅：一章放哪些事件、每件事多長

**判斷：部分，而且分章這一步在卡片裡被刻意延後。**

- `把情節填進骨架.md`：「同一段擠了太多事件，或整本事件太少，都要提出來。事件不夠時，光靠擴寫細節只會虛胖。」這句正是第二輪的病因，但層級是全書骨架。
- `大綱拆幕.md` 第 5 步：「章怎麼分可以之後再決定。」
- `該演還是帶過.md`：一件事要演還是帶過，是「每件事多長」的一半，但只看單段。

沒有一張卡問「這一章有幾件事？撐得起預定的字數嗎？哪件事要多長？」。

**來源：有，而且很直接。**

| 說法 | 出處 |
|---|---|
| 「一幕通常是一個事件」；每幕 3 千到 5 千字；「事件不夠多，故事也寫不長，光靠擴寫形容細節只會讓故事虛胖」；敘述式一幕約 2000 字、言行演出可到 6000 字 | `Data/【小說】.txt:329–340` |
| 「1000個字要講完一個事件應算合理」 | `Data/【編劇結構】.txt:54` |

| 事件少、字數多就繞 | `第二輪/01-結果.md`、`第三輪/01-結果.md` |

## 問題 2：哪些 skill 會用到

| 技巧 | `/check`（幫我看） | `/passage`（局部操作） | 幕綱轉章 | 備註 |
|---|---|---|---|---|
| 1. 普通劇情直接說 | 會：作者覺得某段要猜才懂 | 會，但要作者點名卡片 | 不需要 | `/draft` 修正段刻意沒收（「要先判斷哪裡算懸疑」） |
| 2. 句子接得起來 | 會：作者覺得某段讀不順 | 會：作者用「其他」指令改句子，要點名卡片 | 不需要 | 六條已在 `/draft` 修正段 |
| 3. 只講一次、場景細節 | 會 | 擴寫時會用到（`放快或放慢.md` 已有「不把演過的意思再講一遍」） | 不需要 | 「只講一次」已在修正段 |
| 4. 一章的起伏結構 | 會：作者拿整章或幕綱來問 | 很少：它只動一段 | **需要**，見下 | |
| 5. 危機段給足篇幅 | 會 | 會：對危機段擴寫，要點名卡片 | **需要**：哪段是危機、要多長，要在寫之前決定 | |
| 6. 事件量決定篇幅 | 會：作者拿幕綱問「這章夠不夠撐」 | 不會 | **需要**，這一項就是那一步的工作 | 搬遷文件「待決定」4 已記作者的話 |

兩個 skill 讀卡的方式不同，影響要補哪裡：

- **`/check`** 照 `SKILL.md` 第 2 步「讀 `knowledge/索引.md`，先定領域再看症狀，選 1–2 招」。它選不選得到卡，取決於索引行。所以第 1、3、5 項的問題主要在索引行，不只是卡片內容。
- **`/passage`** 的 `SKILL.md` 寫 `knowledge/`「除非作者點名招卡，那就只讀 `knowledge/cards/<招名>.md` 那一張」。它不讀索引，作者不點名就用不到任何卡。

**會不會需要幕綱轉章：** 第 4、5、6 項需要一個「決定這章放哪些事、各多長、哪段是高點」的時間點。現在沒有：`/draft` 第 1 步直接從 `beats/` 組 prompt，模板寫死「按順序講四到七件事」和「篇幅大約三千字，寧可多一點」。這幾張卡（如果補）是在規劃時用，不是寫手 context，所以不違反索引「正文類的卡不放進落筆的寫手 context」。這一步要不要做、放在哪，不在這次範圍。

第 1、2、3 項不需要這一步：它們是寫完後檢查（`/check`）或局部修（`/passage`），以及落筆的固定規則（修正段）。
