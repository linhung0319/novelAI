# 第1章 父親抄錯了一個字

灰曆一一四七年二月初七，奧倫·維斯在謄抄司第七排第三張桌前坐下。這張桌子原本是他父親賈里德·維斯的。賈里德是二等抄寫員，在這張桌前抄了十九年《符文正典》，沒有出過一次差錯。四十一天前，淨誤庭說他抄錯了一個字，判他污損典籍，當場把他處死了。

謄抄司在灰塔學院的地下三層，專門抄寫學院要用的《正典》抄本。巫師施展的每一道法術都照《正典》來做，人人都相信《正典》是從世界的規則本身抄下來的，所以改動一個字就是污損世界，律條上寫得明白：「污損典籍者，罪同污損世界。」抄寫員抄錯一個字，就算污損典籍，由淨誤庭裁決，裁決完可以當場處死。至於宣稱《正典》本身有錯，那同樣是死罪。

奧倫今年十五歲，個子瘦小，身上穿的是父親留下的灰袍，袖子太長，他挽了三折。父親死後留下一筆欠學院的債，債落到奧倫頭上，他便以三等雜役的身分進了謄抄司抵債，要做滿三年，沒有工錢。他名義上是雜役，做的卻是抄寫員的活，每天的份額和別人一樣，三十頁。

他翻開份額單。今天要抄的是《正典》第七卷第二百頁到第二百三十頁，照他平常的速度，過了午就會抄到第二百一十四頁。父親就是因為第七卷第二百一十四頁被判的罪。

奧倫怕的就是這一頁。父親十九年沒出過錯，卻因為這一頁被處死，淨誤庭從頭到尾沒說父親錯在哪個字。奧倫不知道父親錯在哪裡，也就不知道自己照著原典抄下去，會不會抄出和父親一樣的錯，落得和父親一樣的下場。

他抄到第二百零三頁時，身後傳來銅鑰匙一步一響的聲音。老赫姆，謄抄司的司務長，六十多歲，跛著左腳，腰上掛著一大串銅鑰匙，從走道那頭慢慢走過來，在奧倫桌邊停下。

「旬末要核對本旬的抄本，」老赫姆說，「第七卷也在裡面。」他低頭看了一眼奧倫攤開的原典，又說：「有些頁，抄快一點。」

奧倫點頭，以為司務長嫌他抄得慢，要他在旬末前趕齊份額。老赫姆沒有再說什麼，鑰匙串一路響著往第八排去了。

奧倫取了一張新紙，把它轉了四十五度。這是父親教他的，父親說紙斜著放，手腕順著走，墨不會拖，奧倫從小跟著學，到現在也改不掉。

隔壁桌坐的是莫甘，二等抄寫員，二十多歲，抄書的時候嘴也停不下來。莫甘把筆擱在硯台邊，壓低聲音說：「上個月院子裡處死的那個，你聽說了沒有？抄了快二十年的老手，聽說最後就栽在第七卷上……」他說到這裡，眼睛掃到奧倫身上那件挽了三折的灰袍，話便噎在喉嚨裡。莫甘咳了一聲，低頭去看自己的原典，過了好一會兒才換了個話頭：「嘖，這頁給蟲蛀了。」

莫甘把原典推過來一點給奧倫看。那一頁第五行開頭的字被蟲蛀掉半邊，只剩一個偏旁。莫甘照著抄下那個字，接著在自己抄頁上那個字的左側點了三個點，兩點在上，一點在下。

「疑字符。」莫甘朝頭頂的原典架比了一下，像在背規矩，「核到拿不準的字，就在左邊點這三個點，意思是這裡我不確定，請下一手複核。原典一筆不動，抄本上也不多一個字，合規的，登記簿不記，淨誤庭核點也不查。」他吹了吹墨，又說：「抄本一年裝訂一次，二十頁一疊，左邊打孔穿線，靠線那兩分寬全壓在線底下，不拆線誰也看不見。我這三個點剛好點在那條裡面，裝訂完就沒了，跟沒點一樣。」

奧倫應了一聲，回頭抄自己的。

過了午，奧倫翻到第二百一十四頁。原典的第一行是黑的。

奧倫從小就看得見這種黑：紙上寫錯的規則，在他眼裡會發黑。符文畫錯一筆、藥方配錯一味、告示上的條文寫錯一句，錯的那一處就黑成一片，像有人把墨潑在上面。黑只告訴他那裡錯了，不告訴他錯在哪個字，也不告訴他對的應該是什麼。他小時候指著一張發黑的告示問過父親，父親看了很久，說紙上什麼都沒有。從那以後，奧倫就把這件事藏起來，對誰都沒說過。

他在謄抄司抄了四十一天《正典》，從沒在《正典》上看過黑。

奧倫用拇指指甲刮著右手食指第二節那圈繭，刮了幾下，然後彎腰從桌下的布袋裡取出父親的殘抄本。這疊抄本是行刑後發還的遺物，照規矩要燒掉，老赫姆通融，才讓他留了下來。父親最後那張剛好抄到第七卷第二百一十四頁。奧倫把父親那張和原典並排放好，一個字一個字對下去，對完第一行，又從頭對了一遍，父親那張和原典一字不差。

奧倫明白了：父親沒有抄錯，錯的是原典本身。父親照著原典一字不差地抄下來，淨誤庭卻判他抄錯了字。這件事他不能說出口，因為說《正典》有錯，就是死罪。

就在這時，謄抄司門口響起了銅鈴。鈴是淨誤庭的巡查員入場時搖的，鈴一響，所有抄寫員都得停筆，雙手攤在桌上，直到巡查員離開。滿室的筆聲一下子停了，奧倫把父親的殘抄本塞回布袋，也把雙手攤平在桌面上，抬眼看著門口進來的人。

進來的是塔洛·格林，淨誤庭的巡查員，五十上下，穿一身灰袍。四十一天前，就是塔洛在院子裡當場處死了賈里德。本旬的核點應該在旬末，塔洛卻提早來了。老赫姆捧著登記簿迎上去，塔洛沒有看老赫姆，接過登記簿，便從第一排第一張桌開始核。巡查員核的是本旬的抄本，抄到哪頁就交到哪頁，塔洛一桌一桌、一頁一頁地翻，不看人，只看紙。

奧倫算了算，輪到第七排第三張桌大約還有一刻鐘，而他面前的第二百一十四頁還沒抄。

照原典抄，交上去的就會和父親那張一模一樣，進了檔，就等於證明父親死得不冤。改成對的也不行，因為他根本不知道對的是什麼，何況改原典一筆就是污損。不交這一頁更不行，他四十一天每天三十頁從沒斷過，偏偏少了這一頁，塔洛一定會追問。

塔洛核到第一排中段時，老赫姆一拐一拐地抱來一疊舊抄本，放在第七排第一張桌上，說這桌上一旬的抄本漏了核，請巡查員一併看過。塔洛點了一下頭，沒有說話。這樣一來，第七排第一張桌要核兩疊，前面又多出一炷香的工夫。奧倫只當是司務長在補登記，沒有多想。

奧倫的目光落到隔壁桌。莫甘雙手攤在桌上，手邊那張抄頁的左緣，三個墨點還在，奧倫便想起了疑字符。他決定照原典抄，再在第一行旁邊點上疑字符。這樣交上去的抄本一筆不錯，可是將來只要有人拆開裝訂線看見這三個點，就會回頭去核這一行。父親沒能留下的話，這三個點可以替他留著。

塔洛還在前排低頭翻紙。奧倫的左手仍攤在桌上，右手拿起了筆，照著原典抄第一行。寫到第一個字的第三筆時，他想起父親抄到這裡也是這樣寫的，同一個字，同一個斜度，筆尖便在紙上停了一下。然後他接著寫下去，把第二百一十四頁整頁抄完，在頁腳畫上校字符，表示這頁核過，又在裝訂線內側、第一行第一個字的左邊，點下三個點。他放下筆，把右手也攤回桌上，低下了頭。

一炷香又一刻鐘過去，塔洛核到了第七排第三張桌。塔洛拿起奧倫本旬的抄本，一頁一頁往後翻，翻到第二百一十四頁時，手指在裝訂線那一側停了半秒，然後翻過去，說：「過。」

塔洛把抄本放回桌上，轉身往門口走，走的時候沒有回頭，說：「你父親也是這麼低著頭的。」他走到門口搖響銅鈴，離開了謄抄司。

奧倫桌上的第二百一十四頁，裝訂線內側那三個點還沒乾。
