# 幕與步：跨媒介資料整理（2026-11-09）

接 `06-幕綱轉章設計.md`。作者要先定「幕」「步」的名稱，並考慮把散在各卡的「步」技巧抽出來，所以到編劇、電影、動畫、漫畫、短劇查了一輪。三份原始筆記（共 71 條）在 `Data/跨媒介技巧/`：

- `編劇與電影-場景內單位.md`（23 條）
- `動畫與漫畫-步與節奏.md`（25 條）
- `短劇-節奏與爽點.md`（23 條）

由三個 subagent 分頭搜尋，Claude 讀過全文，沒有回頭核對網頁。下面用「編 N」「動 N」「短 N」指這三份的條號。

**證據強度：** 實驗只有 Doicaru 2016（編 13）、Bálint 等 2017（編 14，有測文字）、Cohn 的漫畫實驗（動 16–19，材料是 4–6 格《Peanuts》條漫），以及一篇只讀到摘要的微短劇內容分析（短 7）。其他都是從業者經驗或教科書，短劇那份的來源最弱。McKee、Pearlman 都沒讀原書。

## 一、名稱：步該多大

各家的 beat 大小相差兩三個層級（編 1–7 小結）：

| 誰說的 | 大小 | 相當於 |
|---|---|---|
| Save the Cat 15 beats | 數場到數十場 | 好幾章 |
| 電視編劇室的 beat（編 5） | 約一場 | 幕 |
| McKee sequence（編 2） | 2–5 場，最後一場最重 | 章 |
| McKee scene | 價值轉一次 | 幕 |
| McKee beat、Stanislavski bit、Sorkin（編 1、3、4） | 一組動作與反應；策略換了才算新的一個 | 步 |
| 劇本裡的「(beat)」（編 7） | 對白中間的停頓 | 句 |

**結論：**

1. **「幕＝局勢改變一次」對應 McKee 的 scene，站得住。** 短劇也用類似的切法：「人物眼前的目標連續變化」三次就拆三場（短 16）；Mamet 說角色這一幕的目標達成或確定落空，戲就該結束（編 11）。
2. **「步」要比 Claude 之前切的粗。** 判準是「角色碰壁之後換了做法」（編 3、4），不是動作一步、反應再一步。同一種交換重複幾次，都還是同一步（編 1）。照這個算法，神秀第 403 章「烏龍」那幕不是 9 步，而是大約 4–5 步：
   - 喝令，對方哭
   - 改問「此人是誰」，被哭罵
   - 不信，自己查證（回想氣息、招來金丹）
   - 明白
   - 將錯就錯
3. **不要用「拍」或 beat。** 外部資料裡這個字的大小不固定，novel-desk 的 `beats/` 又是幕綱。用「步」可以避開。

## 二、起伏和快慢是兩回事

三個來源各自得出這個結論：

- **McKee（編 21）：** rhythm 是場景長度，tempo 是場內的活動量，tension 是幕與幕之間的收緊與放鬆。他的例子：「望著窗外下重大決定」是低 tempo，但張力可以很高。
- **Pearlman（編 20）：** 節奏的目的是做出張力與釋放的循環，速度只是工具。她分的身體、情緒、事件三層，大致對到句、步、幕。
- **Cohn（動 23）：** 漫畫的敘事結構和版面結構各自獨立，「not isomorphic」。

**快慢有兩個旋鈕：** 幕有多長、幕裡的步有多密（編 21）。另外要注意，讀者覺得快，是因為「有意義的改變很頻繁」（編 22）。步很多但每一步都沒改變處境，讀起來反而慢。

**只有一個例外：** 每一步都沒改變處境，但讀者知道有個結果懸在那裡（例如桌下有炸彈），這時讀者感到的是懸疑，不是拖（編 13、16、22）。

**分工：**

- 幕與幕之間的起伏，在對話裡排幕綱時決定。
- 步的快慢在排章時決定。

這和 06 的設計一致。Pixar 的分鏡師也說，一張圖講一個故事點的 beat board 看不出一場戲是 3 分鐘還是 7 分鐘，還會把故事問題藏起來（動 8）。也就是說，只到幕的幕綱，看不出快慢。

## 三、高點怎麼排步

這是和 06 第 4 題實驗最直接相關的部分。

| 原則 | 依據 | 和之前假設的差別 |
|---|---|---|
| 多放的步放在高點**之前**，高點本身可以短 | Lasseter 的預備動作（動 3）；《キングダム》從見せ場前 5–6 頁開始吊（動 9）；Cohn 的 Prolongation（動 18） | 之前說「高點那幕多放幾步」，要修正成「轉折前多放」 |
| 延後用的材料要在故事裡：動作、聲音、物件、旁人 | Bálint 2017，**有測文字**：用敘事者或故事外的東西拖延，懸疑和投入感都下降（編 14） | 新增。內心獨白算故事內還是故事外，摘要沒說 |
| 延後的方式可以是同一個瞬間多寫幾次，不一定要加新事件 | Doicaru 2016：重複高點前的鏡頭，懸疑感隨延遲線性上升（編 13）；日漫把同一刻拆成幾個局部（動 20） | 新增 |
| 延後之後要兌現 | Hitchcock 後悔讓炸彈爆炸（編 15） | |
| 高點之後要有收尾，自己成一步 | Lasseter 把反應列成獨立一段（動 1、2）；短劇的「餘震」（短 18）；`爽點與節拍.md` 的「結算獎勵」 | 新增 |
| 接近高點時整幕收緊，只在轉折前一刻拉長 | McKee：接近幕的高潮時，場景縮短、活動加快（編 21）；副作用第 6 點 | 不要把高點那幕整個拉長 |
| 一章一個主要高點，其他幕替它墊 | 《キングダム》一話一個見せ場（動 9）；《リクドウ》先定這一話的メイン，刪掉妨礙它的部分（動 10） | 新增 |
| 高點靠對比，篇幅從別處扣回來 | 各媒介在高點時，有的變快、有的變慢，共通的只有「前面有預備」和「前後有落差」（動 24）；章的總量固定時，多給高點的要從別處扣（動 12） | |

**警告：**

- Cohn 的實驗裡，讀者刪掉 Prolongation 幾乎察覺不到（動 17、18）。多放的步不會自動被讀者感覺到，放多了就是填充。
- 美漫「拉長分格」的爭議（動，副作用 1），以及短劇被批評「45 分鐘拆成 11 個反轉點」（短 22），都是步放太多的例子。
- 只在真正的高點用，每幕都延後會讓讀者疲乏（動，副作用 2）。

## 四、一幕的骨架

Cohn 的 Visual Narrative Grammar（動 14–17）把一組畫格分成五個角色：Establisher（建立）、Initial（開始）、Prolongation（延長）、Peak（高點）、Release（釋放）。只有 Peak 一定要有。這套也可以一層包一層：一組畫格在上一層可以整體當 Initial 或 Peak（動 15）。

實驗發現：

- 讀者會留住 Initial 和 Peak，而 Establisher、Prolongation、Release 刪了也不太察覺（動 17）。
- 讀者會在組和組的邊界切開。插進來的東西放在組內，比放在組間更傷（動 16）。

**對小說：**

- 可以拿來當幕的**檢查**，不要當模板（動，副作用 5）。這一幕的開始在哪一步？高點在哪一步？
- 快慢主要靠調建立、延長、釋放這三種步。
- 回憶或設定說明放在幕和幕之間，傷害比放在幕中間小。

## 五、排章的順序

| 做法 | 依據 |
|---|---|
| 先定每幕的頭和尾，再填中間的步 | 韓國短劇作家每集先只寫鉤子和結尾兩三行（短 14） |
| 先把篇幅分給情節，再寫細節 | 小學館講座：先分配頁數，再畫ネーム（動 11） |
| 先決定這一幕是誰的時間，快慢跟著他的感受走 | 押井守（動 7）；多 POV 時要調整（動，副作用 7） |
| 幕的邊界落在角色壓力自然到頂的地方，不要等距切 | Slakter（短 9） |

## 六、數量

沒有可靠的小說數字。

- 日本短劇：台詞來回 10–12 次約 30 秒（短 13），只能當上限參考。
- 網文的「每 500–800 字一個波動點」（短 21）沒有數據。

讀者控制閱讀速度，作者控制不了每一步讀多久，所以步數比字數可靠（動 22）。這一點只是推論。

## 七、不要搬

- 固定秒數或字數的反轉間隔（短，副作用 1）。
- 用合理性換密度（短 22、23）。小說讀者會回頭檢查因果。
- 每幕都給回報，會讓大高潮被小高潮稀釋（短，副作用 5）。
- 高點不寫，只留一個閃光（動 19）。小說沒有漫畫那種約定俗成的符號，讀者要推的太多。
- 起承全部後補（短 13）。小說只有文字，讀者會在不該用腦的地方用腦。

## 八、對 06 和步卡的影響

**06 第 4 題的實驗，乙組要改：**

- 危機那幕多放的步，要放在「比對出一字不差」之前和「鈴響之後」，而且都用故事裡的東西：翻頁、比對、聲音、時限、旁人。不要用奧倫的內心說明來拖。
- 高點本身保持短。
- 危機之後加一步收尾。
- 其他幕壓縮，讓總篇幅不變。

**步卡（如果作者決定抽出來）的材料：**

- 判斷新的一步：策略換了沒有。
- 高點前用故事裡的東西延後。
- 高點本身可以短。
- 高點後收尾。
- 一章一個主要高點。
- 延後要兌現。
- 延長放多了就是填充。

這些可以和 `複沓與反常.md`、`對白升溫.md`、`爽點與節拍.md`、`打鬥.md` 的步序整合。

**Cohn 的五個角色和 McKee 的三個詞**（rhythm、tempo、tension）可以當排章的檢查問句，不寫進寫手的 prompt。
