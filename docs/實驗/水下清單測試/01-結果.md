# 水下清單測試：結果（2026-11-11）

受測：novel-desk 工作區（未 commit）改版後的 `passage/SKILL.md`、`draft/SKILL.md`、`README.md`。改版內容見 `docs/搬遷到novel-desk.md`「水下」一節。

要回答的問題：真相照實寫在卡片和場景表上，只靠 `cards/hidden/` 清單告訴 AI 哪些事讀者還不知道，`/passage` 擴寫時會不會把真相寫出來或暗示出來；`/draft` 的主 agent 能不能把場景表上的真相改寫成現象。

材料、判讀都出自 Claude，只算方向。下面的判斷要等作者看過輸出原文才算數。

## 材料

測試書 `novel-desk/books/水下清單-測試/`（commit `fa35fa9`），從 `局部操作-測試` 改來：

- `cards/characters/沈舟.md`、`cards/world/這趟鏢.md`：直接寫上真相（沈舟是韓家的人、換藥是要廢林硯的手、匣裡是血書、掌櫃和斗篷人是接應）。
- `scenes/arc01.md`：四個場景，真相和原因照實寫，包含一句作者口吻的寫法註「他是發現重量不對了。讀者只要看見他停了一下」。
- `cards/hidden/沈舟.md`：三條清單。兩條揭曉在 arc01「雁門關前」，一條沒排揭曉。
- `chapters/ch0005.md`：用舊測試的稿 1 當正文。

七次執行都是 subagent 照 SKILL.md 做，輸出原文在 `輸出/`。

## `/passage`：6 次、18 個版本

**沒有一版寫出真相或原因。** 18 版都沒有出現韓家、藥的作用、布包裡是什麼、匣裡是什麼，也沒有讓林硯多想到一步。六次都讀了清單和場景表，都判斷出段落在揭曉之前。

**加的東西有沒有暗示：** 有幾句會把原有的伏筆加重，沒有新增指向真相的線索。

- P2 的指令要求多寫沈舟的樣子，六版都往「和平常不一樣」寫，等於加重原文「安靜得像換了一個人」。例如 P2b 版本 2「他平常站著，重心總是落在一條腿上，肩膀鬆鬆垮垮的，手裡不是轉著根草，就是在拋一枚銅錢。這時候他兩隻手空著，垂在身側」。這是指令要的方向，不知道真相的寫手也會這樣寫。
- P1a 版本 3「昨晚。林硯想起停在舊傷上的那根拇指，冰涼的。」把夜裡的事和換藥連起來。兩件事讀者都已經讀過，是林硯自己的疑心，不是新資訊，但比原文明白一點。
- P3 的指令本身就靠近真相（沈舟為什麼想進村）。六版給的理由都只用老周的病、天氣、地勢，沒有讓他顯得認識這家客棧。P3b 版本 2「要堵我們，用不著等我們進村」說得比較篤定。

**「碰到水下」這一項：** 五次有寫，一次（P1b）判斷沒有就省略。上面這幾句它們都自己列出來了。也有報得太細的：P2a 把「斗篷下襬結著雪殼」「布是粗布，繩子繞了兩道」都列為可能指向真相，這類算雜訊。P3a、P3b 都先說明「你的指令本身就靠近清單第一條」，再列最容易起疑的句子。

**沒要求動的句子：** 抽看 P1、P2，原句都逐字留著，藥味那一段六版完全沒動。

## `/draft`：1 次

D1 的 prompt 沒有任何一句真相。

- 角色段和世界設定段只用了卡片的第一段，卡片上的真相段沒進去。
- 場景表的原因句都拿掉了：「這是藥開始起作用」「沈舟等的就是這一天：手廢了，林硯只能把匣子交給他」沒寫；「掂了掂，停了一下」留下，寫法註的「他是發現重量不對了」沒寫。
- 沒有寫「不要揭露某事」。
- 「水下」一項照新格式逐條說明，並列出三處「寫手仍可能自己猜到」的地方，例如包袱裡是馬蹄鐵加上「掂了掂，停了一下」，寫手多半會直接寫出沈舟察覺重量不對。這是讀者也猜得到的事，留不留由作者決定。

## 沒測到的

- **揭曉在這一章的情況。** 排章測試破梗的就是這種（S403 的「覆海老祖」）。新規則要主 agent 把「揭曉前不能出現的事」寫成具體的事，並查稱呼，這次的測試書沒有這種章，沒驗證。
- **回頭改已揭曉之後又寫的前文。** 測試書的揭曉場景還沒寫成正文。
- **`/settle` 新規則**（不拆句子、只顧清單）沒跑。
- **`/search`、`/check`** 的標【水下】沒跑。
- 每個段落只跑 2 次，都是同一個模型。沒有對照組（不知道真相的寫手擴寫同一段），所以「加重伏筆」有多少來自知道真相、多少來自指令，分不出來。
- D1 只組了 prompt，沒生成稿子，上面三處「可能猜到」實際會不會被寫出來不知道。

## 結論（方向）

作者的判斷在這次測試裡成立：擴寫時明說哪些是水下，它避得開。風險不在洩漏真相，而在作者的指令靠近真相時，原有的伏筆會被寫得更重；這種情況它會在「碰到水下」列出來，由作者挑版本時決定。
