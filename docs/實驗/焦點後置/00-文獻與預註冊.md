# 焦點後置實驗：文獻與預註冊

寫於判讀開始之前（2026-11-07）。判讀時如果偏離設計，要記在結果報告裡，不回頭改這份檔。

## 起點

作者的觀察：自解釋句人類也很多（`../AI腔成因/01-結果報告.md`），但 AI 的文章讀起來特別累，有時每句都懂，連起來卻不知道在說什麼。

作者的猜想（焦點後置）：人類常把重點放在開頭，後面是補充，讀者認真讀前面一點，後面可以略過；AI 把烘托放前面、重點放後面，讀者不知道重點在哪，只好每句都從頭認真讀到尾。後置本身不算錯，例如漸進推情緒時就該後置，但用多了就累。

## 查到的研究

只列跟這個猜想有直接關係的。多數只讀到摘要或二手引述，細節沒核對原文。

| 研究 | 說了什麼 | 跟猜想的關係 |
|---|---|---|
| Kieras 1978/1980/1981（二手引述） | 段落第一句不管是不是主旨句，讀者都多花時間讀；問段落主旨時，讀者傾向選第一句，即使主旨其實在後面 | **支持**：讀者預設段首就是重點。主旨放後面時，前面那句已經被當成重點讀過了，後面得再讀一次 |
| Gernsbacher 結構建構框架、先提優勢 | 理解時先打地基，再把後面的資訊掛上去；句子裡先出現的人物在記憶中最容易取用，跟它是不是主語無關 | **支持**：開頭決定讀者拿什麼當地基。開頭是烘托，地基就打歪了 |
| Haviland & Clark 1974「舊－新資訊契約」 | 讀者先在記憶裡找舊資訊，再把新資訊掛上去；找不到就得自己搭橋推論，推論要花時間 | 句子的開頭應該接上讀者已經知道的東西 |
| 中文句末焦點（漢語資訊結構研究） | 中文單一小句的常規焦點在**句末**，新資訊往後放 | **修正猜想**：小句內部焦點在後是正常的。可以比的是多小句長句和段落：主要事件先出現，還是先鋪陳 |
| 環形句與鬆散句（修辭學；Christensen 1963 累積句） | 環形句把主句留到最後，製造懸念，讀者要讀完才知道主旨；鬆散句（累積句）先給主句再疊細節。英文寫作以鬆散句為常態，環形句用多了就失去力量 | **支持**：幾乎就是作者描述的那件事，連「可以用，但不能多」都一樣 |
| Miall & Kuiken 1994「前景化」 | 文體上偏離常規的段落（新奇比喻、反常搭配、修辭重複）讀得較慢，讀者覺得較醒目、較有情緒。跟文學素養無關 | **另一條路**：每一處新鮮寫法都會讓讀者減速。處處新鮮就處處減速，沒有地方可以滑過去 |
| Ferreira「夠用就好的處理」 | 讀者常只做部分理解，靠經驗法則，任務需要時才深讀 | **支持**：略讀是讀者的常態。文字要讓讀者知道哪裡可以略 |
| Zwaan 事件索引模型 | 讀者沿時間、空間、人物、因果、目的五個向度追蹤情境；時間、因果、目的、人物不連續時，閱讀時間上升 | 「推進」可以拿這個定義：哪幾句改變了情境 |
| Hyönä 等人（說明文眼動） | 有一類讀者專門抓主題句，回頭看的也是段首句；回看主旨句的時間跟記住重點正相關 | 段首句是讀者的導航點 |
| 資訊密度均勻假說、GPT-who 偵測器 | 用意外度（surprisal）的變異當特徵，可以分辨 LLM 文字和人類文字 | 間接：人類文字的資訊有高有低，LLM 較平。這是偵測器的結果，不是定律 |
| Reinhart 等 2025（PNAS） | 經指令微調的 LLM 名詞化用量是人類的 1.5–2 倍，文風資訊密集、名詞多 | 英文非虛構，只當旁證 |
| Villanova 讀者研究 2026 | AI 短篇更直接、更好讀，常把主題直接說出來；人類較含蓄。另一研究發現 AI 故事段落和句子較長、人類風格變化較大 | 小說旁證，跟「累」的方向不同，要注意 |

另外，本 repo 知識庫的「文句就是鏡頭」（`docs/新技巧知識庫/cards/文句就是鏡頭.md`）說的是同一件事的鏡頭版：句子決定讀者盯哪裡、盯多久。「重音放哪」（`cards/重音放哪.md`）問的是一段裡有幾處在喊「這裡重要」。`Data/【創作技巧】.txt` 的「對白、動作多斷句、用短句；描寫細節、敘述說明多用長句」是經驗法則，沒有研究支撐，不納入判讀。

排比給人壯闊感、調換語序給人不同感覺這類說法，查到的都是寫作建議，沒有找到受控研究，不納入判讀。

## 從研究推出的判讀表

判讀單位是段（原文一行）。每段判下列欄位：

1. **類型**：純對白／敘述／混合。
2. **焦點位置**：只判至少兩個小句、而且不是純對白的段。
   - **前**：第一個小句就交出這段的主事（新事件、新資訊、轉折），或明白告訴讀者這段在講什麼，後面是補充、細節或反應。
   - **後**：主事到最後一個或兩個小句才出現，前面是鋪陳、背景、氣氛或細節，讀者讀到前面時還不知道它們是為了什麼。
   - **平**：幾個小句地位相當，是並列或清單，沒有主從。
3. **前景化**：列出段內偏離常規、會讓讀者減速的寫法：新鮮比喻、反常搭配、刻意的修辭重複或節奏。只列原文字串。
4. **套語**：列出段內讀者熟到可以直接滑過去的現成說法（例如「寶相莊嚴」「一本正經」）。只列原文字串。
5. **重音段**：這段的主要作用是不是叫讀者停下來記一個點（短句收束、單行評語、單行反應）。
6. **推進**：這段有沒有改變情境（Zwaan 五向度任一，或新資訊）。沒有的就是烘托或重述。

## 預測

依作者的猜想：

- **P1 焦點後置**：Claude 稿「後」的比例比人類高，差距至少 10 個百分點，而且倍率至少 1.5。
- **P2 前景化**：Claude 稿每千字前景化較多，人類稿套語較多。
- **P3 重音**：Claude 稿重音段的比例較高。

讀法：P1 成立，焦點後置的猜想得到方向支持。P1 不成立而 P2 成立，表示累的原因不是焦點的位置，是每一處都要讀者減速（顯著性扁平）。
