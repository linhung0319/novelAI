# 段落判讀表

你要逐段判讀中文小說段落。每段都附了前段和後段當上下文，但**只判「本段」**。段落來自不同的文本，順序已經打亂，彼此不一定相關。每段獨立判，不要猜段落出自哪裡、誰寫的。拿不準時照定義選最接近的一項，不要留空。

每段判下列八個欄位。

## 1. type 類型

- `對白`：整段都在引號「」『』裡面。
- `混合`：有引號裡的話，也有引號外的敘述。
- `敘述`：沒有引號。沒加引號的內心話也算敘述。

## 2. focus 焦點

這段的**主事**是什麼：新事件、新資訊、轉折、這段要讓讀者知道的那一件事。問的是主事出現在段落的哪個位置。

先決定判不判：
- `不判`：純對白段，或整段只有一個小句（中間沒有逗號、分號、句號之類把它分成兩個以上的語塊）。

其餘的段選一個：
- `前`：第一個小句就交出主事，或第一個小句就明白告訴讀者這段在講什麼；後面是補充、細節或反應。
  - 例：「厚實寬大的手掌輕撫了一下孟奇的頭頂，一根根枯發在他眼前飄落，這讓他悲從中來……」主事（手掌撫頭）在第一個小句。
  - 例：「『哎呀，玄苦師弟，玄藏師兄，你們來得這麼早？』門口一胖大僧人笑嘻嘻迎了上來，同樣一襲黃衣，但衣領斜開，肚子腆著。」台詞和來人一起先出現，外貌是補充。
- `後舊`：主事到最後一兩個小句才出現，但前面放的是**讀者已經知道**的東西：時間轉場、回指上文、已經發生過的事。
  - 例：「交代完這些事情後，他和玄藏帶著這幫小沙彌離開了『雜物院』。」「交代完這些事情後」回指上文。
  - 例：「寬面大耳的玄苦一一詢問完剩下的孩童後，加孟奇、真慧一起，共有六人入雜役院，其餘則歸屬武僧院。」前面是讀者已經看過的過程。
- `後新`：主事到最後一兩個小句才出現，前面放的是**新的鋪陳**：讀者第一次看到的背景、氣氛、細節或人物狀態，讀到那裡時還不知道它們是為了什麼。
  - 例：「孟奇本來還在琢磨剃度該用什麼刀，這時卻瞪大了眼。」主事是「瞪大了眼」，前面是新的鋪陳。
  - 例：「低沉的聲音一次次響起，越來越近，身旁落髮的輕響也越來越近。枯黃的髮絲飄到孟奇膝前，他還沒想好該擺什麼表情，一隻乾燥而溫熱的手掌已按上了他的頭頂。」主事（手掌按頭）在最後。
  - 例：「孟奇正低頭整理衣帶，見他這副模樣，存心逗他，便揹起雙手，擺出師兄的架子，悠悠說道：『師兄我還不餓，你先去吧。』」主事是那句話，前面四個小句是新鋪陳。
- `平`：幾個小句地位相當，是並列、清單或一連串同等的描寫，沒有哪一個是主事。
  - 例：「房間不大，一張長長的通鋪佔了半邊，牆角擺著兩隻舊木櫃，窗紙破了個洞，透進一線昏黃的光。」
  - 例：「他一邊悄然感謝著僧衣穿戴簡單，自己不至於出乖露醜，一邊檢查著之前來不及審視的身上事物。」

分辨「後舊」和「後新」：問前面那幾個小句，讀者在讀到它們之前是不是已經知道了。知道就是後舊，不知道就是後新。

## 3. foreground 前景化

抄出段內**新鮮、偏離常規、會讓讀者放慢**的寫法：新鮮的比喻、反常的搭配、刻意的修辭重複或刻意的節奏。只抄原文字串，每處一條。沒有就給空陣列。

- 算：「布料粗得能當砂紙」「那肚子卻比胸膛挺得更快」「由黑轉黃，由黃轉枯」「像一隻被裝進麻袋的猴子」「步伐不快，幾步之間卻已走出老遠」「叫得毫不猶豫，毫無負擔，一點討價還價的意思都沒有」「頗有小學生要與壞同學劃清界限的意味」。
- 不算：讀者早就見慣的比喻和說法，例如「像兔子一樣竄到了門口」「餓死鬼投胎」。這些放到下一欄「套語」。
- 不算：只是具體的細節，沒有偏離常規（「腰帶繫得歪七扭八」只是描寫；它如果要讀者推出意思，放到「推論」欄）。

## 4. cliche 套語

抄出段內**讀者熟到可以直接滑過去**的現成說法：成語、四字格、慣用的比喻、網文常見的固定描寫。只抄原文字串，每處一條。沒有就給空陣列。

- 算：「寶相莊嚴」「一絲不茍」「一本正經」「鋸嘴葫蘆」「目不斜視」「栩栩如生」「鴉雀無聲」「像兔子一樣」「餓死鬼投胎」「老臉微紅」。
- 不算：普通的動詞、名詞、日常說法（「點了點頭」「走了進去」）。要是「現成的、帶修飾作用的說法」才算。

同一個字串不要同時放進前景化和套語。

## 5. inference 推論

段裡有沒有細節，讀者要**自己推出它的意思**才看得懂這段在說什麼，而文字本身沒有把意思說出來。有的話，每處給一條 `{"text": 原文字串, "meaning": 要推出的意思（15 字內）}`。沒有就給空陣列。

- 算：「臉上兀自印著兩道席子的壓痕」→剛睡醒。
- 算：「他沒有說話，只是看了看胖和尚的衣領，又看了看他的鞋」→玄苦在無聲責備他衣衫不整。
- 不算：意思直接寫出來的，例如「他不願意在這個問題上與玄苦糾纏，直接指著孟奇等人道」。
- 不算：意思一看就懂、不需要停下來想的動作（「點點頭」＝同意，「皺起眉頭」＝不滿）。
- 不算：本段或緊接的前後段已經把意思說破了。

## 6. stress 重音

這段的主要作用是不是**叫讀者停下來記住一個點**：短句收束、單行評語、單行反應、心聲的驚嘆。是就 `true`，不是就 `false`。

- 是：「穿越小說可不是這麼寫的。」「好嘛，一個自閉，一個高冷。」「上頭是鐵面鬼，直屬領導是這位，也不算壞到底。」「可玄苦離開，澄凈消失之後，孟奇的信念依然堅定，將來一定要還俗！」「玄苦的眉頭皺了起來。」（單行反應，單獨成段）
- 不是：單純推進動作的短段，例如「他一個轉身就飛跑了起來。」「眾人依著吩咐跪在蒲團上，向佛像磕了三個頭。」
- 不是：普通的短對白，例如「『隨我來。』」

## 7. setup 預告段

這段是不是**只負責宣告「下一段有事」**，事件本身留到下一段才演。是就 `true`，不是就 `false`。

- 是：「就在這時，通鋪上傳來一陣窸窣聲。」（真應起身出門寫在下一段）
- 不是：「這時，一直沉睡狀的真應猛地翻身坐起，麻利地穿鞋出門，看得孟奇一愣一愣。」（事件就在本段）
- 不是：一般的轉場句，如果這段自己也演了事情。

## 8. events 事件編號

**只有批次附了「事件清單」時才判。** 沒附清單時一律給空陣列 `[]`。

這段在演清單上的第幾條事件（整數）。演到兩條就列兩條，例如 `[5, 6]`。這段跟清單上任何一條都對不上（清單外的情節、或者跟這個故事根本無關的段落），給 `[]`。

- 對話、反應、內心話只要屬於某條事件的過程，就算那一條。
- 批次裡有些段落來自別的故事，跟清單無關，給 `[]` 就好，不必解釋。

## 輸出格式

輸出一個 JSON 物件，鍵是段落編號，值是八個欄位。每個段落編號都要有，不能多也不能少。

```json
{
  "P0001": {
    "type": "混合",
    "focus": "後新",
    "foreground": ["布料粗得能當砂紙"],
    "cliche": ["鴉雀無聲"],
    "inference": [{"text": "臉上兀自印著兩道席子的壓痕", "meaning": "剛睡醒"}],
    "stress": false,
    "setup": false,
    "events": [3]
  }
}
```

- `type` 只能是 `對白`、`混合`、`敘述`。
- `focus` 只能是 `前`、`後舊`、`後新`、`平`、`不判`。
- `foreground`、`cliche` 是字串陣列；`inference` 是物件陣列；`events` 是整數陣列。
- `stress`、`setup` 是布林值。
