# AI 腔成因實驗：預註冊

**寫於任何受測稿生成之前（2026-11-01）。** 事後對設計的任何偏離，要記在結果報告裡，不改這支檔。

## 要回答的問題

作者的觀察：AI 寫的小說讀起來怪，最明顯的是**重複自解釋**；另一個 Claude Code 專案（oh-story）也有同樣的病。兩個懷疑：

- **H1**：context 放太多造成的。
- **H2**：Claude Code 是為寫程式而做的，所以寫文章才這樣。

隱含理論：**實寫一章要吃很短的 context**。討論劇情、設計角色可以長 context，落筆時交給只吃一小段 brief 的 AI。

## 為什麼不能只跑「短 context 看還有沒有病」

1. **沒有對照就沒有因果。** 短 context 寫得好，可能是這次運氣好。同一個場景要有長 context 的對照臂。
2. **「量」和「內容」被綁在一起。** 舊系統的長 context 同時也塞滿了**意義**。實例：`细纲` 寫「必須寫清他知道會被看見，並且要的就是被看見」，正文就出現「他要的就是這個」。這是**第三個假設 H3**：病因不是量，是 brief 裡寫了「為什麼／讀者該感受到什麼」，而模型忠實地把它寫出來。所以量與意義要獨立操縱。
3. **「Claude Code」是兩個東西。** 外殼（寫程式用的 system prompt、工具、CLAUDE.md）和模型本身。H2 要拆開測。
4. **人類也會解釋。** 《一世之尊》原著第 2 章有「他并未暗示，直接說了出來」「他所指的正是孟奇和真慧」。不用人類文本校準的指標沒有意義。

## 設計

### 刺激（兩個場景）

- **S1 十七次**：取自 oh-story《典籍有誤》第 6 章。只有 AI 稿，沒有人類版本。
- **S2 空門**：取自《一世之尊》**人類原著**卷一第 2 章。事件清單從人類原文抽出，所以 AI 稿可以和原著逐場比。

### 主實驗：2×2（模型固定 Opus 5.5、乾淨外殼）

| | 只給事件 brief | 事件 brief ＋ 意義／意圖 |
|---|---|---|
| **短 context**（≈1 KB） | **A** | **B** |
| **長 context**（≈200 KB，真實管線檔） | **C** | **D**（最接近舊管線） |

- 意義句的來源：S1 取自 `细纲` 原句；S2 由人類原文反推，並用同樣的欄位口吻。
- 長 context 的內容：該書設定、大綱、前文、寫作規則與技法檔，全部是兩個專案真的會餵的檔。

### 外殼對照（H2a）

- **H**：與 A 相同的 brief，但走完整 Claude Code 外殼（預設 system prompt、工具、repo 的 CLAUDE.md）。A vs H 只差外殼。

### 本地模型（H2b）

- **QA／QB**：Qwen3.5-9B Q4_K_M，brief 同 A／B。
- **QC**：Qwen，事件 brief ＋ 長 context 截短版（顯存限制，≈40 KB，與 C 不等量，只做 Qwen 內部比較）。

### 樣本數

每格每場景 n=3。主實驗＋H＋Qwen 共 8 格 × 2 場景 × 3 ＝ **48 稿**。

### 基準語料（校準用，不受操縱）

- **人類**：《一世之尊》《詭秘之主》《極道天魔》《從紅月開始》《神秀之主》《我有一個修仙世界》各抽 2 段。外加 S2 的原文。
- **舊 AI 稿**：repo《一世之尊》、《消失的密室》、oh-story《典籍有誤》各抽數章。

## 量測（先訂好）

### 正規化

全部轉繁體（OpenCC）、引號統一成「」、去標題與註解標記。評分者看不到臂別、檔名、書名。

### 確定性指標（每千字，或比例）

| 代號 | 指標 |
|---|---|
| neg_contrast | 否定對比句「不是 X，（而）是 Y」 |
| explain_marker | 解釋標記（意思是／這就是／換句話說／其實／原來／他知道／他清楚／他明白……） |
| single_para | 單句成段的比例 |
| short_close | 段尾 ≤12 字短句（金句收尾）的比例 |
| numeral | 數字＋量詞的密度（假精確） |
| negation_gesture | 「沒有／沒」的密度（克制腔：沒抬頭、沒說話） |
| dialogue_ratio | 對白佔字比 |
| sent_cv | 句長變異係數 |
| expo_para | repo 既有 `prose_metrics` 的解說段候選數 |

### 盲評標注（claude-sonnet-5-5，一次看一篇，看不到其他稿）

每篇獨立標注，要附逐字引句，引句由程式核對存在於原文：

- **J1 自解釋**：敘述者把前文已足以推知的含義、動機或意義明講出來。
- **J2 重述**：同一個意思在短距離內換句話再講一遍。
- **J3 情節事件數**：場上真的發生、改變局面的事件。
- **J4 閒筆**：對當前衝突沒有直接功能、純為活人感的細節或對話。

引句核對不到的條目不計。評分者不被告知是 AI 還是人類。

### 最後裁判：作者本人

作者的語感才是病的定義。會產出盲讀包：每臂抽 1 篇加人類原文，打亂，對照表另存。**指標與作者的盲讀衝突時，以作者為準，並回頭檢討指標。**

## 判定規則

主指標 ＝ J1＋J2 每千字（下稱「自解釋率」）。

**先驗指標有效性（V）**：人類基準的中位數必須明顯低於舊 AI 稿（差距 ≥2 倍）。**V 不過，所有依賴這個指標的結論作廢**，只留作者盲讀。

- **H1（量）成立**：C 對 A 的自解釋率 ≥1.5 倍，且 D 對 B 也 ≥1.5 倍，兩場景方向一致。
- **H3（意義）成立**：B 對 A ≥1.5 倍，且 D 對 C ≥1.5 倍，兩場景方向一致。
- **H2a（外殼）成立**：H 對 A ≥1.5 倍。
- **H2b（模型）**：比較 QA 與 A。若 QA 也明顯高於人類基準，病不專屬於 Claude。
- **「短 context 治好了病」**：A 落在人類基準的範圍內（≤人類 P75）。**只比 D 好不算治好。**

n=3 只能看方向與量級，不做顯著性宣稱。落在 1.2–1.5 倍之間一律報「不確定」。

## 事前預測（供事後打臉）

我的預測：H3 > H1 > H2a。量本身的效果小，意義的效果大；但 A 仍不會落入人類範圍，因為模型預設就有這個腔。Qwen 也會有同型的病，因為它也是被訓練成「把事情講清楚」的助手。

## 已知限制

- Claude 的 CLI 無法設溫度，也無法把外殼完全移除；乾淨外殼實測仍有約 600 tokens 殘留。
- 評分者也是 Claude，可能對同門的腔調不敏感。人類基準與作者盲讀是對這點的制衡。
- 原著是長篇連載的中段，AI 稿是單次生成，風格可辨，所以盲評只做逐條計數，不做整體排序。
- Qwen3.5-9B 整體能力較弱，「較差」和「同型的病」要分開看。
- S1 的長 context 內含 AI 寫的前文，S2 的長 context 主要是分析檔與規則，兩者本質不同，只比較同場景內的差異。
