# 神秀之主實驗：結果

設計見 `00-設計.md`。24 篇稿在 `稿件/`，每章比較報告全文在 `比較/`，代號對照在 `代號對照.json`。

## 結論

1. **指示能讓 Claude 寫出能讀的網文，但寫不出這位作者。** 最好的稿「像同一位作者」6–6.5 分（原文基準 8 分）。
2. **最大的問題是我的指示把原文的腔洗掉了。** 我把半文半白的原文轉述成現代白話，模型就照那個語域寫，還常常逐字抄轉述句。
3. **同書片段對 Claude 有小幅幫助，對 Qwen 沒看出幫助。**
4. **Qwen 差距明顯。** 有指示語漏進正文、事件走樣、人稱和意思錯誤，部分稿件混入簡體字。
5. **Claude 的舊毛病換了形狀還在：** 包袱太密、反應鏡頭、段尾小收束、替讀者補邏輯，而且不同篇會想出同一批梗。

以上判斷來自隔離 subagent 逐句閱讀，並經我抽讀稿件確認。分數是單一讀者的印象，只能看方向。作者本人尚未閱讀。

## 分數

每格為「像同一位作者／好不好看」，滿分 10，原文當 8 分基準。每格兩篇。

## 原文有、稿件沒有的

| 原文做法 | 原文 | 稿件 |
|---|---|---|
| 敘述句自己開嘴 | 拿性命保證？他拿個頭去保證啊？ | ‘要我拿命保證？我拿什麼保證？……’＋他心裡暴躁得很，臉上還得陪著笑。 |
| 主角演老怪 | 好膽色，竟敢誆騙于我？ | 你在騙我。 |
| 打完就走 | 他輕輕一拍，兩名金丹老祖就口吐鮮血，落了下去。 | 元道人兩眼發直。‘這怎麼可能？……’鐘神秀沒理他，反手輕輕一拍。 |
| 過場省力，重複也無妨 | 此言一出，很多人都是滿臉失望之色。 | 就這麼幾句話，底下涼了一大片。 |
| 平淡句就讓它平淡 | 劉文棟大喜，跪在地上連連叩首。 | 也不知道到底該磕給誰，索性四面都磕了一遍。 |
| 容許粗糙 | 將旁邊的陳文霽都嚇傻了。 | 稿件的前段幾乎沒有這種隨手滑過的句子。 |

最有個人味的是這種小地方：「如果說普通金丹修士，只是孩童的話，那還丹之后，便是……成人了也！」。我把它壓平成「普通金丹好比小孩，到了還丹就是大人了」，8 篇就都沒有找回來。

## 稿件有、原文沒有的

- **跨篇共用的梗：** 第 400 章有起跑線、鞋磨爛十幾雙、祖墳冒青煙；第 425 章有集市挑牲口、懶洋洋、呱哈哈哈；第 367 章有「伊志松自己也沒見過經」。指示都沒有給這些。
- **反應鏡頭：** 打完必接一個表情，「全場鴉雀無聲」反覆出現。
- **段尾收束：** 「那才叫弄巧成拙。」「一陣風吹過，灰都散了。」寫法已明令禁止，還是出現。
- **替讀者補洞：** 解釋神通失靈時法寶為何還能用、陳文霽為何帶走蘇味、誰為什麼追得上。
- **主角換人：** 原文的鐘神秀張揚，會哈哈一笑、自稱本座；稿件常把他寫成懶得看人的現代酷哥。

## 指示本身的錯

這幾項是我的責任，不是模型的。

| 我寫的 | 後果 |
|---|---|
| 把對白轉述成白話（「對方不是來找麻煩的」「誰不怕」） | 被逐字抄進正文，「本座」「區區」「么」全消失 |
| 「仙俠術語和現代口語、粗話可以混在一起」 | 語域滑向現代段子。原文的俗是「呔」「忒」，還混著「乃是」「奈何」 |
| 「敘述交代」「敘述揭底」 | Qwen 直接寫進正文，例如「敘述揭底了。」 |
| 「這章的重點是……」 | 被當成內容寫進去，例如「語氣很輕鬆。」 |
| 點名李白、「兩根手指」、「它自己的道行也在燒」 | 這些是我自己加或改的，幾乎每篇照演 |
| 漏掉「連他自己都怕」「那樂子可就大了」和「還丹老怪，果然不差！」 | 主角只剩穩贏，少了自嘲和得意 |
| 寫法列全書通則，沒標本章用不用 | 模型當配額打卡。第 425 章原文沒有單引號獨白，稿件卻到處都是 |

下一版指示應改成：

- 事件只寫要點，對白只寫意圖，不寫可貼上的句子。
- 不用導演語言，刪掉「重點」段。
- 直接規定語域和速度：舊式評話詞與少量粗話混用；被打者不給反應，一件事一句話結束；大半句子是平的。
- 指明主角的戲服：自稱本座、帶半文言、會得意。
- 語域主要靠同書片段示範，不靠描述。

這些改法是讀稿後的推論，尚未驗證。

## 事前預測對帳

| 預測 | 結果 |
|---|---|
| Claude 守事件、AI 腔變少，但太精緻 | 大致對，還多了太賣力的問題 |
| IE 比 I 接近原文 | Claude 小幅成立；Qwen 沒看出 |
| Qwen 守事件但扁平 | 只對一半，事件也常走樣 |
| 指示寫明的笑點每篇都有，模型很少自己補活力 | 前半對；後半不完全對。Claude 會補活力，但都是自己的腔和共用的梗 |

## 限制

- 指示由我讀完原文後手寫，換人寫結果可能不同；每章每格只有 2 篇。
- 每章只有一位 AI 讀者，章與章之間的分數不完全可比。
- 讀者不知道模型和臂別，但 Claude 和 Qwen 的稿很容易分辨。
- 寫手 subagent 只讀了工作檔和寫出稿件（已查工具紀錄），但 subagent 本身仍帶約 5.6 萬 tokens 的基礎 context。讀者提到的幾處短語近似原文（如「擺脫掌控」），因此判斷是巧合或仙俠套語，不是偷看原文。
- 比較報告的引文用程式核對過，未命中的都是切字誤差或讀者自己提出的建議句，沒發現捏造引文。這個核對不是逐條人工確認。

## 與設計的偏離

- 比較用 subagent 不能寫報告檔。`比較/` 裡的全文是從它們的工作紀錄取出的。
- 開跑前發現指示有較長的片語和原文相同，先改寫後才產稿。
