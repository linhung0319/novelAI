# 神秀之主實驗：設計

動筆前寫定。不使用本專案的 skill、舊實驗程式、刪句或統計評分。

## 問題

只給「怎麼寫出這一章」的指示，不給該章原文，模型寫出來的稿和真人原文差多遠？差距在哪裡？

## 材料

- 實驗章：第 367 章（內心戲、算計）、第 400 章（群像、揭底）、第 425 章（多人打鬥、罵街）。
- 風格片段：只取第 408、444 章，兩章都不參與實驗。
- 指示由 Claude Code 讀原文後逐章手寫，內容集合先前實驗和網路資料的做法：
  - 只給事件和人物行為，不給可照抄的意義句。
  - 人名、法寶、數字給足。
  - 寫法描述的是這位作者的實際做法。
  - 明確避開已知的 AI 習慣：替讀者解釋、用身體反應寫情緒、段尾金句、章末收束。
- 指示不得含該章原句，專名和固定詞語除外。寫完用程式核對這件事，只核對事實，不評品質。

## 臂

| 代號 | 給什麼 |
|---|---|
| I | 指示 |
| IE | 指示＋第 408、444 章片段 |

| 模型 | 跑法 | 每格篇數 |
|---|---|---|
| Claude | 隔離 subagent，只讀工作檔 | 2 |
| Qwen（qwen3.5:9b） | 本機 ollama，同一份提示 | 2 |

每章 8 篇，共 24 篇。產出直接使用，不刪句、不修改、不重跑；Qwen 若混入簡體也照留，只在報告註明。

## 比較

每章一個隔離 subagent，讀原文、該章指示和 8 篇隨機代號的稿。它不知道模型和臂別，但會讀到指示，以判斷問題是指示造成的還是模型自己的。判斷以逐句閱讀為主，必須引用原句。

## 事前預測

1. Claude 能照事件順序寫，AI 腔比前幾輪少，但原文的粗糙活力、碎嘴和說書腔仍難追上，容易寫得太精緻。
2. IE 比 I 更接近原文，因為片段是同一作者。
3. Qwen 會守事件，但語言扁平、接近摘要，片段的幫助小於 Claude。
4. 指示裡寫明的笑點會出現在幾乎每一篇，指示沒寫的活力很少被模型自己補出來。
