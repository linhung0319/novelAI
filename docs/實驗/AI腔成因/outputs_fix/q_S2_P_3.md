這大殿裡靜得可憐，空氣彷彿都凝滯了。六個被選中的孩童排成一列，低著頭，只有腳尖不安地踢著地上的青磚。我——孟奇，此刻正穿著那身土黃色的粗布衣裳，心裡暗罵玄苦這個老色鬼兼大專職，這判罰也太狠了吧？堂堂少林，竟讓我這種「雜役」去伺候那些連狗都不如的掃地僧人。

我轉頭看向帶我來的黃衣僧人玄藏。那傢伙一臉慈悲相，可剛才在殿上他明明就站在玄苦旁邊，一副看戲的樣子。我看著他搖了搖頭，眼神裡透著股「這事沒得商量」的無奈。果然，他開口了：「師父既已判下，弟子無權更改，一切照辦便是。」

老實說，我聽得耳朵都聾了。這玄藏大概是覺得自己很公正？還是單純懶得管閒事？

玄苦和尚慢吞吞地繼續問話，最後一個名字念完，六人正式入雜役院。其他人倒是還算幸運，進了武僧院，看來在少林寺混口飯吃也不容易，得看師父心情和自身福報了。

一行人被帶到小佛堂拜佛。這佛堂裡香火不算濃，佛像也顯得有些陳舊。玄苦手按在每個孩童的頭頂上，動作極慢，像是在進行某種古老的儀式。他口中念念有詞：「煩惱落盡，紅塵遠離。」說得倒是口沫橫飛，我看他那滿臉皺紋下的眼睛，彷彿能看出些許禪意，但更多的是對我們這些小沙彌的漠視。

輪到我了。玄苦的手按在我頭頂時，我感覺一陣涼風拂過，頭髮竟真的枯黃飄落幾縷下來。這什麼鬼把戲？我還以為是心理作用呢。玄苦輕聲低語，聲音在空蕩蕩的佛堂裡迴盪，讓我忍不住打了个寒顫：「紅塵遠離……唉，離紅塵有多遠說不準，但離挨罵肯定不遠。」

接著便是領東西的環節。兩套僧袍、一雙鞋襪、還有一本厚厚的戒律冊子。玄苦講解著主要戒律，什麼「不殺生」、「不偷盜」之類，听得我頭皮發麻。最讓我在意的是他特意強調了僧袍顏色的分別：武僧院穿紅褐色，雜役院穿黃灰色。這顏色區分得也太明顯了吧？是不是故意羞辱我們這些進來的？

「記住，穿著這身衣服，就要守著這規矩。」玄苦語氣平淡，卻透著一股不容置疑的威嚴。

他交代完便讓我們自行前往分配的禪房。我隨眾人走到偏僻角落的雜役院入口處時，管事胖僧玄心已經衣衫不整地迎了出來。那傢伙一看就沒啥好脾氣，穿著破爛袈裟，肥肉抖個不停。玄苦皺眉看向他，顯然對這種行為很不滿。

就在這時，一旁的玄藏忽然開口：「玄心師兄，孟奇與真慧需與真應、真觀同屋。」

這話一出，現場氣氛瞬間尷尬起來。玄苦瞪了玄心一眼，訓了一頓無關痛癢的話後，便和玄藏離開了。

玄心看著他們走遠，終於鬆了一口氣，抖著肥肉說：「總算走了！最怕那個鐵面鬼！」

我站在門口，心裡暗笑：「什麼鐵面鬼？我看是鐵齒吧？」不過嘴上不敢多言，只能跟著大家走進禪房。

禪房裡佈置簡單，四張床並排擺著。真應躺在上鋪發呆，真觀坐在下鋪冷冷地看著我們，只簡報了名字就沒再多說半句。我轉向那個呆呆的小胖子真慧，他正愣愣地看著窗外飛過的蝴蝶。

「師弟，你叫什麼？」我笑著問。

「真……真慧。」他結結巴巴地回答，眼神清澈卻帶著點困惑。

「那以後叫我師兄吧！」我說得輕鬆自然，試圖拉攏氣氛。

說罷，我們開始換上僧衣。我仔細檢查身上隨原主帶來的物品：一枚玉佩和胸口的玉佛墜子。這兩樣東西在現代大學時我還以為只是飾品，沒想到在這裡成了重要信物。我將它們小心收好，心想：「看來這趟穿越之旅不是那麼簡單啊。」

換好衣服後，真應突然起身推門而出，打斷了我們的對話。真觀淡淡地說：「晚膳時間到了，還不去？」

「對哦！」真慧竄到門口，回頭問我：「師兄不去嗎？」

我故意拖著腳步，開玩笑說：「我還不餓呢，再歇會兒。」其實肚子早就咕咕叫了，但面子還是要撐著的。

真慧認真地點點頭，轉身就跑出去了。我一看情況不妙，立刻大喊：「喂！真慧別跑那麼快！」然後起身追了出去。

走廊裡燈火昏暗，我們幾個小沙彌嘻嘻哈哈地往食堂走去。雖然剛剛經歷了一番波折，但此刻的氛圍卻莫名輕鬆起來。看來在少林寺這個地方，即使身份低微如雜役，也能找到屬於自己的溫暖角落。

我一边跑一边想：「這輩子算是徹底跟過去告別了……希望以後别再遇到什麼奇怪的事情吧！」
