夜風捲著灰塔學院特有的塵土味，從後坡的廢料堆裡鑽出來，帶著一股陳舊的紙張和燒焦墨跡混合的氣味。奧倫蹲在亂石叢中，手指撫過手中那塊殘破的符文板。這是他今夜挑選的第七塊。

父親死的那天，也是這樣一個寒冷的冬夜。抄寫員被處決的消息像瘟疫一樣在學院裡傳開，但沒人知道這意味著什麼。對於奧倫來說，這意味著他再也無法像父親那樣，用那雙佈滿老繭的手去觸摸那些完美的符文了。現在，他是地下謄抄司的一名少年雜役，唯一能做的就是在廢棄的符文中尋找還能引動一次的殘料。

他的眼睛裡藏著一個無人知曉的秘密。當旁人看著那些刻錯或損壞的符文時，看到的是灰撲撲、毫無生氣的石頭；而在奧倫眼中，那些失敗的符文呈現出漆黑的顏色，像是一道道深不見底的裂縫，透著死寂的寒意。只有那些尚未完全失效、還能勉強引動一次符文的殘料，才在他的視線裡呈現出淡淡的灰白，那是最後一絲機緣的證明。

他選紙的方法沿襲了父親留下的舊法：對著斷面呵一口氣，看呼出的白霜在符文刻痕處停留多久。霜化得快，代表符文已近油盡燈枯；霜化得慢，甚至凝結成冰晶再緩緩融化，才是尚可一用的好料。他挑了一夜，數九個寒暝，終於從這座巨大的廢棄山崗裡撿出了七塊這樣的殘料。

天剛蒙蒙亮，奧倫將這些寶貝藏進貼身的懷袋裡，開始收拾工具。他把工作地點定在了北坡小路旁的一塊平整大石上。這條路是學院裡的動脈，每天兩趟學徒會從這裡去藥圃採集材料。而在西邊，有一處背風的凹地，那裡積著昨夜未融的雪，寒冷卻安靜，適合他進行那種需要極度專注的工作。

奧倫坐下來，拿出第一塊符文板。這是一塊殘缺的小石板，上面刻著一個不完整的「引燃」符紋。他從懷裡掏出最細的刻刀，開始了一點一滴地試角度。這不是簡單的雕刻，而是要在原有損傷的基礎上，找到那個能觸發最後反應的精確切入點。他的呼吸變得極其微弱，生怕呼出的氣息會干擾石頭內部的能量流動。

第一塊板子在他手裡顫抖，每一次下刀都像是在與死神博弈。當刻到第八次時，石板突然發出「咔噠」一聲輕響，順著一道細微的暗傷裂開了一道縫。那是符文結構崩潰的前兆。奧倫沒有停手，他看著那道裂紋在晨光中閃爍，彷彿看見父親被處決時那條黑色的痕跡在他眼前放大。

白天的陽光透過樹葉灑在北坡小路上，斑駁的光影晃動著。兩個學徒正三兩成群地往藥圃走去，他們穿著整齊的制服，談笑聲在風中傳得很遠。其中一個叫賽拉斯的學生停在了奧倫面前。他皺著眉頭，看了看這塊破石頭和正在忙碌的少年雜役。

「這是在幹什麼？」賽拉斯問，語氣裡帶著幾分嫌棄，「地下謄抄司已經禁止私自處理廢料了。」

「我……我只是在挑選能用的東西。」奧倫低聲回答，手裡的刻刀沒有停下。

賽拉斯站了一會兒，似乎覺得這種場景有些礙眼，又有些好奇，但他最終還是搖了搖頭。「算了，別弄出什麼亂子來。」他轉過身，跟班立刻跟了上去。沒走幾步，那個跟班回頭看了一眼，用鞋尖毫不客氣地把奧倫身邊的一塊殘料撥了下去。那塊石板滾落坡下，混進碎石堆裡，消失了身影。

奧倫低下頭，默默地去撿回那塊石板。他的手指沾上了灰塵和石粉，但眼神依然專注。「沒關係，」他自言自語道，「只要還沒完全變黑，就還有機會。」他將石板放回膝蓋上，繼續刻著剛才的中斷處。角度要更精確一些，速度也要更快一些，因為每一次失敗都在消耗他僅存的耐心。

夜幕再次降臨時，奧倫已經完成了第四、第五和第六塊符文的處理。現在只剩下最後一塊了，而第二夜過後半夜，第二塊板子在第十七次刻劃後突然亮了起來。那是一點微弱的光，像螢火蟲一樣在石頭表面流動了一瞬，隨即又黯淡下去。奧倫用炭筆在石頭上劃了一道記號，記錄下這個時刻。他不知道為什麼要這樣做，或許只是為了提醒自己不要在同一個位置重複錯誤，或者是在尋找某種規律。

白天到來時，他和往常一樣下到地下三層，謄抄三十頁那些永無止境的文字。在那裡，空氣更加潮濕，霉味更重，但他卻能聽見上方傳來的一些聲音——那是學生們在走動的聲音，是老師講課的聲音，是整個學院運作的節奏。他知道自己只是其中一個微不足道的小齒輪，隨時可能被碾碎，隨時會被拋棄。

到了第三夜，奧倫的手指已經裂開，鮮血順著指縫流下來，滴在他腳邊的石頭上。那紅色的血跡在灰暗的環境裡顯得格外刺眼。他的鼻子也不爭氣地流起血來，血絲掛在下巴上，滴落在刻刀柄上。他沒有擦拭，只是繼續工作。第三塊符文板一直不亮，無論他是怎麼調整角度，怎麼嘗試不同的力度，石板都像是一塊死寂的廢鐵，拒絕任何能量的注入。

「為什麼……」奧倫喃喃自語，聲音沙啞。他的眼睛發紅，視線有些模糊，但他依然能看見那塊不亮的符紋呈現出一種奇怪的顏色——不是完全的黑色，也不是灰色，而是一種詭異的深紫，彷彿在暗示著某種未知的危險。他不知道這是什麼意思，只知道父親教導他說：「符文有靈，不可強求。」

天亮時，奧倫終於停下了手中的工作。他抬頭看向北坡小路，陽光刺得他睜不開眼。同班的米蘭達站在小路上，她穿著潔白的法袍，手裡拿著一本書，正注視著他。她的眼神清澈而平靜，像是一潭湖水，映照著奧倫滿身血污和疲憊的身影。

「你起來了嗎？」米蘭達問道，語氣中帶著幾分驚訝，「我看見你昨晚還在這裡。」

奧倫愣了一下，抹去臉上的血跡，苦笑了一下。「嗯，」他回答，聲音輕得像風中的落葉，「我在挑選廢料，希望能找到最後一塊能用的符文。」

米蘭達走近一步，看著他那雙佈滿裂紋的手，眼中閃過一絲不忍，但她沒有說話，只是轉身繼續往前走。奧倫看著她的背影消失在樹林後，心中湧起一股複雜的情緒。他知道自己的秘密已經快要守不住了，那個能把刻錯的符文看成黑色的能力，或許就是命運對他的懲罰，亦或是某種徵兆。

他撿起那塊一直不亮的第三塊符文板，仔細地檢查著它表面的裂紋。在晨光中，那道裂紋似乎正在擴展，像是一張大網，即將將他困住。奧倫深吸一口氣，再次拿起刻刀，準備開始新的一輪工作。不管前方是什麼，他都要繼續下去，直到最後一刻。
