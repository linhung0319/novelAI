大殿之上的空氣凝重得彷彿能滴出水來，無數雙稚嫩卻充滿驚恐與鄙夷的眼睛齊刷刷地投向孟奇。這些都是和他一般大的小沙彌，他們穿著整齊的灰色粗布僧袍，腰間束著同樣規整的束帶。在孟奇看來，那些眼神就像是在看一個被丟棄的垃圾，或是什麼不潔之物，帶著毫不掩飾的嫌惡與幸災樂禍。

孟奇沒有出聲，他只是低垂著頭，目光落在自己腳尖前那塊粗糙的地磚上。他試著回憶原主的記憶，卻是一片模糊的空白。只知道自己叫真定，來自一個不知名的地方，然後就到了這個少林，站在了這裡。至於為什麼會被判入這最低賤的雜役院，他並不清楚，或許是某種天資的評斷，又或是命運開了一個玩笑。

轉過頭去時，恰好撞見帶他前來的黃衣僧人玄藏。那人身材魁梧，面容嚴肅，此刻正微微搖著頭，目光掃過滿殿眾人，最後落在玄苦身上，口型動了動：「一切照大師決定。」

孟奇心中莫名湧起一股蒼涼感。玄苦坐於高位之上，神色淡漠地看著下方這六個孩童，聲音平淡無波地宣佈最終結果：「真定入雜役院，其餘五人，皆入武僧院。」

隨著那冷冰冰的判決，一行七人緩緩走出大殿。兩側的建築巍峨壯觀，飛簷斗拱直指蒼穹，卻顯得格外肅殺。走在前面的是玄苦，身後跟著神色各異的幾個小沙彌，而最後面便是那個一直保持沉默、內心卻如亂麻般的孟奇。

一路行來，沿途的僧侶弟子投來的目光有好奇、有譏諷，也有漠不關心。唯有玄藏始終走在玄苦身側，一言不發，偶爾用衣袖掩住口鼻，似是不願沾染半分雜氣。

來到一處偏僻的小佛堂前，這裡遠離了主殿的喧囂與香火鼎盛，空氣中多了一絲陳舊的檀香味和淡淡的灰塵味。玄苦停下腳步，轉身看向眾人。他抬起寬厚的手掌，逐一按在每個孩童的頭頂之上。

輪到孟奇時，玄苦的手掌略顯粗糙，掌心帶著常年握念珠留下的老繭與熱度。當那手掌觸碰額髮的一瞬，幾根枯黃的頭髮應聲飄落，掉落在灰色的僧袍上，顯得刺眼異常。

「煩惱落盡，紅塵遠離。」玄苦低沉地說道，語氣中帶著一種近乎機械化的慈悲與疏離，彷彿只是在完成一項宗教儀式，而非針對一個活生生的生命。

孟奇靜靜地承受著，沒有掙扎，也沒有反駁。他知道，從踏上少林這一步開始，他就已經死了，現在站在这里的，只是一具被借來的軀殼，一個名為真定的廢人。

領完東西後，玄苦轉身面向眾人，開始講解基本的規矩與戒律。「這身僧袍顏色不同，代表著不同的身分。」他指了指自己和玄藏身上整潔明淨的黃袍，又指了指武僧院弟子們的灰色長衫，最後目光落在孟奇那套佈滿塵埃、縫線鬆散的灰褐粗布上：「黃衣者為長老，白衣者為武僧，灰褐者為雜役。你們需記住自己的身分，莫要張狂。」

接著，他將兩套新的衣物——一疊皺巴巴的布頭、一雙磨損嚴重的草鞋、幾塊洗得發白的襪子，以及一本泛黃的戒律冊子遞給孟奇。「這是你的物件。雜役院雖苦，卻是修行之地，若能於勞碌中悟道，亦不虛此行。」

孟奇雙手接過那些東西，指尖觸碰到的布料粗糙如沙紙。他將玉佩從衣領後取出，仔細端詳片刻，然後收進懷中貼身的內袋；又摸到胸口那枚溫潤的玉佛墜子，那是前主唯一的信物。他深吸一口氣，將兩者一同妥當收起。這世間萬千浮沉，如今只餘下這方寸之地可寄身了。

一行人繼續前行，終於來到了雜役院的入口。這裡的建築簡陋破舊，牆壁斑駁，屋檐下有蜘蛛網結成的絲線在風中輕輕搖曳。門口站著一個胖僧人，名叫玄心。他衣衫不整，袖口沾著油漬，腰間還掛著幾個空酒壺，見玄苦等人來臨，慌忙迎上前去，臉上堆滿了討好的笑容，只是那笑容裡藏著一抹不易察覺的怯意。

「哎呀，大師您來了！」玄心搓著手，肥肉顫抖著，「這些年頭，雜役院的日子也不好過啊……」

玄苦皺了皺眉，目光如刀般掃過玄心身上凌亂的衣裳，冷冷道：「這裡不是酒肆，莫要失了威儀。」

就在此時，黃衣僧人玄藏忽然開口，聲音不大卻清晰有力地響起：「玄心師兄，將真定與真慧安排到與真應、真觀同一間禪房吧。其餘幾人各自為伍。」

玄苦微微一怔，隨即點頭道：「也好，雜役院人多口雜，同屋者彼此照應，倒也省得麻煩。」說完，他便對玄心訓誡了幾句，語氣稍緩後便與玄藏轉身離去。

玄心看著兩位大和尚的背影逐漸消失，終於鬆了一口氣，整個人像是被抽走了骨頭般癱軟在門口，雙手抖著肥肉喃喃自語：「總算走了……這鐵面鬼真是嚇人！剛才那眼神，簡直要殺人啊！」他低聲嘟囔著，眼角余光卻瞥向屋內角落那两个瘦削的身影。

孟奇換上那身嶄新卻破舊的僧袍，站在禪房門口打量四周。這間屋子不大，四壁空空，只有一張簡陋的木床和一張小桌。靠牆邊躺著一個小胖子，頭髮稀疏，眼神呆滯，正是真慧。他正發著呆，似乎還沒從剛才的驚嚇中恢復過來。

「你……也是新來的嗎？」孟奇走到胖子身邊，輕聲問道。

胖子愣了一下，慢慢轉過頭來，眼睛眨了眨，結結巴巴地說：「是、是啊，我叫真慧。」

「以後叫我師兄吧。」孟奇溫和地笑了笑，盡量讓語氣聽起來自然些。

真慧似乎有些緊張，又像是因為長期營養不良導致表情呆滯，只是點點頭，不敢多話。

這時，另一個少年走了進來，他靠在門框上，神色冷淡，目光掃過屋內的三人，淡淡道：「我是真觀。」

他的聲音清冷，像是在念誦經文，沒有太多情緒波動。孟奇注意到他手中握著一根簡單的木棍，那是雜役弟子常用的工具，用來清理寺院周邊的草叢或搬運重物。

真應則已經躺在床鋪上，雙手枕在頭下，閉目養神，彷彿對周遭的一切都不感興趣。房間裡靜悄悄的，只有微風吹動窗簾的聲音。

孟奇走到窗邊，看著外面灰蒙蒙的天空和遠處層疊的屋頂，心中一片茫然。他摸了摸懷中的玉佩，那溫潤的觸感讓他感到一絲安寧。這裡是少林，是武俠世界的中心之地，但他卻覺得自己像是一個局外人，格格不入。

「師兄，你不餓嗎？」真慧突然打破沉默，聲音裡帶著一絲期待與不安。

孟奇轉過頭，看著這個天真無邪的小胖子，忍不住開玩笑道：「我還不餓呢，再等等吧。」

真慧認真地點點頭，似乎真的以為師兄是不想吃飯，隨即轉身跑向門口，邊跑邊回頭喊道：「那我去了！」

孟奇看著他小小的背影消失在走廊盡頭，忍不住大笑着追了上去：「喂！真慧你等等我啊！」
