少林大雄寶殿內，煙燭搖曳，梵音低迴。空氣中浮動著一股混合了檀香與舊書紙張的氣息，莊嚴肅穆，卻又帶著幾分孩童特有的喧囂。

孟奇睜開雙眼，入目的是一張雕樑畫棟的大殿，四周跪坐著數十名稚齡僧童。他下意識地摸了摸自己的頭頂，觸感光滑，卻無髮絲，心中暗自驚嘆：這具身體眉清目秀，皮膚白皙勝過女子，粉雕玉砌的模樣極似富家貴種，哪裡有半分乞兒的寒酸相？

記憶如潮水般湧來——熬夜看球賽，睡著後穿越，成了這少林雜役院的小和尚，法號真定，年約十二三歲。原身的記憶一片空白，唯有一顆現代人靈魂還在腦海中高速運轉。他很快發現自己胸口懸掛著一塊溫潤的玉佩，衣襟處還別著一枚玉佛墜子，這兩件寶貝在穿越前似乎一直伴隨在原身身上，如今成了他唯一的依仗。

玄苦大師端坐於殿上，身著黃衣，鐵面無聲，目光如電，掃過下方眾人。他剛才的判詞猶在耳邊迴響：「既入少林，俗名已忘。機心太重，入雜役院，法號『真定』。」

那「機心太重」四字，似是一枚烙印，精準地擊中了玄苦這位鐵面執事的心防。孟奇心中暗自苦笑，面上卻不動聲色，微微低頭，露出一副恭順怯懦之姿。他知道自己穿越成這樣一副富貴相，若表現得太清醒、太機敏，只怕更容易引起注意。在這個弱肉強食的武俠世界，暴露實力或心思，往往是災禍的開始。

「玄藏師兄，」玄苦的聲音低沉冷硬，打破了殿內的寧靜，「其餘孩童，六人入雜役院，餘者入武僧院。」

孟奇順勢抬眼，看見一位身披黃袈裟、面容慈悲的僧人正站在殿門處。那人正是帶他進來的玄藏。玄藏對著玄苦微微頷首，眼中帶著一絲無奈與同情，搖了搖頭，示意一切照舊。

一行人魚貫而出，來到殿後的小佛堂。這裡陳設簡陋，僅供拜佛誦經之用。玄苦盤腿坐在蒲團上，雙手合十，神色莊嚴。他緩緩站起身，一步步走到那些小沙彌面前。

「煩惱落盡，紅塵遠離。」

玄苦口中念誦，右手按在第一個孩童的頭頂。隨著他手掌落下，那孩童頭頂的頭髮竟如枯葉般飄落數根，顯現出僧侶剃度的儀式感。輪到孟奇時，玄苦的手掌落下，動作略顯遲緩。孟奇心中警覺，表面上卻緊張地低著頭，不敢接話。

隨後，眾人領了兩套僧袍、鞋襪和戒律。玄苦語速極快地講解了主要戒律，又提點道：「僧衣顏色各有分別，灰衣為一般僧人，黃衣為執事，方丈、首座和長老則穿黃衣披紅袈裟。你們切記，不可僭越。」

孟奇暗自记下這些信息，尤其對「輩分排字」也仔細聽聞：「心空無玄真，清淨智慧深」。他是「真」字輩，上一輩為「玄」，再上為「無」，更上是「空」。這套輩分制度，他得好好背熟，免得日後惹禍。

一行人被帶往雜役院。這處院落位於寺廟偏僻角落，環境破舊，牆壁斑駁，與武僧院那氣派建築形成鮮明對比。玄心——雜役院的管事，衣衫不整地迎了出來。這人肥胖圓滾，肚子上的肥肉隨著走動晃蕩，臉上堆著誇張的笑容，說話時還不忘吹牛：「哎喲，歡迎新兄弟來雜役院！我玄心雖胖，卻是真心待客……」

玄苦皺眉，冷聲打斷：「玄心，莫要胡言亂語。」

玄心嚇得臉色一白，肥肉抖了抖，連聲道謝：「是是是，謝謝玄苦大師。」

玄藏忽然開口，插話道：「玄心師兄，將真定與真慧安排與真應、真觀同屋可好？」

玄苦聞言，看向玄藏，點了點頭，不再多言。他轉身訓話幾句，隨即與玄藏一同離開。

玄心見兩位大人物走遠，鬆了口氣，抖著肥肉對孟奇笑道：「小兄弟，以後這裡就是你的家了！有什麼事儘管找哥哥我！」

孟奇心中暗自評估此人，表面卻裝作惶恐：「不敢不敢，玄心師兄大恩大德，真定銘記在心。」

眾人來至禪房。房間內佈置簡單，四張床鋪並排。真應躺在床上發呆，神情渾濁；真觀則坐在角落，冷冷地報了名字，態度冷淡。只有真慧，一個呆頭呆腦的小胖子，正興奮地打量著新環境。

孟奇換上僧衣，仔細檢查身上的玉佩和胸口的玉佛墜子，收好後，才開口道：「真慧師兄，以後我們便是師兄弟了。」

真慧愣了一下，憨笑出聲：「師兄好！」

真應突然起身，穿鞋出門：「我去外頭走走。」

真觀淡淡道：「晚膳時間到了。」

真慧竄到門口，回頭問：「師兄們不去嗎？」

孟奇開玩笑道：「還不算餓。」

真慧認真點頭，自己跑了出去：「那我去找師兄們！」

孟奇看著真慧離去的背影，輕笑一聲，也大步跟了上去：「慢著，師弟！」

走廊上，夕陽西下，拉長了眾人的影子。孟奇心中思緒飛快轉動：這少林看似莊嚴，實則暗藏玄機。玄苦鐵面無情，玄心肥胖愛吹牛，真應真觀性格迥異，而真慧則是個可憐的呆子。他自己穿越而來，身懷現代知識，卻要藏鋒露拙。

他摸了摸胸口的玉佛墜子，心中默念：「既入少林，便得守規矩。機心太重，反成累赘。從今起，低調行事，步步為營。」

風吹過屋檐，簷鈴輕響，彷彿在提醒他，這一生之尊的旅程，就此開始。
