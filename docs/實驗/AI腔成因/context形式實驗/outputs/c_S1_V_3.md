敲過晚鐘，守坡的老頭回了棚屋，灰塔學院的後坡便只剩下風聲，以及廢料堆裡偶爾滑落一塊碎板的輕響。

奧倫蹲在廢料堆的背陰面，撿起一塊巴掌大的石板，掰掉一角，把斷面湊到嘴邊，呵了一口氣。

一層薄霜貼著斷口浮了起來。

「一，二，三，四……」

數到四，霜化了，他把石板丟向左手邊，又撿起下一塊。

這是抄寫員驗紙的辦法。符紙存放久了，外表看不出好壞，裡面那點力有沒有散盡，只有對著裁開的斷面呵一口氣才知道：力還在，就會吸走氣息裡的熱，凝成霜，力越足，霜化得越慢。父親教他的時候，他才七歲，站在謄抄司的紙架前呵得滿紙都是口水，被父親用筆桿敲了一下額頭。數到二十的是上等紙，數到十二的還能用，再少，就裁了包東西。

至於石板和木板該數到多少，沒有人教過他，畢竟沒有人會去驗廢料。奧倫只能先找來幾塊確實燒過、已經發白的板子當底，再一點一點往上比，直到後半夜，才認定石板要數到九，木板要數到七，大概還夠引動一次。

這數字多半有猜的成分，但他也沒有別的數字可用。

廢料堆裡的東西，大半是學徒刻壞的。在別人眼裡，那只是一堆帶著灰白刻痕的碎料，在奧倫眼裡，所有刻錯的筆畫卻都是黑的，比夜色更黑，層層疊疊鋪了半面山坡，就像誰往坡上潑了一整缸墨。這件事他從未對任何人說過，父親在世時沒有說，父親被處決以後，就更不會說了。

可惜黑色與力沒有關係，他只能一塊一塊地呵過去。呵到嘴唇發麻，呵到東邊的天色開始泛青，右手邊一共只攢下七塊，五塊石板，兩塊木板。

奧倫把它們裝進麻袋，先去了西邊。

學院西牆外有一處凹地，三面是土坎，風吹不進，離廢料堆不過兩百步，舊年燒炭的人還留下半截矮灶，坐在裡面，手指很快就能恢復知覺，從早到晚也不會有人經過。他在矮灶邊坐了一會兒，把這些好處逐一算過，覺得凹地的壞處其實只有最後那一條。

然後他站起身，扛著麻袋翻過坡脊，去了北邊。

北坡小路旁有一塊平石，桌面大小，正對風口，沒有半點遮擋。學徒們每天要從這條路去藥圃兩趟，早上一趟採藥，午後一趟澆水，無論如何都得從離平石不到三步的地方走過去。

奧倫把七塊殘料在石頭邊排好，取出那把磨短了的裁紙刀，拿起第一塊。

引燃符是學徒入門的第一道符，三筆，兩個夾角，見於典籍第一卷第三頁。這一頁奧倫抄過不下四十遍，每一遍，那兩個夾角明明是赭紅的顏料，落到他眼裡都成了黑色。學徒們照著刻，十塊裡亮一兩塊，教習說這是手還不穩，再練。

奧倫知道問題不在手，但黑色只告訴他錯了，從不告訴他對的在哪裡。

所以只能試。第一個夾角放一度，刻完，看，黑的，用刀把板面刮平；收一度，刻完，看，還是黑的，再刮平。第一個角試過一輪，又去動第二個角。每刮一次，板子便薄一層，到了第八次，刀尖剛走到第二筆中段，石板輕輕響了一聲，順著一道先前看不見的暗傷裂成兩半。

他對著新的斷口呵了口氣，霜沒有浮起來。

「還剩六塊……」

奧倫把兩半石板擱到一旁，拿起第二塊。

太陽升起來之後，灰袍的學徒們提著竹籃上了小路。有人放慢腳步，有人回頭，有人笑了一聲，也有人壓低聲音問：「那是謄抄司的吧？」「他在刻什麼？」「你不知道？他父親不就是——」話說到這裡，大概是被同伴碰了胳膊，後面便聽不見了。

奧倫沒有抬頭。

午後那一趟，賽拉斯走在最後，竹籃由跟班替他提著。他在平石前停了下來，先看了看板子，又看了看奧倫手裡那把裁紙刀，就這樣站了一會兒，什麼話也沒有說，抬腳走了。

跟班落後兩步，經過時伸出鞋尖一撥，石頭邊的三塊殘料便滑下了坡，磕在亂石上，一路蹦跳著滾遠。他甚至沒有低頭看。

奧倫等腳步聲遠了，才放下刀，往坡下走。

北坡又陡又滑，枯草底下全是碎石，他找了小半個時辰，最後一塊卡在荊棘根底，伸手去掏時，手背被劃開了兩道。回到平石上，他對著三塊殘料逐一呵氣，數到十一，數到九，數到八——那是一塊木板，還夠。

他把它們放回原來的位置，連順序都沒有改動，然後重新拿起了刀。

第二夜比第一夜更冷，風從坡頂直灌下來，燈是不敢點的，好在月亮還算亮。奧倫已經不太記得自己試過哪些角度，只好每刻一次，就在心裡把兩個數字念上一遍，就像抄書時默念頁碼。第十四次，黑的。第十五次，黑的。第十六次，刀滑了一下，不用看也知道是黑的。

後半夜，月亮偏到了西邊，他刻下第十七次的第三筆，收刀，習慣性地等著那兩個夾角變黑。

它們沒有變。

奧倫以為自己眼花了，揉了揉眼睛，又把板子舉到月光底下。刻痕仍是新鑿開的石頭那種灰白色，除此之外，什麼顏色也沒有。

沒有黑！

他屏住呼吸，把拇指按上符心，將那口憋了許久的氣緩緩吐出去，同時引動。

噗的一聲，一粒黃豆大小的火苗從第三筆末端跳了出來，晃了晃，燒了約莫三次呼吸的工夫。石板隨即褪成灰白，火滅了，拇指上留下一點刺痛。

奧倫想笑，可是臉早已凍僵，沒有任何反應。

這點火，大概連燈芯都點不著，教習看見了，恐怕還要問一句是不是火星子……他這樣想著，從麻袋裡摸出一截炭條，在平石右上角劃了一道。

比典籍窄兩度，寬四度。他把這兩個數字又念了三遍，才拿起第三塊。

天亮以後，他照樣下了地下三層。

謄抄司的三十頁是按頁計的，只要傍晚交得上，管事不會過問他什麼時候下去，所以他等學徒們早上那一趟走完，便順著七十二級石階往下走，走進那股終年不散的潮氣和燈油味裡。今天要抄的是一卷舊符譜，翻開第一頁，裡面就有不少筆畫黑得發亮。謄抄司的規矩是一筆不差，原本怎麼畫，副本就怎麼畫，於是那些黑色的角度便從他筆下一個一個爬到了新紙上，端端正正，分毫不改。

抄到第十九頁時，他打了個盹，筆尖在紙上拖出一點，這一頁只能作廢，三十頁就成了三十一頁。

交稿的時候，管事翻了翻，看了一眼他的手，沒有說話。

第三夜，奧倫原本以為會很短。

他把那兩個數字原樣刻到第三塊石板上，收刀，黑了。

同樣的角度，換了一塊板子，黑了。

他盯著那幾道刻痕看了很久。也許和石紋的走向有關，也許和刻痕的深淺有關，也許第二塊根本就是碰巧……這些他全都答不上來，典籍上也不會有，他只好刮平板面，從頭試起。

半夜起了霜，右手的拇指和食指開始開裂，起初只是刀柄有些滑，後來才發現滑的是血。他撕下一截衣襬纏上，沒過多久，布條也浸透了。不知什麼時候，鼻腔裡忽然一熱，一滴血落在板上，不偏不倚，正落在第二筆裡。奧倫用袖子抹了一把鼻子，拿刀尖把血剔乾淨，刮平，再刻。

第二十三次，黑的。第二十九次，黑的。中途他對著斷面呵過一回氣，霜還在，數到九，比昨晚少了一點。板子卻已經薄得能透出指頭的影子了。

第三十八次，黑的。

東邊的坡脊上亮起一線青白，風停了，四周忽然安靜下來。奧倫放下刀，血已經把手指和刀柄黏在一起，他費了點力氣才掰開。他想活動一下僵硬的脖子，於是抬起了頭。

小路上站著一個人。

是米蘭達，同班的米蘭達，兩隻手攏在袖子裡，頭髮上凝著一層細細的霜水。這個時辰，離學徒們第一趟去藥圃還早得很，奧倫不知道她已經站了多久。

她沒有看他的臉，目光越過那塊薄得發亮的石板，落在平石右上角那道炭痕上。
