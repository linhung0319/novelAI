他把粉在袍角上擦掉，換一塊碎片，再刮一次。這一塊的粉粗些。兩塊他都留下了，因為他分不出來。
他看了很久。
看不出來。這一塊可能能用，也可能刻到第三十筆就裂。上一次他就是這麼撿的，四十塊裡要是有一半是這種，七日根本不夠。
他把那塊碎片握在手裡，站起來，往坡上走。
走了二十來步，他撿到一塊不一樣的。
那塊上頭刻著半個符文，刻到第九筆斷了，斷口是新的。坡上這種東西不多，大多數殘料是燒過三遍的爐渣，這一塊是有人刻壞了直接扔上來的。
符文在他眼裡是黑的。黑的位置在第三筆。
他蹲在那裡，把它翻過來又翻過去。
二百步寬的坡，天黑之前他走不完三分之一。往東是藥劑系倒的，往上是誰倒的他不清楚，走錯一邊就是白走一夜。他手上這塊板能回答這個問題，前提是他肯付錢。
三注。今天剩下的抄書份額要靠手熬。
他往那一格裡看。
黑往裡陷下去，變成一個方向。指針指著起筆的角度偏大，和課堂教材上那一格指的是同一邊。
照這本教材刻的人，只有符文系的學徒。
鼻血下來的時候他已經在往上走了。血滴在袍子前襟上，他沒有擦。東邊那三分之二不用去了。
整片坡地在他眼前黑下去。遠處學院的燈一盞一盞亮起來，亮在他背後，照不到這裡。
他蹲下去，接著撿。

奧倫將最後一塊篩選好的殘料揣進懷裡，那塊石板在他掌心溫熱，卻帶著一種即將崩潰的寒意。這是他在地下謄抄司最後的篩選，明日便是處決他父親的忌辰，學院裡流傳著父親臨死前試圖偷學禁忌符文的消息，雖然他奧倫從未在父親口中聽過半分真話，但那些輿論像瘟疫一樣在學院牆縫裡滋長。他必須在夜裡完成所有準備，因為白天的目光太尖銳，容不得絲毫差錯。

他收好工具，熄滅了最後一盞煤油燈，鑽進了位於學院最北端、被眾人所忽視的廢料堆。這裡堆積著無數被判定為劣等或過時的符文板，散發著陳舊的墨汁和灰燼味。奧倫沒有點燈，他習慣了在黑暗中工作。他的工作地點定在了北坡小路旁的一塊平石上，那裡背風，且距離藥圃僅有一箭之地，學徒們每日兩趟經過此路去採集藥草，是唯一的生路與干擾源。

他開始呵氣。對斷面呵氣，數霜多久才化，這是抄寫員驗紙的舊法，用來判斷板材的濕度與導電性。奧倫的手指在無數塊碎裂的石板上遊走，指尖傳來細微的顫抖，那是長期暴露於低魔環境與極度疲勞的結果。他挑了一夜，直到東方的天際泛起魚肚白，才從那亂石堆中剔出七塊看起來尚可的殘料。

其中一塊，他在上面刻下了一道引燃符的起筆線。符文在他眼中呈現出濃郁的墨黑色，如同活物般在紙面上蠕動。他開始嘗試角度，第一刀落下，石屑飛濺。他屏住呼吸，等待反應。時間一分一秒流逝，石塊表面沒有任何光暈湧動，只有他掌心的汗漬讓石板變得濕滑。刻到第八次時，原本完整的符文裂紋順著暗傷延伸，整塊板子無聲無息地裂開，像是一張笑臉。奧倫沒有驚呼，只是默默地將碎塊拼湊起來，用衣角擦掉手上的灰塵，繼續刻下一塊新的。

白天有學徒經過看他。賽拉斯來了，他是符文系高階學徒，穿著潔白的長袍，與奧倫身上那件沾滿灰塵的破袍形成鮮明對比。賽拉斯站了一會兒，眼神裡帶著一種居高臨下的憐憫，彷彿在審視一隻受傷的老鼠。「還在這裡？」賽拉斯問了，語氣裡沒有問候的意思。奧倫沒有回答，只是低頭看著手中的石板。賽拉斯的跟班見狀，用鞋尖把奧倫腳邊的一塊殘料撥了下坡。那塊殘料滾落幾步，被奧倫眼疾手快地撿了回來。他重新擦淨，繼續刻。賽拉斯冷哼一聲，帶著跟班走過了。奧倫知道，無論他們怎麼驅趕，只要還有石板能引動，他就必須待在這裡。這是他唯一的生路，也是他父親教他的最後一課——在絕境中尋找機會。

第二夜，後半夜。奧倫坐在平石上，手裡的第二塊板子終於在第十七次嘗試時亮了起來。那是一點微弱的光，像螢火蟲在深淵中閃爍，但對於奧倫來說，這已是神蹟。他用隨身攜帶的炭筆在石頭上劃了一道記號，那是一塊「可用」的標記。光暈擴散，照亮了他滿臉的疲憊，也照亮了手中那塊即將碎裂的石板。他沒有慶祝，只是輕輕放下石板，繼續處理下一塊。

第三夜，手指裂開，鮮血順著指縫流下，滴在石板上。奧倫沒有停手，鼻血也跟著流下來，滴落在袍子前襟上，他沒有擦。第三塊石板一直不亮，無論怎麼調整角度，無論怎麼呵氣，它都像是一塊死物。他開始懷疑自己，懷疑這世間是否還有能引發魔力的板材，懷疑父親死前是否真的嘗試過偷學禁忌符文。但他沒有停下，因為他知道，一旦停下，這七日就不夠了。

天亮時，他抬頭，同班的米蘭達站在小路上。米蘭達穿著藥劑系的制服，手中捧著一籃新鮮採集的藥草，目光在奧倫身上掃過，最後落在奧倫手中那塊尚未完成的石板上。她的表情複雜，有驚訝，有恐懼，也有一丝不易察覺的同情。「你還在這裡？」她問，聲音很輕，卻在寂靜的廢料堆裡清晰可聞。奧倫沒有回答，只是將手中的石板藏進懷裡，那上面還沾著他的血。他站起身，拍了拍袍子上的灰塵，準備離開這個廢料堆，回到地下三層繼續他的抄書工作。
