灰塔學院的地下三層，空氣裡永遠浮動著一股陳舊的墨汁味與乾紙的酸澀。奧倫·維斯將最後一頁抄寫完畢，墨跡未乾，他沒有像其他人那樣立刻起身去交卷，而是先用那隻食指第二節有厚繭的右手，輕輕刮去指腹上蹭到的黑灰。那圈繭厚得像老樹的痂，是他父親賈里德·維斯生前留下的烙印，也是他如今生存的工具。

「再試一次。」奧倫低聲自語，聲音沙啞，像被砂紙磨過。

謄抄司的規則簡潔而殘酷：抄錯一字，淨誤庭問責；廢紙一張，焚毀登記；人身一出司門，搜身如防賊。奧倫是這裡的三等雜役，抵債他父親的命。雜役無配額，無符文課，連符文材料都要靠自己撿。

他背起那個磨得發亮的舊書箱，袖管挽了三折，露出消瘦的小臂，獨自走下螺旋樓梯，離開了喧囂的抄寫區。

後坡的廢料堆位於學院北牆外，那裡堆滿了被視為垃圾的斷字殘片。夜風從斷壁間穿過，吹得人皮肉生疼。奧倫蹲在一處背風的凹地，從箱底倒出一些半燒焦的紙片。這是他的「礦場」。

他沒有用那些昂貴的驗紙術，而是學了抄寫員最笨的法子：對斷面呵氣，數霜多久才化。若能引動一次，便是好料。

奧倫屏住呼吸，對著一塊殘破的符文板呵出一口白氣。寒氣凝結，紙面上的微塵在月光下靜止。他目不轉睛地盯著那團白霜，時間一分一秒過去，霜跡開始縮小。

第一夜，他挑了整整一晚，從滿地的廢紙中篩選出了七塊還帶著微弱靈氣的殘料。天剛亮，他將這七塊材料搬來北坡小路旁的一塊平石，那是他固定的工作位。路邊有兩條常規路線：一條通往藥圃，是學徒們每天兩趟必經之地；另一條往西，則是通往後山的背風凹地。奧倫選在了北坡，因為那裡人來人往，熱鬧能壓過恐懼。

他開始在第一塊板上刻引燃符。符文刻刀在他指間飛舞，動作熟練卻帶著一絲緊繃。每刻一刀，他都必須確認角度，力道要均勻，呼吸要平穩。

第一塊板，刻到第八次時，板子突然發出一聲細微的裂響，順著暗傷處的紋路崩開了一道口。奧倫手一抖，刻刀掉在地上。他沒有慌張，只是彎腰撿起碎片，用拇指指甲刮了刮食指上的繭，那裡有些發紅，但他不在乎。

「再試一次。」

白天，他照樣下到地下三層，在謄抄司裡機械地抄寫三十頁，用那種近乎麻木的動作填滿時間。只有在回到後坡的深夜，當四周安靜下來，他才真正開始「工作」。

第二夜，後半夜。奧倫手中的第二塊板子已經刻了十七次。每一次刻刀落下，他都感覺指尖傳來一陣熟悉的刺痛，那是符文材料中的殘留靈氣與他自身精神碰撞的結果。

終於，在第十八刀落下時，板子發出清脆的爆鳴聲，一道淡金色的光弧順著刻痕蔓延，整塊殘料煥然一新。奧倫長舒一口氣，額頭上沁出了冷汗。他迅速從懷中掏出一塊黑炭，在平石上劃了一道記號，那是「十七」，代表這次嘗試的次數。

這道記號在月光下顯得格外刺眼。奧倫看著它，心中湧起一股難以言喻的衝動，但他強忍住了。他不能慶祝，更不能停頓。

手指在裂開，鮮血順著繭的邊緣滲出，滴落在石板上，混入黑色的墨灰中。鼻子裡也是一熱，溫熱的血液順著鼻孔流下，洶湧而出，染紅了下巴。奧倫沒有伸手去擦，他只是繼續握著刻刀，眼神專注於第三塊板子。

第三塊板子始終沒有反應。無論角度如何調整，無論嘗試了多少次，它就像一塊死寂的石頭，沒有任何光亮。奧倫試了又試，從子時試到雞鳴，手指已經麻木得失去了知觉，鼻血也流到了衣領上，但他依然堅持著。

他有一種能力，一種無人知曉的天賦。在普通人眼中，這些殘料只是普通的廢紙，但在他眼中，符文、配方和條文裡出錯的部分會發黑。那是「勘誤」的第一層，一直開著，關不掉。他能看到那些隱藏在紙面上的裂痕、錯別字和靈力斷層。而他還有一層能力，叫「溯因」。凝視黑斑，可以看見偏差的方向，但這需要消耗三注精神力，每一次使用都會伴隨著劇烈的頭痛和大量的鼻血。

他已經付了三次，三次都留在了這裡，三次都沒有離開。

天光微亮，奧倫終於停下了動作。他抬頭，看見小路上站著一個人影。

是米蘭達·奧塞。她是維倫王國奧塞男爵的次女，丙級學徒，務實、算得清，說話總是先報價。她穿著乾淨整齊的學徒袍，手裡捧著一本書，正冷冷地看著奧倫。

「維斯。」米蘭達的聲音很冷，像地下室的風。「你在這裡多久了？」

奧倫沒有回答，只是指了指石板上那道用炭劃下的記號，又指了指自己手上的血痕。

米蘭達皺了皺眉，顯然對這個滿身墨汁和血跡的少年感到不適。「雜役沒有配額，抵債也不能折成配額。你這樣做，只是在浪費時間。」

「再試一次。」奧倫終於開口，聲音輕微卻堅定。

米蘭達冷哼一聲，轉身準備離開。她的跟班，一個身材壯碩的少年，正蹲在路邊吃著乾糧。看到奧倫還在石板上擺弄那些廢料，跟班不屑地笑了笑，伸出腳，用鞋尖將石板上那塊尚未完成的殘料撥了下去。殘料滾落斜坡，消失在廢料堆的深處。

奧倫低下頭，撿起那塊殘料，拍了拍上面的灰塵，然後繼續對著新的材料呵氣。他的眼神沒有絲毫波動，彷彿剛剛發生的事根本不存在。

米蘭達走了幾步，又停下了腳步。她看著奧倫那隻受傷的右手，指節上帶著墨，眼白偏紅，像是一個在黑暗中行走的孤獨者。她沒有再說話，只是冷冷地注視著他，然後轉身走遠。

奧倫繼續他的工作。他從廢料堆中撿起新的殘料，用溯因判斷方向，付了三注精神力，流了鼻血，確定東邊不必去，就留在坡上繼續撿。

灰塔學院的夜，永遠不會結束。奧倫·維斯在後坡的廢料堆裡，用抄寫員驗紙的辦法，數霜多久才化，挑選還能引動一次的符文殘料。他挑了一夜，挑出七塊。他把工作地點定在北坡小路旁的一塊平石上，學徒每天兩趟從這條路去藥圃，而西邊另有一處背風的凹地。他開始刻引燃符，一度一度試角度，第一塊板刻到第八次時順著暗傷裂開了。白天有學徒經過看他。賽拉斯來站了一會兒就走，他的跟班用鞋尖把殘料撥下坡，奧倫下坡撿回來，繼續刻。到了第二夜後半夜，第二塊板在第十七次亮了，他用炭在石頭上劃了一道。白天他照樣下地下三層抄三十頁。第三夜他手指裂開、流鼻血，第三塊一直不亮。天亮時他抬頭，看見同班的米蘭達站在小路上。

奧倫沒有抬頭看她，只是繼續手中的動作。他將刻刀重新握緊，指節因為用力而泛白。他看著那塊剛剛裂開的殘料，又看向手中新的材料。

「再試一次。」

他低聲說道，然後開始了新的刻劃。陽光灑在灰塔學院的牆壁上，將影子拉得細長。奧倫的影子投射在廢料堆上，像是一個孤獨的守護者，守著這些被遺棄的符文，守著他心中那個永遠不完美的世界。

他不知道自己的命運會如何，也不知道父親的死因是否會有真相。他只知道自己必須活下去，必須完成這三年的抵債期，必須在謄抄司的規則下找到一條出路。

他不知道的是，他的能力正在逐漸覺醒，而灰塔學院的陰影也即將籠罩過來。但此刻，他只知道一件事：再試一次。

奧倫繼續著他的工作，直到夜幕再次降臨。
