夜裡的灰塔學院，空氣裡總帶著一股陳舊紙張與墨汁混合的霉味，那是屬於地下三層謄抄司特有的氣息。奧倫獨自坐在後坡的廢料堆旁，周圍堆積著從正廳撤下的舊符板。這些板子大多已被判定為「刻錯」，按照學院規定，应当直接焚毀或研磨成粉。但奧倫知道，在那些看似無用的廢料中，殘留著尚未完全失效的引燃符文。

他屏住呼吸，從懷中摸出一塊從抄寫員那兒偷來的薄紙，對著其中一塊符板的斷面輕輕呵氣。這是最古老的驗紙法，透過氣溫變化誘發結霜，再細數霜層融化的時間長短，便能判斷符文內部的魔力流動是否穩定。若能支撐一次以上的引動，這塊廢料便有了重生的價值。

奧倫挑了一夜。月光慘白地灑在他嶙峋的肩背上，他的手指因為長期接觸粗糙的板面而佈滿老繭，卻異常靈敏。他將那些還帶著微弱氣息的殘料一一標記，最終從數不清的廢墟中挑選出了七塊。每一塊都像是沉睡的星火，只要一點引信，便能再次燎原。

天亮時，奧倫將工作地點定在了北坡小路旁的一塊平石上。這條路是學院學徒每天兩趟往返藥圃的必經之處，人來人往，卻也有它的規律。西邊另有一處背風的凹地，那裡避開了清晨的涼風，陽光能直直射入，是進行精細手工活的最佳場所。奧倫將七塊符板小心翼翼地排列在石面上，開始了他獨屬的「雕刻」工作。

他拿起刻刀，屏息凝神，第一塊板子上的符文在刀尖下微微顫動。他需要找到那個剛剛好的角度，讓魔力在符紋的裂痕處重新聚合，而非引發爆炸。刻刀在石板上劃出一道道淺痕，每一次輕觸都是一次試探。第一塊板子刻到了第八次，原本穩定的符文突然順著一道暗傷裂開，發出細微的滋滋聲，隨即黯淡下來，像是被掐斷了喉嚨的螢火蟲。奧倫沒有驚慌，只是輕輕將裂開的碎片拼湊好，繼續在旁邊的位置落下第十一次刻痕。

白日的喧囂逐漸逼近，學徒們開始沿著北坡小路走動。奧倫低著頭，手中的刻刀彷彿有了生命，自動避開了那些路人的視線。賽拉斯帶著他的跟班從路過，賽拉斯駐足看了一眼，眼神中帶著幾分詭異的好奇與憐憫，那是對「地下老鼠」特有的輕蔑。他站了一會兒，似乎想聽聽這少年在低吟什麼咒語，卻什麼也沒聽到，只是走了一會兒便轉身離開。

然而，他的跟班並沒有那麼客氣。那少年伸出鞋尖，毫不猶豫地將奧倫剛剛調整好位置的幾塊殘料撥向了坡下的泥濘。石頭滾落的聲音在寂靜的坡道上格外刺耳。奧倫連頭都沒回，只是順勢彎腰，在殘料即將觸地前將其撿了回來，拍了拍上面的灰塵，繼續在石板上刻劃。他的動作絲毫沒有停頓，彷彿那被踐踏的符板不過是些無生命的石頭。

第二夜，後半夜的風更冷了。奧倫的手指因為反覆的運刀而泛紅，第二塊板子在第十七次嘗試時終於亮了。一道微弱的流光在符紋中閃過，那是一種近乎虛幻的藍光，照亮了奧倫沾滿墨汁的側臉。他用炭筆在旁邊的石頭上劃了一道痕跡，記錄下這一刻的成功。那是他今晚的第七塊，也是最後一塊有望完成的作品。

白天的地下三層依舊是忙碌的謄抄現場，奧倫混在人群中，表面上跟班上的其他人一樣抄寫著三十頁枯燥的法典，實際上他的心早已飛到了北坡的小路上。他必須在眾目睽睽之下保持低調，一旦被发现是在進行這種「違規」的實驗，等待他的將是嚴厲的處罰，甚至更糟。

第三夜，手指已經裂開，鮮血染紅了指紋，流鼻血更是家常便飯。第三塊板子一直不亮，無論他如何調整角度，符文始終像是一團頑固的霧氣，無法凝聚成光。奧倫看著手中漸漸變得模糊的符文，眉頭緊鎖，他不敢再輕舉妄動，生怕一次錯誤的嘗試會引發不可預料的爆炸。

天亮時，奧倫抬頭，陽光刺眼得讓他不得不眯起眼睛。他看向北坡的小路，那裡站著一個熟悉的身影——同班的米蘭達。她穿著整潔的制服，手裡拿著一本書，正注視著他所在的方向。奧倫迅速將殘料藏進懷中，低著頭走了過去，避開了她的目光。他知道，秘密一旦被看見，就再也無法完全掩藏，但他必須繼續走下去，為了父親，也為了這座充滿謊言的學院裡，那一點點微弱卻不屈的火光。
