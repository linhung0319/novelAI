「機心太重」四個字落下，大殿裡靜了片刻。

幾個小沙彌悄悄抬起眼，朝孟奇望來。有人好奇，有人害怕，也有人看得出鬆了口氣，彷彿在慶幸挨罵的不是自己。

孟奇跪在蒲團上，面上一派平靜，心裡早已翻了天。

不是吧？不記得名字，總比胡亂報一個被當場拆穿強。他還以為那句「俗名已忘」答得頗有慧根，說不定能博個滿堂彩，哪知道這位執事不吃這一套。

雜役院是什麼地方，他還不清楚，可單聽名字也知道不是什麼好去處。

孟奇轉過頭，看向站在一旁的玄藏。這位黃衣僧親自帶他上山，一路上雖然話少，倒也算照應。這具身體眉清目秀，細皮嫩肉，一看就是富貴人家養出來的，說不定有人打過招呼。此時不拉這根線，更待何時？

他沒敢開口，只拿一雙眼睛望著對方，盡量望得可憐些。

玄藏迎著他的目光，輕輕搖了搖頭。

「此事一切照玄苦師兄的決定。」

孟奇暗嘆一聲，收回目光。

這條路走不通，那就記下來，以後再說。

玄苦沒有多看他，繼續問下一個孩童。他問話極短，有時問俗名，有時問來意，孩童答話時若是結巴哭鼻子，他的臉色也不見半分變化。一個瘦高的孩子答說想學武，將來不受人欺負，去了武僧院；一個虎頭虎腦的答得響亮，也去了武僧院。

輪到一個小胖子時，玄苦問他為何上山。

小胖子張著嘴想了半天，答道：「爹說，這裡有飯吃。」

殿上有人忍不住吸了口氣，又趕緊憋回去。

玄苦面無表情：「入雜役院，法號『真慧』。」

真慧？孟奇瞥了那小胖子一眼，見他還呆呆張著嘴，顯然沒聽明白發生了什麼，心裡不禁嘀咕，這法號取得倒是頗有勉勵之意。

等全部問完，連孟奇在內共有六人入雜役院，其餘的都進了武僧院。兩撥孩子分立左右，一邊挺著小胸脯，一邊垂頭喪氣。孟奇站在垂頭喪氣的那一邊，努力把胸口挺得不高不低，免得又被人看出什麼機心來。

隨後，玄苦領著眾人轉入後方一座小佛堂。

佛堂不大，燭火搖曳，檀香的氣味濃得化不開。佛像低眉垂目，半隱在昏暗之中。孩子們依次跪下，跟著磕頭禮拜，孟奇也規規矩矩磕了下去，順帶在心裡念了一句：佛祖在上，晚輩初來乍到，保佑我多活幾年。

玄苦走到第一個孩童面前，伸手按在他頭頂。

沒有剃刀，也沒有清水。只見那孩子的頭髮迅速失去光澤，由黑轉黃，乾枯如秋草，隨即一綹綹飄落下來，露出青白的頭皮。

「煩惱落盡，紅塵遠離。」

玄苦的聲音平平淡淡，孟奇的眼睛卻已瞪圓了。

這就是武功？

他前一刻還把這裡當成一座規矩森嚴的古寺，此刻才真切地意識到，這個世界跟他熟悉的那個不一樣。一隻手就能讓頭髮枯死，要是再多用幾分力呢？他摸了摸自己的脖子，覺得還是不要往下想比較好。

孩童一個接一個落髮，地上漸漸積起枯黃的碎髮。那隻手終於移到了孟奇頭頂。

掌心乾燥，並不沉重，卻有一股溫熱透進頭皮，又麻又癢。孟奇繃著身子，連大氣也不敢喘，只看見幾縷枯黃的頭髮從眼前飄下，打著旋兒落在膝邊。

「煩惱落盡，紅塵遠離。」

手掌移開，頭頂一陣涼意。

孟奇偷偷摸了一把，光溜溜的，手感還不錯。他苦中作樂地想，往後洗頭省事了，也不必擔心掉髮。上輩子熬夜看球，最怕的就是這個。

出了佛堂，一名灰衣僧人已備好東西，每人領到兩套僧袍、兩雙鞋襪，外加一本薄薄的戒律。孟奇翻開瞄了一眼，還好，字認得，就是看著頭疼。

玄苦站在廊下，目光掃過眾人。

「戒律需熟讀熟記。不得殺生，不得偷盜，不得淫邪，不得妄語，不得飲酒。不得私自下山，不得同門相殘，不得偷學武功。犯戒者，自有戒律院處置。」

他語氣毫無起伏，孩子們卻聽得縮起了脖子。

「僧袍顏色各有分別。尋常僧眾著灰衣，執事著黃衣，方丈、首座與長老著黃衣，披紅袈裟。見之須行禮，不得失了規矩。」

孟奇默默記下。灰衣可以套近乎，黃衣要低頭，看見紅袈裟就繞路走，要是繞不開，就站到路邊，把腰彎得低一些。至於玄苦這樣的，最好連影子都別碰上。

一行人抱著衣物出發，由玄苦和玄藏領著往後山方向走。起初還是青石鋪地、殿宇相連，遠處傳來整齊的呼喝聲，想必是武僧在操練。走著走著，呼喝聲遠了，殿宇矮了，青石板也變成了踩得發硬的泥土路。路邊出現了柴垛、水缸和一畦畦菜地，空氣裡飄著淡淡的煙火氣。

孟奇越走心越涼。這地段，放到前世也是鐵定賣不出價錢的。

路的盡頭是一片低矮的院落，牆皮斑駁，院門半掩。一名小僧探頭看了一眼，慌慌張張地跑進去，裡頭隨即響起一陣雜亂的腳步聲。

片刻後，一個胖大和尚匆匆迎了出來。他邊跑邊繫僧袍的帶子，衣襟還是歪的，一隻鞋只趿了一半，臉頰上印著幾道壓出來的紅痕，渾身肥肉隨著腳步一顛一顛。

「玄苦師兄、玄藏師兄！怎敢勞動兩位親自過來，貧僧有失遠迎，有失遠迎！」

玄苦的眉頭皺了起來，目光在他歪斜的衣襟上停了一停。胖和尚乾笑兩聲，手忙腳亂地拉了拉衣襟，結果把另一邊也拉歪了。

「玄心，這六人交給你了。」

「是，是，師兄放心。」

一路都沒說話的玄藏忽然開口：「玄心師弟，真定和真慧，便安排與真應、真觀同屋吧。」

孟奇心裡一動，抬眼看去。玄藏神色淡淡，並沒有看他。

剛才在殿上一句話不肯多說，這會兒卻特意來安排住處。是照顧，還是另有用意？真應、真觀又是什麼人？他把這兩個名字牢牢記下，面上仍是一副什麼都沒聽懂的模樣。

玄心連連點頭，也沒問緣由。玄苦這才轉向六個孩童，聲音依舊冷硬。

「挑水砍柴，掃地燒火，皆是修行。在雜役院勤勉者，日後未必沒有前程；懶惰懈怠、心思不正者，少林也容不下。好自為之。」

說到「心思不正」時，他的目光似乎從孟奇臉上掠了過去。孟奇立刻垂下眼簾，老老實實合十行禮。

玄苦不再多言，與玄藏轉身離去。

玄心弓著腰，一直目送那兩道黃色身影消失在小路盡頭，又等了好一會兒，這才直起身子，長長吐出一口氣，滿身肥肉跟著抖了三抖。

「終於走了！佛祖保佑，我這輩子最怕的就是這鐵面鬼！」

孩子們呆呆地望著他。玄心大概也覺得失了威嚴，咳嗽一聲，挺起肚子：「咳，也不是怕，是懶得與他計較。想當年，我玄心在寺裡也是響噹噹的人物，只是淡泊名利，才來管這雜役院。你們跟著我，算是有福氣了。」

孟奇差點就信了，如果他沒看見那隻還趿在半路上的鞋的話。

玄心喚來小僧領走其他四人，自己則帶著孟奇和真慧繞到院子東側，隨手一指其中一間禪房，說了句「就是這兒，明早有人叫你們幹活」，便打著哈欠走了，看方向是要回去接著睡。

孟奇推開門。屋子不大，光線昏暗，靠牆擺著四張窄床，除此之外幾乎別無他物。兩個穿灰衣的少年已在屋內，一個仰面躺在床上，直勾勾盯著屋頂，彷彿那裡刻著什麼絕世武功；另一個坐在床沿，抬眼看了過來，眼神冷得跟井水差不多。

孟奇立即掛上一臉笑容，合十道：「小僧真定，這是真慧師弟，今日初來，還請兩位師兄多多關照。」

坐著的少年看了他片刻，吐出兩個字：「真觀。」

然後就沒有了。

孟奇等了等，確定真的沒有了，便轉向床上那位。那位連眼珠都沒動一下。

行吧。那這位就是真應了。孟奇收起碰了一鼻子灰的笑容，挑了張靠裡的空床放下東西。回頭一看，小胖子還抱著衣物傻站在門口，圓圓的光頭上泛著油光。

孟奇招招手，把他叫過來，壓低聲音：「你今年幾歲了？」

真慧想了想：「不知道。」

「那你看，方才落髮，是我先還是你先？」

真慧又想了想：「你先。」

「這就對了。先入門者為師兄，以後你得叫我師兄。」

「師兄。」真慧答得毫不猶豫，聲音憨憨的。

這麼好騙？孟奇倒有點不好意思了，心裡卻莫名地鬆了鬆。來到這個世界以後，總算有個人能讓他覺得不必時時提防。

他背過身去換僧袍。灰布粗糙，磨得皮膚有些發癢，大小倒還合適。換下舊衣時，他從裡頭摸出那塊玉佩，握在手裡細細看了看。玉質溫潤，紋路古樸，看不出什麼名堂。他又低頭摸了摸胸前那個玉佛墜子，觸手微涼，貼著皮肉安安靜靜地掛著。

這兩樣東西，是他和原身來歷僅有的聯繫。也許是線索，也許是麻煩，也可能是將來走投無路時能換命的本錢。無論是哪一樣，都不能讓人隨便瞧了去。

他用眼角餘光掃了掃身後，把玉佩貼身藏進僧袍內側，又將玉佛塞回領口，按了按，確認看不出痕跡。

剛整理妥當，身後忽然「嘎吱」一響。

孟奇嚇了一跳，猛地回頭。只見方才還像死了一樣的真應已經坐起身來，一言不發地穿鞋下床，徑直出了門，從頭到尾沒看任何人一眼。

這又是唱哪一齣？

真觀也站了起來，淡淡說了一句：「晚膳時間到了。」

話音未落，孟奇只覺眼前一花，方才還慢吞吞的小胖子已經竄到了門口，速度快得跟那身肉完全不相稱。真慧一隻腳跨過門檻，總算想起了什麼，回過頭來。

「師兄，你不去嗎？」

孟奇正要抬腳，見他這副模樣實在好笑，便起了逗弄之心，故意慢悠悠地擺擺手，端出師兄的架子：「師兄還不餓，你先去吧。」

真慧認真地點了點頭。

「哦。」

說完，他轉身就跑，一溜煙沒了蹤影，連個猶豫的停頓都沒有。

孟奇的手還停在半空。

他愣愣地望著空蕩蕩的門口，真觀也已不知何時走了，屋裡只剩他一個人。肚子偏偏在這時「咕嚕」響了一聲。他這才想起來，自己根本不知道飯堂在哪兒，而雜役院這種地方，去晚了多半連鍋底都舔不著。

「喂！真慧！你這小胖子！」

孟奇一把拉開門衝了出去，僧鞋還沒穿穩，邊跑邊扯著嗓子大喊：

「師兄是開玩笑的！等等我！」
