廢料堆傾在學院後坡，三十年沒清過。刻壞的符板、燒裂的銘石、學徒練手的邊角，全從坡頂倒下來，一層壓一層，踩上去就滑。

熄燈鐘敲過，奧倫摸上坡。他沒帶燈。滿坡碎料爬滿黑痕，刻錯的筆畫比夜色更沉，一道咬著一道。這種黑只有他看得見，他從沒對任何人提過。

他抽出一塊巴掌大的符板，往石頭上一磕，磕掉一角，把斷面湊到嘴前，呵氣。

白霜爬上斷面。

一、二、三、四。霜化了。他把板丟向左邊。

下一塊。呵氣。數到五，化了。左邊。

這是抄寫員驗紙的辦法：撕開紙邊，呵一口氣，霜留得越久，紙裡存的力越足，越吃得住符墨。父親驗紙從不抬頭，數到幾，紙就落進哪一疊。奧倫七歲起站在他肘邊看那雙手。後來行刑官綁那雙手，繞了兩道。

紙要數到二十才算上等。石頭沒人數過，他只能自己數。前半夜磕碎四十多塊，他摸出一條線：數到十二還白著的，指腹貼上去會微微發麻，裡面還剩一點東西，夠引動一次。

只有一次。

嘴唇呵得發木，他就張嘴灌一口冷風，再呵。碎石割開掌根，他往褲腿上抹一把，抽下一塊。月亮滑過塔尖，沉到坡後。左邊的碎料堆到膝蓋高，右邊的他摸黑點過：三塊，四塊，五塊。

東邊發灰時，右邊有七塊。

他脫下外衣兜住它們，先往西走。那裡有一處凹地，三面土壁圍著，風透不進來，從小路上也看不見。他蹲下，攏起雙手，掌心的熱氣久久不散。

他站起來，兜著七塊板走向北坡。

北坡小路旁橫著一塊平石，齊膝高，光禿禿杵在風口。學徒每天兩趟從這裡去藥圃，早鐘後一趟，晚鐘前一趟，離這塊石頭不到五步。

奧倫把板擺上去，靠路的那一側，一字排開。

引燃符三筆。他抄過不下千次，閉著眼也能默。可紙上的符是平的，紙不會告訴他刀該斜幾度。

他磨平第一塊板的舊痕，下刀。第一筆乾淨。第二筆剛收刀，整道溝就黑了。

太陡。他把刀放平一度，沿溝壁再削一層。黑。再放一度。黑。他吹掉石粉，瞇眼對著灰白的天光驗刀口。第四次。第五次。刀柄磨著掌根的傷，血把木頭浸得發滑，他往衣襟上一蹭，換個握法。第七次，黑色淡了一線。他屏住氣，又放一度。

第八次，刀尖剛吃進去，手下一鬆。

裂縫從第二筆尾端竄出去，順著藏在石肉裡的暗傷，直劈到板邊。板斷成兩半。

霜驗得出力，驗不出傷。

他拿起斷片呵氣，霜還沒掛住就沒了。他把兩片疊在石腳下，拉過第二塊。

早鐘響過，腳步聲從坡上下來，到五步外慢了。有人笑了一聲。有人問他在幹什麼，另一個答：「謄抄司的雜役，刻著玩。」接著聲音壓低，只漏出三個字：「抄寫員。」

笑聲斷了。腳步加快，走遠。

奧倫沒抬頭。他把刀收進袖子，下地下三層抄完當日的份，爬上來時晚鐘還沒響。他走回平石，拿起刀。

第二趟學徒提著空籃經過，隊伍走得鬆散，一雙靴子在石前停住。靴面新上過油，扣環是銀的。後頭兩個學徒跟著收住腳，誰也不敢越過去。

賽拉斯。

奧倫的刀沒停。第二筆，第六次，黑。

賽拉斯站著，一個字也沒說。他的影子斜過石面，蓋住符板。奧倫把板往旁邊挪了兩寸，挪回光裡，再下一刀。

影子收走了。銀扣一晃，靴子邁開。跟在後面的跟班經過平石，步子都沒放慢，鞋尖一撥，把最邊上兩塊板撥出路肩。

石板撞上碎石，一路往下跳，一聲比一聲遠。隊伍裡有人嗤笑，笑聲跟著籃子往藥圃去了。

奧倫放下刀，下坡。

坡面陡，長滿枯荊。他抓著荊條往下滑，在溝底的爛葉裡摸到一塊，又在二十步外的石縫裡摳出另一塊。他對著斷面呵氣，數。十三。再換一塊。十二。

他爬回路邊，手背扎滿荊刺。他用牙咬出最粗的兩根，吐掉，把板擺回原位，拿起刀。

第七次。

入夜起風，吹得石粉貼著刀口亂飛。第十一次，他的右手開始自己抖。他把手肘頂上石棱，用骨頭壓住那陣抖。第十三次，黑色淡了。第十五次，又濃回來。他退回半度，削得比頭髮還薄。月亮過了中天，霜爬上平石的邊緣，爬上他的鞋面。

第十七次，刀抬起來。

溝裡只剩石頭本來的灰。

他盯著那道溝，等它變黑。它沒有。三筆乾乾淨淨躺在板上，他從沒在自己手下見過這樣的筆畫。

他把拇指按上符頭。

板身一震。第一筆先亮，火線順著溝跑過第二筆，衝到第三筆盡頭，一粒豆大的火苗從石面上立起來。它燒了三息，滅了，焦味直衝鼻腔。

他把板翻過來呵氣。霜一碰就散。一次，用掉了。

他從懷裡摸出炭條，在平石上劃下一道。

他只看了那道炭痕一眼，便拉過第三塊板，把刀斜到剛才的角度，刻下第二筆。

黑。

天亮後他照樣下地下三層。一百一十二級石階，燈油味越往下越濃，長桌兩側的人都低著頭。掌事發下底本，三十頁，少一頁扣一天的飯。

他研墨，蘸筆，落紙。眼皮往下墜，他就用指甲掐虎口。第九頁有一枚符是黑的，黑得穩穩當當，壓在學院的朱印旁。他照抄，一筆不差，那枚符落上新紙，依舊是黑的。他換行，抄下一枚。

第三十頁交上去，掌事翻了翻，沒抬眼。

第三夜，平石上只有一道炭痕。

第三塊板的石紋斜著走，刀一進去就往旁邊滑。他從昨夜的角度退一度，進一度，再退兩度。第九次。第十五次。第二十次。黑色文風不動。

指腹裂了，從指甲邊一路裂到第一節，手指一彎就張開一道口子。他撕下衣角纏上，血滲透布，把刀柄黏在手上。

他磕下一小角，對著新斷面呵氣。十。選出來時是十三，每下一刀，它就少一點。

第二十六次，有東西滴在板上。他以為是手，抬起手，又一滴落進溝裡。他一摸鼻子，滿指溫熱。他仰起頭，一股鐵鏽味灌進喉嚨，可仰著頭看不見溝。他低回來，撕下布條塞住鼻孔，拿袖口把溝裡的血吸乾，湊到星光下。

黑。

第三十一次。第三十二次。耳朵裡嗡嗡響，風聲被隔在外頭。刀口的線開始重影，他閉眼數到五，睜開，對準其中一條切下去。第三十五次。呵氣。八。

第三十八次。

灰白爬上石面，先照出炭痕，再照出板上乾掉的血點。溝裡的黑在天光下一分也沒褪。他吹掉石粉，抬頭找光，想看清刀口。

小路上站著一個人。

同班的米蘭達。早鐘還沒響，整條路上只有她。她沒提藥籃，目光從他纏血的手移到那道炭痕，又移到石腳下那兩片斷板，一路看得很慢。

她的斗篷肩頭結著一層霜，厚而勻，不是剛站過來的人能有的。

奧倫握著刀，開始數。

數到二十，霜沒化，她也沒走。
