大殿之上，梵音低迴，空氣中浮動著淡淡的檀香。

孟奇睜開雙眼，這世界與他記憶中的現代截然不同。身下是堅硬冰冷的青石地，身上穿著不合時宜的粗布衣，胸口壓著一股奇異的無力感。他下意識地摸向胸口，指尖觸碰到一塊溫潤的玉佩，以及那枚懸在喉結處的玉佛墜子。那是他穿越時僅有的隨身物品，也是這具身體原主唯一留下的痕跡。

「既入少林，俗名已忘。」

孟奇在心中默念著這句話，面上卻勉強擠出一抹符合場景的茫然。剛才在法號取決時，面對玄苦那雙如鷹隼般銳利的眼睛，他本想胡亂編造個名字，卻發現原主記憶一片空白，索性順水推舟。

玄苦端坐於高台之上，黃衣袈裟在殿內光影下顯得格外莊重。他鐵面無情，目光掃過腳下那六個稚嫩的孩童，最終落在孟奇身上，嘴角勾起一抹極淡的譏誚：「機心太重，入雜役院，法號『真定』。」

這句判詞如同定心針，讓孟奇的心跳微微一滯。機心太重？原身的記憶雖然模糊，但那種被看穿的羞澀感卻真實存在。孟奇腦海中飛快閃過無數現代知識與生存策略，他深知在這種等級森嚴的門派，初露鋒芒或顯露異樣，往往意味著災禍。

「是。」孟奇躬身低頭，語氣謙卑，儘量壓低那口帶著現代腔調的嗓音，使其聽起來更像一個受了委屈的小沙彌。

玄苦揮了揮手，殿外傳來的腳步聲響起。帶孟奇上山的黃衣僧玄藏走了進來，他面容平和，對玄苦的決定只是搖了搖頭，道了一聲「一切照決」，便不再多言。

殿上其餘孩童被一一審問，最終除了孟奇外，其餘五人也被判入雜役院，唯有少數資質或背景優異者被送往武僧院。六個小沙彌整齊列隊，跟著玄藏與玄苦向大殿外走去。

一路行來，孟奇悄悄打量著周圍。寺廟建築巍峨壯觀，飛檐斗拱間雲卷雲舒，可那氣勢壓得人喘不過氣。他意識到自己身處的少林，絕非凡俗之地。這具身體雖是富貴相，眉清目秀，粉雕玉砌，卻戰力純屬新手，連基本的自衛都沒有。

「真定師兄，你叫什麼名字？」一個呆愣的聲音打斷了他的思慮。

孟奇順聲望去，見一個圓滾滾的小胖子正跟在他身後，眼睛直勾勾盯著他，滿臉的懵懂。這便是真慧，他的小師弟，一個有點呆的小胖子。

「在下真定。」孟奇連忙拱手，裝作一副恭敬模樣。

真慧似懂非懂地點點頭，繼續發呆，完全沒察覺到周圍人目光中那種若有若無的打探。

抵達小佛堂後，玄苦駐足，雙手分別按在不同孩童的頭頂。他聲音蒼老而沉穩，口誦「煩惱落盡，紅塵遠離」。髮絲從孟奇頭頂飄落，那枯黃的髮絲似是原主多年勞碌或體質虛弱的象徵。輪到孟奇時，玄苦的手輕輕一頓，隨即移開，並未多作停留。

「領了兩套僧袍、鞋襪和戒律。」玄苦語氣平淡地交代。

孟奇接過包裹，小心翼翼地打開檢視。僧袍質地粗糙卻整潔，鞋襪雖舊卻乾淨。他將其中一套收入袖中，另一套準備換上。玄苦接著講解起少林戒律與僧袍顏色的分別：一般僧人穿灰衣，執事穿黃衣，方丈、首座和長老則穿黃衣披紅袈裟。

「輩分排字：心空無玄真，清淨智慧深。」孟奇在心中默默記下這句口訣。自己身處雜役院，屬「真」字輩，上一輩是「玄」字，再往上是「無」字，更上層是「空」字。這階級制度森嚴，每一步都需謹慎。

一行人來到偏僻角落的雜役院。這裡環境簡陋，與大殿相比如同兩個世界。管事玄心衣衫不整，袒露著肚皮，滿臉油光地迎了出來。他見玄苦到來，臉色瞬間變青，顫聲說道：「玄苦師兄，您可算來了，這地方實在難伺候。」

玄苦皺眉，目光如刀般掃過玄心肥胖的身軀，冷哼一聲：「玄心，管好你的院務。」

玄藏忽然開口，打斷了兩人對峙：「玄心，把孟奇和真慧安排跟真應、真觀同屋吧。」

玄苦愣了一下，隨即訓話道：「玄藏，這是你們的事，我 лишь 來監督。記住，雜役院雖低微，卻也是少林根基，不可輕慢。」

說完，玄苦與玄藏轉身離去。玄心待他們走遠，才抖著肥肉罵道：「呸！這兩個鐵面鬼，最討厭他們了！尤其是玄苦，鐵面無情，誰惹誰倒霉。」

禪房裡，真應正躺著發呆，真觀則冷冷地坐在角落，只報了名字：「真觀。」

孟奇換上僧衣，鏡中映出一張清秀卻略显稚嫩的臉龐。他再次檢查身上的玉佩與玉佛墜子，確認它們安然無恙，便將它們小心翼翼地收好，藏於貼身處。

「真應師兄，真觀師兄，真慧師弟。」孟奇逐一見禮，語氣恭敬。

真應突然起身，大步邁向門口，語氣冷淡：「出去了。」

真觀淡淡道：「晚膳時間到了。」

真慧竄到門口，回頭問：「師兄們不去嗎？」

孟奇開玩笑道：「我還不餓，想再待會兒。」

真慧認真點頭，隨即自己跑了出去，完全不理會孟奇的挽留。孟奇無奈一笑，大喊著追了上去：「真慧師弟，等等我！」

走廊裡傳來真慧的歡呼聲，孟奇跟在他身後，心中暗自思忖：這少林果然不是輕易可混的地方。從雜役院起步，每一步都要步步為營。他想起玄苦那句「機心太重」，不禁苦笑。或許在別人眼中，他的機心是過分小心，但在這充滿隱憂的環境裡，唯有機心才能保命。

「機心太重」或許是缺點，卻也是他在這個新世界生存的唯一利器。

孟奇追著真慧的背影，腦海裡已經開始推演接下來的計劃：如何在不暴露本質的情況下融入這群小沙彌？如何利用現代知識改善生活？又該如何應對可能出現的危險？

夜幕降臨，寺廟裡燈火點亮，孟奇站在走廊上，望向遠處的大雄寶殿，心中默念：「既入少林，俗名已忘。但我的心，還活著。」

他深吸一口氣，邁步跟上真慧，走向晚膳時間。這一章的旅程才剛開始，而他的故事，才剛剛寫下第一頁。
