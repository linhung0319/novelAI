# Context 形式實驗：預註冊

**寫於任何受測稿生成之前（2026-11-01）。** 偏離要記在結果報告，不改這支檔。

## 要回答的問題

作者的觀察：AI 稿除了結構問題，句子層也會卡。用詞被精簡過頭（如「不推，而是撞」），句子之間畫面斷掉，一卡一卡，最後不知道在寫什麼。

作者的假說：這是 context 帶出來的。角色卡是電報體，前情提要是跳剪，規則裡的「緊湊」「張力」會被照做，AI 前文會自我強化。

## 為什麼要重新設計

第一輪不能回答這個問題：

1. **沒量過這個缺點。** 第一輪和修復實驗量的是意義解釋、默劇、沒有音量，沒有句間斷裂和用詞過猛。
2. **形式沒有被操縱。** 長 context 把規則、設定、前文綁在一起，而且量和形式同時變。
3. **控制組也是條列體。** 短 brief 本身就是編號事件清單，可能也算 spec 式。
4. **已有線索顯示場景有影響。** 第一輪 S1 的 A 臂（短 context）已明顯一句一跳，S2 的 A 臂卻大致順。

不重跑的部分：外殼（H 臂已顯示無影響）、意義句（已有對照）。

## 設計

固定：模型、溫度策略、約 3000 字的要求。場景 S1、S2 沿用第一輪，brief 事件相同。

| 代號 | 寫手拿到什麼 | 測什麼 |
|---|---|---|
| **M** | 編號事件清單 | 控制組 |
| **MP** | 同一批事件，改寫成連續文字 | brief 本身的形式 |
| **S** | M ＋ 條列角色卡、規則、前情（2–3 KB，取自真實管線檔） | 量＋spec 形式 |
| **N** | MP ＋ S 的同一批事實寫成說明文字 | 量＋散文形式 |
| **R** | M ＋ 常見行文規則（節奏緊湊、張力、動詞有力、刪贅字） | spec 規則是否傳染 |
| **V** | M ＋ 人類片段，放在寫作要求前 | 範文 |
| **PA** | M ＋ AI 寫的上一章結尾 | AI 前文傳染 |
| **PH** | M ＋ 人類寫的上一章結尾（只有 S2） | 對照 PA |

M、MP、S、N 構成 量 × 形式 的 2×2。S 與 N 用同一份事實清單，開跑前逐條核對。

S、N 都不含行文規則，也刪掉伏筆、水下、弧線、動機等設計分析，避免和意義句的效果混淆。

**前文來源：** S1 的 PA 用 oh-story 第 5 章結尾（真實管線稿）。S2 的 PA 用 Claude 依上一章事件新寫的結尾（固定一份），PH 用《一世之尊》原著第 1 章結尾。

**模型與樣本：**

- Claude：`claude-opus-5-5`，走第一輪 A 臂的乾淨 CLI，effort high。每格 n=3，共 45 稿。
- Qwen：`qwen3.5:9b`，同一批 prompt，每格 n=3，共 45 稿。`temperature 0.8`、`top_p 0.95`、`top_k 20`、`repeat_penalty 1.0`、`presence_penalty 0`、`num_ctx 32768`、`think false`，參數全部入紀錄。

## 判定

裁判順序：**作者盲讀 > Claude 盲讀 > 逐句標注（過閘門才算）> 確定性輔助。** 確定性輔助只用來核對事實。

### Claude 盲讀（主要層）

兩位隔離 subagent（Opus 5.5）。讀者一讀每格第 1 篇，讀者二讀每格第 2 篇，加 S2 人類原著。代號打亂，不知道臂別，也不讀預註冊。每篇給：

- **順暢 0–10**：能不能在腦裡連續跟著畫面。
- **斷裂**：相鄰句之間要自己補「誰、在哪、怎麼到這裡、視線落到哪」才接得上。刻意的場景切換、笑點省略不算。
- **用力過猛**：動作或措辭被升級、搭配不自然，一般人會用平常的字。
- **電報感**：該有的虛詞、主語被刪，像電報。

每項都要引原句。

**成立條件：** 兩位讀者、兩個場景方向一致，且平均差 ≥2 分才算有效；1–2 分報「不確定」；方向不一致報「無證據」。各假說的比較：

| 假說 | 比較 |
|---|---|
| 量傷害 | S 對 M、N 對 MP |
| 形式傷害 | S 對 N、M 對 MP |
| 規則傳染 | R 對 M |
| 範文有效 | V 對 M |
| AI 前文傳染 | PA 對 M（兩場景）、PA 對 PH（只有 S2，單場景最多算「傾向」） |

「修好了」不宣稱，S2 還要和人類原著比。

### 逐句標注（輔助層）

`claude-sonnet-5-5` 一次看一篇，看不到其他稿。對全部 90 稿、13 段人類語料、8 章舊 AI 稿，以同樣定義標出斷裂、用力過猛、電報感並附引句，程式核對引句存在，查不到不計。

**效度閘門：** 人類中位數必須 ≤ 舊 AI 中位數的 1/2。不過閘門，這層不用於判定。第一輪的計數主指標就是死在這裡。

### 確定性輔助

- 敘述部分的虛詞率（了、著、過、便、卻、還、就、又、也、才、而、但、可、再、都）
- 句長中位數、單句成段、否定對比
- 與 context 的最長共同子字串（是否照抄）
- 事件關鍵詞是否遺漏
- **噪音底線：** 新 M 對第一輪 A 臂（同 prompt、同路徑）。差距在這條線內的數字都不解讀。

### 作者盲讀

產出兩份盲讀包：每臂一篇 Claude 稿，S2 加人類原著。問題只問一個：讀起來哪裡卡，順暢幾分。作者結果與 Claude 衝突時以作者為準。

## 事前預測

1. **R 傷害最大**，因為「刪贅字、動詞有力」幾乎就是在下這個指令。
2. **形式效果存在但比規則小。** S 比 N 稍差，未必到 2 分。
3. **N 和 MP 的代價是照抄**，因為神秀實驗顯示白話指示會被逐字搬進正文。
4. **S1 的 M 仍然會卡**，因為這個缺點有一部分是模型預設，加上程序性場景的影響。作者的 context 假說只能解釋一部分。
5. **V 改善銜接最明顯**，但會把片段的格式和腔調一起帶來。
6. **PA 比 PH 差**，比 M 也差，但 S2 的 AI 前文是乾淨環境寫的，效果可能偏小。
7. **Qwen 差異小，** 雜訊大過 context 效果。

## 已知限制

- 散文版和條列版都由實驗者（Claude）撰寫或擷取，散文版可能帶入 Claude 的聲音。
- 片段由實驗者挑選，換一段可能結果不同。
- n 很小，只看方向和量級。
- S1 沒有人類版本，只能跟 S2 和人類語料間接比。
- 讀者是 Claude，對自己的腔可能不敏感。作者的例句「不推，而是撞」來自另一批稿件，本實驗未必會原樣重現。
- Claude CLI 不能設溫度。
- 「規劃和寫作分對話」不在此實驗：第一輪外殼與無關量看不出傷害，真實討論歷史則需要另外設計。
