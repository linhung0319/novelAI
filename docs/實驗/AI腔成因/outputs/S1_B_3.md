灰塔學院後坡的廢料堆有半座屋子高。

歷年的試刻板、裂開的符牌、學徒練壞的石片，從坡頂傾倒口一筐筐倒下來，堆成一道不長草的斜面。入冬的夜裡，奧倫提著一盞不敢點的燈站在坡底，看了很久。

在他眼裡，這堆東西是黑的。

月光下石頭都發灰，只有刻過符的地方一道道黑下去，層層疊疊，像有人把墨潑在山上。他的眼睛平日能替他省不少事，到了這裡卻派不上用場。這裡每一塊都刻錯了，不然不會被倒在這裡。他分得出錯，分不出一塊錯板裡還剩多少力。

刻錯的符大多死透了，少數幾塊的力沒放完，還卡在板裡，能再引動一次。雜役領不到新板，他要的就是這幾塊。學徒有驗符的銅針，一根抵他半年工錢。他只有一雙手。

他撿起一塊，放下，又撿起一塊。半個時辰過去，手裡的和腳邊的毫無分別。

手凍僵了。他把一塊斷板握在掌心，湊到嘴邊呵氣暖手，斷面上結了一層白。

霜化掉時，他發現自己的嘴唇在動。他數到了三。

這是在地下三層養成的毛病。紙從冷窖取出來，抄寫員撕開一角，對著毛邊呵一口氣，然後數。漿打得實的紙鎖得住冷，數得到九；摻了爛料的數不到四，落墨三年就洇。他七歲起坐在父親腳邊替他數，數錯一次，挨一下界尺。

他換了一塊，呵氣。五。再換一塊。十一。

同樣的青板，同樣的厚。他拿起數到十一的那塊，拇指按上符心，指腹一麻，槽裡竄起一線暗紅，啪地滅了。再按，什麼也沒有了。數到五的那塊，按下去沒有動靜。他又試了九、十四、四。後來翻出一塊數到二十六的，他沒用手，退開幾步拿長樹枝戳了一下。板炸了，碎片擦過他的耳朵。

月亮過塔尖時，他有了規矩：數不到八是死料；八到十九，還有一口氣；過了二十，力憋壞了，不能碰；霜化得不勻、一頭先化的，裡面有暗傷。

沒有人教過這個，也不會有人想到。驗符的人不屑驗紙，驗紙的人摸不到符，只有這座垃圾堆讓兩樣東西碰了頭。

之後便只剩手上的活：蹲下，拿起，呵氣，數，放左邊或放右邊。後半夜他呵得頭暈，嘴唇裂了，就停三息再呵。數到第幾百塊時，他已經不必看，霜一結，舌根自己開始數。天邊泛灰的時候，右邊有七塊。

學院北坡有條小路，從學徒宿舍通到藥圃，學徒每天早晚各走一趟。路旁有塊平石，齊膝高，三面沒有遮擋。

西邊另有一處凹地，土坡圍著，從哪條路都看不見。奧倫過去站了一會兒，風確實吹不進來。

他走回北坡，把七塊板放在平石上。

一個被處決的抄寫員的兒子，有一天忽然會刻符，第一個問題不會是刻得好不好，而是誰教的、哪本書、他父親留下了什麼。在凹地裡練成的本事答不了這個問題。所以他得讓人看著他不會，看著他刻壞，一天兩趟，看到他們膩。將來有人問起，不必他開口，二十個學徒都會不耐煩地說：那傢伙？他在北坡刻了一冬天。

他也知道坐在這裡意味著什麼。誰都能走過來掃掉他的板，誰都能去司裡告他私刻符文，輕則一頓打。他拿安全換來歷。這筆帳他只算了一遍。

引燃符是入門的符，三筆：豎、斜折、回鉤。全部的學問在第一筆和第二筆之間那個角。《初階符式》上寫的是三十七度。

他把板翻到背面，舊符不動，用界尺上自己拿針劃的刻度定好角，下刀。三十七度。回鉤收筆，刀一抬，整個符從刀尖底下黑了上去。

他看了一息，還是把拇指按上去。黑的符按下去不會有任何結果，但路上要是有人，得讓人看見他是按過才知道的。

他刮平，摸出一截炭，在平石靠路的那一側劃了一道。三十八度，黑，一道。三十九度，黑，一道。每刮一次，板薄一層。

第八次，四十四度。豎筆沒事，斜折沒事。回鉤走到三分之二，刀尖下輕輕一響，像牙齒咬到一粒沙。一條縫從鉤尖斜出去，直奔左下角，他還沒抬刀，板已經在手裡分成兩片。

他翻過來看。新斷面中間有一道褐線，頭髮粗細，順著板面走，始終沒走到他呵過氣的那條邊。紙只有一條毛邊，板有四條，他只驗了一條。

他劃下第八道，把兩片並排擺在炭痕下方，然後取出剩下的六塊，四條邊逐一重驗，換了次序。

學徒提著籃子經過時，有人放慢腳步，有人根本沒轉頭。

「那是在幹嘛？」

「謄抄司的雜役。他爹不就是……」

話沒說完，人已經走遠了。奧倫沒有抬頭。

那天傍晚賽拉斯來了。別人的腳步在他前後自動讓開一段。他在平石前站定，看了看板，又看了看那排炭痕，站的時間大約夠刻完一筆斜折，奧倫就刻完了一筆斜折。賽拉斯什麼也沒說，走了。

他的跟班落在後面，鞋尖伸過來，把石邊一塊板撥了一下。板滑出去，沿著坡一路磕碰，滾進下面的碎石裡。跟班站著看他。

奧倫放下刀，下坡。

坡陡，草上結了霜，他半走半滑，在荊棘根下找到那塊板，手背劃開一道。他先驗板，四條邊都呵過，十三，化得很勻，沒摔壞。爬回來時路上已經沒人了。他把板放回原位，拿起刀，接著剛才那一筆往下刻。

那跟班長什麼樣，他沒去記。那人撥板時，路上站著九個人，九個人都看見雜役下坡去撿。要入帳的話，這一筆還該記在進項。

第二夜過了一半，風轉北，炭凍得發脆。第二塊板刻到第十六次，都是黑的。

第十七次，四十七度。回鉤收筆，刀抬起來，符沒有黑。

他盯了三息。槽線是石頭的灰，和板上任何一處一樣。

他按上去。槽底亮起來，一粒米大的火頭立在回鉤尖上，橘黃色，燒了三息，照出他指節上的裂口。他看的是火頭直不直。火滅了，板上留下一道焦痕，那口力用完了。

他拿起炭，在第二排劃下第十七道，和前面十六道一樣長。那塊板他擺到斷板旁邊，焦痕朝路。然後取出第三塊，四條邊又呵了一遍，十二，開始刻第一筆。

早趟過後他下地下三層，一步也沒有少走。規矩是一天三十頁，錯一字整頁重抄。冷窖旁的油燈底下，他閉上眼是符，睜開眼是字。第十九頁，手開始抖，他把手腕死死壓在桌沿上，讓抖停在腕子以上，到不了筆尖。第二十六頁他睡著了一瞬，醒來筆還懸著，墨沒有落。他把三十頁交上去，管事翻了翻，沒有抬眼。他上樓，啃完半塊冷餅，趕上晚趟。

第三夜，第三塊板怎麼也不亮。

四十七度，黑。他早料到了，每塊板的紋路不同，上一塊的角度帶不過來。四十八，黑。四十九，黑。他退回去，從四十六往下走。

拇指和食指的裂口到這時已經開到肉裡。刻第二十三次時，血順著刀桿流下來，刀握不穩。他從袋底抓一把炭粉按在裂口上，黑糊糊地壓住，接著刻。斜折比上一次歪了半度，他刮掉重來，這一次不算。

每按一次符心，指頭裡就有一口熱被抽走，黑的符照抽，什麼也不還。第二十六次按完，鼻子一熱，有東西滴到手背上。他立刻把頭偏開，第二滴落在石頭上，沒落在板上。血進了刻槽，這塊板就廢了。他捏住鼻梁，仰頭等了十幾息，嚥下一口鐵鏽味，血沒停。他撕下一條袖口塞進鼻孔，左手還在塞，右手已經拿起了刮刀。

第二十七次。第二十八次。炭痕的最後幾道沾著暗色的指印，他沒去擦。

第三十一次，黑。他按下去，什麼也沒有。他劃下一道，把板舉起來對著天光看厚度，已經薄了將近一半，還夠刻十來次。天光能照透板邊，說明天亮了。

他抬頭，想看離早趟還有多久。

小路上站著一個人。

是同班的米蘭達。她沒提籃子，離學徒出門還有半個時辰。她站在十來步外的路當中，手攏在袖子裡，呵出的白氣一團一團，看樣子不是剛到。

她沒有看他。她看著平石靠路那一側的炭痕，從第一排往下，嘴唇微微地動。

奧倫認得那個動法。
