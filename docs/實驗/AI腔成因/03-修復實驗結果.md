# AI 腔修復實驗：結果

設計見 `02-修復實驗預註冊.md`。稿件在 `outputs_fix/`，盲讀分數在 `fix_blind_scores.json`，對照表在 `fix_blind_key.json`。

## 結論

1. **聲音來源對 Claude 有效。** V（人類片段）和 P（聲音卡）都達到預註冊門檻。
2. **同一招對 Qwen 幾乎無效。** 問題仍在，稿子還變短。
3. **獨立刪句不要用。** Claude 只刪約 2%，而且常刪掉最有聲音的句子；Qwen 刪得過猛，連事件都會刪掉。
4. **還沒有修好。** 最好的稿仍和人類原著有差距，而且各自長出新毛病。

以上是 Claude 的閱讀判斷，統計數字只用來核對事實，不用來判定好壞。作者盲讀（`盲讀包/修復-*`）尚未回填，衝突時以作者為準。

Qwen 把聲音卡當規格照念，Claude 則把它轉成行為。例如 Qwen 寫「因為他記仇，記住了所有不公平的事」，直接說出卡片上的性格；Claude 寫「奧倫記住了，包銅，左腳那隻磨得比較厲害」，只寫他記了什麼。

## 盲讀分數

每格只有 1 篇。問題總分滿分 16，越低越好；「講故事」滿分 10，越高越好。

## 句子對照

同一個情節，S2 孟奇頭髮被按掉之後：

- B0：「孟奇膝蓋底下涼了一片。」，敘述精良，人物偏冷。
- V：「這一手要是放到他原來的世界，全國的理髮店都要關門，植髮醫院倒是能大賺一筆。」，平實的連載腔。
- P：「煩惱落盡個鬼，煩惱明明多了一項。」，人物開口了。

S1 奧倫挑凹地還是平石：

- B0：「躲起來的人，被找到那天得有個說法。坐在路邊的人不用。」，像格言。
- P：「他爹這輩子什麼事都選凹地，低頭、背風、不惹人，凹地也沒救他。」，同樣在交代理由，但像這個人自己在說。

## 各方法的副作用

### V（人類片段）

- 沒有抄句：與片段的最長共同子字串 ≤6 字，專名 0。
- **格式和腔調整個搬過來，連缺點一起。** S2 片段幾乎一句一段，稿子的單句成段比例就到 0.98（B0 0.51、人類 0.72）。片段的口頭禪也傳染，例如「心裡面」「能夠」。S1 片段驚嘆多，敘述驚嘆號就從 0 變 1.24／千字；S2 片段驚嘆少，就仍是 0。
- 所以選什麼片段，就得到什麼聲音，片段品質要由作者把關。

### P（聲音卡）

- 活人感最強，但 S2 幾乎句句抖包袱，段尾短句比例 0.46（B0 0.29、人類 0.13），連著讀會累。
- **會發明情節和改人物。** 孟奇當面說出「聽見了，鐵面鬼」，玄心因此罰他挑水；奧倫變成一路回嘴。卡片上的性格是實驗者代寫的，這種改動是否可接受要由作者決定。
- 同一個梗會重複：「爹不回嘴」反覆出現；「備了三句話沒用上」在兩篇都出現。

### 模型預設沒有消失

六篇 Claude S1 有三篇寫「他以為下雨了」，然後發現是鼻血；S2 六篇都收在「我開玩笑的」。換了聲音，想到的梗仍高度相同。

## cut

| | 刪句比例中位數（範圍） | 事件關鍵詞遺失（刪前→刪後） |
|---|---|---|
| Claude | 2.0%（0.7–4.5%） | 0/90 → 0/90 |
| Qwen | 23.1%（5–94%） | 11/225 → 49/225 |

Qwen 的 11 筆含 `q_S2_P_1` 的 3 筆，是它中途變簡體造成的假遺失。

**Claude：** 依預註冊逐句歸類 35 句，該刪約 11 句、可刪可不刪約 11 句、誤刪約 13 句，誤刪約 37%，超過 20% 的門檻。歸類是開表後做的，只算粗估。

- 該刪：「財不露白這個道理，放在哪個世界都是通用的。」、「在這裡，不問是一種很高的禮貌。」
- 誤刪：「一隻手按上去，頭髮就死了。」、「這比罵他還氣人。」、「他無話可說，這話還真對。」

編輯分不出多餘的解釋和人物的聲音。在 P 稿裡，人物的聲音正好就是那些「不必要」的句子。

**Qwen：** 確實常刪掉最差的結尾（「雖然前路未卜……」「他知道，這只是開始」），但也會刪掉事件和整段對白，有一篇刪掉 94%。

## 事前預測對帳

| 預測 | 結果 |
|---|---|
| V、P 都增加活人感 | 對（Claude）；Qwen 只有 P 微幅上升 |
| P 會變成滿篇吐槽的另一種腔 | 對，S2 明顯 |
| V 有抄句風險 | 錯：沒抄句，搬的是格式和腔調 |
| cut 對 Claude 最有效 | **錯** |
| cut 修不了默劇與句句用力 | 對，連嘗試都很少 |
| Qwen 上限低 | 對 |

## 限制

- Claude 盲讀每格 1 篇，評分者只有一個。
- 盲性不完整：卡片和片段是我選的，讀到時大致猜得出臂別；模型之間也很好認。
- 片段只各試一本，聲音卡只寫了一版。
- V＋P 組合沒有測。
- Qwen 只細讀了每格第 1 篇，其餘只看確定性輔助。
- subagent 的工具回報每次約 5.6–6 萬 tokens，連只讀一份短稿的編輯也約 5.6 萬，表示隔離不等於 context 很短。無關內容仍在，這和第一輪「無關的量看不出傷害」相容，但沒有單獨驗證。

## 與預註冊的偏離

- 片段修正殘留簡體字後，刪除 `q_S2_V_1` 重跑，Claude 工作檔也重建；其餘稿件尚未開始。
- 盲讀後另外非盲讀 Claude 第 2 篇，預註冊沒有這一步。
