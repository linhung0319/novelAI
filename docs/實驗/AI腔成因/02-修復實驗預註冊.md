# AI 腔修復實驗：預註冊

**寫於任何受測稿生成之前（2026-11-01）。** 偏離要記在結果報告，不改這支檔。

## 要回答的問題

第一輪只測了「拿掉東西」。這一輪測「補上東西」：只給事件的短 brief，加上聲音來源或獨立刪句，能不能修掉閱讀時抓到的問題？

## 設計

固定：只給事件的 brief（`stimuli/S1_A.txt`、`S2_A.txt`），不給意義句、行文規則、AI 前文。

| 代號 | 寫手拿到什麼 |
|---|---|
| **B0** | brief |
| **V** | brief ＋ 人類文本片段（另一本書，只學聲音） |
| **P** | brief ＋ 敘述者聲音卡（這個人是誰、像在跟誰講話） |

每份草稿再做一次 **cut**：獨立編輯只看草稿，回傳要刪的句子編號，由程式執行。編輯無法改字或加字。

- **V 的片段**：S1 用《詭秘之主》第 3 章，S2 用《我有一個修仙世界》第 796 章。都不是受測場景的書。
- **模型**：
  - Claude：`claude-opus-5-5`，走 Claude Code 的 context 隔離 subagent（`general-purpose`），工作檔放在代號路徑，不暴露實驗目的。每格每場景 n=2，共 12 篇草稿、12 次 cut。
  - Qwen：`qwen3.5:9b`，參數同第一輪。每格每場景 n=5，共 30 篇草稿、30 次 cut。

Claude 少跑是因為 subagent 要花額度；Qwen 不花錢，所以多跑。

## 判定

上一輪的計數主指標未過效度閘門，這輪不再用它判定。

**裁判順序：作者盲讀 > Claude 盲讀 > 確定性輔助。**

### Claude 盲讀（Claude Code 主線程）

每場景每模型每臂取第 1 篇未刪稿，連同 S2 人類原著打亂成代號，讀完才開對照表。以下每項給 0（沒有）／1（偶見）／2（常見），並附引句：

1. 替讀者下判決：把意義、動機、情緒定論直接寫出來
2. 重述：同一個意思短距離內再講
3. 金句收尾：段尾或章尾擺格言
4. 機械節拍：獨立短句、對稱句、重拍
5. 默劇：該開口的地方靠眼神和沉默
6. 內心沒有音量：主角像想好才說
7. 句句用力：沒有平的交代句
8. 細節全回收：道具或小動作反覆回來當巧思

另給「像有一個人在講故事」0–10 分。

讀者（Opus 5.5）可能認得出自己寫的聲音卡或片段的影響，所以這層盲性不完整。

### cut 的判讀

打開對照表後，逐篇看被刪的句子，歸類為：該刪、可刪可不刪、誤刪（丟掉事件、笑點或活人感）。

### 確定性輔助（只作交叉核對）

敘述驚嘆號／千字、對白佔字比、否定手勢／千字、單句成段、段尾短句、句長中位數、字數、刪句比例。

### 另外必查

- **抄襲**：與 V 片段的最長共同子字串；片段內的人名或專名是否進稿。
- **事件完整性**：brief 的七個事件是否都在（刪句後也查）。
- **事實正確**：是否和 brief 矛盾。

## 成立條件（Claude 盲讀層）

- **聲音來源有效**：V 或 P 在同模型的兩個場景，「講故事」分都比 B0 高 ≥2，且問題總分較低。
- **cut 有效**：誤刪句低於被刪句的 20%，且判決、重述類問題可見地減少。
- **修好了**：不宣稱。「比 B0 好」不等於「像人」，S2 還要和人類原著對照。

## 事前預測

- V、P 都會增加活人感，但 P 容易變成滿篇吐槽的另一種腔；V 有抄句風險。
- cut 對 Claude 最有效，因為它的判決句可以單獨刪掉。Qwen 的判決常揉進敘述，比較難靠刪句修。
- 「默劇」和「句句用力」cut 修不了。
- Qwen 能力上限低，即使改善也不會接近 Claude 的整體水準。

## 已知限制

- n 很小，只看方向。
- Claude 路徑和第一輪（CLI 乾淨外殼）不同，所以 subagent 另跑自己的 B0，不沿用舊稿。subagent 會載入本 repo 的 CLAUDE.md。
- 聲音卡是實驗者代寫的，角色性格多少是新發明。實際使用要由作者決定。
- 片段由實驗者挑選，換一本可能有不同結果。
