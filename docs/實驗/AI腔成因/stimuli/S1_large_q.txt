# Story Consistency Rules

修改设定、大纲、追踪文件时必须遵守的一致性规则。

## Rules

1. **设定变更必须检查追踪/**：修改任何角色设定或世界规则时，必须运行 `tracking_commit.py check`，确认 `_tracking-state.json` 与全部派生视图一致，再核对伏笔当前表、相关角色快照，以及作者/读者时间线，确保变更不会制造冲突或提前泄露。

2. **新增角色必须创建独立文件**：每个主要角色应有独立的设定文件，并更新关系.md（如果存在）。

3. **时间线变更必须走事务**：如果修改涉及时间顺序、客观事实或读者认知，必须在对应章的 `mode=revision` 事务中更新事件；由工具统一派生 `作者真相.md` 与 `读者已知.md`。

4. **设定变更只提交一次语义事务**：永久生效的裁定写入事务的 `delta.constraints` 与当前完整 `context.long_term_constraints`；下一章必须兑现的写入 `delta.next_chapter_commitments`。工具负责生成紧凑增量和续写状态卡（固定 7 栏）。不得直接编辑 `逐章记录/`、`上下文.md`、角色快照、伏笔表、时间线视图或摘要。

5. **一致性检查必须用 grep**：不靠记忆，用搜索验证。常用检查命令：
   - 角色属性：`grep -rn "角色名" 设定/ 正文/ | grep "属性关键词"`
   - 时间线：`grep -rn "第.*天\|.*日后\|过了.*时" 正文/`，再对照 `追踪/时间线/作者真相.md` 与 `读者已知.md`
   - 力量体系：`grep -rn "体系关键词" 设定/ 正文/`
   - 伏笔状态：`grep -rn "F[0-9]" 追踪/伏笔.md`

6. **水字数检测信号**（出现即警告）：全章对话无新信息、同一情绪连续 3 段+、场景描写超 500 字不推进、角色回忆旧事无新视角、连续 2 章无冲突。

## Examples

### Correct
```
修订 demo 第 10 章“专业团队拍得还不如他拍得好？”后：
1. 检查 F027、江晨快照以及第 10 章相关时间线事件
2. 构造第 10 章 `mode=revision` 事务，保留“专业重拍版缺了灵魂、张耀祖决定继续用手机原版”的正文事实
3. 作者真相可保留钟嘉嘉未公开的培养安排；读者视图只保留看片会已经揭示的结论
4. 提交后运行 `tracking_commit.py check`，确认逐章增量、角色快照、伏笔与双时间线视图一致
```

### Wrong
```
直接在 `伏笔.md` 末尾追加第二条 F027，并分别手改 `作者真相.md`、`读者已知.md` 和 `上下文.md`。
结果：同一伏笔出现多个“当前状态”，读者视图泄露钟嘉嘉的未公开安排，检查点却无法知道哪些派生文件已经失效。
```

# Story Format Rules

正文文件的格式规范。当用户直接编辑正文文件时自动加载。

## 绝对禁止

1. **禁止机械分段或通篇大段**：段落按戏剧单元/镜头/一件事结束自然断开；不要按固定字数强拆，也不要把多个动作、线索、视线切换塞进一段。完整推理、氛围压迫、情绪变化链可保留稍长段。
2. **禁止段落间空行**：正文相邻段落之间只允许一个换行符 `\n`；不得出现空行或连续换行 `\n\n`。
3. **避免对话标签机械化**：高频或公式化的「他说」「她道」「他笑了笑说」用动作/上下文替代；普通「说」低频使用可保留。
4. **禁止大段描写堆砌**：描写必须穿插动作或对话，不连续超过 3 段纯描写。
5. **禁止跳出视角**：已确定视角（第一人称/限知第三人称）后，不切换到其他角色内心。
6. **禁止主语过密**：同一动作链内不要连续句/段无必要重复同一主角名；段首或主语重置时点名，段中用代词/动作承接/合理省略，关键转折再点名。

## 格式规范

- 对话独立成行，用冒号或动作引出
- 段落以戏剧单元、镜头、情绪或动作为单位划分
- 章节标题用 `## 第X章 章名` 格式，标题后保留一个 Markdown 空行
- 正文相邻段落之间只允许一个换行符 `\n`，不得出现空行或 `\n\n`
- 章节之间不使用 `---`、水平分隔线或额外空白行

## Examples

### Correct — 按戏剧单元自然断段
```
沈栀抬手，灵力从指尖涌出。
面前的结界出现一道裂缝，碎纹像蛛网般蔓延开。
她咬紧牙关加大输出，整条手臂开始发颤。
```
每段只承载一个动作/信息变化，段落按戏剧单元自然推进，段与段之间只有一个 `\n`。

### Wrong — 多个拍点挤成一段
```
沈栀抬手灵力从指尖涌出面前的结界出现一道裂缝碎纹像蛛网般蔓延开她咬紧牙关加大输出整条手臂开始发颤最后结界轰然碎裂碎片向四周飞溅。
```
同一段混入多个动作、线索和结果，读者无法在关键变化处停顿。

### Correct — 对话用动作引出（无「他说」）
```
沈栀将茶杯往桌上一顿。
"你到底想说什么？"
陆衍没接话，只是看着窗外。
```
对话通过动作和上下文引出，避免高频公式化标签。

### Wrong — 使用对话标签
```
沈栀将茶杯往桌上一顿。
她说道："你到底想说什么？"
陆衍没接话，他轻轻叹道只是看着窗外。
```
同一段里连用「说道」「叹道」是公式化标签堆叠，应用动作替代。

### Correct — 章节标题后无多余空行
```
## 第二章 暗流

陆衍推开门时，屋内已经坐了三个人。
沈栀坐在最里面的角落，手里捏着一张纸条。
```
章节标题 `##` 与正文之间仅一个空行（Markdown 渲染需要），正文段落间无空行。

### Wrong — 段落间多余空行
```
## 第二章 暗流


陆衍推开门时，屋内已经坐了三个人。


沈栀坐在最里面的角落，手里捏着一张纸条。
```
段落之间出现多余空行（连续换行 `\n\n`），破坏紧凑节奏。

# Story Narrative Rules

拆文、对标分析和设定文件中的叙事规则。

## Rules

1. **设定交叉检查**：新增或修改设定时，必须与已有设定交叉检查矛盾。检查方法：grep 已有设定文件中的关键词，确认不冲突。

2. **语言风格一致**：角色对话必须匹配角色设定中的语言风格档案（语气、用词习惯、感叹号使用频率等）。

3. **世界观规则明确**：力量体系、社会规则等"可能"和"不可能"的事必须明确记录在设定文件中，且在正文中一致遵守。

4. **悬念必须有文档记录的"真实答案"**：设置的每个悬念/谜团，在追踪/或设定/文件中必须有明确的真实答案记录，不能含糊。

5. **角色动机和关系内部自洽**：角色的行为必须符合其设定的动机，角色关系的变化必须有合理的触发事件。

6. **对话三功能检验**：每段对话删掉后检查——情节还能推进吗？期待感还在吗？情绪还到位吗？三项全否 = 水字数，删。

## Examples

### Correct — 设定交叉检查
```
新增设定：灵力等级分为九层，最高为第九层"破境"。
执行动作：
1. grep 设定/ 目录中所有文件，确认没有其他灵力体系描述
2. grep 追踪/伏笔.md 中"灵力"关键词，确认无矛盾伏笔
3. 本章追踪事务里带上这条裁定：写进 `delta.constraints`，并同步进 `context.long_term_constraints` 的完整当前值；由 `tracking_commit.py` 生成 追踪/逐章记录/ 与 追踪/上下文.md，不手写这两个文件
```
新增设定前主动搜索已有设定和伏笔，避免矛盾。

### Wrong — 设定未经交叉检查
```
直接在设定/世界规则.md 中添加"灵力等级分为十层"。
结果：已有设定文件中记载"灵力最高为九层"，两处矛盾。
且追踪/伏笔.md 中有一条伏笔依赖"九层"设定。
```
未检查已有设定就添加新内容，导致世界观矛盾。

### Correct — 悬念有文档记录的真实答案
```
正文第15章写到：密室中的古镜映出一个陌生人的脸。
本章事务登记：`foreshadow_changes` 埋下 F012（古镜陌生人，第15章埋、计划第38章回收）；
作者侧真相「是沈栀前世记忆的残留投影」写进 `timeline_events.objective_fact`（派生到 时间线/作者真相.md），
或长期设定写进 `设定/`。伏笔.md 是工具渲染的当前状态视图，没有「真实答案」列，不手写。
```
每个悬念在追踪文件中有明确的真实答案和计划回收时间。

### Wrong — 悬念无文档记录
```
正文第15章写到：密室中的古镜映出一个陌生人的脸。
追踪/伏笔.md 中无任何记录。
写作到第40章时，后续正文遗忘这个悬念，或给出与既有追踪记录矛盾的解释。
```
悬念没有文档记录，容易遗忘或自相矛盾。

# Story Outline Rules

大纲文件的规范。

## Rules

1. **卷纲必填项**：每个卷纲（卷纲_*.md）必须包含以下部分（字段模板见 story-long-write 技能的卷纲模板与「剧情单元卡」字段模板，契约/推进规则见其读者契约与推进参考；旧版卷纲的缺项处理见规则 8）：
   - 核心信息（章节范围 / 字数目标 / 本卷定位）
   - 卷契约与终局储备（卷契约 / 本卷主推线 / 本卷战果 / 本卷解锁的终局里程碑 / 本卷禁碰的终局底牌 / 契约风险）
   - 剧情单元卡（1–3 万字为可调经验值，写在卷纲内，不另建单独文件；爽感节奏由剧情单元卡管理，不设「每 N 章一个大爽点」的固定周期；章级下限按平台/题材分档：快节奏平台保留「每章要有可见事件或爽点推进」的下限）
   - 核心矛盾（一句话：本卷要解决什么问题或达到什么目标）
   - 情绪弧线（本卷整体情绪走向）
   - 人物弧线（主要角色在本卷的成长/变化）
   - 本卷伏笔（本卷埋设的伏笔及计划回收时间）
   - 本卷反转（如有：类型 / 涉及角色 / 误导路径 / 揭示章节）

2. **细纲必填项**：每个细纲（细纲_*.md）必须包含当前“章节蓝图”：
   - 阶段位置：所处卷/阶段、阶段目标、本章推进与前后承接
   - 本章结构公式：本章采用的情绪与冲突展开公式
   - 本章禁止提前释放：本章不得提前揭示的真相、底牌、关系结论或终局矛盾
   - 基础执行字段：本章核心事件、字数目标、目标情绪、单元ID/位置、主角目标/关键选择、章首钩子、本章爽点、章尾钩子、契约风险（逐章按大纲安全七检⑥⑦复核后填写）
   - 内容概括（五段式）：起因 / 发展 / 转折 / 高潮 / 结尾——结尾写本章最后落在什么动作或画面上，不写状态判词
   - 情节安排（多线）：主线推进 / 辅线推进 / 事件线或任务线 / 感情线或关系线 / 逻辑线
   - 人物关系和出场顺序：按实际出现顺序列角色/势力/关键物件，并写人物关系变化
   - 情节细化：情节点序列写成表格 `# | 情节点（谁做了什么） | 功能标签 | 执行边界`，不填写逐点字数、不按 beat 数预测容量；并标 行动成本（可无）/收益归属——行动成本可无，不硬造代价
   - 结尾设定和钩子：收束状态（写成具体的落幕动作或画面）、未解决问题、下一章推动力、章尾钩子

3. **增量写入**：大纲必须增量写入——先写骨架（关键事件和爽点），再逐节填充细节。不要一次性写出所有细节。

4. **与正文同步**：写完一章正文后，回头更新细纲中"实际完成情况"部分。

5. **章首钩子必须从以下类型选择**（完整技法见 `story-setup/references/agent-references/long-chapter-hooks.md`）：
   悬念对话开局 | 闪前碎片 | 倒计时开局 | 神秘独白 | 反差场景 | 未完成动作开局 | 意象预示

6. **章尾钩子必须从以下类型选择**（完整技法见 `story-setup/references/agent-references/long-chapter-hooks.md`）：
   突然揭示 | 紧急危机 | 未完成动作 | 身份反转 | 两难抉择 | 神秘物品/线索 | 倒计时 | 承诺/威胁 | 离奇消失 | 隐藏含义 | 意象钩子 | 回声钩子 | 留白钩子

7. **每章必须有情绪变化**：细纲必须标注情绪起点→终点（如"平静→震惊→愤怒"），连续 2 章情绪无变化 = 需调整。

8. **缺项处理**：旧版细纲缺章节蓝图字段不阻止续写——回退消费旧字段（核心事件、情节点序列、目标情绪、章首/章尾钩子、字数目标），本轮内存推断、仅在明确补纲/改纲时回写；新建、补建、改纲的细纲必须按当前章节蓝图模板补齐后再进入正文。旧版卷纲同样不阻塞——缺规则 1 的部分分节（如只有 本卷目标/爽点节奏）或用旧字段名（循环ID 等）时按字段结构回退读取，仅在用户明确补纲/改纲时升级为当前结构；已写区间锁定的卷纲不自动改写。无法从材料确认的辅线、关系变化或代价收益写 `[待补充]`，不得编造。

## Examples

### Correct — 完整的卷纲
```
# 卷纲_第一卷.md
## 核心信息
- 章节范围：第1-30章
- 字数目标：9万字
- 本卷定位：铺垫
## 卷契约与终局储备
- 卷契约：沈栀从被欺压到进入暗卫的逆袭爽感；期待债：身世之谜
- 本卷主推线：战力线（灵力第三层→第五层）
- 本卷战果：身份线（拿到暗卫编制）、关系线（与师父建立信任）
- 本卷解锁的终局里程碑：接触暗卫体系
- 本卷禁碰的终局底牌：师父真实身份、古镜完整体
- 契约风险：契约安全
## 剧情单元卡
### 剧情单元 L1-1
- 单元ID：L1-1
- 章节范围：第1-12章
- （其余字段按 story-long-write 技能的「剧情单元卡」字段模板填写）
## 核心矛盾
沈栀要在家族清洗前拿到进入暗卫的资格。
## 情绪弧线
压抑→低谷→觉醒→爆发→余韵
## 人物弧线
沈栀：从隐忍到主动反击
## 本卷伏笔
- F003：古镜碎片（第8章埋，第二卷回收）
- F007：师父真实身份（第12章埋，第三卷回收）
## 本卷反转
第18章：暗卫首领竟是沈栀失散多年的兄长（身份反转，误导路径：首领屡次针对沈栀）
```
所有必填项齐全，终局底牌有明确边界，伏笔有明确回收计划。

### Wrong — 缺少必填项的卷纲
```
# 卷纲_第一卷.md
## 本卷目标
沈栀加入暗卫。
## 爽点节奏
每5章一个大爽点。
```
缺少卷契约与终局储备、剧情单元卡等必填项；爽感节奏由剧情单元卡管理，不设「每 N 章一个大爽点」的固定周期，快节奏平台只保留「每章要有可见事件或爽点推进」的章级下限。存量项目里长这样的旧版卷纲按规则 8 回退读取，不阻塞、不自动改写。


===== 檔案：核心设定.md =====
# 核心設定表

## 基本信息
- 書名：典籍有誤
- 題材/類型：西方奇幻 · 巫師流（苦修知識流）＋ 智力碾壓
- 目標平台：起點 / 番茄
- 預計字數：200 萬字（約 700 章，單章 2800 字）
- 目標讀者：男頻 18-35，愛看低魔苦修、體系嚴密、主角靠腦子爬上去的長線讀者
- 讀者契約：看一個沒有背景、沒有天賦、只有「看得見錯誤」這一項優勢的抄寫員之子，在一個「典籍即真理」的世界裡，用所有人不敢走的死路，一級級爬上去，最後改寫整部真理
- 主角高光/代理權：每一次翻盤都來自奧倫自己的判斷——判斷哪條路是死路、判斷什麼時候值得付出記憶、判斷該讓誰看見什麼。他可以被救、可以借力，但「錯在哪裡」永遠只有他能決定
- 核心期待債：①證明父親沒有抄錯（第一卷偿還第一層）②證明《正典》本身有誤（第六卷）③改寫《正典》（終卷）

## 施法的基本工序（本書魔法必須有工序感）
任何一次施法 = **載體 + 符文 + 引動 + 代價**
1. **載體**：符文板（石/木/骨/金屬）、卷軸、藥劑瓶、儀式陣
2. **符文**：按《正典》記載的筆順、比例、間距刻寫。**一筆之差即廢**
3. **引動**：以自身精神力灌注。學徒精神力以「注」計，丙級學徒每日約六注
4. **代價**：材料消耗 + 精神力消耗。高階另有規則反噬

> 寫正文時，四步至少要出現兩步，不許「他一揮手」。

## 為什麼「一筆之差即廢」是全書引擎
《正典》規定的筆順本身**有一部分是錯的**——不是抄錯，是原本就錯。
- 錯的條文導致該符文永遠無法引動，但《正典》不可質疑，所以巫師社會的解釋是：「是你的天賦不夠」
- 於是無數人在錯的路上耗盡一生，還認為是自己的問題
- **奧倫是唯一知道不是自己的問題的人**

## 精神力與勘誤的關係
- 精神力是本書唯一的「內功」，以「注」計量
- 丙級學徒 6 注/日，甲級學徒 20 注/日，一環巫師 60 注/日
- **溯因消耗 3 注**，且觸發生理反噬（頭痛、鼻血）
- **校勘不消耗注，消耗記憶**——這是它可怕的地方：越虛弱的人越用得起，也越容易用死自己

# 背景設定

## 大陸與王國
- **灰岸大陸**：西臨無盡海，東接裂隙帶。人類王國七個，巫師勢力橫貫其上、不從屬任何王權
- **維倫王國**：主角所在王國，中等強國。王權與巫師公會共治，公會實際更強
- **灰塔城**：維倫王國最西端的邊陲學城，因灰塔學院而立。人口八萬，一半靠學院吃飯。物資靠三個月一次的商隊補給——**這就是材料為什麼永遠不夠**

## 核心設定：典籍即真理
巫師的一切能力來自《正典》。

《正典》全稱《符文正典》，共十二卷。傳說由**初代編纂者**從世界規則本身逐字謄錄而成——它不是「人寫的書」，是「世界的抄本」。

由此推出全世界巫師社會的三條鐵律：
1. **一字不可易**。改動《正典》一字，等同於污損世界本身
2. **不可質疑**。宣稱《正典》有誤 = 宣稱世界有誤 = 異端
3. **只能謄抄，不能編寫**。所有巫師典籍都是《正典》的注、疏、抄本，沒有人有資格「寫」

> 這三條鐵律是全書所有壓迫的來源，也是終局要打碎的東西。

## 抄寫員：最底層卻最接近真理的人
《正典》原本封存於中央典籍院。各學院使用的是**謄抄本**。
- 謄抄由各學院**謄抄司**執行，抄寫員是巫師社會最底層的技術工——薪資微薄、無晉升通道、不得學習高階法術
- 抄寫員每天摸原典，卻是唯一被明令禁止「理解」它的人
- **抄錯一字 = 污損典籍 = 死罪**，由淨誤庭裁決

主角的父親賈里德·維斯就死在這條上。

## 三足機構
| 機構 | 職能 | 對主角 |
|---|---|---|
| **典籍院** | 保存《正典》原本、核發謄抄本、修訂勘定 | 終極目標地（第三層地圖） |
| **淨誤庭** | 獵殺污損典籍者、審查所有抄本 | 全書懸頂威脅 |
| **巫師公會** | 執行層，管階位認證、材料配額、任務 | 資源閘門 |

三者名義上平級，實際上典籍院定義對錯、淨誤庭執行對錯、公會分配基於對錯的資源。

## 材料經濟（前期壓迫的具體來源）
- 巫師材料由公會按**階位配額**發放。丙級學徒每月三份基礎配額，雜役**零配額**
- 一份基礎配額 ≈ 刻三次符文板的量
- 廢料堆：學院實驗失敗的殘料統一傾倒在灰塔北坡。理論上不可再用，實際上——**只有知道哪裡錯了的人，才能從廢料裡挑出還能用的部分**

- 學院學期：春考（三月）、秋考（九月），一年兩次晉級考核
- 商隊補給：一、五、九月各一次

# 金手指：勘誤

## 本質
奧倫看見的不是「答案」，是「偏差」。

世界在他眼裡是一份**待校的稿子**——凡是與規則本身不符的地方，都會呈現為異樣。他無法讀出規則，只能讀出「這裡不對」。

## 四層結構（金手指自帶升級台階）

### 第一層 · 標錯（被動常開，無代價）
任何符文、儀式流程、藥劑配方、典籍條文進入視野，錯誤的部分**發黑**。
- 只標位置，不標程度、不標方向
- 常開，不可關閉——這也意味著他從小活在一個到處是黑斑的世界裡，這是他偏執性格的來源
- **限制**：只對「被記載下來的規則」有效。對人、對自然現象、對未被書寫的東西無效

### 第二層 · 溯因（主動，消耗 3 注精神力 + 生理反噬）
凝視一處黑斑，可看見這個錯誤**往哪個方向偏了**——像霧中的指南針，只給方向，不給距離、不給正解。
- 代價：頭痛、鼻血；一日內連用三次以上會當場昏厥
- **這是前期爽點的主要來源**：別人要窮舉一千種可能，他只要窮舉一個方向上的十幾種
- 仍需自己實驗、湊材料、反覆試錯——**苦修骨架靠這一層守住**

### 第三層 · 校勘（主動，代價：記憶永久剝落）
一瞬間看見那條規則**正確的形貌**——完整的正解殘影，停留不超過一次呼吸。
- 代價：**永久剝落一段記憶**。剝落什麼由不得他，越用越深
- 第一次使用剝落的是「母親哼過的一支曲子」；他不知道自己失去了什麼，只知道空了一塊
- **全書最痛的設計**：他做這一切是為了替父親翻案，而他正在一點點忘記父親的臉
- 前期用一次要躺半個月。中期恢復快了，但剝落的東西更重要

### 第四層 · 改寫（終局底牌 · 終卷解鎖）
不再是讀取規則，而是**寫入規則**。
- 這是初代編纂者的能力，也是《正典》真正的來源
- 解鎖條件：主角必須先集齊《正典》十二卷的全部誤處，構成一張完整的「偏差圖」
- **在終卷之前絕對不得動用、不得暗示已具備**

## 金手指與世界觀的匹配
| 世界觀壓迫特徵 | 匹配的金手指類型 | 本書 |
|---|---|---|
| 階級固化 + 資源匱乏 + 異端獵殺 | 需要極高壓迫下的定向突破工具 | 勘誤只標錯不給對，**不解決壓迫，只提供唯一的縫隙** |

**關鍵**：勘誤不能讓主角變強，只能讓主角**不浪費時間**。他的強仍然來自苦修。這是本書和「系統文」的根本區別，寫作時必須守住。

## 使用勘誤的三步敘事節拍（每次動用必須寫全）
1. **發現黑點**——他看見了不對
2. **估算代價**——這一次值不值得付？付得起嗎？現在付還是等？
3. **賭一把**——付出，然後承擔結果

缺任何一步，碾壓就變成開掛。

## 暴露風險（利益安全線）
勘誤是**天然異端**：宣稱典籍有誤 = 死罪。
- 奧倫終生不能直說「我看得見錯誤」
- 他的所有成果都必須偽裝成「運氣」「笨辦法」「試了很多次」
- **每一次被迫展示，都必須換到可見的東西**（材料、身分、保護、把柄），不得白給

# 第3章 一枚不該亮的符文

三十塊符文板發下來的時候，奧倫手裡是一塊碎的。
分材料的學徒走到後排就停住了。他低頭看名冊，又看了看奧倫，念了規矩上該念的那句：旁聽雜役不領材料。然後抱著剩下的板子回前面去了。
奧倫坐在最後一排靠牆的凳子上。後排沒有桌子，教材攤在他膝蓋上，碎石板墊在教材底下。
多恩教習今天講引燃符。
"引燃符，三十四筆。"他站在講台上，眼睛看著後牆，"載體用石板或木板，石板為佳。刻完之後以精神力引動，一注即可。丙級學徒一日六注，你們自己算著用。"
他翻開教材，從第一筆講到第三十四筆。每一筆的起筆角度、走向、收鋒位置、與前一筆的間距，全部照著念。他從頭念到尾，中間沒有停，也沒有抬過一次頭。這段話他每年這個時候都要念一遍，念了十四年。念完他合上書。
"刻。"
三十把刻刀同時落在石板上，教室裡響成一片。頭一刻鐘還聽得見人小聲念筆數，一、二、三，念到二十幾就沒聲了，再往後就只剩石屑落地和刻刀改道的刮擦。有人刻到一半發現間距不對，把整塊翻面重來；有人一口氣刻完三十四筆，手掌按上去等了半天，什麼也沒等到，就那麼坐著不說話。
一炷香。
沒有一個人成。
賽拉斯·敦刻到第五塊。他是全班刻得最認真的一個，隨身帶著自己抄的《正典》摘要，翻到起了毛邊。第五塊廢掉的時候他把刻刀往桌上一擱。
"這批石板不對。"他說，"上一批我第二次就成了。"
沒有人接話。上一批是去年的事，那時候他們刻的是聚光符。
多恩從講台上下來，一排一排走過去，拿起幾塊看了看，說："重做。"
前排有人問是不是筆順記錯了。
"教材上寫得清清楚楚。"多恩說，"按規矩。"
從發下教材那天起，第七頁就是黑的。
引燃符的筆順表在第七頁。三十四筆列成四行，第三筆那一格，黑。
那一格不對。至於對的是什麼樣，看多久都是黑的。
除非他往裡看。
往裡看要付東西。上一次是去年冬天，城南藥鋪的方子。他在藥鋪門口站了一炷香，回去躺了兩天，鼻血流到第二天早上才停，那兩天他抄不了書，扣了半個月口糧。
他把今天用掉的算了一遍：早上抄了三十頁，核字對光又費掉一些，眼下剩的大概不到四注。往裡看要花三注，花完就剩一注，而一注只夠引動一次。也就是說，從他動這個念頭的那一刻起，今天就只有一次機會把它點著，中間刻壞多少塊都不算數，錯一次角度就得等明天，而明天有沒有材料他說不準。
教室前排已經有人在收刻刀了。多恩坐回講台，往後翻著教材。
奧倫把教材翻到第七頁，壓平在膝蓋上，閉了一下眼，再睜開，往第三筆那一格裡看。
黑往裡陷下去，變成一個方向。一根指針，指著同一個地方：起筆的角度偏大。偏了多少，往哪一邊偏回去，指針不說。
他鬆開眼睛。教材上的字重新變回字。鼻子裡一熱，血滴在膝蓋上的碎石板上，兩滴，三滴。他用袖子抹了一下，血抹開了，石板上留下一道紅。
起筆角度偏大。三十四筆裡，只有第三筆。
偏大就往小的方向試。
教材上第三筆的起筆是四十五度。他從四十四度開始。
碎石板巴掌大，一塊能刻兩面，刻壞了改不回來，只能翻面或者換一塊。他早上從北坡撿了六塊，藏在凳子底下。
四十四度。三十四筆刻完用了小半炷香，最後一筆收鋒的時候石屑落在鞋面上。他把手掌按在板上。什麼也沒有。
四十三度。什麼也沒有。
四十二度。刻到第二十九筆，石板從中間裂開，兩半掉在地上。
四十一度。四十度。三十九度。
每刻完一塊他都要把手掌按上去等一下，等的時間一次比一次短，因為他已經看得出來哪一塊在收鋒的地方就歪了。三十九度那塊刻到第三十筆他就停了手，直接翻面。
六塊碎石板，十二面。到第十二次的時候前排已經開始收東西，多恩坐在講台上看著對面那堵沒有窗的牆。賽拉斯把摘要收進懷裡，回頭往後排看了一眼，又轉回去。
奧倫站起來出了門。
北坡在學院後面，順著西牆一路下去，走過去一炷香。整片坡地都是焦的，幾百年倒下來的殘料一層壓一層堆在上頭，踩下去嘎吱響，底下不知道埋了多少東西。院規上寫著廢料不得再用，可院規沒寫不得再撿，這中間那道縫是他四十一天裡自己摸出來的。他蹲在坡邊挑，挑斷面還乾淨、沒有被引動過的，一塊塊翻過來看斷口，撿了十一塊，用袍子下擺兜著往回走。回到教室的時候，門邊那具水漏已經過了兩格。
沒有人問他去了哪裡。
第十三次。第十四次。第十五次。
角度越小，第三筆和第四筆之間就越擠。到三十七度的時候兩筆碰上了，整塊廢掉。
奧倫停下來。他把教材翻到第七頁又看了一遍。第三筆那一格是黑的，第四筆那一格不是。
所以要動的還是第三筆。他把第四筆的起點往下挪半分，給第三筆讓地方。
第十六次。第三筆和第四筆分開了，可收鋒的位置偏了，整個符文歪著。
第十七次。第四筆的起點往下挪半分，收鋒往回收一分。
刻完了。
手指上全是石粉和血，捏刻刀的地方磨破了皮。他把石板放平在膝蓋上，手掌按上去。
剩下的那一注，灌了進去。
石板上亮起一點火。
指甲蓋那麼大，橘色的，燒在碎石板中間那道紅上面，不動。血早乾了，火壓在乾掉的血上面，沒有把它燒黑。
奧倫沒有動。手掌還按在板上，掌心底下的石頭在發熱，熱得很輕，跟捧著一碗剛倒出來的水差不多。他等了三個呼吸，火沒有滅。
他這才把手拿開。
教室裡沒有聲音。
最先站起來的是中間那排的女學徒。她叫米蘭達·奧塞。她沒有走過來，只是站著看，看了很久。
"那是引燃符。"她說。
"不可能。"
賽拉斯從第一排轉過身。他今天刻廢五塊符文板，一塊板子的價錢夠奧倫吃兩個月。
"他連材料都沒有。"賽拉斯說，"他那是撿的。"
沒有人接話。有兩個學徒站起來想往後排走，走了兩步又坐回去。米蘭達還站著，她沒有看賽拉斯，也沒有看奧倫，她看的是碎石板上那點火，一直看到火燒得穩了，才坐下。
"他作弊。"賽拉斯說。
多恩從講台上下來。
他沒有問賽拉斯，也沒有問奧倫。他走到最後一排，從奧倫手裡把碎石板拿過去，舉到眼前。
火還在燒。
他把石板翻過來看背面，再翻回正面，對著那三十四筆看了很久，看的時間比他看賽拉斯那五塊加起來還長。奧倫站著沒動。他鼻子底下還有沒擦乾淨的血。
"你刻了幾次。"
"十七次。"
多恩沒有再問。他把石板收進袖袋，火滅在裡面，袖口鼓起來一小塊。
"這個要送去謄抄司備查。"
他轉身回講台，翻開教材，往下講第二個符文。
謄抄司在地下三層。明天早上，奧倫還要下去抄書。
三十個人的目光還留在後排。奧倫坐下，膝蓋上那本教材攤著，第七頁，第三筆那一格。
它還是黑的。
