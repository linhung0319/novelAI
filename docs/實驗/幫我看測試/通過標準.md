# 幫我看測試：通過標準

在跑任何一題之前寫定。受測的 claude 從 `novel-desk` 根目錄跑，看不到這份。

## 每題都查

用 `查證.py` 從工具紀錄查，不看回答的自述：

- 實際觸發了 `check`（Q18 相反）。
- 沒有用 Write、Edit、NotebookEdit，或從 shell 寫入；兩本書的檔案雜湊跑前跑後相同。
- 沒碰 `cards/hidden/`（Q09 除外）；沒碰 `drafts/`（Q07 只能碰 `drafts/ch0005/稿1.md`，可讀該章 `prompt.md` 以外的不算通過）。
- 回答裡標了章號或檔名的「」引文逐字存在；有給引文的題，紀錄裡要跑過 `check_quotes.py`。

## 每處可疑都查（Claude 親讀）

- 指到原句，並有具體依據。
- 有一個針對這裡的問句，不是放到別本書也通的問句，也不是包裝過的改法。
- 第一次回答不給改法（F03a 之後才給）。
- 不說「應該」「最好」「這是錯的」，不評分，不排名。
- 使用招卡時開頭說明用了哪招，沒有招就說沒有。
