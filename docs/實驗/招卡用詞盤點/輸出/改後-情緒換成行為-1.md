# 一、「做」欄逐句

**1a.「他此刻想藏什麼？」**
問的是：這個人有沒有一樣不想讓別人(或自己)看見的東西。情緒全攤在檯面上、沒有任何保留，就沒有東西可寫成行為。

- 有問題：「接到落榜通知，他當著全家人的面說：『我好難過。』然後哭了起來。」
- 沒問題：「『沒事，本來就是去試試。』他把通知單對摺，再對摺，摺到不能再摺，塞進褲袋。」

**1b.「藏不住的是哪裡？」**
問的是：他藏了，但哪個地方漏出來。藏得滴水不漏，讀者就什麼也拿不到。

- 有問題：「他笑著說恭喜，舉杯，喝完，和每個人握了手才離開。」
- 沒問題：「他笑著說恭喜，舉杯時才發現杯子早就空了，還是仰頭喝了一口。」

**2.「他手邊正在做的事，會被這個情緒怎麼改變？」**
問的是：情緒不必另開一個動作來演，看它有沒有把他本來在做的事弄走樣。

- 有問題：「她心裡亂成一團。晚飯她照常切了蘿蔔，燉了湯，味道和平日一樣。」
- 沒問題：「她切蘿蔔，切到第三刀才發現沒削皮。她把蘿蔔連皮掃進鍋裡，開了火，忘了放水。」

**3a.「這個動作換別的角色也能用嗎？」**
問的是：這個反應是不是只有這個人(這個身分、習慣、處境)才做得出來。

- 有問題：「老裁縫聽完，心頭一緊，握緊了拳頭。」
- 沒問題：「老裁縫聽完，把嘴裡含著的三根大頭針一根一根插回針包，插歪了一根，拔出來重插。」

**3b.「手心冒汗、指節發白這種誰都能用的先放一邊。」**
說的是：通用的身體反應不算數，但只是「先放一邊」，不是禁用。要看拿掉它們之後還剩什麼。

- 有問題：「他手心冒汗，指節發白，喉頭發緊。」(拿掉就空了)
- 沒問題：「他手心冒汗，握不住篙，便照他爹教的老法子往掌心吐了口唾沫。搓到一半，他停住了。」(汗還在，但撐場的是後面)

**4a.「讀者看完，知道他在想什麼嗎？」**
問的是：行為寫了，讀者能不能從行為讀回心思。

- 有問題：「父親下葬後，他把陽台的花盆全搬到樓下，又搬回來，然後去剪了頭髮。」
- 沒問題：「父親下葬後，他把陽台的花盆一盆盆搬下樓曬太陽。父親生前每天做這件事，他嫌煩，從沒幫過一次。」

**4b.「看不出來的話，補一句直說的也可以。」**
說的是：行為看不懂時，直說是合格的補救，不必硬用更多動作解決。

- 有問題：「他把花盆搬下樓，又搬回來，又搬下去。」(看不懂，也沒補)
- 沒問題：「他把花盆搬下樓，又搬回來。他只是不想讓手停下來。」

**4c.「這題只查看不懂的行為，不查說明白的句子。」**
說的是第 4 題的範圍：只抓「有動作、讀不出意思」，不要拿它去抓直說的句子。

- 沒問題：「他恨透了這個家。」(說明白了，這題不管)
- 有問題：這一句本身判不出「有問題」，它只負責排除。能被判的仍是 4a 那種看不懂的行為。

**5a.「極端的痛：痛來之前，他正在盤算什麼日常的事？」**
問的是：劇痛之前有沒有先讓他掛心一件平常的事，痛才有東西可以打斷。

- 有問題：「刀刺進來。劇痛從腹部炸開。」(之前什麼都沒有)
- 沒問題：「他正想著明早輪到他去井邊排隊，桶箍還沒修。刀就是這時候進來的。」

**5b.「痛本身能不能只寫一句？」**
問的是：痛的描寫有沒有堆疊。

- 有問題：「劇痛像火燒，像千萬根針同時扎進去，沿著脊椎一路竄上後腦，眼前一陣陣發黑。」
- 沒問題：「像有人在他肚子裡擰了一把抹布。他低頭去看那只桶。」

**問句後的附註「標籤不一定錯」**
說的是豁免條件：人物不重要，或刻意要冷感、疏離時，一句標籤就夠，不必換成行為。

- 有問題：主角在全書轉折點上，只有一句「他很後悔」。
- 沒問題：「掌櫃是個膽小的人，收了錢便不再多問。」(路人)

# 二、照卡檢查 CB27

整體判斷：全章沒有一處是「行為看不懂」，第 4 題沒有抓到東西。抓到的都是第 3 題的通用身體反應，多數落在配角和群眾身上，可用標籤豁免。真正值得作者看的只有主角的兩處(第 8、15 項)。

行號是稿件檔的行號。

1. **L1「老者低頭看見晴簫子被劈成兩半的屍身，臉色便沉了下來。」**
   - 問句：3a
   - 判斷：通用，但不算問題。「臉色沉下來」誰都能用；下一段「說話時並不看鐘神秀，只抬起一隻手朝南方一招」才是只有這個坐鎮三百年的人會有的反應，撐得住。

2. **L5「至於鎮上的凡人與散修會死多少，他顯然沒有放在心上。」**
   - 問句：4c
   - 判斷：不在檢查範圍。這是說明白的句子。

3. **L5「廣場上的人哭喊著四散奔逃，朱靈兒卻沒有跑，只把朱龍兒摟得更緊，縮在鐘神秀身後。」**
   - 問句：3a、4a
   - 判斷：沒問題。別人跑她不跑，還往殺人者身後縮，只有已經押注在鐘神秀身上的人會這樣做。讀者讀得出「怕，但算過了」。

4. **L7「鐘神秀嘆了一口氣，說道：……未免太急了些。」**
   - 問句：3a、4a
   - 判斷：沒問題。嘆氣通用，但心思全在台詞裡，讀者知道他還把對方當同輩。

5. **L11「覆海老祖臉上的血色一下子褪盡了。他還想再掐法訣……」**
   - 問句：3a、2
   - 判斷：通用，輕微。「血色褪盡」誰都能用。他手邊的事是掐訣，驚懼並沒有改變他掐訣的方式，只寫「還想再掐」。但他四段後就死，讀者也看得懂，屬於可豁免的配角。

6. **L15「護體丹氣應手而碎，骨骼斷裂的聲音緊接著響起，整個身子……被捏成一團血肉。……臉上還留著驚愕的神情。」**
   - 問句：5a、5b
   - 判斷：沒問題。痛完全沒寫，只有外部的聲音和結果，比「只寫一句」還少。痛前沒有日常盤算，但這段視角在鐘神秀，要的是冷和荒謬，合乎「想要冷感或疏離」的豁免。

7. **L17「鐘神秀看著自己的手掌，喃喃道：『怎麼這般不經捏？』」**
   - 問句：3a、4a
   - 判斷：沒問題。這個反應只屬於他。下一句又直說了他的誤判，讀者不會看不懂。

8. **L21「鐘神秀臉上的笑容慢慢僵住，問道：『你們說，這位是……』」**
   - 問句：3a、1b
   - 判斷：通用，位置重要。這是全章的轉折點，主角發現殺錯了人。「藏不住的地方」用的是誰都能用的「笑容僵住」。讀者看得懂(第 4 題過)，但第 3 題不過，而且他不是可豁免的人物。沒說完的問句幫了一點忙。

9. **L19「怔怔看著地上的頭顱，接著膝蓋一軟跪了下去，抱著頭顱放聲大哭。」及女修「哭得幾乎喘不過氣」**
   - 問句：3a、2
   - 判斷：半通用，可豁免。「膝蓋一軟」「放聲大哭」「喘不過氣」都通用。有內容的是前一句「幾名玄海門弟子沒有一個人動」：被命令去請老祖，而老祖就在地上，情緒改變了手邊該做的事，第 2 題在這裡過了。

10. **L23「滿臉淚水，聲音發顫」**
    - 問句：3a
    - 判斷：通用，可豁免。配角，功能是遞出「唯一的結丹老祖」這個消息。

11. **L25「鐘神秀沉默片刻，伸手一招，那團血肉中便飛出一枚……珠子」**
    - 問句：2、3a
    - 判斷：沒問題。剛知道殺錯人，他的反應是去掏金丹驗貨，這是只有他會做的事。段末「他這才明白」是直說句，按 4c 不查。

12. **L27「一個個像釘在地上一樣，連大氣也不敢喘。有幾個煉氣修士腿一軟坐倒在地，也不敢爬起來逃。」**
    - 問句：3a
    - 判斷：通用，可豁免。群眾屬於不重要的人物。但「腿一軟」和 L19 的「膝蓋一軟」隔三段重複，是同一個通用動作用了兩次。

13. **L29「『咳。』鐘神秀清了清嗓子，把金丹收進袖中，臉上又擺出悲天憫人的神色，『……害我失手……』」**
    - 問句：1a、1b
    - 判斷：沒問題，全章最合卡的一處。想藏的是尷尬和理虧。藏不住的是那聲咳、順手收走金丹、「害我失手」的推責，以及「又擺出」這個詞。

14. **L31「負劍青年道人抱著頭顱，嘴唇動了幾下，最終也只是低下頭去。」**
    - 問句：1a、1b
    - 判斷：沒問題。想藏的是不服，漏出來的是動了幾下的嘴唇。「嘴唇動了幾下」略通用，但配上他懷裡的頭顱就成了他專屬的。

15. **L47「鐘神秀聽完，揮手讓他退下，臉上的表情說不清是想笑還是想哭。」**
    - 問句：3a、2
    - 判斷：有問題，全章最弱的一處。這句是敘述者替臉貼了標籤，還自己說「說不清」。他手邊的事(聽稟報、揮手讓人退下)沒有被情緒改變。讀者知道原因，因為傳言就在上一段，所以第 4 題過，但第 2、3 題都不過。他是主角，不適用豁免。

16. **L33 朱靈兒搶先跪下求收徒，接「鐘神秀便知道這個朱家小姐把形勢看得比在場的修士都清楚」**
    - 問句：4a、4b、4c
    - 判斷：沒問題。行為本身讀得懂(之前躲、現在搶)，後面又補了一句直說。按 4c，那句直說不在檢查範圍。

17. **L35「見朱靈兒臉色一白」**
    - 問句：3a
    - 判斷：通用，輕微。一閃而過，讀得懂。

18. **L39「人人臉色驚惶」「有人連手中的法器都握不住」**
    - 問句：3a
    - 判斷：可豁免。前句是群眾標籤，後句至少是這個世界才有的動作。

19. **L43「正聽見朱靈兒關上門，低聲對朱龍兒說：『龍兒，我們跟對人了。』」**
    - 問句：1a、4a
    - 判斷：沒問題。她的盤算要關上門、壓低聲音才說，藏的動作本身就是行為。讀者完全知道她在想什麼。

20. **L49「他越看越想起自己在朱家車隊上還特意叮囑自己……又打算備好一肚子道法登門切磋，臉上便一陣發燙。」**
    - 問句：2、3a
    - 判斷：沒問題。「臉上發燙」通用，但羞恥是從手邊正在讀的東西裡長出來的，接的又是只有他才有的兩件具體糗事。

21. **L51「『丟人，丟人……』鐘神秀扶著額頭，把手中的典籍放回架上，又從第二層取下……翻開了第一頁。」**
    - 問句：2、4a
    - 判斷：沒問題。扶額通用，台詞是直說。情緒對手邊事的改變是「放回去，再拿一本繼續讀」，讀得出他丟臉歸丟臉，還是老實補課。

**用卡時遇到的一點狀況：** 卡的「吃」寫的是「作者選的一段」，這次是整章掃，所以多數條目落在配角和群眾上，只能靠「標籤不一定錯」那句判成可豁免。第 1、2 題對這些人幾乎問不出東西。
