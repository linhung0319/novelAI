# 一、卡上「做」欄的七個問句

**問句 1：這段有幾處在喊「這裡重要」？真正轉折的是哪一處？**

它在問：數一數這段有幾個強調記號（獨立成行、破折號、短句、重話），再找出事情真正改變方向的那一處。記號比轉折多，多出來的就是假重音。

- 有問題：「他推開門。／屋裡沒有人。／一個人都沒有。／桌上，只有一封信。」四處都在喊，真正的轉折只有信。
- 沒問題：「他推開門，屋裡沒人，被褥疊得整整齊齊，灶上的水還溫著。桌上壓著一封信。」前面平著走，只有信那句單獨立起來。

**問句 2：單獨一行的短句，有新的事發生，還是把剛說過的話再說一次？**

它在問：這行拿掉，讀者會不會少知道一件事。

- 有問題：「她把鑰匙放在鞋櫃上，沒有回頭，走了。／她走了。」
- 沒問題：「她把鑰匙放在鞋櫃上，沒有回頭，走了。／樓下傳來發動機的聲音。」

**問句 3：夾在長段之間的極短段，是要讀者在這裡停下來嗎？併回去會少什麼？**

它在問：這個停頓是不是作者有意要的。測法是把它接回上一段，看有沒有損失。

- 有問題：長段寫他清點帳目，然後獨立一段「他繼續算。」，再接長段寫帳目。併回去什麼都沒少。
- 沒問題：長段寫他清點帳目，然後獨立一段「少了三百兩。」，再接長段寫他翻查經手人。併回去，這個發現就淹在帳目裡。

**問句 4：想快的地方，是靠一句話說完一件事，還是把句子砍斷？**

它在問：速度感是來自一句話推完一件事，還是只把句子切碎。切碎的句子每個句號都是一次煞車，反而慢。

- 有問題：「刀來了。很快。他側身。躲過。反手。一劍。」
- 沒問題：「刀來得很快，他側身讓過，反手一劍從那人肋下遞了進去。」

**問句 5：留白是留給讀者想像，還是沒寫清楚？**

它在問：沒寫出來的東西，讀者憑前文補不補得出。補得出是留白，補不出是漏寫。

- 有問題：「他看著那張照片，想起了那件事。原來如此。他把照片收了起來。」前文沒交代是哪件事，也沒交代明白了什麼。
- 沒問題：「母親把他的碗筷也擺上了，擺完才想起來，又一樣一樣收回櫥裡。」沒說人不在了，但讀者知道。

**問句 6：段尾那句是把事情講完，還是把前面鋪的東西收成一句判斷或格言？這一章這樣收了幾次？**

它在問兩件事：段尾是事情的最後一步，還是作者跳出來替讀者下結論；以及這種收法在全章出現幾次。一次不算問題，成了習慣才算。

- 有問題：「他把攤子收了，零錢一枚一枚數進鐵盒。有些人一輩子都在數別人的錢。」
- 沒問題：「他把攤子收了，零錢一枚一枚數進鐵盒，扣上蓋子，推著車往橋那頭去了。」

**問句 7：這段有沒有平的句子？**

它在問：有沒有只負責交代、不帶巧思的句子讓讀者喘氣。每句都有設計、每個小動作都回來呼應，就沒有輕重之分。

- 有問題：「她攪了攪茶，匙子碰著杯壁，叮的一聲。他說他要走了，匙子又叮了一聲。她笑了，匙子停在杯沿，像一根沒落下的指針。」
- 沒問題：「她攪了攪茶。他說他下個月調去高雄，房子已經找好了。兩人又坐了一會兒，他去結了帳。」

# 二、照卡檢查 CB27

**總判斷：這章基本不在這張卡的適用範圍內。** 全章沒有獨立成行的敘述短句，沒有破折號，沒有砍斷的句子，平的交代句很多。下面是逐處的結果，真正可疑的只有第 1 處，第 2、3 處是輕微。

### 可疑

**1.「晴簫子要收朱龍兒時，她躲開了，現在卻搶在所有人前面開口，鐘神秀便知道這個朱家小姐把形勢看得比在場的修士都清楚。」**

- 問句：6（段尾是講完事情，還是收成判斷）
- 判斷：有問題。「躲開」和「搶先開口」的對照已經把意思說完，段尾再替讀者下一次結論。
- 全章次數：這是唯一一處純粹的判斷式收尾，沒有成為習慣。

**2.「鐘神秀的神識掃過時，正聽見朱靈兒關上門，低聲對朱龍兒說：『龍兒，我們跟對人了。』」**

- 問句：6，連帶 2（有沒有新的事）
- 判斷：輕微可疑。單看是一句台詞收段，不算格言。但它和第 1 處說的是同一件事（朱靈兒看得清形勢），等於同一個判斷收了兩次，一次由敘述者說，一次由角色說。新增的資訊只有「她私下也這麼想」。

**3.「廣場上一片死寂。」→「一個個像釘在地上一樣，連大氣也不敢喘。」→「無人說話。」**

- 問句：1（幾處在喊重要）
- 判斷：輕微可疑。「全場嚇呆」在七段之內說了三次。真正的轉折是負劍青年那句「門中唯一的結丹老祖」，以及鐘神秀看金丹後的「他這才明白」。
- 三句裡，「無人說話」是在回答「可有異議」，有新的事。「一片死寂」和下一段的「釘在地上」做的是同一件事，前者是概括，後者是具體畫面。

### 檢查過，判斷沒問題

**4.「道友別慌，坐下來說話。」**（獨立一行）

- 問句：2、3
- 判斷：沒問題。這是新的事（他開口，而且語氣和手上的動作相反），下一段的「哪裡肯聽」接的就是它。併回上一段，這句會埋在抓人的動作後面，少了一拍。

**5.「無人說話。負劍青年道人抱著頭顱，嘴唇動了幾下，最終也只是低下頭去。」**（夾在兩個長段之間的短段）

- 問句：3
- 判斷：沒問題。這是對「可有異議」的回答，是易主這件事落定的地方，值得停。併回去會讓問句和朱靈兒的求徒黏在一起。

**6.「鐘神秀聽完，揮手讓他退下，臉上的表情說不清是想笑還是想哭。」**（短段）

- 問句：3、5（留白是否清楚）
- 判斷：沒問題。短段是對傳言的反應，併進上一段會被稟報內容蓋掉。「想笑還是想哭」沒有說破，但上一段的傳言已經給足原因。
- 保留一點：我只讀了這一章，「桃花盜」指的就是他這件事，是照本章文意推定的。

**7.「他這才明白，此界所謂的結丹老祖，根本不是他以為的元丹老怪。」**

- 問句：6、1
- 判斷：沒問題。形式上是段尾的判斷句，但它是角色此刻才得到的認知，也是全章真正的轉折，後面的收門派、翻典籍、「丟人」都從這句來。它不是把已經演過的東西再收一次。

**8.「從前只擋外人，如今連陣中的人也出不去了。」**

- 問句：6
- 判斷：沒問題。句型是對仗式收尾，和卡上的例句長得像，但內容是一件新的事實（大陣變成了牢籠），不是格言。

**9.「結果覆海老祖的護體丹氣應手而碎，骨骼斷裂的聲音緊接著響起，整個身子在元氣大手中被捏成一團血肉。」以及水牆崩解那一句**

- 問句：4（快是靠一句說完，還是砍斷）
- 判斷：沒問題。兩處都是一個長句把一件事推到底，沒有切碎。

**10.「你們說，這位是……」「害我失手……」「老祖……老祖……」**

- 問句：5
- 判斷：沒問題。三處省略號都在對話裡，沒說完的部分讀者都補得出，下一句也立刻接上。

**11. 頭顱反覆出現（滾出指縫 → 青年抱著哭 → 抱著頭顱低頭 → 被元氣一起托走）**

- 問句：7（小動作是否都回來當呼應）
- 判斷：沒問題。它出現四次，但每次都是場面上實際還在的東西，沒有被拿來做意象，不是卡上「鞋跟踩下去、拉上來、又踩下去」那種回扣。

**12. 全章有沒有平的句子**

- 問句：7
- 判斷：沒問題。「他袖袍一捲……朝玄海門山門飛去」、護山大陣一段、重煉陣眼一段、三日後稟報一段、藏經閣翻書一段，都是平的交代。
