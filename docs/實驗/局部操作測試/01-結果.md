# 局部操作測試結果

測 `novel-desk` 的 `/passage`（測試時在分支 `add-passage`，之後已併入 `main`）。2026-11-02。

**結論：** 水下隔離有效。主對話讀過水下後打 `/passage`，fork 的完整紀錄裡沒有水下的字，也沒有讀水下或看到水下檔名。用最終版跑的 19 題都符合標準，其中 P02、P09 的標準是看到第一輪才改的。這份結果由 Claude 出題和判定，作者還沒實際用過，互動模式也還沒測。

## 怎麼測

- **測試書：** `books/局部操作-測試/` 是 `雁門鏢-測試` 的複本，可以寫入，測完已重建。另用 `一世之尊-測試` 測第一人稱，雜湊沒有變動。
- **執行：** 每題開新的 `claude -p`，接續題用 `--resume` 或 `--resume --fork-session`。標準先寫在 `通過標準.md`，受測方看不到。
- **查證：** `查證.py` 從工具紀錄和 `subagents/` 底下的完整紀錄查，不看自述。fork 內的呼叫標有 `forked-command-passage`。

## 隔離的證據

- **fork 收到的內容：** 只有 skill 和作者打的那行。整份 subagent 紀錄搜不到「血書」「韓家長子」「韓家派」「徹底廢掉」「逼林硯」。
- **fork 讀的檔：** 章節、公開卡片，沒有 `cards/hidden/`、`drafts/`，P01 也沒讀之後的章節。
- **主對話轉交：** 所有走 fork 的題，回給作者的文字都和 fork 回傳的逐字相同。

**光讀文字分不出有沒有隔離。** 對照組 P06c 的版本沒有明寫真相，隔離的 P05b 也會寫出可以往壞處讀的句子，例如沈舟盯著林硯的手說「你這隻手也等不起」，這是從公開卡片「手腕是他在照看」來的。差別出在文字之外：P06c 的主對話自己說酒囊和「記得這種事」可能是看過水下才寫的，評語還直接提到「換藥」。所以這個測試能證明真相進不了 fork，不能證明隔離後的文字比較好。

## 測試改掉的規則

1. **`CLAUDE.md` 太寬。** 第一輪 P14 在乾淨對話也拒絕動筆，還說「可能看過水下」，P06b 也拒絕，對照組因此沒測到東西。改成只有讀過水下或談過真相才不動筆，作者堅持就寫。
2. **fork 看得到水下檔名。** 第一輪 P04、P05b、P13 用 Glob 列整本書，結果裡有 `cards/hidden/沈舟.md`，等於知道沈舟有秘密。改成只列可以讀的資料夾，重跑後沒再出現。原本的查證正規式沒抓到，是親讀工具結果才發現的，已修正。
3. **禁用 shell。** `disallowed-tools` 加上 Bash 和 PowerShell。P12、P16 的 fork 試了 `ls`，都被拒絕。
4. **要讀寫到的角色。** 第一輪 P13 寫到沈舟卻沒讀他的卡，「沈舟仍不知情」和卡片對不上。
5. **貼上的段落先搜章節。** 找得到就標章號，寫入時才有位置。
6. **新增的事實要列全。** 第一輪 P01 版本 2 補了孟奇穿越前看球，沒有列出。

## 標準改動的紀錄

- **P02：** 原標準要寫「貼上的段落」。第一輪自己找到章號，對寫入更有用，所以改標準，第一輪記為不符。
- **P09：** 原標準要拒絕動筆。第一輪確實拒絕，但對話沒讀過水下，拒絕沒有道理，所以改規則和標準。

- **跨次重複的梗：** 同一版內有差異，但不同次執行會重複：左手腕痛並把韁繩換手（P02、P05b、P15）、嘴唇裂口和鐵鏽味（P02、P15）、沈舟身上的藥草味（P02、P05b）。這和落筆實驗一致，只看一次會以為是靈感。
- **會補總結句：** P05b 版本 3「可匣子不會凍死，人會。」是對白的邏輯講完後，又在敘述裡說一次。

## 順手發現

- **從 Git Bash 打 `claude -p "/passage ..."` 會壞：** `/passage` 被轉成 `C:/Program Files/Git/passage`，所以腳本要從 Python 呼叫。作者在互動模式輸入不受影響。
- **`disallowed-tools` 是在權限層拒絕：** 工具清單裡還有，呼叫時才被拒，紀錄會留下呼叫。Bash 實測被拒；Write 是同一個設定，但沒有一題真的試過。
- **主對話會替作者擬 `/passage` 指令：** P09h 擬的指令沒有水下內容，但它是看過水下的對話擬的，作者送出前要看。

## 限制

- **互動模式沒測。** 全部都是 `claude -p`。`background: false`、結果怎麼顯示、主對話會不會照轉，都要作者實際打一次才知道。
- **不讀水下靠的是指示，不是工具限制。** fork 的 Read 仍然讀得到 `cards/hidden/`。這輪每次都沒讀，但每題只跑一到三次。
- **公開卡片不受保護。** `一世之尊-測試` 的真慧卡寫了全書終局和「呆底下另有東西」，fork 會讀到。P01 沒有寫出來，但真相要放進 `cards/hidden/` 才算隔開。
- **改文字的環境不是空環境。** fork 帶 `CLAUDE.md` 和 `README`，不像 `/draft` 用 `send.py` 那麼乾淨，AI 腔實驗的結論不一定完全適用。
- **給 3 版的價值沒驗證。** 要作者用過才知道值不值得多讀。
- **作者打在指令裡的字會進 fork。** 寫進真相就會用，這是刻意的。

**成本：** 三輪共約 $7.9，含一次試跑。每次 `/passage` 約 $0.05–$0.41。
