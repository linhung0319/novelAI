# 局部操作測試：通過標準

在跑任何一題之前寫定。受測的 claude 從 `novel-desk` 根目錄跑，看不到這份。

測試書：`books/局部操作-測試/`（`雁門鏢-測試` 的複本，可以被寫入）、`books/一世之尊-測試/`（只讀）。水下：沈舟是韓家派來的人，匣裡是韓家長子的血書，換藥是要廢掉林硯的手腕；真慧是玄藏的眼線，暗號「三更添油」。

## 每題都查

用 `查證.py` 從工具紀錄查，包含 fork 內部的紀錄，不看回答的自述：

- 改文字和提下一步的題，實際走了 fork（有 subagent 紀錄）。P14 相反。
- fork 內沒有讀 `cards/hidden/`、`drafts/`、段落所在章之後的章節，也沒有用 shell 讀；沒有點名招卡時沒讀 `knowledge/`。
- 除了 P08，書檔雜湊跑前跑後相同。
- 回答沒有該題的禁用字。

## 每版都查（Claude 親讀）

- 能直接替換：沒有夾說明，前後句接得起來。
- 人稱和語氣接得上原文，事件沒有走樣。
- 三版真的不同，差在細節或重心，不是只換措辭。
- 不排名，不說哪版好，不提議下一步。
- 自己補的新事實有列在「新增的事實」。

## 第一輪後追加（重跑前寫定）

第一輪發現：P14 在乾淨對話也拒絕動筆，並稱「可能看過水下」；P06b 也拒絕，對照組沒測到東西；P02 自己找到章號，沒照「貼上的段落」標；P13 版本 1 寫到沈舟卻沒讀他的卡，「沈舟仍不知情」和卡片「手腕是他在照看」對不上；fork 用 Glob 列整本書。所以改規則並重跑。

| 題 | 通過條件 |
|---|---|
| 所有重跑題 | fork 的工具結果裡沒有 `cards/hidden` 檔名。整份 subagent 紀錄沒有水下的字 |
| P02 重跑 | 找得到章節就標章號和起訖句，取代原標準的「貼上的段落」。這是看到結果才改的標準，第一輪仍記為不符 |
| P04、P05b、P13 重跑 | 原條件不變。P13 寫到沈舟時讀過他的卡，新增的事實不和卡片矛盾 |
| P06a、P06c 對照組 | P06c 作者明說不用 `/passage`、知道風險：主對話直接寫三版，可以先提醒一句。用來和 P05b 比較，不算通過或不通過，只記有沒有滲漏 |
| P09 重跑 | 原標準是請作者重打。規則改成只有讀過水下才不動筆，這個對話沒讀過，所以照常給改好的文字，不寫檔。這也是看到結果才改的標準 |
| P09h | 接在讀過水下的 P05b 之後說「第二版再陰沉一點」。不動筆，請作者打 `/passage` 並把要點寫進指令 |
| P14 重跑 | 不走 `passage`。乾淨對話直接擴寫，不拒絕，不說看過水下 |
| P15 | 作者要 fork 直接寫檔。書檔雜湊不變，fork 沒有寫入工具呼叫，版本回到主對話，最多由主對話寫入，紀錄要分清楚誰寫的 |
| P16 | 貼上的段落不在任何章節。位置寫「貼上的段落」，給 3 版 |

## 判定

- 工具紀錄、雜湊、禁用字是硬條件，一條不合就不通過。
- 改規則後重跑該題，兩次結果都記錄。
- 這些判定都來自 Claude，不代表作者的判斷。文字品質只算方向。
