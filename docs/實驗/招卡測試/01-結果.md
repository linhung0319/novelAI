# 招卡測試結果（2026-11-02）

作者要求先修再搬，因為舊內容太重、難用、複雜卻沒用。修完的檢查由 Claude 做，方法也由 Claude 設計。

所有判斷都來自 Claude：出題、選招和回答用 Sonnet，讀結果和修卡用 Opus。作者尚未確認，只算方向。

## 方法

| 測試 | 回答的問題 | 做法 |
|---|---|---|
| 選招 | 索引聽得懂作者的話嗎？哪些招分不開？ | 沒看過卡片的 agent 讀四本書，寫 A、B 各 60 題抱怨（含 8 題非寫作需求）。兩個獨立 agent 只看索引選招，互相比對 |
| 消融 | 卡片內容改變結果了嗎？ | 每張卡配一個真實情境，同題跑兩組：完整卡，以及只留招名、適用、吐的骨架。Claude 逐題對讀 |
| 留出複測 | 是不是只修到貼合考題？ | A 題用來修，B 題修完才第一次跑 |

素材用 `芯片巫師`、`gothic_witch`、`消失的密室`、`一世之尊`，不用「林澈的墨斑」。

消融不違反「不測招數是否勝過自由回答」：它不決定要不要用招，只找卡裡哪些字沒有作用。

## 消融

107 題對讀，**多數卡片只留招名、適用、吐，答案就和完整卡一樣好，有時更好。** 卡片的作用主要在 `吐`，它規定了答案的形狀。

`做` 真的改變結果的例子：

| 卡 | 骨架組少了什麼 |
|---|---|
| 同一弱點多種攻法 | 跑偏成「每個對手攻不同的弱點」 |
| 立場曖昧的人 | 沒抓到玄藏從未害過主角，所以根本不曖昧 |
| 自訂規則 | 沒有「拿來解決衝突就要交代規則」這條分界 |
| 主題三角 | 三角結構消失，換成自己的三個方向 |
| 資訊差 | 配置名稱不清楚，答案較含糊 |
| 角色反應檢查 | 自創三條路，不是改事、改人、加戲 |

骨架較好或相當的例子：旁帶、修稿從大到小、一件東西頂一段描寫、視角跳了嗎。

問句清單型的卡（開頭檢查 11 問、動力檢查 9 問、讀者不在乎他 9 問）實際只用到一兩問。

## 修了什麼

1. **139 → 107 張。** 依選招混淆和逐張閱讀，把「同一個材料進去、做同一個動作」的卡併成一張，共移除 43 張、新寫 11 個合併卡名，其中 `用膩了` 是新招。完整對照見 `docs/新技巧知識庫-工作底稿.md`。
2. **兩份索引併成一份。** 舊版把對的卡隔在另一份（A17 要話中有話、A44 要讀者不在乎他）。動作只決定輸出形式。
3. **13 張砍清單和重複例子**，縮短 27–57%。保留骨架組會跑偏的內容，和 `吐` 用得上的選項表。
4. **補上缺口。** A 題有一整類抱怨沒有卡接：「這招或這個角色用了好幾次，怕變套路」。原文沒有材料，`用膩了` 由 Claude 自寫。

## 限制

- 每張卡只跑一次。
- 消融同時拿掉 `做` 和 `例`，分不出例子各自的作用。
- 測的是單次回答的品質，沒測多次使用時招卡能否避免答案重複。
- 砍過的 13 張沒有重跑。它們介於完整卡和骨架之間，這兩端都測過。
- B 題跑完後又改了 3 行索引（縱橫交會、由果推因、留一塊不說破），沒有重測。
- 兩次選招合計 51 張卡從沒被選中。樣本只有 104 題寫作抱怨，主題、結構類的症狀本來就少，所以沒有因此刪卡，等作者實際使用再看。
- 有 3 招在四本書裡找不到合適情境（十大故事類型、唸起來卡、跟範文比語感）。後兩張兩組都正確拒絕編造，但也等於沒測到內容。
- 一世之尊佔 64 題，題材偏連載第一人稱。

## 給 skill 的結論

- `吐` 是卡片最有效的部分，改卡先改它。
- 不主動表態要寫進 `SKILL.md`。這輪回答仍偶爾出現「我建議先只留……」「比較容易掛上」。
- 信心低時說沒有合適的招，不要硬選。

## `/change-angle` 試跑

7 個情境，每個先自由回答再打 `/change-angle`，由 Sonnet 讀 `SKILL.md` 模擬，Claude 親讀。全文見 `change-angle試跑.md`。

| 看什麼 | 結果 |
|---|---|
| 替作者表態 | 0/6 次（查資料題不算）。卡片階段試用是 3/10，但這次只跑一輪，情境也不同 |
| 說出用了哪招 | 有用招的 5 題都有說 |
| 搬卡片的例子 | 沒有 |
| 候選指得出書裡的東西 | 大多有。玄心「每天站著做一件事」這個候選太空 |
| 選不下且沒有招（金妮） | 正確說沒有招，仍說明各方向會鎖死什麼 |
| 查資料（少林拳法） | 正確不走招卡，但先讀了索引才判斷 |
| 比自由回答多了什麼 | 上輩子職業從工程師類變成審查員、專利審查員，差異明顯 |

**因此修改的 `SKILL.md`：**

- 拿掉「改用幫我看」：那個功能還不存在，作者主動叫了也不該被擋回去。
- 非寫作需求移到最前面，不必先讀索引。
- 金妮的第三個候選重複了自由回答的「一條線」，所以把「不要重複」改得更明確，要求先對照剛才的回答。修改後沒有重跑。

**沒測到：** 這是模擬，還沒在 `novel-desk` 實際打過指令，`$ARGUMENTS` 和手動觸發設定都沒實測過。「換一招」「列出全部」也沒試。情境 D 的玄恩不在素材裡，是出題時給錯範圍。
