## 逼他上路

現在的鏈條是：家庭背景設定 → 孤兒院 → 領養又退回 → 疾病 → 魔法學校。小女孩在每一步都是被安排的，只有「偷藥」那一步是她自己做的。三個候選都從那一步接過去：

1. 學校是為了那群孩子。藥讓孩子們覺醒魔法，教廷會抓野巫師，孤兒院保不住他們。她一開始拒絕，後來發現只有跟孤僻男孩去學校，才能把那些孩子擋在教廷視線外。連到上一段：她的決心來自她餵的那些藥。
2. 她要維持「畫中居民」的假身分。特殊性被注意到之後，她不去的話，孤兒院的人會追問她的來歷，假裝會破功。連到上一段：她上次搞砸就是因為被發現不是畫中人。
3. 她想看男孩的魔法。男孩是早先就展現天賦的孤僻者，她想弄懂自己給的藥到底做了什麼。連到上一段：她是帶著罪疚或好奇離開古宅的。

三條各會讓學校的第一場戲不同：第一條她心裡掛著孩子，第二條她得時時防穿幫，第三條她對男孩有所圖。

## 縱橫交會

你的素材裡金妮已經有三處自然的線頭：洞穴屋飯桌打翻麵包、躲到門後（ch0004）、「還沒想清楚」裡的甲乙案。三條候選：

1. 金妮 × 日記，撞在「本子乾淨」那一格。先露：她打翻東西、躲人，還有紅墨水潑到所有書、唯獨那本沒事時，她在場。補完：在她選擇繼續寫的那一刻（乙案），讓她自己說出口。代價：十一歲要背責任，結尾不處罰她時讀者可能不服。
2. 金妮 × 哈利的孤單，撞在「沒人理他」。她和他一樣是沒人聽的孩子，哈利暑假等信的那條線和她寫日記是鏡像。先露：兩人在不同場合都不說話。補完：哈利發現日記時認出那種寂寞。代價：副線偏情感，推進主線的力道弱。
3. 金妮 × 貓。把「貓為什麼算進去」這個你目前沒解的洞，改成跟她有關（貓出事那晚她在哪）。先露：她身上有一處對不上的小細節。補完：貓的理由揭曉時回頭全對得上。代價：甲案幾乎做不到，她必須有行動。

## 給他一個不足

三個不足，各推出不同的書：

1. 芯片只優化「收集過的資料」，他自己沒有本地知識。一個穿越者沒有師承、沒有出身，進不了巫師的知識圈。主線變成他要拿什麼去換第一批資料，也就是他怎麼被迫欠人、被迫偷、被迫賣自己地球的知識。
2. 芯片越聰明，他越分不清哪些念頭是自己的。它給的建議每次都對，但他慢慢發現，它的「最佳解」從不替他的人際關係考慮。主線變成他要不要放棄一個對的決定，去保住一個人。
3. 地球科技腦只懂「無魔環境」的原理，到了有魔的地方，一半直覺會騙他。他需要一個本地巫師告訴他哪裡錯。主線變成師徒或搭檔：誰教他、他拿地球知識換什麼。

## 幕裡寫了什麼

粗分五類：對白、動作、物件／環境、內心／感受、說明。這幕前半是對白加動作，滿滿的，但哈利的內心和感受幾乎是零。你整本綁死哈利視角，這裡卻像在看一場沒有他的戲。怪的原因在這：他被兩個月沒人理，走進一桌八個人，只有「放下去又加一勺」那一下是對他的，但哈利對它沒有任何反應。

三處改寫：

1. 「九家」「它飛得怎麼樣」那段，加哈利一個身體動作或視線：他看著衛斯理先生的手，等著有人說車的事是他們的錯。
2. 金妮的盤子滑落，讓哈利聽見麵包滾的聲音，並且看見她躲開的視線，不解釋。
3. 衛斯理先生「看了哈利兩秒」之前，加半句哈利預期被罵、肩膀縮著。這樣笑起來才是被接住。

## 旁帶

「有主心骨」是作者在說，讀者沒東西比。三個場面，各借一個人：

1. 借齊正言。張遠山報「粗淺外門功夫」時，讓齊正言（他在孟奇旁邊會倒抽涼氣）認出張遠山一個小動作，低聲說「這不是外門」。懂行的人替他證明。
2. 借戚夏。ch0020 的機關戰裡，戚夏是全隊最吃重的刀。讓她在最險的一波裡，有一次不看傀儡而先看張遠山的手勢再動。強者服從他，比他自己強更有說服力。
3. 借敵人。ch0010 黑衣人專挑空當下手，讓他們有一次繞開張遠山斷後的那一側，或有一人直接撞上，被一掌震飛，其他人在黑裡停了半拍。

## 誰來點醒他

三個候選：

1. 江芷微給玉牌但不說那九個字。誰給：她。給什麼：只有玉牌。主角付什麼：之後罩子破了他自己痛過，才知道要買保命的。之後帶出：她事後問「你換了什麼」，那時才說保命、改資質、輸出後置，說教有了他的痛當底。
2. 齊正言說，因為他資質同樣薄。誰給：他。給什麼：同樣的建議，但帶著自己的盤算，因為他也要別人幫他。主角付什麼：一筆善功或一條情報作交換。之後帶出：兩人立刻有了互相算計又互相依靠的線。
3. 江芷微先問一題才給。她問他剛才為什麼往人堆最裡頭擠。他答了實話（怕），她才給玉牌和話。主角付什麼：承認自己的怕。之後帶出：她對他的觀察變成後面幾場她替他留位置的依據。

## 內外目標排序

我只看到 ch0070 的開頭和一段，以下是依此推的骨架：

1. 被撈進市集，罵不是時候，少林那本簿子還掛著（已有）。
2. 領任務，三人分工（已有）。
3. 任務本身：這裡缺一場讓少林那條線介入的戲。例如任務裡某個兌換項或某個人，剛好碰到簿子上那個影子。
4. 人少、位置空，他把空「按了下去」（已有，但只有一段內心）。
5. 結算：沒有人跟他對答案，他獨自核一次。這場是內在問題最好演的地方。

標出：「少林的帳」在輪回世界裡全程沒有戲，只有開頭一句話；「對答案的人不在」只有第 43–51 行那一段，被按下去了。這兩處是需要戲的。

可刪候選：市集的環境鋪陳、重複說明輪回規則的段落、任務中段第二場同型的戰鬥。

## 自訂規則

ch0004 的衛斯理先生已經替這輛車宣告過規則：點菸器接去別處、試了三次、第一次只有前半截不見。語氣是「改造失敗的實驗」，這已經是它的規則了：不穩定、不合理，而且是人為造成的。所以你不用另外解釋成因，三種選擇：

1. 永遠不解釋成因，只讓它每次回來都有用處。代價：讀者可能覺得隨便，所以每次出現要多做一件事（救人、嚇人、露出線索）。
2. 結尾由衛斯理先生用一句話回收（「我當初拆的是……」）。代價：解釋可能比讀者累積的想像小。
3. 它第二次消失時，由角色半開玩笑地猜（車想回森林）。代價：「很不合理的地方回來」的驚喜會變成有伏筆。

## 無關組合

三個新概念：

1. 「引用就是防護」：克蘇魯的瘋狂知識只在沒有出處地接觸時傷人，所以學術格式（引用、同行評審）成了防瘋的儀式，主角的芯片負責幫他查出處。衝突：巫師組織要快速晉升，不要慢慢審。說不通：為什麼格式能擋瘋狂。
2. 「新聞業巫師審稿」：維多利亞報紙巫師的力量與信息有關，克蘇魯知識像一種會自我複製的新聞。主角寫論文，其實在做審查：哪些知識可以出版。衝突：他的誠實和組織對知識的壟斷。說不通：論文怎麼變成力量，不只是情節裝飾。
3. 「入侵世界是田野調查」：巫師入侵異世界掠奪知識，主角卻用論文記錄那個世界，結果他寫的東西比戰鬥更改變局勢。衝突：他的記錄方式讓被入侵者看起來是人。說不通：芯片是不是有倫理，還是只優化。

## 這段回憶該不該插

這段不是岔題，它是因果鏈：想找人說 → 摸冊子 → 他不在了。冊子是觸發物，回憶是必經的路，結尾「該有另一半的地方是空的」靠回憶撐起來。但長度確實可能卡。四種安排：

1. 整段插，現在這樣。代價：「你這道斜的是幾點」那一整輪對話占了篇幅，前面「然後我想找個人說」的動力會被稀釋。
2. 縮成幾句，只留一個來回（三十七那段）加「他那本記得比我齊整」。代價：他笑到岔氣的溫度沒了，後面的空沒那麼重。
3. 換位置：這章只寫到「天底下曾經有第二個人」，回憶整段挪到 ch0070 人少那處。代價：這章少一個鉤，而且 ch0070 要負責補完。
4. 刪掉，只留空白的冊子。代價：ch0070 那句「他不在了」讀者沒有重量可感。

1. 戚夏漏掉一尊傀儡 → 江芷微被咬住 → 傀儡撲燈。綁住兩人，前者的失手決定後者的難。

## 誤導佈局

幕綱已經禁止替派西做記號、也不能用敘述提示，所以疑心只能由別人或哈利自己製造。三個方案：

1. 一層偽誤導，靠「看見但沒懂」。哈利看見他在地下層、臉色慘白，也看見他按住金妮，但當時在想別的事。讀者的層次：他是繼承人 → 他在遮掩什麼 → 揭曉他在保護妹妹。最難兜：他阻止妹妹說話的那一下，必須有一個無辜版本的解釋。
2. 兩層：先讓讀者疑馬份（慣性），再讓派西的異常浮上來，最後回到金妮。讀者層次：馬份 → 派西 → 他們都不是。最難兜：馬份那層要有真的偽證據，不能只是嘴上說。
3. 疑心由弗雷喬治的玩笑說出（「他一定是繼承人」），讀者以為是笑話；後來玩笑變認真，最後仍無罪，煩不等於有罪。最難兜：玩笑的措辭必須在揭曉後仍站得住。
