唐花離手的那一刻，孟奇心頭忽然一緊。幻形練出來的預感比念頭還快地浮了上來，他便往左橫移了半步，原地只留下一道暗金色的虛影。唐花穿過虛影，結果去勢不減，直直釘進了神廟的土牆，然後在牆面上綻開。八片薄如蟬翼的花瓣向四周彈出，花心跟著噴出一蓬淡綠色的粉霧。

牆根下原本藏著幾窩躲風沙的蟲蟻，還有一隻縮成一團的沙鼠。粉霧落下，蟲蟻便蜷起細腳一動不動，沙鼠抽搐兩下也翻了肚皮，土牆上被花瓣割開的地方則冒出細細的白煙。陳瀟和羅友正擠在破窗邊往外看，粉霧離他們不過一丈遠，陳瀟臉色一白，往後退了一步。羅友嚥了口唾沫，低聲道：「這要是打在人身上……」後半句他沒敢說完。

孟奇沒有回頭看那面牆，收回橫移的半步，紅日鎮邪刀已經舉過頭頂。唐這時才發現自己打中的只是虛影，正要抽身後撤，孟奇便一刀劈了下去。刀光赤紅，就像沙暴裡忽然升起一輪太陽，從唐的左肩斜斜斬到右肋，刀上的灼熱把傷口邊緣燒得焦黑。

刀鋒入肉的那一瞬，唐想起的卻不是眼前這個小禿驢。她想起九歲那年被關進藥房，師父每天逼她吞下一種毒，看她嘔吐，看她抽搐，看她手背上的皮一片片爛掉，然後才把解藥扔到她腳邊。她也想起第一次被竹葉青咬中，小腿腫得像柱子，三天三夜沒人管她死活。她咬著牙熬了過來，練成一身毒功，卻也熬成了人人繞著走的怪物。後來她被六道輪回之主召進輪回，在第一個輪回世界裡遇見了云霆鋒。云霆鋒笑著遞給她一塊手帕，讓她擦掉臉上的血，說：「姑娘生得這樣好看，怎麼弄得這樣狼狽。」那是第一次有人不怕她。

唐的雙腿一軟，倒在沙地上，血從斜貫胸口的傷口裡湧出來，很快又被風沙蓋上一層。她的右手卻還在動，袖口裡飛出一點金光，直撲孟奇的咽喉。那是一隻指甲大小的金色甲蟲，是唐壓箱底的本命毒蟲，口器能咬穿精鐵，連金鐘罩第五關也擋不住。孟奇的預感又一次搶在眼睛前面，他便左手往頸前一抄，把金蟲攥進掌心，然後五指一合。甲殼碎裂的聲音清脆得像捏碎一顆核桃，黃綠色的汁液從指縫裡淌下來，滴在沙上滋滋作響。

唐盯著那團汁液，嘴唇動了動，卻沒有發出聲音，接著頭一歪就死了。她的眼睛還睜著，瞳孔裡映著灰黃的天。

孟奇甩掉手上的汁液，攤開掌心一看，皮膚上有個極細的紅點，是金蟲臨死前咬出來的，再深一分就破了金鐘罩。他暗自後怕：「這蟲子快得我根本沒看清，全靠開竅以後生出的第六感，晚上半息，現在躺在地上的就是我了。」這時，六道輪回之主冷漠的聲音在他腦海裡響起：「正道陣營孟奇擊殺魔教陣營唐，正道陣營每人善功加一百，魔教陣營每人善功扣一百。」

陳瀟和羅友從破窗裡翻了出來。他們聽不見宣告，卻親眼看見孟奇空手捏死了那隻金蟲。羅友張著嘴半天才找回聲音：「法師這一刀，這一抓……我師父也未必做得到。」陳瀟沒有接話，只是重新打量孟奇，眼神已經和看師門長輩差不多了。孟奇單掌豎起，對著唐的屍體念道：「阿彌陀佛，女施主一路走好。」

話音未落，唐的屍體忽然鼓動起來，衣服底下一拱一拱。接著無數毒蛇、蜈蚣、蠍子和叫不出名字的蟲子從她的袖口、領口和傷口裡鑽出，然後掉頭啃咬她的血肉。陳瀟捂住嘴轉過身去，羅友彎腰乾嘔了一聲。不到一盞茶的工夫，屍體就只剩下一副白骨，毒物們卻也一隻接一隻僵住、翻倒，最後全數死去，在白骨四周鋪了薄薄一層。孟奇猜這些是唐用自己精血養在身上的毒物，主人一死，牠們吃了主人的血肉，也就跟著斷了生機。

孟奇用刀尖撥開死蟲，蹲下身翻找遺物。骨頭上掛著幾片褪了色的破衣，腰間還有一個鹿皮囊，裡面裝著三枚沒用過的唐花、幾包藥粉和一個小瓷瓶。他正拿著瓷瓶端詳，六道輪回之主的聲音又響了起來：「魔教陣營擊殺正道陣營夏丹丹，正道陣營每人善功扣一百，魔教陣營每人善功加一百。」孟奇握著瓷瓶的手停了一下。夏丹丹到底沒能替弟弟報仇，姐弟倆都死在了魔教手裡，而他剛掙來的一百善功，轉眼又被扣了回去。

沙暴另一頭，齊正言，權力幫裡那個一張死人臉、話很少的輪回者，仍被兩名魔教使者夾在中間。剛才替他帶開偷襲的白煙和赤霞並沒有散去：白煙是他從沙暴裡收來的陰濕之氣，赤霞是藏在雲層後的日光，兩樣都被渾天寶鑒煉成了護身的氣勁。前面那名使者身形一矮，半個身子沉進沙裡，想借泥土遁到齊正言腳下；後面那名使者則借著雲縫漏下的一縷天光，化作一道光影撲來。

齊正言沒有轉身，左袖一揮，白煙便纏住了光影。那名使者被煙氣一裹，遁光一滯，從光裡跌了出來。齊正言接著右腳往下一踏，腳下的沙地便隆起一座小丘，硬得像山岩。這是渾天寶鑒裡借地脈之氣凝成的土昆侖，專破藏在地底的敵人。沙下的使者被土昆侖從底下往上一擠，骨頭碎裂的聲音悶悶傳出，然後整個人就被夾死在岩石裡，只露出一隻手。跌出光遁的那名使者爬起來還想逃，白煙卻已經鑽進他的口鼻，赤霞跟著從他心口穿過，他便仰面倒下死了。

齊正言收起氣勁，臉上依舊沒有表情，心裡卻在算帳。這一戰他用了三種能量，沙暴的陰濕、雲後的日光、荒漠的地脈，都是這方世界今天剛好有的。渾天寶鑒越往上練，需要的能量就越稀奇：要星辰墜落時的流火，要地震時翻湧的地氣，要百年一遇的日蝕。這些東西不是想有就有，有的得等，有的得搶，有的只能拿善功向六道輪回之主兌換，而他的善功經夏丹丹這一扣，已經不算寬裕了。

乾涸的涵洞裡，張遠山，已開四竅的真武派弟子，擺著太極守勢擋在符真真身前，螣蛇劍斜指洞壁的暗處。符真真，他的伴侶，蹲在他身後，手裡的火折子燃著一點昏黃的火苗。影殺，云霆鋒手下的刺客，就藏在火光照不到的那片影子裡。影殺天生夜視，又極有耐心，被張遠山擋下第一擊以後便一動不動，等著兩人鬆懈。唐的死訊傳來時，張遠山握劍的手沒有晃，影子裡卻傳出一聲極輕的吸氣。

火折子後面其實還藏著一截小指粗的蠟燭，是符真真用七心海棠的花汁和蜂蠟熬成的。這種蠟燭點著以後無色無味，一刻鐘之內就能毒倒一頭牛。符真真點火折子時順手把蠟燭也點著了，張遠山則在進涵洞前就吞下了她給的解藥。涵洞裡不通風，毒氣慢慢積滿了每個角落，也漫進了影殺藏身的那片影子。

影殺先覺得手腳發麻，以為是蹲得太久，接著胸口就像壓上了一塊石頭。他明白自己中了毒，想從影子裡竄出來拚命，結果剛現出半個身子，膝蓋便一軟跪倒在地。張遠山的劍尖抵上影殺的咽喉，影殺張嘴想說什麼，一口黑血卻先噴了出來，然後撲倒在地上死了。六道輪回之主隨即宣告：「正道陣營符真真擊殺魔教陣營影殺，正道陣營每人善功加一百，魔教陣營每人善功扣一百。」

符真真吹熄蠟燭，長長吐出一口氣，手還在發抖。張遠山收了劍，扶住她的肩膀說：「真真，你留在這裡，把洞口堵上，誰來都別出聲。孟奇他們不知道在哪裡，羅前輩那邊多半是云霆鋒，我得去看看。」符真真抓著他的袖子，張了張嘴，最後只說了一句「小心」，把一包解毒散塞進他手裡。張遠山便提著螣蛇劍鑽進了沙暴。

羅勝衣，人稱「鐵拳無敵」、已開七竅的人榜高手，這一戰卻打得極為憋屈。云霆鋒，魔教陣營輪回者的頭目，一隻手牢牢扣住他的右拳，羅勝衣體內的真氣便像決了堤的水，源源不斷流進對方掌心。羅勝衣只能用左拳一下下轟向云霆鋒的胸口和面門，逼他分神去擋，不讓他吸得太順。兩人腳下的沙地已經被踩出一個淺坑，每一記落空的拳風都在沙暴裡轟出一個短暫的空洞。云霆鋒臉上還掛著笑：「羅兄，再撐一炷香，你這七竅修為就要分我一半了。」

六道輪回之主宣告孟奇擊殺唐的那一刻，云霆鋒的笑容僵在了臉上，扣著羅勝衣拳頭的手指也鬆了一分。羅勝衣等的就是這一分，七竅真氣猛然回衝，右拳從云霆鋒指間掙脫，左拳緊跟著轟在他胸口。云霆鋒連退七八步，嘴角滲出血絲，站穩以後卻沒有立刻反撲，只是望著孟奇所在的方向。羅勝衣第一次在他臉上看不到笑。

羅勝衣正要追擊，宣告又接連響起，先是夏丹丹死在魔教陣營手裡，接著是影殺死在符真真手裡。聽到夏丹丹的名字，羅勝衣的拳頭頓了一下，畢竟那個一路敬著他的姑娘不久前還跟在他身後。云霆鋒卻趁這一頓往後一躍，身形沒入翻滾的黃沙，聲音隔著風傳了過來：「羅兄，今日不奉陪了。」羅勝衣追出十幾步，眼前只剩一片昏黃，云霆鋒已經不見了。
