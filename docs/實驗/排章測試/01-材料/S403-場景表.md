# S403 場景表

主持者從 `docs/實驗/事件形狀/事件清單/S403.md` 整理，2026-11-10。格式照 novel-desk `/settle`：每個場景寫誰想要什麼、發生什麼、結尾處境變成什麼。這一章四個場景，一章寫完。

## 1. 覆海老祖出手

玄海門的覆海老祖要替死在鎮上的門人報仇，從墨綠色流光中現身，施展翻江倒海神通，把海水壓向臨仙鎮。鐘神秀放出元丹位格，海水散成一片水霧。他用元氣大手把老者抓到面前，老者放出丹氣想反抗，鐘神秀稍一用力就把他捏死，頭顱落在地上。

結尾：出手的人死了，鎮上的人和玄海門弟子都呆住。鏡頭跟鐘神秀。

## 2. 誰是結丹老祖

鐘神秀想見玄海門的結丹老祖，叫在場的玄海門弟子去請他出來談。負劍青年道人和一名女修抱著頭顱哭，他這才知道剛捏死的就是結丹老祖。他取來那枚碧綠金丹察看，發現此界的金丹遠不如自己的外丹，明白自己把此界結丹的分量弄錯了。在場修士都不敢動。鐘神秀決定將錯就錯，宣布玄海門從此歸他，沒有人敢反對。朱靈兒帶著朱龍兒求拜入他門下，他說不收徒，但帶上了他們。

結尾：鐘神秀從來拜山的客人變成玄海門的新主人，身邊多了朱家姐弟。鏡頭跟鐘神秀。

## 3. 進山門

鐘神秀帶朱家姐弟和幾個玄海門弟子飛到山門。門裡亂成一團，有人去催護山大陣；鐘神秀以元丹壓倒門中長老和弟子，煉化並加強護山大陣，把全門的人困在陣內。朱靈兒私下對弟弟說跟對了人。

結尾：玄海門全門落入鐘神秀手裡。鏡頭跟鐘神秀。

## 4. 三天後

玄海門易主的消息在附近修仙界傳開，傳言走了樣，說成桃花盜為了一名美貌女弟子殺了覆海老祖；外面的探子都被陣法擋在臨仙鎮。鐘神秀不理外界，進藏經閣補讀此界的常識，懊惱自己鬧的笑話，翻開一部《九品丹論》。

結尾：章末停在鐘神秀翻開《九品丹論》。鏡頭先拉到外界的傳言，再回到鐘神秀。
