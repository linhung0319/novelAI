# 材料說明（2026-11-10）

| 檔 | 內容 | 誰做的 |
|---|---|---|
| `{章}-場景表.md` | 從事件清單整理的場景表 | 主持者 |
| `{章}-角色與前情.md` | 出場角色、世界設定、前情 | 主持者，從前幾章原文整理 |
| `排章輸入-{章}.md` | 給排章 subagent 的唯一輸入：草稿第一、二節原文、場景表、角色與前情 | 主持者 |
| `{章}-排章.md` | 排章表、檢查結果、補的節拍，原樣存檔 | 隔離 subagent（每章一個，只讀自己的輸入檔，不讀其他檔） |
| `{章}-事件段-甲.md` | 甲組事件段，照現行模板「用一段話按順序講」 | 主持者 |
| `{章}-事件段-乙.md` | 乙組事件段，照草稿第三節從排章表轉寫 | 主持者 |
| `乙組篇幅.txt` | 乙組篇幅句，取排章表的範圍 | — |
| `build.py` | 組 prompt，輸出 `prompts/` | — |
| `check_prompts.py`、`leak_report.json` | 洩漏檢查：沿用 `事件形狀/code/check_leak.py`，四份 prompt 和本章原文都沒有 ≥8 字的共同片段 | — |
| `gen.py` | 生成，參數照 novel-desk `send.py` | — |
| `代號對照.json` | 稿件代號對應的章、組、稿 | 生成後寫 |

兩組 prompt 用 `difflib` 比過，只差事件段和篇幅那一句。

## 和設計不同、或設計沒寫到的地方

1. **篇幅 N：** 設計表裡的 6348、9558 是檔案的位元組數，不是字數。實際字數（不含空白）S403 約 2,080、Y17 約 3,140，扣掉標題後取整，N 定為兩千字和三千一百字。排章時告訴 subagent 這個總量，要它的範圍中間值放在 N 左右。
2. **排章輸入的補充說明：** 草稿第二節有兩處要等作者，但 subagent 沒有作者可以問，所以輸入檔開頭加了說明：高點自己選並寫理由；交出排章表、檢查結果、補的節拍就好，不等確認；`knowledge/checks/節拍.md` 就是第一節。
3. **Y17 的 1-1（作者決定，2026-11-10）：** subagent 沒看到上一章結尾，補了「唐帶毒蟲現身、撂狠話、孟奇回嘴」，1-2 前半又寫「孟奇衝上去、唐射出唐花」。但上一章結尾已經演到唐打出唐花。作者選擇刪掉 1-1，1-2 從「打中虛影」寫起。排章表本身沒改。
4. **排章表轉寫成事件段時，主持者做的處理：**
   - 排章表的寫法提示沒有轉寫進去，因為草稿第三節規定只寫發生什麼。這些提示是：Y17 1-7「寫成身體的反應（例如頸後一涼）」、4-3「宣告不重寫原文」，以及各節拍的「演（短）」、字數分配。
   - Y17 2-2 括號裡的例子「沙暴過去後，天地間的異種能量就沒了」沒放：它是新設定，而且「天地間的異種能量」和原文有 8 字重合。
   - Y17 2-1「沙遁、影遁」改成「遁法」：前情寫的是借陽光或泥土遁走，影遁對不上。
   - S403 2-1 的台詞「你們老祖總該比這位明理」改寫成意圖，照 `/draft`「對白只寫意圖」。1-1 的「報名『覆海』」寫成「報出名號」。
   - 乙組事件段一個場景一段，甲組照現行模板寫成一段。草稿第三節沒規定段落。
5. **上一章結尾：** 從前一章原文末尾切 S402 約 1,060 字、Y16 約 780 字，只刪掉 Y16 末尾的浮水印「rs」。
6. **鏡頭句：** Y17 是多線，兩組都寫「先跟著孟奇，再依序切到齊正言、張遠山、羅勝衣和云霆鋒」。排章表裡唐、云霆鋒的短暫鏡頭沒寫進鏡頭句，因為這一句兩組要相同。
