# 排章任務

你要替一部長篇小說的下一章排章。下面依序是：排章的做法和注意事項、這一章的場景表、出場角色與世界設定、前情。只用這份檔案裡的資料，不要讀其他檔案，也不要上網。

說明：

- 下面第二節提到的 `knowledge/checks/節拍.md`，就是下面第一節。
- 場景表已經說明這一章包含哪些場景，不用再提分章。
- 作者這次不在。第二節說「看不出來就問作者」的地方，請你自己選，並在檢查結果裡寫出你的理由；其他要「給作者看」的東西，照第二節最後一段的格式交出來就好，不用等確認。
- 這一章的總篇幅，作者定在大約三千一百字。請在這個總量裡分配；提篇幅範圍時，中間值放在三千一百字左右。
- 交出的內容只要三樣：排章表、檢查結果（只列有問題的）、你補的節拍。不要寫正文。

---

## 一、節拍注意事項（`knowledge/checks/節拍.md` 草稿）

`/draft` 排章時讀。這些是每次都該成立的條件，不是寫作技巧；卡住想找方法時用招卡。作者看過說照排，就照排。

只回報有問題的。用問句，標出場景和節拍：

1. 這一章的主要高點是哪一個節拍？其他場景在替它墊，還是在搶？
2. 高點前有沒有延後？用的是故事裡的東西（動作、聲音、物件、旁人、時限），還是敘事者的說明、角色的內心？延後之後兌現了嗎？
3. 高點本身夠短嗎？高點後有沒有收尾，自己成一個節拍？
4. 每個節拍都換了做法，或改了處境嗎？同一種來回重複的，算同一個節拍，可以併掉或一句帶過。
5. 哪些一句帶過？給高點前的篇幅，從哪裡扣回來？

不檢查場景接不接、整個故事弧的起伏，那些在 `/settle` 寫場景表時看。

## 二、排章怎麼做（`/draft` 第 1 步草稿）

組 prompt 之前先排章，給作者看，確認後才組。

1. **定範圍：** 這一章放哪幾個場景。場景表沒分章時，提分法給作者選；高點前可以切開做章尾鉤子。
2. **定高點：** 這一章的主要高點是哪個場景的哪個節拍。看不出來就問作者。
3. **拆節拍：** 每個場景寫頭、尾、跟誰的鏡頭，再按順序列節拍。每個節拍一行：角色怎麼做，碰到什麼、結果是什麼。角色碰壁後換了做法才算新的節拍。
4. **標演或帶過：** 每個節拍標「演」或「一句帶過」。高點前延後用的節拍、高點後的收尾也要列出來。場景表沒寫、你補上的節拍要標出來。
5. **提篇幅：** 依要演的節拍數，提一個字數範圍。
6. **檢查：** 讀 `knowledge/checks/節拍.md`，逐條看。

給作者看：排章表、檢查結果（只列有問題的）、你補的節拍。作者改了就照改。

# 這一章的場景表

## 1. 破廟外：孟奇對唐

唐想用暗器和毒蟲殺掉孟奇；孟奇想速戰速決。唐射出唐花，卻打中孟奇的虛影；唐花在牆上綻開，附近的蟲蟻沙鼠全部死去，陳瀟和羅友看得心驚。孟奇衝到唐身邊一刀斬中她；刀下唐想起自己學毒的痛苦和與云霆鋒的相遇，倒地。孟奇捏碎唐放出的那隻能咬破金鐘罩的金色毒蟲，唐死不瞑目；孟奇自忖是靠開竅後的第六感識破這蟲。六道輪回之主宣告擊殺唐，每人加一百善功；陳瀟和羅友對孟奇刮目相看。唐身上鑽出大批毒物啃食她的屍體，隨後全數死去，只剩白骨、破衣和暗器。孟奇翻找遺物時，聽到宣告：夏丹丹死在魔教一方手裡，每人扣一百善功。

結尾：孟奇贏了這一場，卻知道同伴那邊出事了。鏡頭跟孟奇；唐倒下那一刻跟唐。

## 2. 齊正言對兩名使者

兩名魔教使者想偷襲殺掉齊正言。齊正言用渾天寶鑒的煙霧、霞光和土昆侖殺掉兩人，並盤算這門功法往後的難處。

結尾：齊正言脫險。鏡頭跟齊正言。

## 3. 涵洞：張遠山、符真真對影殺

影殺想殺符真真；張遠山想護住她。涵洞內張遠山和影殺對峙。符真真點著藏在火折子後的七心海棠蠟燭，影殺中毒倒下死去，宣告擊殺影殺。張遠山讓符真真留下，自己去救援。

結尾：張遠山出洞去找同伴。鏡頭跟張遠山。

## 4. 羅勝衣對云霆鋒

云霆鋒想吸乾羅勝衣的內力；羅勝衣想撐住。云霆鋒聽到唐的死訊後心神大亂，被羅勝衣逼退；接著又聽到夏丹丹和影殺的死訊，云霆鋒退入沙暴離去。

結尾：章末停在云霆鋒退入沙暴。鏡頭跟羅勝衣和云霆鋒。

# 出場角色、世界設定、前情

## 角色

孟奇，少林弟子，法號真定，是個光頭小和尚，也是六道輪回之主召來的輪回者。他已經開竅，把金鐘罩練到第五關，運功時全身泛著暗金色，用的兵器是紅日鎮邪刀。他練過幻形，開竅以後偶爾會有近乎預感的直覺。他平常嘴貧，愛開玩笑，在本地人面前會合掌念佛，裝出高僧的樣子。打起來他不繞路，直接衝上去硬碰。他現在在意的是完成陣營任務、活著回去，也對這方世界魔教的通幽異能很好奇。

唐，魔教陣營的輪回者，一個衣著鮮豔的少女，用毒，會驅使毒蛇毒蟲，身上帶著叫「唐花」的暗器。她手臂上有一道被紅日鎮邪刀劃出的傷，到現在還焦黑發紅，她很愛美，所以恨透了孟奇，想讓他慢慢爛死。

陳瀟和羅友，本地門派的師兄妹。陳瀟會風遁異能，配一套劍法；羅友嘴甜，常奉承師妹。他們的師父要他們留意權力幫這幾個人。兩人剛看過孟奇一刀殺了一名魔教弟子，對他收起了輕視，改口叫他真定法師。

齊正言，輪回者，權力幫的一員，一張死人臉，話很少。他練的是渾天寶鑒，要借天地間的異種能量修行，所以對天象變化特別敏感。

張遠山，輪回者，真武派弟子，已開四竅，擅長劍法，守的時候擺太極守勢，用螣蛇劍。他和符真真是一對，處處護著她。

符真真，輪回者，張遠山的伴侶，只有蓄氣大成，近戰不強，但在藥物和毒物上很有天分。

影殺，魔教陣營的輪回者，云霆鋒的手下，一等一的刺客，天生夜視，會借影子藏身，極有耐心。

羅勝衣，輪回者，人稱「鐵拳無敵」，已開七竅，在人榜上有名，用拳。夏丹丹和她弟弟夏初臨原本跟他一隊，很敬重他。

云霆鋒，魔教陣營輪回者的頭目，臉上常帶著笑，對人和善。他能抓住對手，把對方的真氣內力吸過來。

六道輪回之主把輪回者送進輪回世界做任務。這一趟除了攻伐魔教，還有陣營對抗：殺掉敵方陣營的輪回者，本陣營每人得善功，殺六竅以下的一人每人一百，六竅以上的一人每人兩百；自己這邊有人被殺，每人扣同樣的數；最後善功不夠的人會被抹殺。每次擊殺和善功增減，六道輪回之主都會向所有輪回者宣告。這方世界的魔教弟子會通幽異能，有的能藏在影子裡，有的能借陽光或泥土遁走。

## 前情

孟奇、張遠山、符真真、齊正言和江芷微臨時結成一個幫派，叫權力幫，和羅勝衣、夏丹丹同屬一個陣營。夏丹丹的弟弟夏初臨先前已經被魔教陣營殺了。

這天他們在一片半荒漠裡分散埋伏，想誘殺魔教陣營的輪回者。魔教那邊卻借勢把沙暴變得異常猛烈，眾人看不清也聽不見，彼此聯絡不上。云霆鋒照事先探出的位置分頭派人：他自己去攔羅勝衣，唐去對付孟奇，影殺去殺符真真，兩名魔教使者對付齊正言，小紫去殺一心想替弟弟報仇的夏丹丹。

羅勝衣和云霆鋒對了幾拳，被云霆鋒抓住拳頭，真氣內力不斷流向對方，兩人在近處纏鬥，一時分不出勝負。張遠山帶符真真躲進一處乾涸的涵洞，影殺潛進洞裡偷襲，被張遠山一劍擋下，又躲回暗處，兩邊僵住；符真真說要點火折子，點亮了。齊正言被兩名魔教使者一前一後偷襲，一陣白煙和一道赤霞把他們的攻擊帶開。夏丹丹背靠一棵胡楊木等沙暴變小，小紫從風沙裡走了出來。

孟奇和陳瀟、羅友躲進一座破舊的魔主神廟避風沙。
