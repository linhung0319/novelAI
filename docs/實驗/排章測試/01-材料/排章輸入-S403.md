# 排章任務

你要替一部長篇小說的下一章排章。下面依序是：排章的做法和注意事項、這一章的場景表、出場角色與世界設定、前情。只用這份檔案裡的資料，不要讀其他檔案，也不要上網。

說明：

- 下面第二節提到的 `knowledge/checks/節拍.md`，就是下面第一節。
- 場景表已經說明這一章包含哪些場景，不用再提分章。
- 作者這次不在。第二節說「看不出來就問作者」的地方，請你自己選，並在檢查結果裡寫出你的理由；其他要「給作者看」的東西，照第二節最後一段的格式交出來就好，不用等確認。
- 這一章的總篇幅，作者定在大約兩千字。請在這個總量裡分配；提篇幅範圍時，中間值放在兩千字左右。
- 交出的內容只要三樣：排章表、檢查結果（只列有問題的）、你補的節拍。不要寫正文。

---

## 一、節拍注意事項（`knowledge/checks/節拍.md` 草稿）

`/draft` 排章時讀。這些是每次都該成立的條件，不是寫作技巧；卡住想找方法時用招卡。作者看過說照排，就照排。

只回報有問題的。用問句，標出場景和節拍：

1. 這一章的主要高點是哪一個節拍？其他場景在替它墊，還是在搶？
2. 高點前有沒有延後？用的是故事裡的東西（動作、聲音、物件、旁人、時限），還是敘事者的說明、角色的內心？延後之後兌現了嗎？
3. 高點本身夠短嗎？高點後有沒有收尾，自己成一個節拍？
4. 每個節拍都換了做法，或改了處境嗎？同一種來回重複的，算同一個節拍，可以併掉或一句帶過。
5. 哪些一句帶過？給高點前的篇幅，從哪裡扣回來？

不檢查場景接不接、整個故事弧的起伏，那些在 `/settle` 寫場景表時看。

## 二、排章怎麼做（`/draft` 第 1 步草稿）

組 prompt 之前先排章，給作者看，確認後才組。

1. **定範圍：** 這一章放哪幾個場景。場景表沒分章時，提分法給作者選；高點前可以切開做章尾鉤子。
2. **定高點：** 這一章的主要高點是哪個場景的哪個節拍。看不出來就問作者。
3. **拆節拍：** 每個場景寫頭、尾、跟誰的鏡頭，再按順序列節拍。每個節拍一行：角色怎麼做，碰到什麼、結果是什麼。角色碰壁後換了做法才算新的節拍。
4. **標演或帶過：** 每個節拍標「演」或「一句帶過」。高點前延後用的節拍、高點後的收尾也要列出來。場景表沒寫、你補上的節拍要標出來。
5. **提篇幅：** 依要演的節拍數，提一個字數範圍。
6. **檢查：** 讀 `knowledge/checks/節拍.md`，逐條看。

給作者看：排章表、檢查結果（只列有問題的）、你補的節拍。作者改了就照改。

# 這一章的場景表

## 1. 覆海老祖出手

玄海門的覆海老祖要替死在鎮上的門人報仇，從墨綠色流光中現身，施展翻江倒海神通，把海水壓向臨仙鎮。鐘神秀放出元丹位格，海水散成一片水霧。他用元氣大手把老者抓到面前，老者放出丹氣想反抗，鐘神秀稍一用力就把他捏死，頭顱落在地上。

結尾：出手的人死了，鎮上的人和玄海門弟子都呆住。鏡頭跟鐘神秀。

## 2. 誰是結丹老祖

鐘神秀想見玄海門的結丹老祖，叫在場的玄海門弟子去請他出來談。負劍青年道人和一名女修抱著頭顱哭，他這才知道剛捏死的就是結丹老祖。他取來那枚碧綠金丹察看，發現此界的金丹遠不如自己的外丹，明白自己把此界結丹的分量弄錯了。在場修士都不敢動。鐘神秀決定將錯就錯，宣布玄海門從此歸他，沒有人敢反對。朱靈兒帶著朱龍兒求拜入他門下，他說不收徒，但帶上了他們。

結尾：鐘神秀從來拜山的客人變成玄海門的新主人，身邊多了朱家姐弟。鏡頭跟鐘神秀。

## 3. 進山門

鐘神秀帶朱家姐弟和幾個玄海門弟子飛到山門。門裡亂成一團，有人去催護山大陣；鐘神秀以元丹壓倒門中長老和弟子，煉化並加強護山大陣，把全門的人困在陣內。朱靈兒私下對弟弟說跟對了人。

結尾：玄海門全門落入鐘神秀手裡。鏡頭跟鐘神秀。

## 4. 三天後

玄海門易主的消息在附近修仙界傳開，傳言走了樣，說成桃花盜為了一名美貌女弟子殺了覆海老祖；外面的探子都被陣法擋在臨仙鎮。鐘神秀不理外界，進藏經閣補讀此界的常識，懊惱自己鬧的笑話，翻開一部《九品丹論》。

結尾：章末停在鐘神秀翻開《九品丹論》。鏡頭先拉到外界的傳言，再回到鐘神秀。

# 出場角色、世界設定、前情

## 角色

鐘神秀，外表是年輕公子，對人自稱無門無派的散修，其實是從七曜天來到這片天地的元丹修士，他的丹在體外，稱為外丹。他說話隨意，愛笑，被人挑釁時常常大笑著出手，殺了人以後又擺出一副悲天憫人、怪別人逼他的樣子，嘴上說自己一向溫良，想做個閒雲野鶴，跟道友談仙論道。他對這片天地的修行很好奇，但懂得的還很少。他現在最想做的，是見一見玄海門的結丹老祖。

覆海老祖，玄海門的老祖，一身綠袍的老者，面相清瘦，擅長水法。

負劍青年道人，玄海門弟子，在仙緣大會上替來拜師的孩童檢測根基。旁邊還有一名玄海門女修。

朱靈兒，旭日商行朱家的小姐，帶著弟弟來參加仙緣大會。她精明，會看形勢，也敢下注。弟弟差點被人害死，是鐘神秀救下的，從那之後她就帶著弟弟躲在鐘神秀身後。

朱龍兒，朱靈兒的弟弟，還是個孩子，有上乘道基。

這片天地的修士從百日築基開始，往上是煉氣、凝煞、煉罡，煉罡大成後才能結成金丹，結成金丹的人被尊為結丹老祖。玄海門是越國第一修仙宗門，在越國南端臨海，山門三面臨海，一面和臨仙鎮相接，平日有護山大陣守著，外人進不去。門中有一位結丹老祖坐鎮，還有多位煉罡長老。

## 前情

鐘神秀迷路時搭上朱家的車隊，跟著朱靈兒姐弟來到玄海門附近的臨仙鎮。路上朱靈兒告訴他，玄海門有一位結丹老祖坐鎮。鐘神秀把結丹老祖當成和自己同一級的元丹老怪，提醒自己到了對方地界要收斂，打算等仙緣大會開山時，以道友的身分上門拜訪，談論道法。

仙緣大會上，主持檢測的內門弟子洪元熊收了越國四王子一塊千年寒光鐵，答應害朱龍兒。他當眾指朱龍兒用幻術冒充上品道基，還用帶著煞氣的寒風要凍死朱家姐弟。鐘神秀暗中護住了兩人，當眾說破四王子和洪元熊的勾結，又一掌劈碎客棧的牆，把四王子和他的謀士抓到廣場上。

洪元熊的師父、玄海門長老晴簫子隨即趕到，綁了洪元熊，說要徹查，接著又想收朱龍兒為徒，朱靈兒卻摟著弟弟躲到鐘神秀身後。晴簫子問出鐘神秀沒有師門，便指他是林國白水門通緝的桃花盜，用幻術把通緝榜文上的頭像換成鐘神秀的臉，鎮上的人跟著喊打。鐘神秀只覺得好笑，晴簫子則放出飛劍要殺他。
