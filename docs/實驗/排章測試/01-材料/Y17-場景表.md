# Y17 場景表

主持者從 `docs/實驗/事件形狀/事件清單/Y17.md` 整理，2026-11-10。格式照 novel-desk `/settle`：每個場景寫誰想要什麼、發生什麼、結尾處境變成什麼。這一章四個場景，一章寫完。

## 1. 破廟外：孟奇對唐

唐想用暗器和毒蟲殺掉孟奇；孟奇想速戰速決。唐射出唐花，卻打中孟奇的虛影；唐花在牆上綻開，附近的蟲蟻沙鼠全部死去，陳瀟和羅友看得心驚。孟奇衝到唐身邊一刀斬中她；刀下唐想起自己學毒的痛苦和與云霆鋒的相遇，倒地。孟奇捏碎唐放出的那隻能咬破金鐘罩的金色毒蟲，唐死不瞑目；孟奇自忖是靠開竅後的第六感識破這蟲。六道輪回之主宣告擊殺唐，每人加一百善功；陳瀟和羅友對孟奇刮目相看。唐身上鑽出大批毒物啃食她的屍體，隨後全數死去，只剩白骨、破衣和暗器。孟奇翻找遺物時，聽到宣告：夏丹丹死在魔教一方手裡，每人扣一百善功。

結尾：孟奇贏了這一場，卻知道同伴那邊出事了。鏡頭跟孟奇；唐倒下那一刻跟唐。

## 2. 齊正言對兩名使者

兩名魔教使者想偷襲殺掉齊正言。齊正言用渾天寶鑒的煙霧、霞光和土昆侖殺掉兩人，並盤算這門功法往後的難處。

結尾：齊正言脫險。鏡頭跟齊正言。

## 3. 涵洞：張遠山、符真真對影殺

影殺想殺符真真；張遠山想護住她。涵洞內張遠山和影殺對峙。符真真點著藏在火折子後的七心海棠蠟燭，影殺中毒倒下死去，宣告擊殺影殺。張遠山讓符真真留下，自己去救援。

結尾：張遠山出洞去找同伴。鏡頭跟張遠山。

## 4. 羅勝衣對云霆鋒

云霆鋒想吸乾羅勝衣的內力；羅勝衣想撐住。云霆鋒聽到唐的死訊後心神大亂，被羅勝衣逼退；接著又聽到夏丹丹和影殺的死訊，云霆鋒退入沙暴離去。

結尾：章末停在云霆鋒退入沙暴。鏡頭跟羅勝衣和云霆鋒。
