## 一、節拍注意事項（`knowledge/checks/節拍.md` 草稿）

`/draft` 排章時讀。這些是每次都該成立的條件，不是寫作技巧；卡住想找方法時用招卡。作者看過說照排，就照排。

只回報有問題的。用問句，標出場景和節拍：

1. 這一章的主要高點是哪一個節拍？其他場景在替它墊，還是在搶？
2. 高點前有沒有延後？用的是故事裡的東西（動作、聲音、物件、旁人、時限），還是敘事者的說明、角色的內心？延後之後兌現了嗎？
3. 高點本身夠短嗎？高點後有沒有收尾，自己成一個節拍？
4. 每個節拍都換了做法，或改了處境嗎？同一種來回重複的，算同一個節拍，可以併掉或一句帶過。
5. 哪些一句帶過？給高點前的篇幅，從哪裡扣回來？

不檢查場景接不接、整個故事弧的起伏，那些在 `/settle` 寫場景表時看。

## 二、排章怎麼做（`/draft` 第 1 步草稿）

組 prompt 之前先排章，給作者看，確認後才組。

1. **定範圍：** 這一章放哪幾個場景。場景表沒分章時，提分法給作者選；高點前可以切開做章尾鉤子。
2. **定高點：** 這一章的主要高點是哪個場景的哪個節拍。看不出來就問作者。
3. **拆節拍：** 每個場景寫頭、尾、跟誰的鏡頭，再按順序列節拍。每個節拍一行：角色怎麼做，碰到什麼、結果是什麼。角色碰壁後換了做法才算新的節拍。
4. **標演或帶過：** 每個節拍標「演」或「一句帶過」。高點前延後用的節拍、高點後的收尾也要列出來。場景表沒寫、你補上的節拍要標出來。
5. **提篇幅：** 依要演的節拍數，提一個字數範圍。
6. **檢查：** 讀 `knowledge/checks/節拍.md`，逐條看。

給作者看：排章表、檢查結果（只列有問題的）、你補的節拍。作者改了就照改。

## 三、寫進 prompt（`templates/prompt.md` 事件段草稿）

取代原本的「用一段話，按順序講四到七件事。說明章末停在哪裡。」和「篇幅大約三千字，寧可多一點。」：

- 事件段照節拍的順序寫，每個要演的節拍寫一兩句發生什麼。
- 一句帶過的節拍也寫進去，後面註明「一句帶過」。
- 不寫「高點」「延後」「收尾」這類標籤，也不寫這個節拍的意義和情緒。延後寫成具體發生的事。
- 說明章末停在哪裡。
- 篇幅寫範圍，例如「篇幅大約兩千五到三千字」。不寫「寧可多一點」。
