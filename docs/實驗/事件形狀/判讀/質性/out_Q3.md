# Q3 逐文本讀稿：重事件與輕事件

## 文本 T3659

**最重：事件 1（覆海老祖現身、翻江倒海被元丹壓散）**

這條佔了約十二行，等於一整個小場面。順序是：登場（流光、外貌）→ 喊話 → 施法動作 → 眾人認出神通 → 眾人驚慌 → 鐘神秀一句調侃 → 他的應對 → 結果（水牆崩解）→ 餘波（水霧成虹）。每個段落各做一件事，連續出現的是「動作、結果、反應」的鏈，不是評語堆疊。原文：「遠處海面，轟然隆起一道水牆，足有百丈之高，挾著腥鹹海風，朝臨仙鎮直壓過來。」、「那百丈水牆撞到這股氣息，就像撞上了一堵看不見的天塹，先是一頓，繼而從頂端開始崩解，化為漫天水霧，紛紛揚揚灑落下來。」，收尾還有「鎮上眾人只覺臉上一涼，抬頭時，天邊竟掛起一道淡淡的虹。」讀起來節奏中等偏慢，張力先拉高再放掉；多數是自己「看到」畫面（水牆、崩解、虹），不是被告知；那道虹讓注意力停一拍，不累。

**最輕：事件 7（三天後傳言走樣）**

只有約五行：時間標記 → 一句旁白判斷 → 兩句傳言對白 → 一句探子被擋。沒有場景，沒有動作。原文：「三天之後，玄海門易主的消息，已經傳遍了附近的修仙界。」、「只是傳來傳去，便走了樣。」、「嘖嘖，衝冠一怒為紅顏，這桃花盜倒也是個情種……」。感覺是快速掠過；傳言用對白直接演出來，所以是「聽到」而不是被告知，帶一點幽默；幾乎不費力。

## 文本 T5334

**最重：事件 1**

約十六行，是這個文本最厚的一條。多出的部分是登場道具與聲響：外貌＋海螺、雷般的喊聲、念咒、隆隆聲、眾人回頭看、老修士的驚呼、鐘神秀的質問、他的應對、結果、老祖的僵住。原文：「老者聲如悶雷，滾滾壓下，鎮上屋瓦都簌簌作響。」、「那道水牆衝到鎮外三里，忽然一頓，像是撞上了一堵看不見的牆。」、「覆海老祖托著海螺的手，僵在半空。」，中間有獨立成行的「一絲而已。」。讀起來是慢鋪陳、高張力，聲音與動作交替；結尾用對手的僵硬反應收，而不是用評語收；有點長，但畫面感強。

**最輕：事件 7**

約四行：時間句 → 傳言一句總結（不用對白）→ 探子被擋。原文：「到了最後，竟成了桃花盜看上玄海門一名美貌女弟子，覆海老祖不肯放人，被桃花盜一掌拍死，滿門盡數淪為賊窩。」、「各家各派都派了探子過來打探，可一到臨仙鎮，就被那層淡青色的光幕擋住，連山門的影子都看不清楚。」。是敘述者直接轉述，沒有人說話，所以偏「被告知」；很快、很平，但資訊清楚，不累。

## 文本 T4380

**最重：事件 1**

約十二行，有背景與台詞：登場外貌 → 他看到多具屍首、臉皮抽動 → 長篇喊話（帶「坐鎮此地三百年」背景）→ 動作 → 水牆 → 點名神通 → 旁人反應（柔雲仙子）→ 鐘神秀質問 → 應對 → 結果。原文：「好膽！老夫覆海，坐鎮此地三百年，還是頭一回有人敢在我山門腳下殺我門人！」、「柔雲仙子雙腿發軟，連逃都忘了。」、「百丈浪牆撞上這股氣勢，就像撞上一堵看不見的山壁，先是停住，繼而從頂端開始崩解，化作漫天水霧，緩緩飄落。」。節奏中速，有背景交代，但夾在動作裡，注意力集中；偏「看見」；中等分量，不累。

**最輕：事件 7**

約四行：時間句、「走了樣」一句、一句傳言（含具體畫面「頭都滾到了地上」）、探子被陣法擋住。原文：「三天之後，玄海門易主的消息，已經在附近的修仙界傳開。」、「有人說，那桃花盜看上了玄海門一名美貌女弟子，玄海門不肯給，覆海老祖親自出面，結果被桃花盜當街捏死，頭都滾到了地上。」。快速摘要，偏被告知，但傳言本身有個畫面，所以不乾。

## 文本 T6228

**最重：事件 4（發現結丹是爛貨）**

約二十行，是五個文本裡單一事件最長的。段落種類很雜：對白（“這特么能是結丹老祖？”）→ 評語（表情）→ 內心分析（氣息只與神通相當）→ 回想（“等等……”）→ 動作（招手取丹）→ 描寫 → 內心比喻 → 結論 → 再次對白 → 旁人反應（他們不敢動）→ 眾人內心 → 比喻 → 鐘神秀自嘲。原文：「鐘神秀滿臉你們特么在逗我的表情。」、「等等……這人最后掙扎之時，腦后似乎的確有一枚丹丸飛出的樣子？」、「這一枚金丹光澤暗淡，內里似乎還有些駁雜，與他的外丹一比，簡直是螢火與皓月的區別。」。讀起來是慢而滿，主角內心不停吐槽，節奏是「想一句、說一句」；不是看到而是被一路告知他怎麼想、旁人怎麼想；有喜劇效果，但最後連旁人心理也重複強調（「簡直恨不得，自己變成一塊石頭。」），略累。

**最輕：事件 2（捏死覆海老祖）**

只有約五行：抓人 → 老者掙扎 → 捏死 → 音效「啪嗒！」→ 結果描寫。原文：「鐘神秀不耐，略微用力，就把此人捏死了。」、「老者身軀炸開，頭顱在地上滾落，雙目圓瞪，赫然死不瞑目！」。極快、乾脆，用音效和感嘆號頂過去；少了其他文本裡的停頓（沒有「全場死寂」那一拍），衝擊靠驚嘆號，不靠留白；也因為過快，之後事件 4 才顯得特別厚。

## 文本 T3519

**最重：事件 1**

約十三行，並且是五個文本中唯一在攻擊前插入來回對話的：登場 → 覆海報名、要名號 → 鐘神秀回嘴「你便當我是吧」→ 覆海回應 → 動作 → 水牆 → 鎮上混亂 → 老修士台詞 → 鐘神秀抬眼皮 → 應對 → 結果 → 感官細節。原文：「好！好一個桃花盜！」、「他沒有出手，只將體內元丹的位格微微放了出來。」、「有人伸手接了一把，是鹹的。」。讀起來是慢、帶諷刺，把先前的「桃花盜」伏筆接上；有具體觸感（水是鹹的、打濕屋瓦），自己看得到；張力靠對話而不是靠形容詞。

**最輕：事件 7**

約四行：時間句 → 「走了樣」→ 傳言（含「裙子顏色」細節）→ 探子過不去（海鳥意象）。原文：「只是傳來傳去，就走了樣。」、「海上那層深藍光幕，連一隻海鳥都飛不進去。」。快、輕，屬於被告知；但每句都有一個具體小細節，沒有空泛評語，讀起來輕而不乾。

## 比較

**四個彼此很像：T3659、T5334、T4380、T3519。** 它們的事件骨架和寫法幾乎一致：水牆 → 氣息壓散 → 元氣大手 → 骨碌碌滾落的頭顱 → 一個靜場句（T3659「全場死寂。」、T5334「整條長街，鴉雀無聲。」、T4380「滿街寂靜。」、T3519「長街上靜得只聽得見海風。」）→ 取金丹 → 領悟 → 認領玄海門 → 傳言 → 藏經閣。重事件（事件 1）都用十二行以上，以「動作、結果、旁人反應」交替；輕事件（事件 7）都壓在四五行，用「時間句＋『走了樣』＋傳言＋探子被擋」處理。連句子都重複，例如 T3659「只是傳來傳去，便走了樣。」與 T3519「只是傳來傳去，就走了樣。」，以及 T3659「這笑話若是傳出去……」、T4380「這笑話，鬧得有點大。」。這四篇之內的差別是：T3659 與 T4380 用內心說明發現「分量弄錯了」（T4380：「這一回，是他把此界結丹的分量弄錯了。」），T5334 把事件 1 拉得最長最有聲響，T3519 在事件 1 加了名號對話與觸感細節，T4380 是唯一在事件 6 之後加一個夜晚、朱龍兒開口說話的場景（「姐，那個人殺了好多人……」）。

**不一樣的是 T6228。** 差別具體在：

1. 輕重分配相反：事件 2（殺死）反而最輕，五行就過，事件 4（發現）最重，二十行。其他四篇的殺死事件都有一段慢鏡（抓、抵抗、收緊、碎裂、頭落），T6228 是「鐘神秀不耐，略微用力，就把此人捏死了。」
2. 靠音效與驚嘆號推動：「轟隆！」「啪嗒！」「赫然死不瞑目！」「其名為九品丹論！」，其他四篇都沒有這種標點與擬聲主導的結尾（它們以「翻開了第一頁」之類的動作收）。
3. 評語與直白內心很多：「這少女不愧商賈出身，極有決斷，更有下注的勇氣。」、「這都叫什么破事啊！」、「我的形象，我的道心……」，是敘述者與主角直接告訴讀者感受；其他四篇多讓反應落在動作或細節上（例如 T3519 的「有人伸手接了一把，是鹹的。」）。
4. 現代口語吐槽：「這特么能是結丹老祖？」、「這特么就很離譜了……讓我緩一緩先。」，其他四篇的主角語氣是古風的「原來如此」。
5. 補背景說明：「玄海門作為越國第一大派，雄霸附近數個小國，皇室都要年年上供的巨無霸存在。」，這是事件 7 中唯一出現世界設定說明的文本，所以它的「輕事件」並不最短，反而夾了設定；其他四篇的事件 7 都只談傳言與探子。
6. 事件 6（飛到山門、煉化大陣）也被縮成幾行摘要，緊接著用人物感想（「日后在越國之中，大可橫著走了」）收，不像其他四篇用一個畫面（光幕、藍光、封門）收。
