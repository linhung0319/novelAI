# 事件形狀實驗：設計

寫於 2026-11-07。執行的 session 依這份設計寫 `01-凍結.md`。凍結之後不改設計，任何偏離都寫進 `02-結果.md`。

作者不參與執行。事件輕重、段落功能、感覺標籤都由隔離的 subagent 判定，主持者負責親讀和引用原句。

## 問題

焦點後置第二輪讀伊志松之死、百獸老祖之死時，看到兩個現象：原文交代完結果就走，Claude 稿把同一件事切成很多段，事後還拖著反應鏡頭和評語尾巴。這次要回答：

> 人類作者會不會依事件輕重改變寫法（用幾段、每段做什麼、讀起來什麼感覺），而 Claude 不論輕重都寫成差不多的形狀？

如果是，Claude 的問題在不知道這件事有多重要，還是知道了也照舊寫？

## 一、語料

### 配對組（3 本 × 2 章）

| 書 | 可選範圍 | 限制 |
|---|---|---|
| 詭秘之主 | 第 11–40 章 | 避開開頭；前一章也要在範圍內 |
| 一世之尊 | 卷二、卷三 | 同卷內取，前一章在同卷 |
| 神秀之主 | 第 365–461 章 | 避開 367、400、425（前幾輪用過，主持者讀過） |

**選章規則**：主持者每本讀 4–6 個候選章，選 2 章。條件是：
- 至少 4 個事件；
- 事件輕重有落差（主持者預估至少一個重、一個輕），不要整章都是打鬥或整章都是閒談；
- 兩章的類型不同，例如一章以對白和交涉為主，一章以動作或揭底為主。

選定後，把理由寫進凍結檔。選章時只能讀原文，這時還沒有任何 Claude 稿。

### 人類範圍組（原文，不配 Claude 稿）

《從紅月開始》、《極道天魔》各 1 章，第 11 章以後，用 seed 抽。主持者照配對組的格式寫事件清單，後續的判讀一樣做。這組只用來看人類作者之間的差距，不做配對比較。

### 不用

《我有一個修仙世界》只有 13 章，事件輕重不容易湊齊。《消失的密室》可能被模型默寫。

## 二、事件清單與輕重

### 事件清單（主持者寫）

每個實驗章寫一份事件清單，4–8 條，依原文順序排列。寫法：
- 每條一到兩句，第三人稱，只寫**發生什麼**：誰做了什麼、結果是什麼。人名、物名、數字要寫足。
- **不寫**對白的措辭、不寫比喻、不寫「重點」「敘述交代」「揭底」這類寫作指示。神秀實驗已經證實，模型會逐字照抄指示裡的轉述句，也會把指示語寫進正文。
- 不寫段數、不寫篇幅比例、不寫哪件重要。
- 寫完跑 `code/check_leak.py`：比對清單和原文，找出長度 ≥8 字的共同片段。專名和固定詞語除外，其餘要改寫。

### 輕重（隔離判者，看不到任何正文）

兩個 subagent 各自判每個事件的輕重。它們只讀**前一章原文**和**這一章的事件清單**，看不到這一章的原文，也看不到任何 Claude 稿。

| 級 | 判準 |
|---|---|
| 重（3） | 事件結束後局勢不一樣：生死、勝負、誰得到或失去關鍵的東西、誰知道了關鍵的事、關係破裂或結成；或是本章的主要衝突在這裡分出結果 |
| 中（2） | 推進主要衝突，但局勢還沒定 |
| 輕（1） | 過場、移動、例行交代、旁人的反應，拿掉也不影響後面 |

兩個判者的分數取平均，作為事件的輕重。同時報兩人的加權 kappa。如果加權 kappa < 0.4，輕重只能分「重」對「非重」兩級：兩個判者都給 3 才算重，其餘都算非重。

## 三、Claude 稿

### 兩個臂

| 臂 | 給什麼 | 回答的問題 |
|---|---|---|
| N（自然） | 前一章原文＋事件清單＋目標字數 | Claude 自己判斷輕重時怎麼寫 |
| W（告知輕重） | N 的全部＋每條事件後面標「（重）（中）（輕）」，用的是判者平均的輕重，四捨五入 | 告訴它輕重後，會不會改寫法 |

每章每臂 2 篇，共 6 章 × 2 臂 × 2 篇 = **24 篇**。

### 寫稿 prompt 的內容

- 前一章原文全文。它同時當劇情銜接和同作者的文風樣本，不用另外轉述文風。神秀實驗的失敗就是轉述把原文的腔洗掉了。
- 一句文體說明，例如「仙俠網文，繁體中文，敘述用第三人稱」。詭秘之主要多加一句「這位作者刻意不用成語」，因為這是作者自己說過的做法。
- 事件清單，要求照順序寫完，不跳也不加大事件。
- 目標字數：原文漢字數 ±10%。
- 格式：一段一行，不寫章名。
- **不給**避開 AI 腔的禁用清單。這次要看 Claude 的自然寫法，禁用清單會改變它的段落行為。
- **不告訴**它這是實驗、要跟原文比、或要觀察什麼。

### 跑法

- 每篇一個隔離 subagent，用和主持者相同的模型。它只讀自己的工作檔，工作檔放在 scratchpad 的中性路徑。
- 產出直接使用，不刪句、不修改、不重跑。只有字數超出 ±25%，或沒有寫完全部事件時，才重跑一次，並在結果裡記錄。

## 四、判讀

所有文本（6 章原文、24 篇 Claude 稿、2 章人類範圍原文，共 32 篇）先照焦點後置第二輪的規則切段：以換行切段、去空行、去浮水印；段尾不是句末標點時，和下一段合併。每篇給隨機代號。

### 判讀表（主持者寫，校準後凍結）

每段判三樣：

**1. 事件編號**：這段屬於事件清單的第幾條。不屬於任何一條時填 0，例如章首寫景、獨立的過場。

**2. 段落功能**：單選。

| 標籤 | 定義 |
|---|---|
| 預告 | 只宣告下一段要出事，本段本身沒發生事。例：「就在這時，通鋪上傳來一陣窸窣聲。」 |
| 動作 | 角色做事，推進事件 |
| 對白 | 以台詞為主，台詞推進事件 |
| 結果 | 交代事件的結果：誰死了、東西到手了、局勢變了 |
| 反應 | 結果出來以後，旁人或當事人的表情、動作、驚叫 |
| 評語 | 敘述者或角色對剛發生的事下判斷、總結、說道理。例：「那才叫弄巧成拙。」 |
| 內心 | 角色的想法、盤算、回想 |
| 背景 | 插入設定、來歷、規則說明 |
| 描寫 | 景物、外貌、氣氛，不推進事件 |
| 音效 | 整段只有擬聲或聲響。例：「轟隆！」 |

一段兼有兩種時，判占篇幅較多的那種。動作和結果在同一段時判「結果」。

**3. 感覺**：五個維度，各選一個值。詞彙取自 `../寫法與感覺對照表.md` 第一節，只取能逐段判的五個。

| 維度 | 值 |
|---|---|
| 速度 | 快／中／慢／停（讀到這裡像被煞車） |
| 注意力 | 盯住（每個字都要看）／一般／可略（掃過就好） |
| 張力 | 升／持平／降／懸著（等答案） |
| 介入感 | 自己看到／被告知 |
| 負荷 | 省力／一般／費力 |

判感覺時要附前段和後段當上下文，因為感覺取決於位置。判者要用一般網文讀者的角度判，不判文筆好壞。

### 校準（第 0 步）

- 校準材料用實驗以外的章節：配對組 3 本書各 1 章，不能是實驗章或實驗章的前一章。主持者先寫事件清單，再親自標全部段落，存成 `校準/host_labels.json`。
- 兩個 Sonnet 判者各判全部校準段落。
- 門檻：事件編號和段落功能，兩個判者對主持者的 kappa 平均 ≥0.6；感覺各維度，兩個判者彼此的 kappa ≥0.4。
- 沒過門檻的欄位，改一次判讀表的定義，然後重判。仍然沒過：段落功能可以合併相近的標籤（例如反應＋評語），合併規則要在重判前寫好；感覺維度沒過就丟掉那一維，在結果裡報告。
- 校準結束後凍結判讀表，寫進 `01-凍結.md`。

### 正式判讀（第 1 步）

- 把全部段落用 seed 打散，切成每批 60–80 段，每批只含同一章的段落（原文和該章的 4 篇稿混在一起），附該章的事件清單。人類範圍組的段落混進各章批次，或自成批次，由凍結檔決定。
- prompt 只有判讀表和批次檔路徑，沒有書名、組別、模型、實驗目的。
- 判者一、判者二各判全部，都是 Sonnet subagent。輸出 JSON，由程式驗格式；不合格的批次重判一次，仍不合格記為格式錯誤，不進統計。
- 每章另外請一個隔離 subagent 逐句閱讀原文和 4 篇稿（隨機代號），挑出每篇最重和最輕的事件，描述它怎麼寫、讀起來什麼感覺，並引用原句。這份是質性對照，不進統計。

## 五、指標與預測

以下「事件」指判者給的事件編號；兩個判者各算一次，兩份都報。

| 代號 | 指標 | 預測 |
|---|---|---|
| H1 篇幅隨輕重 | 每篇算「重事件平均篇幅 ÷ 輕事件平均篇幅」，篇幅用該事件占全篇漢字的比例；同時報段數比 | 原文的比值大於 N 臂稿 |
| H2 形狀均一 | 每個事件的功能分布（10 類比例），算同一篇內所有事件兩兩之間的 Jensen–Shannon 距離，取平均 | 原文的平均距離大於 N 臂稿，也就是 Claude 各事件的形狀比較像 |
| H3 拖尾 | 事件裡「結果」段之後，屬於同一事件的反應＋評語＋描寫段數；分輕、重報 | N 臂稿的輕事件拖尾高於原文的輕事件 |
| H4 感覺起伏 | 每篇算各事件的速度分布（快=1、中=2、慢=3、停=4，取平均），再算事件之間的標準差；張力「升」和「懸著」的位置是否集中在重事件 | 原文的事件間標準差大於 N 臂稿 |
| H5 告知輕重 | W 臂和 N 臂比 H1–H4 | 告知以後，H1 的比值會變大，但 H2、H3 不會明顯改善：Claude 知道哪件重，會把重的寫長，但輕事件照樣拖尾 |

### 判定規則（凍結前寫定，之後不改）

- **單本成立**：該書 2 章合併計算，原文和 N 臂的差在預測方向上，兩個判者都同向，而且差距達到門檻。門檻在凍結檔寫定，建議 H1 比值差 ≥1.5 倍、H2 距離差 ≥0.05、H3 每事件差 ≥0.5 段、H4 標準差差 ≥0.3。
- **假說成立**：3 本中至少 2 本單本成立。只有 1 本成立，降成「這位作者」。
- **人類範圍**：任一本配對書的原文值，落在其他四本人類原文（另外兩本配對書＋兩本範圍書）的最小到最大範圍之外，該書的結論降成「這位作者」。
- **H5**：W 臂對 N 臂的變化，要在 3 本裡至少 2 本同向才算有。
- 數字樣本小（每本 2 章、每臂 4 篇），不報 p 值，只報方向、每本的值和兩個判者是否一致。

## 六、產出

全部放在 `docs/實驗/事件形狀/`：

| 檔 | 內容 |
|---|---|
| `01-凍結.md` | 選章與理由、事件清單、輕重和 kappa、判讀表最終版、校準結果、門檻、批次方式。在第 1 步判讀開始前寫好，之後不改 |
| `02-結果.md` | 結論先講（五條以內）、H1–H5 表格（每本、每判者）、人類範圍、質性對照並引用原句、偏離設計的地方、限制 |
| `code/` | 獨立腳本：切段、洩漏檢查、打散分批、驗格式、算指標 |
| `稿件/`、`判讀/`、`校準/` | 原始產出，不刪改 |
| `代號對照.json` | 代號對應的書、章、臂、篇 |

## 七、限制（現在就知道的）

- 判者都是 Claude（Sonnet）。感覺標籤是「Claude 以為讀者會有的感覺」，不是讀者實測。作者盲讀尚未回填，結論只算方向。
- 事件清單由主持者從原文寫出，事件的切法本身會影響「一件事用幾段」。兩邊用同一份清單，偏差方向相同，但絕對值不能直接解讀。
- Claude 稿是從事件清單寫的，原文不是。原文作者可能邊寫邊決定事件，所以「照清單寫」本身就可能讓稿件更均一。W 臂和 N 臂的對比可以部分區分這一點，原文和稿件的對比不行。
- 每本只有 2 章，事件總數大約 10–16 個，輕重各級可能只有幾個。
