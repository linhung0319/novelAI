1. 孟奇、羅勝衣、阮玉書趴在牆頭等待；勤政殿傳來巨響，太極殿的侍衛想去支援，被侍衛首領喝止回到原位。
2. 孟奇傳音改用第二個計劃；羅勝衣用石子引開注意後衝進殿內，與侍衛首領對了一拳，再翻牆逃走，引走大批侍衛。
3. 孟奇趁亂用飛爪進入太極殿後門，兩劍殺掉兩名守在門內的侍衛；阮玉書在花園接應。
4. 孟奇用金鐘罩撞穿牆壁進入紫極閣，彈石子打向龍床，被一隻手彈開，邪君關應從屏風後走出來。
5. 孟奇與邪君氣機相持，不敢逃走；他發覺門外四名高手早已被邪君制住。
6. 邪君指著龍床說老皇帝已經死了，孟奇看見老皇帝七竅流血；邪君說老皇帝不是中風，而是吸收絳族少主獻上的聖尊遺物晶石時承受不住而昏迷。
