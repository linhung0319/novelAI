# 新技巧知識庫：工作底稿

記錄每批讀了什麼、每招怎麼處理。這份留在本 repo，`novel-desk` 不引用。

卡片和索引在 `docs/新技巧知識庫/`，整理和修正完才搬去 `novel-desk/knowledge/`。

## 判斷標準

作者交由 Claude 判斷（2026-11-02）。每張卡要過五關：

1. **內容對不對：** 原文的主張沒有根據就刪，絕對的說法刪掉或改成條件。
2. **AI 需不需要：** AI 本來就會的只留做法，不留清單和定義。AI 想不到的做法、問句和有代表性的例子要留全。
3. **適不適合這個工具：** 從教人寫作改成 AI 陪作者做。由作者拍板的部分要停下來給候選，不替作者答完。
4. **有沒有重複：** 跨卡去重。共通要求放進 `吐`，不在每張卡重講道理。
5. **實際好不好用：** 拿真實內容試，看 AI 有沒有變死板或照抄例子。

## 寫卡規則

- 卡片自足，不提 `Data/`、舊檔名、舊系統和教學文作者。
- 不寫「必須」、評分、配額或自製數字。
- 數字處理：自製門檻和無來源統計刪；作者經驗值改成文字或刪；外部公式比例改成大約位置。
- 欄位：適用、吃、做、吐、例；`限界` 只在該卡有特殊限制時才寫。
- `吐` 通常是為了新用法寫的，原文不一定有。
