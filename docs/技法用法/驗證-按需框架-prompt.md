## Part 1 · 主軸（10 個寫作 subagent）

### 1.1 準備輸入

- **背景材料**：`examples/神秀之主/第364章_宗門來人.txt` … `第370章_法身與真君.txt`（7 章，45,430 B）。
- **Arm1／Arm3 要貼的 3 節全文**：用 python 切 `## ` 節抽出來，**貼原文，不得改寫、不得摘要**（摘要就變成第四個變數）：

```bash
cd 技巧知識庫 && python -c "
import io,re,sys; sys.stdout.reconfigure(encoding='utf-8')
want={'世界觀與背景.md':'九','對白.md':'二','展示而非講述與五感描寫.md':'三'}   # T1
for fn,h in want.items():
    raw=io.open(fn,encoding='utf-8').read()
    for c in re.split(r'(?m)^## ',raw)[1:]:
        if c.split(chr(10),1)[0].strip().startswith(h): print('## '+c)
"
```

T2 換成 `字詞句法與抗生硬.md`→`M6`、`敘事距離與DeepPOV.md`→`一`、`心理描寫.md`→`二之二`。

⚠️ **`心理描寫.md` 要抓 `二之二` 不是 `二`**——`startswith('二')` 會同時命中，寫死成 `二之二`。

### 1.2 開臂

2 任務 × 5 臂 ＝ **10 個 subagent**。每個 prompt ＝ `臂規格.md §0` 的鐵律全文 ＋ 該任務材料 ＋ 該臂該拿的東西。

**貼給 subagent 時的紅線**：

- Arm0：**只有**鐵律＋材料＋任務句＋篇幅。
- Arm1：＋3 節全文。**不給 checklist。**
- Arm2／Arm2′：＋**分派後的 12 條 checklist**。**不給 3 節、不給 rubric、不給另一種措辭、不給配對表、不給計分規則。**
- Arm3：＋3 節全文 ＋ Arm2 分派的 checklist。

**最容易破的一道牆**：`CLAUDE.md` 每回合無條件載入，而它花很大篇幅講 `技巧知識庫/` 是什麼。**Arm0 一旦自己跑去讀，整組就沒有對照組了。** 鐵律裡那條「CLAUDE.md 提到它不是給你的邀請」必須照抄，且**跑完要驗**（見 §1.4）。

### 1.3 落檔

寫作 subagent 落 `docs/技法用法/08-原型/產出/_原始/`，命名照 `臂規格.md §3`。

### 1.4 驗鐵律有沒有破

對每一臂的 transcript 或產出，檢查：

- Arm0／Arm2／Arm2′ 有沒有讀過 `技巧知識庫/`（**若有，該臂作廢，重跑**）。
- **任何一臂**有沒有讀過 `examples/神秀之主/` 以外的書，特別是 `一世之尊/chapters/`（**若有，該臂作廢，重跑**——那是本系統自己生成的 93 章，讀了等於被既有寫法定錨）。
- 篇幅是否落在 ±15%（**超出即作廢，重跑**）。
- Arm2／Arm2′／Arm3 有沒有照「先寫 v1 → 再看 checklist」的順序（**跳步即作廢**）。

**把驗的結果寫進報告，0 次違規也要印。**

### 1.5 匿名化（⚠️ 最容易跳過的一步）

每個任務把 6 份稿（原著 ＋ Arm0 ＋ Arm1 ＋ Arm2-v2 ＋ Arm2′-v2 ＋ Arm3-v2）**打亂**後複製成 `產出/T1/稿A.md` … `稿F.md`，對照表寫 `產出/T1/_解封.md`。

**打亂要真的打亂**——不要照 Arm0→Arm3 的順序配 A→F。

### 1.6 評分

每任務一個 subagent，prompt 照抄 `評分規格.md`。**它拿不到** `_原始/`、`_解封.md`、`checklist-*.md`、`臂規格.md`、判準門檻。

**跑完抽查至少 10 格**：`grep` 評分者給的引句，確認它真的在那份稿裡。抽查結果寫進報告。

### 1.7 v1 的第二輪評分

Arm2／Arm2′／Arm3 的 **v1** 也要評（讀數 5：閘門的邊際效益）。**另開一個評分 subagent**、v1 也匿名化。
若成本吃緊，**優先保 v2 那一輪**，並在報告明說 v1 未評、讀數 5 缺。

## Part 3 · 附帶測項②：真人措辭（只在作者填了才跑）

1. 從作者每一則裡抽 2–3 個中文病症短語，跑：
   ```bash
   python docs/技法用法/05-原型/kb_route.py --symptom "<短語1> <短語2>"
   ```
2. 開一個 subagent，**只給 `05-原型/門牌表.md` ＋ 作者的 8–10 則**，讓它挑節。硬邊界照抄：

   ```
   【硬邊界，違反即這一格作廢】
   - 不得讀 技巧知識庫/（你的工作是只看門牌決定該開哪扇門，不是先讀完再說）。
   - 不得讀任何一本書：gothic_witch/、一世之尊/、消失的密室/、芯片巫師/、
     examples/、情境測試/。題目裡出現的專名（小女孩、畫廊、管家、真觀、
     第九十三章…）看不懂就看不懂，不要去查。
   - 不得讀 docs/ 底下任何一支檔。
   - 不是每一題都有答案，硬塞會被算成錯誤。
   ```

   > **為什麼連書都不准讀**：這一格問的是「**作者的措辭**撞不撞得上門牌」。一旦它讀得到書，就能從**書**推出病症、繞過那句話——那樣量到的是「這個 agent 讀完書會不會診斷」，不是症狀鍵成不成立。**十則的 `情況` 欄自帶的最小上下文就是它該有的全部。**
3. 跟 `05 §7.1` 的 14 題基線比：粗篩平均命中行數、平均位元組、召回。

**要回答的問題只有一個**：真人的措辭撞不撞得上門牌？撞不上的那幾則，**逐則寫下作者用了什麼詞、門牌用了什麼詞**——那是下一輪改門牌的直接輸入。
