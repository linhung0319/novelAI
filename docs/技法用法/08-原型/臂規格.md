# 五臂規格（寫作 subagent）

> 每一臂一個 subagent。**互不知道對方存在。** 主 session 只當調度器，不寫稿、不評分。
> 2 個任務 × 5 臂 ＝ **10 個寫作 subagent**。

---

## 0 · 所有臂共同的鐵律（每個 prompt 都要照抄）

```
【硬邊界，違反即該臂作廢】
- 不得讀 技巧知識庫/ 底下的任何一支檔。
- 不得讀 docs/技法用法/ 底下的任何一支檔。
- 不得讀 docs/發想引擎/、docs/重構/、結構定義/、.claude/skills/。
- 不得讀 examples/神秀之主/ 以外的任何一本書：gothic_witch/、一世之尊/、
  消失的密室/、芯片巫師/、examples/ 其餘六本、情境測試/。
  （尤其 一世之尊/chapters/ —— 那是本系統自己生成的 93 章，去看它等於
   先被本系統的既有寫法定錨，五臂就不再是從同一個起點出發。）
- 不得搜尋網路。
- 不得呼叫任何 skill。
- CLAUDE.md 會被自動載入，它提到「技巧知識庫」的存在——那不是給你的邀請，
  照樣不准去讀。你需要的東西都已經在這個 prompt 裡。

【交付】
- 純中文正文（繁體），不要標題、不要註解、不要說明你做了什麼。
- 篇幅硬性要求見各任務。超出或不足 ±15% 會讓計數讀數不可比，該臂作廢。
```

> **為什麼要寫最後那條**：`CLAUDE.md` 每回合無條件載入，而它花很大篇幅講 `技巧知識庫/` 是什麼。Arm0 是對照組，它一旦自己跑去讀，整組實驗就沒有對照組了。**這是本輪最容易破的一道牆。**

### T2 腔調打架

| | |
|---|---|

| **篇幅** | **1200–1800 漢字** |

## 2 · 五臂

### Arm0 — 對照組

拿到：鐵律 ＋ 背景材料 ＋ 任務句 ＋ 篇幅。
**零方法論。** 不給技法節、不給 checklist。

> 這一臂的讀數就是「Claude 不被提示時，寫成什麼樣」。它是整輪的基準線，**別對它手軟也別對它放水**。

### Arm1 — 輸入端載入（＝`05` 方案）

拿到：Arm0 的一切 ＋ **那 3 節的全文**，直接貼進 prompt（不是給路徑）。

| 任務 | 貼哪 3 節 |
|---|---|
| T1 | `世界觀與背景.md ## 九、跨語言補充：冰山理論與「按需揭示」`（含「設定帶出的操作判準」5 條與檢查行）／`對白.md ## 二、對白的六大功能`／`展示而非講述與五感描寫.md ## 三、常見「講述陷阱」與對應修法` |
| T2 | `字詞句法與抗生硬.md ## M6 虛詞與語氣顆粒`／`敘事距離與DeepPOV.md ## 一、Deep POV（貼近視角）`／`心理描寫.md ## 二之二、內心戲的兩種：離題型 vs 解說型（★ 配額）` |

**主 session 負責把節內文抽出來貼上**（`kb_route.py` 沒有 `--show` 介面；用 `python -c` 切 `## ` 節即可）。**貼原文，不得改寫、不得摘要**——摘要就變成第四個變數。

**只交一版。**

### Arm2 — 輸出端閘門

拿到：Arm0 的一切 ＋ `checklist-T?.md` 的**分派後措辭**（Arm2 欄）。

流程五步，照 `checklist-T?.md` 文末的「給臂的操作指示」。**交兩版 v1／v2 ＋ 逐條回答。**

⚠️ **checklist 只給問句，不給做法。** 主 session 貼給 subagent 時只貼分派後的那 12 條，**不得**把 `rubric-T?.md`、配對表、計分規則、或另一種措辭一起貼過去。

### Arm2′ — 輸出端閘門·反向措辭

與 Arm2 完全相同，唯一差別是措辭取 `checklist-T?.md` 的 **Arm2′ 欄**（條 1,3,5,7,9,11 用正向版；條 2,4,6,8,10,12 用禁令版）。

> **它為什麼存在**：讓「禁令 vs 正向」的比較變成 **within-item**。只有 Arm2 的話，那個比較是跨條目的，條目難易度會跟措辭混在一起。

### Arm3 — 兩者都有

拿到：Arm1 的 3 節全文 ＋ Arm2 的 checklist（**同 Arm2 的分派**）。
流程同 Arm2（先寫、後查、再修）。**交兩版。**

## 3 · 產出落點與匿名化

寫作 subagent 一律落在 `docs/技法用法/08-原型/產出/_原始/`：

```
產出/_原始/T1-Arm0.md
產出/_原始/T1-Arm1.md
產出/_原始/T1-Arm2-v1.md
產出/_原始/T1-Arm2-v2.md
產出/_原始/T1-Arm2-逐條回答.md
產出/_原始/T1-Arm2p-v1.md   …（以下同理）
產出/_原始/T2-…
```

**接著由主 session 匿名化**，只把送評的那一份複製過去：

| 送評的 | 說明 |
|---|---|
| 原著 | T1 ＝ 368–370 原文；T2 ＝ 370 對應段原文 |
| Arm0 | 唯一一版 |
| Arm1 | 唯一一版 |
| Arm2 | **v2** |
| Arm2′ | **v2** |
| Arm3 | **v2** |

⇒ 每個任務 **6 份稿**，打亂後改名 `產出/T1/稿A.md` … `稿F.md`；對照表寫 `產出/T1/_解封.md`。

**⚠️ 這一步最容易被跳過，一跳過整輪讀數作廢。** 評分 subagent 不得拿到 `_原始/`、`_解封.md`、`checklist-*.md`。

**另外單獨算的一組讀數**：Arm2／Arm2′／Arm3 的 **v1 → v2 差**。那需要 v1 也送評——**用第二輪評分**（同一份 rubric、另一個評分 subagent、v1 也匿名化）。若成本吃緊，優先保 v2 那一輪，並在結果檔明說 v1 未評。
