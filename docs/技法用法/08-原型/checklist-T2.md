# checklist-T2（腔調打架）— 寫作臂用·兩種措辭

> **這一份給 Arm2／Arm2′／Arm3，評分者不得看到。**
> **鐵律：checklist 只有「要檢查什麼」，不含「該怎麼做」。**
> 每條兩個版本，內容相同、措辭相反。分派見文末。

---

| # | 禁令版措辭 | 正向版措辭 |
|---|---|---|
| **1** | 說出口的台詞（引號內）**不得**夾入現代俗語顆粒（差評／劃水／裝逼／特么／個鬼／鳥事這一類）。檢查：有幾處？ | 現代俗語顆粒只出現在內心，不出現在說出口的台詞裡。檢查：台詞裡有幾處？內心有幾處？ |
| **2** | **不得**讓兩種語域混在同一種排版形式裡、讀者分不出哪句是說出口的、哪句是心裡想的。檢查：未分軌的處數？ | 內心與說出口的話靠引號或排版分軌，切換由排版承擔。檢查：分軌的處數／未分軌的處數？ |
| **3** | 岔題的內心戲**不得**連續兩段出現。檢查：有幾次連續？ | 岔題的內心戲之間要隔開。檢查：連續出現的次數是多少？ |
| **4** | 岔題的內心戲**不得**超過配額——約 3000 字 2–3 處。檢查：本稿漢字數多少？幾處？超了嗎？ | 岔題的內心戲維持在約 3000 字 2–3 處。檢查：本稿漢字數多少？幾處？落在區間內嗎？ |
| **5** | **不得**寫「拿掉之後讀者不會漏掉劇情、因為前面已經演過了」的那種內心戲。檢查：有幾段？ | 每段內心戲都要通過這一問：拿掉它，讀者會不會漏掉劇情？「因為前面已經演過了」的那種要清掉。檢查：清完之後還剩幾段這種？ |
| **6** | **不得**讓內心戲只在替讀者做筆記。檢查：有幾段是在做筆記？ | 內心戲要讓讀者「少認識這個人一點」才捨不得拿掉——也就是它推進的是角色，不是理解。檢查：這種的處數是多少？ |
| **7** | **不得**使用過濾詞（注意到／感覺到／看見／聽見／察覺／發現）。檢查：有幾個？ | 感知直接寫感知內容本身，不經過中間的動詞。檢查：做到的處數／沒做到的處數？ |
| **8** | **不得**把感官寫成第三者的客觀描述（「他蒼白乾裂的嘴唇」）。檢查：有幾處？ | 感官詞彙直接落在角色自己身上（「他的嘴唇乾裂得發疼」）。檢查：這樣寫的處數是多少？ |
| **9** | 直接引語式的內心念頭（引號＋當下式）**不得**用在一般敘述段落。檢查：有幾處用在非情緒高點？ | 直接引語式的內心念頭留給真正需要放大的情緒瞬間。檢查：有幾處落在情緒高點？ |
| **10** | **不得**把配額花在日常過場上。檢查：有幾處花在過場？ | 配額優先花在場面最大／最緊繃的地方。檢查：有幾處落在最緊繃處？各是哪裡？ |
| **11** | 兩個主要角色的語氣顆粒**不得**分不出密度差（人人說同一種話）。檢查：兩人的語氣詞計數各是多少？ | 兩個主要角色靠語氣顆粒的密度差被瞬間區分。檢查：兩人的語氣詞計數各是多少？差多少？ |
| **12** | **不得**讓角色的用詞可以互換而讀者看不出來。檢查：有幾處用詞是換了說話者就不成立的？ | 用罵詞或俚俗稱謂做「一字立人」。檢查：這樣的處數是多少？逐處引出。 |

## 給臂的操作指示（照抄進 prompt）

1. 先寫完第一版，**這時不要看 checklist**。
2. 落檔第一版。
3. 逐條回答 checklist（12 條全答）。
4. 依自己的回答修一版。
5. 交**兩版**：`v1` 與 `v2`。

⚠️ **不得跳過第 1–2 步直接照 checklist 寫。**
