# checklist-T1（資訊傾倒）— 寫作臂用·兩種措辭

> **這一份給 Arm2／Arm2′／Arm3，評分者不得看到。**
> **鐵律：checklist 只有「要檢查什麼」，不含「該怎麼做」。** 一旦寫進做法，Arm2 就變成 Arm1 的變體，整組對照失效。
> 每條兩個版本，內容相同、措辭相反。分派見文末。

---

| # | 禁令版措辭 | 正向版措辭 |
|---|---|---|
| **1** | 這一稿**不得**出現連續 5 行以上、沒有任何動作／道具／當下正在發生的事的純背景說明。檢查：最長的那一段幾行？ | 每一段交代背景的文字，都應該有動作或道具同時在場。檢查：做到的段數／沒做到的段數各是多少？ |
| **2** | **不得**讓設定只靠旁白或純陳述帶出。檢查：有幾處設定是這樣帶出來的？ | 設定應該嵌在角色的動作或道具細節裡帶出。檢查：這樣帶出的處數是多少？逐處引一句。 |
| **3** | 同一個場景裡第一次出現的陌生專名**不得**超過 2 個。檢查：最多的那一場有幾個？ | 同一個場景裡第一次出現的陌生專名，控制在 1–2 個。檢查：最多的那一場有幾個？ |
| **4** | **不得**讓一個陌生專名裸著出場、當句沒有交代它是什麼。檢查：有幾個是裸著出場的？ | 每個陌生專名第一次出現時，當句就配一條功能標籤（品階／效果／用途）。檢查：配到的有幾個？ |
| **5** | **不得**由旁白直接開講新設定。檢查：有幾個設定是旁白開講的？ | 新設定由「角色此刻正要做的動作」或「某角色有私心的話」逼出來。檢查：這樣逼出的有幾個？ |
| **6** | **不得**讓角色為了讓讀者聽懂而說話——說話的人必須有自己的私心。檢查：有幾句是為了讀者而說的？ | 每一段設定交代，說話的人都要有自己的動機或私心。檢查：有私心的處數是多少？ |
| **7** | **不得**先丟名詞或定義、之後才給現象。檢查：有幾處是這個順序？ | 先演現象或體驗，名詞延後。檢查：這個順序的處數是多少？ |
| **8** | **不得**在讀者還沒體驗過那個東西之前就替它命名。檢查：有幾處犯了？ | 讓讀者先體驗、後知道術語。檢查：做到的處數是多少？ |
| **9** | **不得**留下贅句——拿掉之後塑造人物／顯現衝突／推動劇情／透露訊息／營造氣氛／默化主題六項一項也不少的對白。檢查：有幾句？ | 每一句對白至少幹一件活（六項之一）。檢查：確認每句都有活幹了嗎？沒活幹的有幾句？ |
| **10** | **不得**讓整段對白只在做「透露訊息」這一件事。檢查：其他五項各有幾句？ | 六大功能（塑造人物／顯現衝突／推動劇情／透露訊息／營造氣氛／默化主題）都應該有對白在做。檢查：六項各有幾句？ |
| **11** | 單一發言**不得**連續 5 行以上沒有被打斷、反問或動作插入。檢查：最長的一段幾行？ | 硬設定要用對話切碎，每輪只給一小塊。檢查：最長的單一發言幾行？ |
| **12** | **不得**讓聽的那一方只是坐著聽。檢查：有幾輪對話裡，聽的人完全沒有反應？ | 聽的那一方要有動機聽——追問、反駁、動作反應、心裡盤算。檢查：有反應的次數是多少？ |

## 分派（先寫死，實驗中不得更動）

| 臂 | 條 1,3,5,7,9,11 | 條 2,4,6,8,10,12 |
|---|---|---|
| **Arm2** | **禁令版** | **正向版** |
| **Arm2′** | **正向版** | **禁令版** |
| **Arm3** | **禁令版**（同 Arm2） | **正向版**（同 Arm2） |

**為什麼要 Arm2′**：如果只有 Arm2，「禁令條 vs 正向條的效力差」就是**跨條目**比較——條目本身的難易度會跟措辭混在一起，量不出東西。Arm2′ 把措辭反過來，於是同一條可以拿**自己**的兩種措辭相比（within-item crossover）。

**Arm3 為什麼跟 Arm2 同分派**：Arm3 要測的是「輸入端＋輸出端有沒有加乘」，措辭不是它的變數。分派不同會多一個混淆因子。

## 給臂的操作指示（照抄進 prompt）

1. 先寫完第一版，**這時不要看 checklist**。
2. 落檔第一版。
3. 逐條回答 checklist（12 條全答，包含「這條我做到了」也要寫出數字或引句）。
4. 依自己的回答修一版。
5. 交**兩版**：`v1` 與 `v2`。

⚠️ **不得跳過第 1–2 步直接照 checklist 寫**——那樣測到的是「輸入端載入一份簡化版方法論」，不是「輸出端閘門」。
