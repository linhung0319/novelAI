蘇家莊的曬穀場上還躺著四個人。

那隻元氣大手抓下來的時候只捉走了蘇味一個，可掌風掃過屋脊，掀了三家的瓦，把老蘇頭從梯子上刮下來，斷了一條腿。鐘神秀進院時，蘇棠正端著一盆血水往外潑，潑到一半看見他，手一抖，盆沿磕在門檻上，噹的一聲。

「道之——」

「先燒水。」他把袖子挽到肘上，走到塌了的偏廈前，一手托住橫梁。那梁是三十年的老榆木，兩個壯漢抬不動，他單手往上一送，樑就回了卯口，屋頂的塵灰像下雪一樣落了他一頭。他抖了抖，「李三家的娃壓在草垛底下，先去挖。」

莊戶們愣愣地看著他。他們昨天還覺得這位蘇家的仙師遠在天邊，此刻他手上全是灰。

半個時辰後，天邊落下一道遁光。

那遁光比來時暗了整整一層，落地時甚至打了個踉蹌。陳文霽從光裡走出來，懷裡抱著蘇味。小姑娘一落地就往鐘神秀懷裡撲，紅襖上兩道黑印，是被那隻元氣大手捏出來的。

「哥哥——」

「哈哈，我這堂妹，承蒙師姐照拂了。」鐘神秀把蘇味接過來，掂了掂，順手往她胳膊上一摸。

小姑娘嘶地抽了口氣。

他把那截袖子捲起來。蘇味的小臂上有五道青紫，指印的形狀，青紫的邊緣卻結著一層極細的白霜——三月天，日頭正毒，白霜卻不化，摸上去黏手，像摸到一層蠟。

陳文霽的臉色變了。她一把抓住蘇味的手腕，指尖搭上去，眉頭越皺越緊。

「師弟，你把她抱遠些。」

「怎麼？」

「這是屍氣。」她從腰間摸了半天，才想起自己的乾坤袖已經沒了，只好折了一根桃枝，在白霜上刮了一下，桃枝的斷口立刻黑了半寸，「妖邪道的路數。他們那一脈的法身叫『白骨魔身』——法身，就是掌教那一級，一根指骨立在城隍廟裡能鎮三十年香火。這種東西擦過的人，身上要留印子，七天內順著印子能找回來。」

鐘神秀低頭看著那層白霜。

『我那道白骨神通不過五品，留下的印子倒跟法身一個路數。』

那隻爪子是他自己伸出去捏死伊志松的，此刻正結在堂妹的胳膊上，冒著白霜等人來找。

「師姐是說，捏死伊師兄的那位，出自妖邪道？」他把蘇味往地上一放，拍拍她的頭，「去找棠嬸要糖。」

蘇味不走。她蹲下來，撿了塊燒剩的木炭，在青磚上畫。畫得很認真，五根手指，指節上一圈一圈的花紋。

「就是這個。」小姑娘說，「它從土裡出來的。」

陳文霽盯著那幅畫，很久沒說話。

院子外頭有人在哭。老蘇頭的腿接不上，正在嚎。

「不對。」陳文霽終於開口，聲音壓得很低，「妖邪道的白骨是素的，越白越貴。這上頭有紋。」

她從懷裡掏出一枚玉符——那是唯一沒被搜走的東西，因為它貼身，燙得很。玉符在她掌心一跳一跳地發熱，像是揣了個活物。

「這什麼？」

「命燈碎了。」她的聲音有點抖，「伊師兄的命燈供在山門裡，滅了就要有人問。這符已經燙了兩個時辰，最多再三天，宗門的查訪使就到扶風。」

「查訪使問什麼？」

「問一份勘合。」她蹲下去，把袖子擼開，「哪一脈、哪個品階、有沒有上頭護著。三欄。三欄填錯一欄，死的就不止我一個。」

她沒有筆。鐘神秀從灶膛裡撥出半截炭遞過去，她接了，又要朱砂，蘇棠翻出過年寫桃符剩的一小罐。她把罐子擰開，手抖得厲害，紅粉撒了半邊磚。

「師姐。」鐘神秀端了碗涼茶蹲到她對面，「你先喝口。」

她一口喝乾了，把碗底剩的一點茶潑在青磚上。

茶水在磚縫裡分成幾攤。她用炭在每一攤旁邊點了一個圈。

「魔門六道。」她說，「六個圈，我得抹掉五個，只留一個寫進去。」

「就這麼定？」

「這麼定。」她抹掉第一個，「血海門。他們的『血海魔軀』過境，方圓十里的井水要泛紅，你莊上的井呢？」

「昨天挑的水，清的。」

「那就不是。」第二個抹掉，「巫教。祖巫真身走的是刻骨，一根骨頭上要刻滿祖巫的圖騰，那是他們的憑證，越顯眼越好。你妹妹畫的紋是暗的、細的，不像。」

第三個。「無生殺教。他們的『殺生劍體』、『滅絕刀身』，出手不留全屍，你師兄——」她頓了一下，「伊師兄是整個被捏扁的，還在，沒被切。」

第四個抹得很慢。「五蓮宗。」

「這個為什麼慢？」

「因為五蓮宗我不敢寫。」她抬起頭，眼睛裡有點紅，「那位宗主是個奇女子，紅蓮業火、黑水滅世、長生魔體三門奧義給她揉成了一個『散花天女法相』，我宗掌教親自去追黑蓮大尊那樁事，跟她做過一場，敗退。」

鐘神秀端著空碗的手停在半空。

「掌教敗了？」

「掌教是清微道妙真君，三百餘歲就證了『龍虎法身』。」陳文霽用炭在磚上重重點了一下，「敗了。所以這個名字我要是填上去，宗門必得再去一趟，再去一趟就要死人，死的人算誰的？算我這份勘合的。」

『……原來寫個名字就能死人。』

鐘神秀慢慢把碗放下。他忽然明白這女人為什麼從落地起就在抖——不是怕死，是怕落筆。

第五個圈她沒抹。

「黃泉魔宗。」她看著它，「他們有『六道輪回真身』和『黃泉魔身』，黃泉一脈驅使白骨，紋是暗紋，走的是陰氣。……勉強能對上。」

「那就對上了。」鐘神秀說得很快。

她抬眼看他。

「師弟這麼急？」

「不急。」他把那碗茶碗底翻過來，扣在第六個沒名字的圈上，「我是想起師姐剛才提過的一位新秀。九宮山那邊，黃泉獄子黃邪，是不是也在？」

陳文霽怔住了。

「……在。」

「那便順了。」鐘神秀笑了笑，「他們的人在九宮山跟貴宗鬥法，分一縷神念到扶風來殺個信使，恰好我這裡有個現成的人證。師姐若在勘合上寫黃泉，宗門要去追，本來就在追。不多死人。」

她盯著他看了很久。

「師弟。」她慢慢說，「你這個腦子，去做斗法道將，真是可惜了。」

『我這個腦子要是不動快點，你那三欄裡就要填我了。』

鐘神秀陪著笑。

那枚玉符又燙了一下，在磚上跳了跳。陳文霽像被燙醒似的，撿起炭要寫，寫到一半又停住。

「還缺一欄。」

「什麼？」

「品階。」她說，「殺伊師兄的那位，是元丹。這一欄我不填也得填，可我填了元丹，就得有人問——為什麼不去報仇。」

「為什麼不去？」

陳文霽笑了一聲，那笑聲很難聽。

她從供桌上抽了一根線香，掰成兩截。

「元丹之後修元神。」她把第一截香在指間轉了轉，「元神之前隔著三災。三災是天要收你的命，一災一災地過，過完了元神才出得來。」

她把那截香折成三段，一段一段丟在地上。

「元神之後修法身。」她拿起第二截，「隔著四劫。四劫盡了，法身才凝得住。」

第二截被她折了四段。

「我宗有位元神老祖坐鎮九宮山，明雪真人、九如真人隨時巡。他們一個個活了幾百年，身上壓著幾百年的道果，過三災的時候要拿命去換。你叫他們為一個內門弟子下山去找一個元丹？」她把七小段香攏成一堆，「他們不會來的。誰的命長，誰就最怕死。」

地上七段斷香，堆得像一小座墳。

鐘神秀看著那堆香，心裡忽然涼了一下。

『三災、四劫……我這外道成的丹，過得去麼？』

「所以到頭來，是我們這些神通級的去填。」陳文霽把炭捏得死緊，「九宮山底下是一座封魔穴，最近漏氣，我宗奉命鎮著，魔門六道去了一半，天天鬥法，天天死人。死的全是神通。上頭那幾位在雲裡站著看。」

「師姐。」鐘神秀忽然問，「若要招回伊師兄的殘魂，妙濟真宗的《度人經》最擅此道，為何不去請？」

陳文霽的手停了。

「請不動。」她說，「道門三宗，我太上龍虎宗、妙濟真宗、太平宗，面上是一家，法統一脈，都奉道祖。可他們家宗主煉的是『靈寶法身』，太平宗宗主是『黃天法身』，三家的法身各煉各的，三百年不通婚。求人家一部《度人經》，人家要問我拿什麼換。」

「拿什麼換？」

「拿不出來。」她苦笑，「我連乾坤袖都沒了。」

鐘神秀摸了摸鼻子。他從懷裡數出三枚黃帝錢，擺在磚上，一枚一枚推到她面前。

「這是……」

「路上總要吃飯。」

那三枚錢，是他從她自己的乾坤袖裡拿的。

陳文霽把錢收了，收得很快，快得不像個內門弟子。她低著頭，把三枚錢在磚上擺成一個三角，指尖點著其中一枚：「太平宗有一部《太清金液神丹經》，道門公認的元丹第一法。」

她抬頭。

「師弟，你說一個散修，沒有宗門，沒有師承，他是怎麼結的丹？」

院子裡的哭聲不知什麼時候停了。

鐘神秀端起空碗，發現裡面沒水了。

「師姐的意思是……」

「我在想，」陳文霽把那枚錢立起來，「那位神秀公子的丹，是從哪裡來的。太平宗的丹經在山門裡鎖著，旁門左道倒是有些歪路子，可旁門成不了仙，這也是有定論的。所以他要麼偷了三宗的東西，要麼——」

她沒說完。

「要麼是旁門。」鐘神秀替她說完，「旁門左道，難以成仙。師姐這麼一說，那位公子倒有點可憐。」

「可憐？」

「他殺人不眨眼，可他這輩子到頭了。」鐘神秀把碗放下，「三災四劫是一道坎，坎前頭沒路的人，才最愛在坎前頭殺人。」

陳文霽愣了一下，隨即嘆息：「師弟見得透。」

『我見得透個屁，我就是那個沒路的。』

他把蘇味叫過來，把她的小臂托在掌心。

「師姐，這印子怎麼洗？」

「洗不掉。要拿同源的陰氣引出來——」她說到一半就住了口，因為蘇味手臂上那層白霜正在退。

不是退，是縮。白霜順著青紫的邊緣往裡收，收成一粒米大的白點，最後被鐘神秀兩根指頭捻走了。他把那粒白點在指腹上搓了搓，搓成一縷煙。

「我那道護身神通有點餘火。」他說，「九清仙光，一品，正好剋這個。」

陳文霽張著嘴，說不出話。

半晌，她低聲道：「我道門三宗之內，煉成一品神通的也不過寥寥……師弟，你這道仙光……」

「廢人一個。」鐘神秀把蘇味推去找糖，「根基有缺，九如長老親口說的。」

天邊這時起了一道白虹。

那不是遁光，是有人在極高處撕開了雲——扶風城的方向，一道，兩道，三道，都朝著半日前雷動百里的那座山頭去。有人循著結丹的天兆來了。

陳文霽騰地站起來，臉都白了。

「我得走。」

「勘合呢？」

她低頭看了一眼那攤茶水，六個圈只剩一個。她蹲下去，用炭在最後那個圈裡寫了兩個字——黃泉。

寫完，她把炭一丟，忽然回頭。

「師弟，那道法旨毀了，你本可以裝作沒這回事。等下一撥使者來，少說也要半年。」

鐘神秀彈了彈袖子上的灰。

半日前他還在盤算著躲，躲一年，躲到宗門忘了蘇道之這個名字。可地上那七段斷香還堆在那裡，天上那三道白虹正往山頭飛。躲一年，他還是要在原地。

「不就是九宮山麼。」他說，「我去。」

陳文霽看著他，眼圈忽然紅了。她盈盈一禮，禮行得很正，是傳功一脈的規矩。

「九宮山鬥法，只論神通對神通，上頭那些人是不下場的。」她說，「師弟以九清仙光護身，立於不敗之地，只要別碰見那幾個真傳……」

「哪幾個？」

「黃泉獄子黃邪、白蓮聖女、妖邪魔子。」她一邊起遁光一邊回頭，「還有——師弟，你到了那邊，若聽見有人問起扶風的元丹，你什麼都不知道。」

「我什麼都不知道。」鐘神秀笑著揮手。

遁光去遠了。

他站在滿院子的碎瓦裡，低頭看著地上那七段斷香、六個茶圈、一隻木炭畫的白骨手爪。

蘇味舉著一塊麥芽糖跑過來，一腳踩在「黃泉」兩個字上，把它蹭花了。

『三災過而元神出，四劫盡而法身凝。』

『我這外道成的丹，走到頭是外道元神、外道法身，怎麼看都是旁門。』

『旁門不能成仙……那就換一個能成仙的門。』

他抬起頭，看著扶風城方向那三道還沒散的白虹，慢慢地把袖子放了下來。
