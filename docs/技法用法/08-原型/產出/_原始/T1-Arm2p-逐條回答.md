## 3. 同一個場景裡第一次出現的陌生專名，控制在 1–2 個。最多的那一場有幾個？

**全篇只有一個大場景（廢鎮），新專名合計 28 個，遠超上限。**

清點：血海門、血海魔軀、金剛寺、曉元大師、般若羅漢金身、陀彌寺、寶相羅漢、阿羅漢金身、度人經、妙濟真宗、妖邪道、白骨魔身、巫教、祖巫真身、五蓮宗、散花天女法相、三災四劫、清微道妙真君、龍虎法身、靈寶法身、太平宗、黃天法身、無生殺教、殺生劍體、滅絕刀身、黃泉魔宗、六道輪回真身、九宮山。

本題是**任務本身的硬衝突**：任務要求交代道門三宗＋魔門六道＋各家法身與掌教＋三災四劫，這份清單的名詞下限就在 25 個上下，壓不到 1–2。

**v2 的可行做法不是砍到 2，而是把廢鎮切成六個有明確邊界的子場**（麥田／井台／土地廟／白骨巷／山坡焦痕／北頭土台），每個子場控制新專名 **2–4 個**，並讓子場之間有動作轉場而非話題轉場。這一條在 v2 只能改善、無法達標，如實記錄。

## 4. 不得讓陌生專名裸著出場、當句沒交代它是什麼。有幾個是裸著出場的？

**4 個。**

1. **炎漢**——「這鎮子已經不是炎漢的地界了」，當句沒說炎漢是什麼。
2. **黃帝錢**——旁白裡一閃而過，沒有任何交代。
3. **妙濟真宗**——「《度人經》。」「妙濟真宗的。」只給歸屬，沒說這一宗是什麼。
4. **九宮山**——「你要去的九宮山，就是這一路人在圍」，只說被圍，沒說它為何值得圍（封魔之穴）。

另外**太平宗**只靠「道門三宗，一宗一具」被順帶歸類，屬於邊緣案例，v2 一併補。

反例（做對的）：金剛寺／巫教／五蓮宗／無生殺教／黃泉魔宗／清微道妙真君，六個都在同句或下一句給了「它是什麼」。

## 6. 不得讓角色為了讓讀者聽懂而說話。有幾句是為了讀者而說的？

**2 句。**

1. 「道門三宗，一宗一具，此外整個天下再沒幾個。」——純補課，說話人此刻不需要這句話換到任何東西。
2. 「他們主持曉元大師證的是般若羅漢金身……陀彌寺的寶相羅漢證阿羅漢金身，走的是不壞的路子。」——前半（判斷來過的是誰）有私心，後半列第二座寺是替讀者補的。

其餘對白都掛得住私心：陳文霽全程有兩個私心（回宗門要有東西交差／想坐實自己夠格當蘇味的師父），小道士有一個（撐不住了要人接手），鐘神秀有一個（他要摸清法身級人物的斤兩，卻不能問得像元丹宗師）。
