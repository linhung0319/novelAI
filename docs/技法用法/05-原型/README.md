## ⚠️ 三個明說的警語

**① `門牌表.md` 是這個 repo 廢除過六次的形狀。**
它是一支 227 行、34 KB 的**集中索引檔**，而 `CLAUDE.md` 對這種檔的判定很明確——它是「全系統唯一一支關於全部東西的檔，所以任何找不到家的內容都會落在它身上，而它的 hash 守的是源檔集合、不是它自己的內容，於是沒有任何東西會反對」。

它之所以還存在，只因為**那一輪的紀律是「不修改 repo 任何既有檔」**，而正式形態需要改動 27 支技法檔。**正式形態是門牌內嵌在各節標題底下**（源檔·強格式·作者直改），索引走 `kb-route --emit` 投影、不落檔：

```markdown
## 四、餘韻四手法
> 模式：生成｜供詞
> 症狀：結局說完就沒了沒有餘味｜想用象徵但不知道怎麼用
> 吃：結局型 → 吐：意象×N
```

**② 這 227 行有已知的錯，而且錯誤率未知。**
`世界觀與背景#二` 那一行已確認寫錯（把該節末行的註腳當成主體，詳見主檔 §6.1）。它是評分 agent 碰巧撞到的，**另外 226 行沒有任何人檢查過**。用這張表之前先讀主檔 §9。

**③ `kb_route.py` 是原型腳本，不是 `tools/` 的一員。**
它不吃 `--book`、沒有 lint、沒有測試、不進生產包，也**不該**進。真要落地時它屬於 `tools/kb_route/`，並需要一支 `kb-lint` 守門牌格式與覆蓋率（守不了誠實度——那正是主檔 §6.1 的未解問題）。
