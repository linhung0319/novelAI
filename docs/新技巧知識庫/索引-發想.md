# 索引：發想

每招一行，卡片在 `cards/`。卡片是材料，不必照步驟；例子只示範形狀，不要搬進候選。正文類的卡不放進落筆的寫手 context。

## 構想

### 沒東西

- 無關組合：靈感單獨看都不夠好，不知道要寫什麼
- 十大故事類型：完全沒靈感，想找個方向刺激一下
- 連問法：有個畫面或題材，但還不是故事
- 三問補三面向：只有人物、情節或背景其中一項，其他補不起來
- 先找題材再賦予主題：有想寫的主題，卻不知從何下手
- 主題三角：有想講的主題或題目，但不知道要寫哪些戲

### 太套路

- 版本改造：這個靈感太普通、太老套
- 相異錯配：角色、設定或點子太平凡，沒有戲
- 三十六劇：想不到要放哪些梗，或這段還能變出什麼戲
- 先找題材再賦予主題：故事有深度，但不有趣
- 結局題旨互推：題旨把故事綁得動不了

### 選不下

- 十大故事類型：有靈感，但不知道哪種類型最能發揮
- 結局題旨互推：結局選不下，或故事有了卻說不出在講什麼

## 世界觀

### 沒東西

- 這條規則該有誰：有世界規則，但沒有人物或勢力在裡面活動

### 太套路

- 背景突兀：世界觀太正常，主角待在裡面沒有戲
- 限制與代價：能力或魔法太萬能，沒有戲
- 綑綁抗衡：衝突不痛不癢，雙方隨時能走開，或只是二選一

### 選不下

- 自訂規則：誇張的設定要不要解釋、什麼時候交代

## 角色

### 沒東西

- 這段戲誰最難做：確定要寫某段戲，不知道該讓誰做、他為什麼難
- 目標互推：想不到主角、反派或配角要什麼，或有目標卻沒有主線
- 角色會做的事：資料有了，人活不起來，猜不到他會怎麼做
- 角色訪談：有初步設定，但抓不到這個人，或每個人都像作者
- 臨摹混搭：想不出這個人，腦中只有「有點像某某」
- 弧線缺一段：轉變像突然開竅，或心境一直沒動
- 抽象反派找代言人：對手是歧視、天災、恐懼，沒有具體的人可恨
- 缺一個反對的人：這段衝突很弱，只剩主角在想事情
- 關係網缺線：角色都只跟主角有關係，配角之間沒戲
- 群像打結：角色一多就各演各的，寫著寫著散掉

### 太套路

- 給他一個不足：主角太完美，或不知道故事要折騰他什麼
- 岔路定性格：性格只在設定裡，這段戲換誰演都一樣
- 三層行為反差：角色表裡如一，太單調
- 改一個條件滾下去：角色很通用，或兩個角色太像
- 核心情緒：行為合理但沒勁，或要做反常的事怕讀者不接受
- 他相信的假話：舊傷只是背景，或反派只能用「他瘋了」解釋
- 兩難釘死：讀者一看就猜到他會學到什麼
- 反派的理由：反派只是為作對而作對
- 同一弱點多種攻法：敵人一個接一個都差不多，或對立只剩善惡
- 立場曖昧的人：想要猜不透的角色，或忽敵忽友看起來很隨意
- 誰來點醒他：主角需要被點醒，但寫出來只是有人說教或送禮
- 反差要收：角色有反差，但只是噱頭，演完就沒了
- 兩極呼應：主角變得很大，卻像換了個人，或變了也沒意義
- 立場四角：主角的變化只有一步，太單調
- 相反觀念的角色：想講的觀念寫出來像在說教

### 選不下

- 鏡像與對照：配角只是襯托主角，不知道該配哪種人給他壓力
- 憧憬與代入：主角太強讀者有距離，或太普通沒人想變成他

## 劇情

### 沒東西

- 把情節填進骨架：想到一堆情節，排不成一個故事
- 七問題：有主角和目標，不知道怎麼把這條線走完
- 縱橫交會：主線太單薄想加副線，或想埋伏筆又不想硬埋
- 中段空洞：頭尾都有了，中間不知道要演什麼
- 下一步從結果長：上一幕寫完，不知道下一幕要做什麼
- 大綱拆幕：大綱有了，一段話變不成一幕一幕
- 特質要有展場：特質或關係定好了，但沒有一場戲在演它
- 由果推因：知道後面要發生什麼，不知道前面怎麼埋
- 舊細節變伏筆：當初沒計畫伏筆，現在要一個轉折又不想憑空冒出來
- 主題落點：題旨定了，不知道怎麼進到故事裡

### 太套路

- 逼他上路：主角走上主線的理由很牽強，或他太乾脆
- 先升後跌：挫折不夠痛，或中段一路順、一路慘
- 轉折錯位：讀者猜得到什麼時候要轉好或轉壞
- 爽點三步：翻盤或打臉的場面讀起來不爽
- 憋與爽的節拍：連載憋太久，或一路順爽沒有張力
- 先笑後哭：這場死亡或背叛應該不會痛，或故事一路沉重
- 誤導佈局：真相想好了，但讀者大概猜得到
- 謎三角：只反轉一次怕被猜到，想騙讀者兩次
- 第三條路：一路在 A 和 B 之間拉扯，怎麼選都猜得到
- 兩難釘死：想給角色一個真正難選的選擇
- 阻礙不夠力：阻礙看起來很大，讀起來卻不緊張
- 讀者想喊停：主角太乾淨、一路做對的事，讀者沒什麼好揪心的
- 資訊差：事件都對，讀起來卻不緊張；所有人知道的都一樣
- 留一塊不說破：什麼都交代清楚了，讀完就結束
- 主題三角：主題只演得出好壞兩邊
- 為什麼這件事重要：主角打來打去，看的人不痛不癢
- 角色各帶主題：人物很多，故事卻只有一層意思
- 結局加力：結局成立，但平淡沒力
- 反高潮：不想照常見的方式收尾
- 綑綁抗衡：衝突不痛不癢，雙方隨時能走開
- 設定怎麼帶出來：設定突然蹦出來，或像旁白在念說明書

### 選不下

- 把情節填進骨架：不知道這本書該用哪種結構
- 內外目標排序：幕排出來順序不對，或不知道哪些戲能砍
- 開始與開場：不知道第一章從哪寫、要不要楔子
- 爽與深的鈕：這段該快還是慢、該爽還是深
- 角色分層放：角色資訊該什麼時候放，一出場就交代完還是慢慢來
- 資訊差：不知道該讓誰先知道答案

## 正文

### 沒東西

- 下一句換方向：對話寫到這裡接不下去，或下一句太好猜
- 補感官：這段很空，看不見也摸不著
- 一件東西頂一段描寫：不知道這裡該描寫什麼
- 換場的橋：換場太硬，只會空一行
- 開打前的鋪墊：直接開打沒感覺，想讓這一戰讓人期待

### 太套路

- 話中有話：角色把心裡想的直接說出口
- 不照問的答：對白一問一答，很死板
- 對白升溫：對白只是傳話，或一開口就吵到頂
- 認得出是誰：角色講話都一個樣，或配角多了記不住
- 情緒換成行為：「他很傷心」一句過去沒感覺，或動作很多卻看不出在想什麼
- 換個管道：性格都是講出來的，或讀者太快看透他
- 旁帶：「她很美」「他很有錢」直說，讀者不信；或沒有東西可比
- 複沓與反常：這段達成得太容易，或情緒推不上去
- 情景相襯或反差：景只是布景，或傷心就下雨
- 一句話幾種寫法：這句就是不對，想看別的寫法
- 心念插進動作：一直寫「他想」，或內心和動作脫節
- 我他你切換：感情太難受，一直「我」顯得矯情，或第三人稱隔太遠
- 痛之前先讓他想事：痛寫得像醫學說明書
- 角色怎麼登場：第一次出場很平淡，像在填資料
- 第一段怎麼抓：第一句或第一段沒有力
- 幕尾停在哪：結尾像在收攤，沒有讓人想看下一頁
- 跳過過程：這段過程寫出來反而普通，或一寫細節角色就不強了
- 自創象徵：想表達的東西太直白，或象徵都很老套

### 選不下

- 該演還是帶過：這段該寫滿還是一句帶過
- 放快或放慢：這段太趕或太拖，想拉長一瞬或壓短很多年
- 換一雙眼睛：不知道這段該由誰來看
- 貼近或拉遠：和角色隔了一層，或太黏想拉開
- 這段回憶該不該插：想插回憶或支線，怕打斷
