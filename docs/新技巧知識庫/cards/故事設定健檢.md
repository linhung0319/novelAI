# 故事設定健檢

適用：故事設定已有雛形，想知道它吸不吸引人、有沒有哪裡撐不住
吃：一段故事設定或摘要
做：用這些問題檢查：
- 素材：有沒有少見、讓人想看的東西？
- 邏輯：有沒有反常的事，讓人想問為什麼？
- 衝突：衝突的人走得開嗎？是不是只有兩方對立？
- 太難：光看摘要，知道故事圍繞什麼嗎？艱深的題材能包裝成好懂的設定嗎？
- 太多：是不是什麼都想放？拿掉哪些，特色反而更清楚？
- 撐不撐得住：作者了解這個素材嗎？這些怪事最後圓得回來嗎？

吐：最弱的 1–2 項，以及可以怎麼改
例：《移動迷宮》
- 素材：四面高牆的迷宮，每月送來一個新人和物資，牆外有怪獸。
- 邏輯：某天竟送來一名少女，並宣告不再送人和物資，擋怪獸的門也不再關。
- 衝突：留守派對冒險派，加上疑似元兇的失憶主角、身分成謎的少女和幕後主使。
