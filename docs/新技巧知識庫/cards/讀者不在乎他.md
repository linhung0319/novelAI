# 讀者不在乎他

適用：這個角色讀者應該不會喜歡，或根本不在乎；或擔心主角太討厭
吃：角色、他的前幾場戲
做：讀者不必認同他，也不必想和他當朋友，只要能理解他。用這些問題檢查：
- 看得出他多想要什麼嗎？他能靠行動改變故事嗎？
- 他向讀者露過一點脆弱嗎？
- 他對無利可圖的人怎麼樣？硬派角色的一點溫柔特別有用。
- 他的善有付出代價嗎？
- 他有沒有不肯越過的線？他越過了，故事有讓人看見重量嗎？
- 缺陷是他自作自受的話，他有什麼補償的優點？對自己的弱點有自知嗎？
- 他有沒有對了卻沒人信的時候？有沒有做他最拿手的事的時候？
- 別的角色怎麼看他？讀者常跟著走。
- 反派：露出多面不是洗白，是讓他的錯更有重量。

作者可能就是要一個討厭的角色，那就只問讀者為什麼還想看下去。

吐：讀者目前可能卡在哪裡，指到具體段落；2–3 個改法，各說改哪一場
