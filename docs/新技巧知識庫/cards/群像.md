# 群像

適用：角色一多就各演各的，寫著寫著散掉；有人消失很久、配角搶戲；或幾個人同一場都在轉折
吃：角色群、各自的線、主線；已寫的話再帶章節或場次
做：群像的重點不是人多，是很多人的命運在某個點被打結。
- 他們共享什麼地點、處境或問題，才被拉進同一個軌道？
- 哪件事讓 A 的選擇直接改變 B 的命運？
- 結構怎麼走？平行式每條線都要能獨立撐住（《冰與火之歌》）；鏈式是 A 帶 B、B 帶 C（《水滸傳》前半）；角色很多可以單元輪流；少數幾人的緊密團隊可以走同一條線。

已經寫了一段時，畫一張表，列是章節，行是角色。戲份不用平均，但要是刻意的。誰消失了多久？配角戲份是否蓋過讀者最跟的人？各角色的轉折有沒有撞在同一場？大場面裡讀者盯得住幾個人？

吐：2–3 個打結點，各說綁住誰、誰的選擇影響誰；已寫的話附戲份表、可疑處和改法
