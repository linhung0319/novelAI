# 機器神檢查

適用：危機或結局靠外力、巧合解決，感覺很便宜；或就是需要一個外力解圍，又知道這樣不好
吃：這段解圍、前文、主角在這場裡做了什麼
做：查主角以外的力量和巧合。主角自己的能力解圍，用能力解圍檢查；想要意外又不想要機器神，可以用七問題，讓意外從他的努力長出來。用這些問題檢查：
- 這個外力前面出現過嗎？硬要追究，說得通嗎？
- 它解決的是大事還是小事？大事由主角解決，小事靠別人，讀者比較不會覺得偷懶。
- 最後的關鍵一擊是主角打的嗎？外力可以幫忙，不搶這一下。

喜劇和諷刺可以故意這樣用。都不成立時，可以提早埋它、讓它改解小事，或把它砍掉，由作者決定。
吐：哪一條撐不住，以及 2–3 個改法
例：
- 撐不住：偵探還找不出犯人，犯人自己自首了；決戰前對手突然心臟病發。
- 撐得住：《齊天大聖東西遊記》靠月光寶盒脫身，但寶盒前面已多次出場。令狐沖的性命隱憂由少林方丈解決，但江湖大事都是他自己力戰解決的。
