# 誤導佈局

適用：真相或結局想好了，但讀者一路看下來大概猜得到
吃：已定的真相，和目前讀者手上的線索
做：先定真相，再佈假象。從下面挑最適合這個故事的形式，不必全用。

| 形式 | 問句 | 例 |
|---|---|---|
| 目光標的 | 誰最適合擋在真相前面，讓讀者一直盯著他？ | 用石內卜擋奎若；用野心外露的左冷禪擋滿口仁義的岳不群 |
| 角色立場 | 這個人的善惡，能不能先往反方向寫？ | 《哈利波特》多個角色的善惡都翻過一次 |
| 結局選項 | 能不能讓讀者忙著猜二選一，忘了還有別的選項？ | 《犀利人妻》雙帥競爭，讀者猜她選誰，結局是不明確選誰 |
| 劇情方向 | 能不能讓整段故事都朝反方向走，最後才揭曉？ | 《俠客行》一路塑造俠客島有去無回，最後發現是誤會 |
| 早說的謊 | 誰可以一出場就在說謊？ | 配角初登場就說謊，讀者已經信他是好人 |
| 假馬腳 | 能不能露一個破綻讓讀者自己發現、以為自己很聰明？ | 讀者一步步推理出的嫌犯，正是作者遞給他的 |

謊說得越早，越不容易露破綻，揭曉時也更傷。讀者看過很多故事，太顯眼的嫌犯反而會被跳過，可以把這點也算進去。

吐：2–3 個誤導方案，各說用哪種形式、讀者會以為什麼、哪一段要改，以及揭曉時哪裡最難兜回來
