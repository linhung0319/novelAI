# 誤導佈局

適用：真相或結局想好了，但讀者大概猜得到；或只反轉一次怕被猜到，想騙讀者兩次
吃：已定的真相（沒有可以先給幾個候選），和目前讀者手上的線索
做：先定真相，再佈假象。挑最適合這個故事的形式，不必全用。

| 形式 | 問句 | 例 |
|---|---|---|
| 目光標的 | 誰最適合擋在真相前面，讓讀者一直盯著他？ | 用石內卜擋奎若；用野心外露的左冷禪擋滿口仁義的岳不群 |
| 角色立場 | 這個人的善惡，能不能先往反方向寫？ | 《哈利波特》多個角色的善惡都翻過一次 |
| 結局選項 | 能不能讓讀者忙著猜二選一，忘了還有別的選項？ | 《犀利人妻》雙帥競爭，結局是不明確選誰 |
| 劇情方向 | 能不能讓整段故事都朝反方向走？ | 《俠客行》一路塑造俠客島有去無回，最後發現是誤會 |
| 早說的謊 | 誰可以一出場就在說謊？ | 謊說得越早越不易露破綻，揭曉時也更傷 |
| 假馬腳 | 能不能露一個破綻讓讀者自己發現、以為自己很聰明？ | 讀者推理出的嫌犯，正是作者遞給他的 |

想騙兩次：想好三個答案再倒著排。真真相是最後要讓讀者知道的；假真相在中後段揭曉，讓讀者以為「果然被我猜中」，要給得夠滿足他才會放下戒心；表面答案是前段一路塑造的。我要甲當真兇，就讓乙當替死鬼，前段再把嫌疑引到丙身上。也可以始終是同一個人翻來翻去。下一次反轉要有前面的線索撐著，否則只顯得離奇。

吐：2–3 個方案，各說用哪種形式、讀者每一層會以為什麼、哪一段要改，以及揭曉時哪裡最難兜回來
