# 假象對帳

適用：有反轉或真相揭曉，怕讀者不服，或怕太早被猜到
吃：真相，和揭曉前讀者看到的事件
做：用這些問題檢查：

- 表面上發生的每一件事，放到真相底下，當事人為什麼這樣做？逐條答。例：石內卜為什麼為難哈利？為什麼又救他？比賽時對著哈利念咒，其實是在做什麼？
- 揭曉靠的人或事，讀者之前認真見過嗎？兇手是只出現過一次、講過兩句話的姑媽，讀者只會摔書。
- 讀者回頭看，找得到線索嗎？
- 誤導是不是太刻意？可疑的人是不是只有一個，又可疑得太用力？
- 讀者大概能猜對哪一半？可以讓他猜到幾種可能，但都不是答案；或猜到結果，卻猜錯原因。全中會無趣，全猜不到又可能不服。

吐：對不起來的地方和太顯眼的地方，每處給改法
