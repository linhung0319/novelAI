# 這段回憶該不該插

適用：想插回憶、支線或配角的事，怕打斷；或已經插了，讀起來卡
吃：要插的內容，插入點的前後
做：問：
- 不插，讀者看得懂接下來的事嗎？
- 進去之前，讀者知道它和主線有關嗎？
- 看完之後，讀者對接下來的事看法會變嗎？
- 這裡是讀者最想看下去的地方嗎？越想看越抗拒。要跳的話，它會影響那個結果嗎？
- 沒那麼要緊的話，能不能幾句帶過，講完就回來？
- 順序換一下呢？把後來的事移到開頭是懸疑，把早發生的事留到最後揭開是驚奇。

吐：2–3 種安排（整段插、縮成幾句、換位置、刪掉），各說代價
例：
- 幾句帶過：走在這條小巷，就想起小時候我故意把妳梳好的頭髮弄亂，妳氣呼呼追我追到巷尾。巷尾的那個轉角，我現在都還想躲進去。
- 《控制》：把失蹤日之後的事調到開頭，和多年前初相識的日記交錯。
