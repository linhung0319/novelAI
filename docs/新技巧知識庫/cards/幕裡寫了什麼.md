# 幕裡寫了什麼

適用：某一幕或某一段寫出來怪怪的，但說不出哪裡怪
吃：一幕正文，或作者選的段落
做：把內容分成五類，看哪類太多、哪類沒有：
- 時空：通常只為了描述背景或提示換場。有特色的地點才值得停。從內心切到外面的景，就順便換場了。
- 人和物：和劇情有關才細寫。其他只點重點，讓讀者自己補。
- 動作和對話：想像在拍特寫，焦點集中時寫得少，畫面反而強。
- 意識：是不是整幕都在想事情？是不是常用「他想」開頭？可以把念頭直接插進行文，從寫物轉到念頭，再轉到行為。
- 說明：和這幕有關嗎？故事本身撐得起這麼多說明嗎？

再查作者介入，例如「這時候的我，還不知道江湖即將掀起腥風血雨」。第一人稱敘事者不該預知未來，除非整本是回憶錄或倒敘的框架。第三人稱全知比較說得過去。

吐：這幕的五類比例，哪裡失衡，以及 2–3 處具體的改寫
例：念頭插進行文。

> 一陣陣香味從鐵鍋裏飄出。
> 是兔肉？還有些野菜？可能還放了魚？
> 哇！真香啊！
> 魏闐在旁練劍，聞得直流口水。
