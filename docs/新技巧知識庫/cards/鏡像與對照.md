# 鏡像與對照

適用：這個配角只是拿來襯托主角，沒對他造成壓力；或主角的選擇太輕鬆，沒人逼他面對
吃：主角的傷口和世界觀、現有角色
做：兩種角色的作用不同，先問這裡缺哪一種。
- 鏡像：他和主角有同一個傷口、缺陷或目標，但在某個選擇上分岔，讓主角看見自己可能變成什麼樣。問：他用什麼不同的方式解決同一個傷口？他怎麼逼主角面對？這會加重內心衝突。
- 對照：他和主角在同一個處境裡，卻跑另一套內在邏輯。問：他怎麼挑戰主角的倫理或策略？他暴露了主角推理的哪個破綻？這會讓外部的選擇變難。

只是個性相反不算，要問他讓主角的哪個決定變難了。兩種可以並存。

吐：2–3 個候選，優先用現有角色；各說是鏡像還是對照、分岔點或破綻在哪、會讓主角的哪個決定變難
例：佛地魔和哈利都是孤兒，都把霍格華茲當成家，分岔在選擇。
