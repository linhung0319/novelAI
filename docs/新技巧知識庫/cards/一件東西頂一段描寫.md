# 一件東西頂一段描寫

適用：場景或人物描寫很長卻沒感覺；或不知道這裡該描寫什麼
吃：作者選的一段，這裡發生什麼事
做：問：
- 這裡哪一兩樣東西，會讓角色的心態或行為改變？
- 這個人身邊的哪樣東西，透露了他的來歷或脾氣？
- 大小、格局、擺設省掉，會少什麼？
- 人也能代替景嗎？

有些書就是靠考究的描寫吃飯，要不要省由作者決定。

吐：2–3 組挑法，各說傳達了什麼沒明說的事，以及建議可省的部分
例：
- 「他手上拿著一支筆。」和「他手上拿著一支專屬訂製的白金尖鋼筆，全世界找不到第二支。」後者讓人開始猜他富有、講究、傲氣。
- 他潛入地下室，桌上放著三樣東西：一根皮鞭、一根蠟燭、一副手銬。心跳立刻加速。大小和擺設都沒寫。
- 「他說要請我喝杯咖啡，我們一起走進麥當勞，麥當勞的門口竟然放了一尊肯德基爺爺！」一句就讓人猜接下來會發生什麼。
- 他走進房間，左手邊是濃妝的老太婆，右手邊是更老的老太婆，正面是最老的那個，正對他舔嘴唇。房間長怎樣已經不重要了。
