# 一件東西頂一段描寫

適用：場景或人物描寫很長卻沒感覺；不知道這裡該描寫什麼；或這段很空，看不見也摸不著
吃：作者選的一段，誰的視角，這裡發生什麼事
做：問：
- 這裡哪一兩樣東西，會讓角色的心態或行為改變？這個人身邊的哪樣東西，透露了他的來歷或脾氣？
- 這個人會先注意到什麼？這由他的經歷決定。
- 這個細節想告訴讀者什麼沒明說的事？說不出來，可能就不用補。
- 這個氣味或聲音會勾起他什麼記憶？想起來之後，能繞回眼前的人或事嗎？
- 大小、格局、擺設省掉，會少什麼？人也能代替景嗎？

不用每種感官都有。有些書靠考究的描寫吃飯，要不要省看這本書。

吐：2–3 組挑法或可插入的候選句，各說傳達了什麼沒明說的事。不重寫整段
例：
- 他潛入地下室，桌上放著三樣東西：一根皮鞭、一根蠟燭、一副手銬。心跳立刻加速。大小和擺設都沒寫。
- 他走進房間，左手邊是濃妝的老太婆，右手邊是更老的老太婆，正面是最老的那個，正對他舔嘴唇。房間長怎樣已經不重要了。
- 他走過我身邊，我聞到一股淡淡的花香，像我奶奶院前種的小白花。他也跟奶奶一樣愛花嗎？從他身上的香，到奶奶，再投回他身上。
