# 角色怎麼登場

適用：這個角色第一次出場很平淡，像在填資料；或一出場就先倒身世
吃：角色、他後面的轉變、登場可用的場合
做：先問讀者第一眼該記住什麼，再挑登場方式：
- 本人出場前，先讓別人議論他。對反派特別好用。
- 用一個典型動作立起他。
- 在他的人生要變的那一刻登場。
- 用他自己的聲音開口，第一句就帶出弧線的核心。
- 一句話的身世，同時給同情和情節前提。
- 一個獨特的外貌或走路方式。

這場戲可以問：
- 他現在在做什麼、有什麼衝突？不要讓他站著被描述。
- 露出了哪一點脆弱、渴望或錯誤的信念？
- 讀者要懂這場需要什麼脈絡？只給這個，不給成長史。

吐：2–3 種登場，各說讀者的第一印象、露出了什麼線索
例：
- 《黑暗之心》：庫爾茲出場前，已被眾人說成既卓越又可怖。
- 《戴洛維夫人》：「戴洛維夫人說她要自己去買花。」
- 《白牙》：開場 Archie 正在自殺。
- 脈絡和背景的差別：讓讀者知道她不偷這批珠寶就會死，不用講她的成長史。
