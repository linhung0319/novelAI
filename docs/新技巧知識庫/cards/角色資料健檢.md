# 角色資料健檢

適用：角色資料寫了很多，人還是沒活過來；或不知道哪些資料該留
吃：角色資料
做：用這些問題檢查：
- 這幾樣有嗎？身分和目標、性格和中心思想、少數顯眼的外觀或行為特點、他在故事裡的作用、準備演給讀者看的經歷和言行。細節很多，這些卻空著，角色容易走偏。
- 他喜歡紅色：為什麼？什麼觀念影響了他？什麼事件造成這個觀念？
- 這筆資料會在哪場戲用到？讀者怎麼知道？
- 正文有沒有為了交代資料而停下來，像是照鏡子描寫外貌？

資料多不一定有害，作者想留就留。問題在於它不等於讀者看到的角色。

吐：可疑的資料，以及可以把它改成哪個行為或情節
例：一頭亮紅色的頭髮，比一整張五官表更容易被記住。
