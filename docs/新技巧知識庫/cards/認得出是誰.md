# 認得出是誰

適用：角色講話都一個樣；或配角一多，讀者記不住誰是誰
吃：一段多人對白，或角色名單和他們的背景
做：
先測：把名字塗掉，還認得出誰在說話嗎？POV 角色的聲音也會影響敘述，一起看。

再找差異，挑一兩項就好：
- 衝突時他怎麼反應？往前衝、往後退，還是找人靠？默默臉紅、憤怒推回、內心煮沸，還是立刻評判？這比背景資料更能推出他怎麼說話。
- 他打比方時會拿什麼？水手、廚師、賭徒拿的東西不一樣。
- 句子長短和節奏：拖成長句，還是斷成碎片？
- 中文可用的：自稱（我、在下、老子）、怎麼稱呼對方、語氣詞多少、文白程度、方言詞、職業術語。
- 不靠嘴巴：同一件事他做的固定小動作、每次出場帶著的同一個意象或物件。這些可以隨劇情增重或改變。

獨特和怪人是兩回事。口頭禪用過頭會變卡通，也不要只靠口氣分人，行動和想法也要不同。

吐：撞聲音的地方；2–3 種分法，各附同一句台詞的改寫
例：
- 同樣是生氣。黑道大哥：「幹，你找死啊！」書呆子：「不好意思，我先走了。」這已經是他的憤怒。
- 收到禮物。外向的人直接拆開分享；傲嬌的人嘴上說無聊，卻偷偷笑；社恐的人臉紅，手足無措。
