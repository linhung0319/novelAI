# 不照問的答

適用：對白一問一答，來來回回很死板
吃：作者選的一段對白，說話的人是什麼樣的人
做：找出最平的那句回話，試這幾條路。挑這個人本來就可能這樣講話的，不必全試。

| 路 | 問句 | 例 |
|---|---|---|
| 翻對方的話 | 能不能拿對方的話回敬他？ | 「你要是孝順就乖乖讀書。」「乖乖讀書不一定就是孝順啊。」 |
| 反話 | 能不能說一句雙方都知道不是真的話？ | 「你在這裡（坐牢）還習慣嗎？」「很好啊！世界上還有什麼地方比監獄好嘛！」 |
| 一語兩意 | 答案能不能同時指兩件事？ | 「妳下午的微積分考得怎樣？」「難過。」 |
| 反著接 | 能不能不接話頭，拿相反的東西放在旁邊？ | 「真想要有大一點的衣櫃。」「妳需要的是少買一點衣服。」 |

這些都是修辭，接連用會像在比機智。一段裡只要有一句接得妙，其他照常講話也可以。

吐：每句 2–3 個候選，標出走哪條路。也可以說這句照答就好
