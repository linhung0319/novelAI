# 起伏怎麼走

適用：挫折不夠痛；中段一路順或一路慘；讀者猜得到差不多要轉壞或好轉；故事好像少了什麼，讀起來一條直線
吃：主角的目標，和目前的大綱、幕綱或事件
做：先不看情節內容，逐段標他離目標更近還是更遠、心情在升還是在跌，看形狀：哪裡連續同一方向？指得出他願意進入主線、順轉逆、逆轉順這幾個事件嗎？

跌不夠痛時，走一遍：
1. 升：跌之前他得到了什麼？還能多給他什麼，讓他覺得勝券在握？順境裡有什麼是後面會反咬他的，例如輕敵、其實在演戲的朋友？
2. 反轉：哪個事件讓順境轉成逆境？賭注變大了什麼？
3. 跌：他失去的是讀者也怕失去的嗎？如果只對他特別重要，前面有鋪過為什麼嗎？
4. 反彈和重整：什麼事讓他回升？他只是重新振作，還是認了自己的錯？之後會用什麼不同的做法？

太好猜時，不換事件，先動起伏本身：多跌一次、在逆境中插一次小順境、從逆境開場、中間好轉最後仍壞，或把轉折提早和延後。動完查因果還接不接得上，沒有因果撐著的急轉會不知所云。

吐：目前的起伏走向，2–3 條調整後的序列，各說升到哪裡、用什麼事件跌、多了什麼驚喜、失去什麼
例：
- 只有跌：富少的財產一夜歸零。先升後跌：富少意外得到加倍的財產，轉眼被奪走，還背上鉅額負債。
- 《食神》：靠瀨尿牛丸重振聲勢，又變回囂張的自己（升）；學院找不到，雞姐中槍，自己身中劇毒被關進少林寺（跌）；回想種種錯誤，一夜白髮，帶著新廚藝回來決戰（重整）。
- 《大英雄天團》：申請上實驗室（揚）→哥哥死於火場（抑）→追查神秘人（揚）→神秘人竟是哥哥拚命救的教授（抑）→重新振作（揚）→杯麵犧牲（抑）→在殘骸手臂中找到晶片（揚）。
