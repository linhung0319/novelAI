# 講給讀者聽的對白

適用：對白像在向讀者交代資料，或把演過的事再講一遍
吃：作者選的一段對白，前面演過什麼
做：問：
- 對方本來就知道這件事嗎？「你師父叫岳不群，你師母叫寧中則」是說給令狐沖聽，還是說給讀者聽？
- 讀者剛看過的事，需要再講一次嗎？一句「他把剛才的事大略說了」夠不夠？
- 這個角色此刻會談這個嗎？他講的道理符合他的年紀和身分嗎？還是作者借他的嘴？
- 是不是照抄了現實說話的重複和囉嗦？如果這正是這個人的特色，可以留。
- 一個人講太長時，能不能讓人打斷、分段，或乾脆改成敘述、獨立一段？
- 讀者一定要知道的事，誰有私心要說？誰不想聽？

吐：可疑的句子，每處 2–3 個改法（帶過、改成有動機的問答、移到敘述、刪掉）
