# 這段戲誰最難做

適用：已經確定要寫某段劇情，但不知道該讓誰去做，也不知道他為什麼會做得很辛苦
吃：那段劇情，和現有角色名單（沒有也可以）
做：先問這段戲要克服什麼，再反過來找人：什麼樣的人做這件事最難？現有角色裡先看誰最不順手，不夠再開新的。可以從這幾個方向想：
- 這件事正好是他最怕的
- 這件事他一直想做到，卻一直做不到
- 這件事碰到他的舊傷，他過去遇到類似情況都躲開了

再追問這個難處從哪裡來、他之前怎麼躲它，追到能影響這段戲就夠了。

吐：2–3 個人選，每個用一兩句話說他是誰、這件事為什麼對他最難，以及選他之後那段戲會變成什麼樣。寫成話，不列恐懼、傷痕、弧線這些欄位
例：
- 要對全國發表開戰演說：最難的人是從小口吃的國王（《王者之聲》）。
- 最後要從高樓一躍而下才能救贖自己：最難的人是懼高的人（《香草天空》）。
