# 整段碎掉

適用：發生了很多事，每件都獨立，讀完不記得；或每章都等長等速，節奏一條直線
吃：連續幾章的正文或幕綱
做：用這些問題檢查：
- 有沒有一條沒解決的大目標、威脅或謎，橫拉過這幾章？它在正文裡一直施壓，還是只在章末被提一句？
- 每章是不是都把自己的目標當場贏掉、收乾淨？能不能只結一個小節拍，把大的留著？
- 篇幅有依張力分配嗎？高潮那幕有沒有比過場厚？過場能不能再薄？
- 高衝突之間有喘息嗎？喘息裡有沒有讓角色的特點長出來？
- 真正的高潮之後，有沒有停在一個畫面、情緒或角色特點上，讓它沉下去？還是馬上切到下一個鉤子？

單元劇或短章連載，本來就可能一章一事。是否要串起來由作者決定。
吐：這段目前橫拉的張力線（或沒有），以及 2–3 個改法
