# 三層行為反差

適用：角色表裡如一，太單調；或想讓他藏著什麼，最後才讓人驚呼
吃：角色真實的樣子，或作者想到的一個方向
做：看他在三種場合做什麼：不熟的人面前、親近的人面前、四下無人時。先定四下無人時真實的樣子，再往外設計落差。接著問：
- 是什麼造成落差？他這樣做有什麼目的？
- 哪些情節分別演出這幾層？
- 落差最後會消除，還是被揭穿？是什麼事造成的？
- 什麼時候讓誰知道？讀者先知道、主角不知道，讀者會替主角著急；兩人最後一起知道，會驚訝；主角知道、讀者不知道，會好奇。

戲份少的配角，演到親近那層通常就夠了。私密的一面不會否定其他層，對老婆溫柔和想殺人可以並存。

吐：2–3 個反差，各用他在每層做的一件事說明，並說落差什麼時候、怎麼揭開
例：
- 張先生在公司彬彬有禮，對老婆溫柔，私人書房裡卻全是虐殺的資料。
- 古道熱腸的人，對朋友外冷內熱，在社交場合非常冷漠。
- 卑鄙無恥的人，朋友都覺得他講義氣，外人都覺得他風度翩翩。
