# 結局沒力

適用：結局成立，但平淡、差一口氣；高潮無力，怎麼改結尾都不對
吃：已定的結局，全書的開頭和主要轉折，前文出現過的物品、動作、地點、對白
做：先往前找，再加力。結局沒力常常是前面沒鋪，只改結尾救不回來。

往前找：
- 落差：可能不是結尾拉得不夠高，而是開頭降得不夠低。中段情緒有沒有太早爬到頂？
- 他的缺憾、心願和敵人，前面露面了嗎？最後都有結果嗎？
- 翻盤的關鍵，是不是前面看似無意義的人、事或資訊？
- 第二次面對：他這次為什麼和第一次重挫時不同？

再挑一兩項加力：

| 加法 | 問句 | 例 |
|---|---|---|
| 小意外 | 有什麼小巧思能在最後掀開？ | 《鐵達尼號》老蘿絲把海洋之心丟入海中 |
| 揭露人物 | 誰的真面目可以相反？前文有跡象嗎？ | 岳不群的野心、石內卜並非敵人 |
| 情感 | 就算知道結局，還是會被什麼打動？ | 《大話西遊》至尊寶的真心話，紫霞永遠聽不到 |
| 不說出口 | 哪句話可以換成一個動作？ | 戰士赴死前豎起大拇指 |
| 首尾呼應 | 哪個出現過的東西可以收回來？ | 《無敵破壞王》同一句座右銘，第一次無奈，第二次肯定自己 |
| 未完的暗示 | 能不能再留一個小懸念？ | 《奪魂鋸》全片終了才暗示真兇另有其人 |
| 再選一次 | 能不能再給主角一次同樣的選擇？ | 《命運遙控器》回到最初，他把遙控器丟進垃圾桶 |

意外要在前文找得到理由。小龍女跳崖沒死，靠崖下深潭說得通；靠上帝神蹟就是作者出老千。

吐：問題出在哪個位置；2–3 個改法，各說改哪幾幕、結局多了什麼、前文要補埋什麼
