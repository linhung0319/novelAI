# 第三條路

適用：故事一路在 A 和 B 之間拉扯，結果怎麼選都猜得到；或高潮打完，後面只剩收尾
吃：讓讀者相信只有兩種結果的那場兩難或對決
做：先讓讀者徹底相信只有兩條路，再給第三種結果。掙扎得越久、劇情越強調，讀者越不會懷疑。可以問：

- 這個「非選一個不可」的前提，其實能不能是假的？
- 如果角色已經做了選擇、付了代價，才發現本來可以兩全，他和別人要怎麼面對？
- 這場對決分出勝負之前，能不能冒出讓雙方都輸的事，逼死對頭合作？

時機可以放在讀者最鬆懈的時候，例如高潮之後、結尾之前。第三條路也要說得通，前面最好留過一點因。

吐：2–3 個第三種結果，各說前提假在哪裡、誰要承受後果，以及前面要補什麼因
例：
- 媽媽和女友同時落海，他救了女友。半個月後，媽媽被路過的漁船送回家。他要怎麼跟媽媽一起生活？女友又要怎麼面對她？
- 主角和對手爭天下第一，戰況最激烈時，第三股勢力一舉擊潰雙方。兩人轉而聯手，勝負始終沒有分出來。
