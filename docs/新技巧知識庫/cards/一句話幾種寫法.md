# 一句話幾種寫法

適用：這句就是不對，想看看別的寫法
吃：作者選的一句或幾句，作者挑的範文片段（如果有）
做：往不同方向試。方向看這句要什麼，不預設越短越好，也不預設越雅越好：

| 方向 | 例 |
|---|---|
| 程度換一格 | 他的神情露出一抹悲傷／悲愴 |
| 俗和雅 | 他氣得快發狂／他目眦欲裂 |
| 白話和文白 | 夕陽即將沒入地平線，月亮也剛剛昇起／紅日將沉，新月初昇 |
| 換個說法 | 這房八尺見方，行不逾十步／這房間放一張床就差不多滿了，連多一張桌子也放不下 |
| 換順序或因果 | 我顛倒了整個世界，只為了撥正妳湖中的倒影／要不是湖中有妳的倒影，我也不必顛倒整個世界 |
| 比喻換來源 | 這個人的生活裡會拿什麼來比？能不能比感受，不比外形？或者不用比喻 |
| 聲音 | 我跑得飛快，她笑得歡快（押）／她笑得歡喜（避開重複） |

太生冷的字會讓讀者停下來查，這也算一種代價。

吐：3 個版本，各說差在哪裡，不排名
