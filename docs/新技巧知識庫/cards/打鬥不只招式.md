# 打鬥不只招式

適用：打鬥寫成招式清單；看得累，也不在乎誰贏
吃：作者選的打鬥段落，雙方各要什麼
做：問：
- 這場打，誰要什麼？輸了會失去什麼？打完兩人的關係或處境變了什麼？
- 讀者透過誰的身體和心思經歷這場打？
- 哪一瞬間值得停下來？其他招能不能帶過？
- 讀者知道這一招的規則嗎？知道了會更有份量嗎？放在動作中哪裡說？
- 有什麼是文字做得到、影像做不到的？
- 比較長的念頭，能不能放到打完之後？

詞彙要鋪張還是要白描，是這本書的風格，由作者決定。

吐：可疑處和 2–3 個改法，只動選定的段落
例：
- 「旌旗般飄舞的冠纓，如一抹真紅的閃電，穿過了黑暗的視野。」只抓一個瞬間。
- 「劍鋒劃過耳際，斷開幾絲髮線，在空中飛散，半黑半白。」寫得少，焦點集中。
