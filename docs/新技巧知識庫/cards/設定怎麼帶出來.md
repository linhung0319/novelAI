# 設定怎麼帶出來

適用：有一批設定要讓讀者知道，或設定突然蹦出來、像旁白在念說明書
吃：要揭露的設定，和相關的幕或章節
做：世界可以很深，但只讓這段故事需要的部分露出來。可以用這些方式：
- 由主角當下的動作需求，或有私心的對話逼出設定。
- 先給現象和體驗，之後才給定義和名詞。
- 陌生詞一次別丟太多，出場時順便讓讀者知道它有什麼用，不打斷動作。
- 硬設定放進有動機的問答或教學，用對話切碎，一次一小塊。
- 拋出的疑問要知道大概何時回收，別一直懸著，也別一次倒完。

吐：逐幕或逐章的揭露安排，並說明每項設定由什麼帶出來
例：
- 想看傷口，逼出幣制。
- 胖和尚炫耀時，漏出門派武功榜。
- 先演「幻象家人」，隔幾章才定義「污染源」。
- 反例：一上來就是某物品偉大的經歷，或引自《XX 大全》。
- 「九幽魔火！這神通位列三品，火焰能滅魂蝕骨。」名字、品階和效果一句話交代完。
