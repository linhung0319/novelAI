# 下一步從結果長

適用：上一幕寫完，不知道下一幕要做什麼；或幕和幕之間只有「然後」，沒有「所以」
吃：上一幕的情節和結果
做：
1. 先把結果弄具體：成功、失敗、有成有敗，或先不講、留到下一幕？這個結果會逼出什麼事？
2. 從結果往下推：他有什麼反應？現在有哪些選項，各自要付什麼代價？他決定怎麼做？反應可以短到一句話。
3. 他的決定就是下一幕的目標。如果接不上，就換結果或換下一幕。

吐：2–3 條「結果→決定→下一幕」，不替作者選
例：
- 哈利很開心地收到入學通知（然後呢？）。能去讀，下一幕收拾行李；不能去讀，下一幕他要爭取。
- 反例：收到通知→下午和表哥打棒球→玩起自己的鼻毛。事件之間沒有因果，讀者進不了故事。
