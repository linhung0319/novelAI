# 唸起來卡

適用：句子讀起來拗口、像翻譯，或換不了氣
吃：作者選的句子，這個人或這本書的語氣
做：問：
- 唸出來時，哪裡換不了氣？
- 主語是不是很晚才出現？一個名詞前面壓了幾層修飾？
- 句子的順序，和事情發生的順序一樣嗎？
- 「當……的時候」「由於……而……」拆開會比較順嗎？
- 同一個主語是不是每句都重掛一次？
- 抽象的話落到什麼東西上了？「一種難以言喻的恐懼席捲全身」，他實際上怎麼了？
- 這個詞是這個人、這個場合、這個年代會用的嗎？武俠裡的「房價」「信息」，字再古老，讀者下意識覺得現代就會出戲。

這張不是要把句子改短。長句、文言、公文腔都可能是角色或風格。拆太碎會換成另一種卡，併太長又會回到套句。

吐：可疑的句子，每句 2–3 個改法，由作者選
例：
- 「當他那雙由於武功遠高於孟奇而時機恰到好處地抬起的鐵掌，因為牽動了他左胸的傷勢而變得短暫無力的時候」和「可是，他的鐵掌剛剛抬起，就牽動了左胸的傷勢，鮮血流出加快，動作為之一滯」。
- 「一位有著一張馬臉的、留著長須的、頭頂巾幘的中年男子」和「他有著一張馬臉，留著五綹長須，頭頂巾幘」。
- 「阿成推開窗戶，阿成看著月亮，阿成決定去找她。」和「推開窗戶，阿成看著月亮，決定去找她。」
