# 缺一個反對的人

適用：這段衝突很弱，只剩主角在想事情；或擋路的人打發完就沒了
吃：主角在這段的具體目標、現有角色名單
做：
1. 問誰也想要這個東西。只想阻止主角的人，打發完就沒事了；和他爭同一件東西的人比較容易一直回來。目標太模糊就找不到人，先陪作者把目標說具體。
2. 表面目標不同時，往下問他們其實在爭什麼。
3. 分清兩種利害：一種是無法並存的直接對抗，一種是同一邊卻互相競爭、仍可能雙贏。兩種都有時，戲比較多。
4. 先盤現有角色：誰能升任、要補他什麼。盟友也算，他可以為了保護主角或為了自己的目標站到對面，這種背叛感或信任感，內心戲做不出來。補不上才開新角色。

作者說「他的對手是他自己」時，通常是在講弱點。可以問外面有沒有人利用這個弱點和他爭；如果這本書就是以內心戲為主，也可以不要。

吐：2–3 個候選，現有角色或新角色都標明，各說他爭什麼、要補什麼、代價是什麼（多一條線、拖慢哪裡）
例：
- 《唐人街》表面是抓兇手和逃脫，底下在爭大家最後相信哪個版本的現實。
- 《教父》麥可和巴齊尼爭的是家族能不能存續。
- 壞蛋要殺主角和配角，車只能載一人：壞蛋是直接對抗；主角和配角在搶位子，但還有雙贏的可能。
