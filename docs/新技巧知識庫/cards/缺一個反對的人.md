# 缺一個反對的人

適用：這段衝突很弱，只剩主角在想事情；擋路的人打發完就沒了；或對手是歧視、政府、天災、恐懼，沒有具體的對象可恨
吃：主角在這段的具體目標、現有角色名單
做：
1. 問誰也想要這個東西。只想阻止主角的人，打發完就沒事了；和他爭同一件東西的人比較容易一直回來。目標太模糊就找不到人，先陪作者把目標說具體。
2. 表面目標不同時，往下問他們其實在爭什麼。
3. 分清兩種利害：無法並存的直接對抗，和同一邊卻互相競爭、仍可能雙贏。
4. 先盤現有角色：誰能升任、要補他什麼。盟友也算，他可以為了保護主角或為了自己的目標站到對面。補不上才開新角色。
5. 對手是抽象的東西時：誰最能代表它，而且會親自找主角麻煩？他是相信它、靠它得利，還是被它逼瘋？

作者說「他的對手是他自己」時，通常是在講弱點。可以問外面有沒有人利用這個弱點；如果這本書就是以內心戲為主，也可以不要。

吐：2–3 個候選，現有角色或新角色都標明，各說他爭什麼、要補什麼、代價是什麼（多一條線、拖慢哪裡）
例：
- 《唐人街》表面是抓兇手和逃脫，底下在爭大家最後相信哪個版本的現實。
- 壞蛋要殺主角和配角，車只能載一人：壞蛋是直接對抗；主角和配角在搶位子，但還有雙贏的可能。
- 《迷霧》真正的反派是恐懼，具體化成一個宗教狂熱的婦人，直接迫害主角。
