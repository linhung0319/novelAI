# 臨摹混搭

適用：想不出這個人；或角色很老套，腦中只有「有點像某某」
吃：一兩個已經活在作者心中的角色。作者說不出來時，可以提幾個問他像不像
做：只借判斷邏輯，不借情節和設定。
- 臨摹：這個角色遇事怎麼想、怎麼做？把這套邏輯丟進新故事的事件裡。
- 混搭：挑兩三個角色融合。相近的混起來有小變化，反差大的混起來有新火花。

接著問：這個混血兒遇到故事裡的事會怎麼反應？哪裡要調比例，哪裡合不起來？

經歷的事件不同，讀者心中就是不同的人。要避開的是情節和設定大量雷同。

吐：2–3 個版本，各附他在這個故事裡的幾個反應
例：
- 韋小寶的無賴加上呂布的武藝；大雄的懦弱加上福爾摩斯的睿智。
- 把哈利波特善良、衝動、優柔寡斷的個性放進高中純愛故事，沒有問題。連父母雙亡、被親戚虐待、住在衣櫃、聰明的女配都搬過來，就是抄情節了。
