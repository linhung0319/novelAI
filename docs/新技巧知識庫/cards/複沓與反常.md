# 複沓與反常

適用：這段達成得太容易，沒感覺；或情緒高點推不上去
吃：作者選的高點，和前面相關的段落
做：問：
- 成功之前可以先失敗幾次？每次有什麼不同？
- 前面幾次讓讀者形成什麼印象，最後一次怎麼翻過來？三次是常見的形狀，不是規定。
- 再推一層：快要達成時，能不能插一個反常？本該成的時候，反而有人退開。原因之後再揭開。

吐：2–3 種排法。要動到選段以外時，列出要動哪裡，等作者決定
例：
- 《三隻小豬》：大野狼摧毀兩間房子，第三間才吃鱉。《狼來了》：說了兩次謊，第三次說真話沒人信。
- 男主角被女主角拒絕很多次。她終於也愛上他時，他反而拒絕了她（反常）。她開始討厭他，卻發現他瞞著絕症（揭開）。
