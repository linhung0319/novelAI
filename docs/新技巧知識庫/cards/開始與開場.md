# 開始與開場

適用：不知道第一章從哪裡寫、要不要寫楔子；或開頭在交代前史，一直進不了故事
吃：主角的處境、第一個重大變化、全書最吸引人的片段
做：這是兩個問題，分開想。

**故事從哪裡開始（對主角而言）：** 故事通常開始在變化發生前不久。平凡的過去簡短帶過。第一個變化前後有三個位置：

| 位置 | 得到 | 欠下 | 怎麼補 |
|---|---|---|---|
| 變化前 | 看得到目標，容易同情主角 | 力道晚來 | 盡快進入第一個衝突 |
| 變化中 | 懸念強，一開場就有張力 | 不知道他要什麼，衝突不夠重 | 快點補上處境和目標 |
| 變化後 | 先看到打擊和低落 | 結果已知，緊張少了；又還沒理由同情他 | 馬上再來一個新事件，邊走邊解釋前因 |

**小說開場放什麼（對讀者而言）：** 把最能引發好奇的片段放到前面。常見排法：
- 平凡→變化：題材夠吸引人，或讀者本來就願意等。
- 懸念→平凡→變化：先給怪事和線索，不說清楚，讓讀者開始猜。
- 高潮片段→平凡→變化→高潮全貌：前提不突出，或推理、懸疑類。
- 從低潮開場：一開始就讓主角的困境露臉，主線馬上聚焦。

**如果要放楔子：** 楔子要短、有懸念、扣主線。
- 高潮前：大戰一觸即發就切回開頭，敘述者也還不知道結局，整本書追上這一刻後一起經歷高潮。
- 高潮後：敘述者已知結局，但只提示。「當時的我還不知道，這竟是我一生最大的錯誤。」
- 前置事件：兩個老前輩打成平手，約定二十年後由徒弟分勝負。
- 片段資料：名言、書信、文件或註解，不做解釋。

吐：2–3 個開場方案，各說從哪開始、開場放什麼、贏了什麼、欠下什麼，以及之後怎麼補
例：
- 男主角會被甩，故事可以從還相愛時開始，從吵架中開始，也可以從分手後開始。第一種輕鬆自然，第二種緊張激烈，第三種消沉低迷。
- 《哈利波特》：奇裝異服的人上街慶祝、滿天貓頭鷹，佛地魔死了，有個男孩神秘倖存；不說清楚，讓讀者自己猜，之後才跳到十年後的哈利。
- 《笑傲江湖》不寫令狐沖從小在華山練劍；《哈利波特》不寫他在德思禮家的十年。
