# 反差要收

適用：角色表裡如一，太單調；有反差，但只是噱頭，演完就沒了；或想讓他藏著什麼，最後才讓人驚呼
吃：角色的第一印象和真實的樣子，或作者想到的一個方向
做：
- 看他在三種場合做什麼：不熟的人面前、親近的人面前、四下無人時。先定四下無人時的樣子，再往外設計落差。戲份少的配角，演到親近那層通常就夠了。
- 是什麼造成落差？他這樣做有什麼目的？
- 相反的那面什麼時候露出來？被什麼事逼出來？什麼時候讓誰知道？讀者先知道、主角不知道，讀者會著急；一起知道，會驚訝；主角知道、讀者不知道，會好奇。
- 兩面最後在哪一場戲變成同一件事？例如他因為那個相反的面，才做得到第一印象做不到的事。也可以停在撕裂。
- 不想大轉變時：他每天做的哪件小事，和他的身分最不搭？

吐：2–3 條「第一印象 → 露出 → 收束」，各用他做的一件事說明，並說靠哪一場戲
例：
- 張先生在公司彬彬有禮，對老婆溫柔，私人書房裡卻全是虐殺的資料。
- 殺人如麻的反派，每天回家都說「我回來了」。
- 《原神》的胡桃是殯儀館館主，性格卻活潑古靈精怪。
