# 反差要收

適用：角色有反差，但只是噱頭，演完就沒了
吃：角色的第一印象和那個相反的面
做：把反差當成會走到終點的東西。
1. 第一印象是什麼？
2. 相反的那面什麼時候露出來？被什麼事逼出來？
3. 兩面最後在哪一場戲變成同一件事？例如他因為那個相反的面，才做得到第一印象做不到的事。
4. 反差不夠意外時，問：拉得更開會怎樣？

也可以只靠一個生活細節，不用大轉變。問：他每天做的哪件小事，和他的身分最不搭？

不是每個角色都要和解，也可以停在撕裂，由作者決定。

吐：2–3 條「第一印象 → 露出 → 收束」，各說靠哪一場戲
例：
- 《原神》的胡桃是殯儀館館主，性格卻活潑古靈精怪；迪盧克外表高冷，內裡熱情。
- 殺人如麻的反派，每天回家都說「我回來了」。
