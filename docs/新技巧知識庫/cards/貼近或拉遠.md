# 貼近或拉遠

適用：和角色像隔了一層；或太黏了，想拉開一點
吃：作者選的一段，誰的視角
做：距離是用來調的，不是越近越好。

想貼近：
- 「他注意到」「他感覺到」拿掉會比較近嗎？注意到這件事本身就是重點時可以留。
- 客觀描述能不能落到他身上？「他蒼白乾裂的嘴唇」和「他的嘴唇乾裂得發疼」。
- 別人的動作，能不能先落到他的反應上？「賈羅德一屁股坐到他身邊，他嚇得一縮。」
- 敘述用的是他的詞嗎？前科犯和貴婦人的敘述不一樣。
- 一直叫他全名，改用「他」呢？

想拉遠：
- 只寫外面看得到的，不進他的腦袋，會怎樣？
- 這裡想讓讀者冷一點，還是想讓他像個陌生人？
- 能不能暫時離開當下，寫一點別的，回來時感受更重？

吐：同一段的近版和遠版，各說差在哪裡，由作者挑
