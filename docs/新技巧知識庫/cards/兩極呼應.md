# 兩極呼應

適用：主角的改變很大，但像突然變了個人，或變了也沒什麼意義；或對手只是用來打的
吃：主角開始和結束的狀態，可以再帶上最大的對手、情人或夥伴
做：
1. 定兩端，如極膽小到極勇敢、互相討厭到互相喜歡。
2. 他骨子裡是不是本來就渴望另一端？孤僻的人也想有知心朋友，消極的人其實也想振作。這樣走向另一端，同時也是走回本心。
3. 開頭放什麼小事，透露他的本心？
4. 也可以把另一端放進別的角色：他最缺的東西，對手身上有嗎？對方又能從他身上學到什麼？

吐：2–3 組設計，各說起始狀態、深處的渴望，以及開頭的小事或對映的角色
例：
- 殺手開頭小心救了一隻受傷的小鳥，下一幕才拿槍殺人。後來他和暗殺目標一起逃亡，其實是做回自己。
- 《火影忍者》鳴人和我愛羅都從小被排擠，一個交到越來越多朋友，一個越來越孤獨。決戰讓他們看見彼此的路。
- 《痞子英雄》痞子變得積極，英雄變得圓融。
