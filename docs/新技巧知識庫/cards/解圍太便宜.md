# 解圍太便宜

適用：主角靠能力解決問題，感覺很便宜；危機或結局靠外力、巧合解決；或就是需要一個外力解圍，又知道這樣不好
吃：這段解圍、前文、讀者到這裡已知的規則、主角在這場裡做了什麼
做：
靠主角自己的能力時：
- 讀者在這之前知道它怎麼運作、有什麼限制嗎？不懂規則就解圍，感覺會像天外救星。
- 這次有付代價嗎？這是為了救場才新加的規則嗎？能不能改用已有的規則解決？

靠外力或巧合時：
- 這個外力前面出現過嗎？硬要追究，說得通嗎？
- 它解決的是大事還是小事？大事由主角解決，小事靠別人，讀者比較不會覺得偷懶。
- 最後的關鍵一擊是主角打的嗎？
- 想要意外又不想要天降：意外能不能因為他的努力才有機會發生？

喜劇和諷刺可以故意這樣用。

吐：哪一條撐不住，以及 2–3 個改法（提早交代、讓它改解小事、付代價、砍掉）
例：
- 撐不住：偵探還找不出犯人，犯人自己自首了；決戰前對手突然心臟病發。
- 撐得住：《齊天大聖東西遊記》靠月光寶盒脫身，但寶盒前面已多次出場。令狐沖的性命隱憂由少林方丈解決，但江湖大事都是他自己力戰解決的。
