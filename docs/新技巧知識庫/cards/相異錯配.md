# 相異錯配

適用：角色、設定或點子太平凡、太老套，想讓它有戲；或背景太正常，主角待在裡面沒事發生
吃：一個角色、身分、概念或背景
做：給它一個錯誤的配對。挑最有戲的一兩型，不必全跑。

| 型 | 問句 | 例 |
|---|---|---|
| 錯配內在 | 如果他不做他的本分，會怎樣？做了本分必有慘事，又會怎樣？ | 不救人的醫生 |
| 錯配環境 | 把他放在哪裡最奇怪？時間、空間、組織、社會、身體都能錯開 | 警探裝成學生；內向宅男就讀女校；假太監住進皇宮 |
| 錯配行動 | 把他用來做什麼最奇怪？ | 少林弟子靠足球弘揚武功 |
| 錯配同類 | 把他們集中起來會發生什麼事？ | 頂尖殺手夏令營 |
| 錯配異類 | 讓他跟相反的人相處會怎樣？ | 警察的爸爸是黑道老大 |
| 換版本 | 改成「○○版」會有什麼情節？試試離原本調性最遠的那個 | 《賭神》的搞笑版是《賭聖》；武俠加現代國中生是《功夫》 |

也可以只抽換背景，看同一件事的意味怎麼變：表哥表妹的禁忌之戀放在現代才有張力。
吐：2–3 個錯配，各說用哪一型、會長出什麼戲、哪裡還說不通
