# 相異錯配

適用：角色、設定或點子太平凡，想讓它變得有戲
吃：一個角色、身分或概念
做：給它一個錯誤的配對。挑最有戲的一兩型，不必全跑。

| 型 | 問句 | 例 |
|---|---|---|
| 錯配內在 | 如果「○○○」不做他的本分，他會怎樣？ | 不救人的醫生 |
| 錯配環境 | 把「○○○」放在哪裡最奇怪？ | 警探裝成學生進校園查案 |
| 錯配行動 | 把「○○○」用來做什麼最奇怪？ | 少林弟子靠足球弘揚武功 |
| 錯配同類 | 把「○○○」集中起來會發生什麼事？ | 頂尖殺手夏令營 |
| 錯配異類 | 讓「○○○」跟相反的「ＸＸＸ」相處會發生什麼事？ | 警察的爸爸是黑道老大 |

錯配內在可以再推一層：他不做本分，是內在抗拒還是外在限制？如果「○○○」執行本分必會發生慘事「ＸＸＸ」，他會怎樣？

吐：2–3 個錯配，各說用哪一型、會長出什麼戲、哪裡還說不通
