# 立場四角

適用：主角的變化只有一步，從軟弱變勇敢就結束了；或變化太單調，沒有深度
吃：主角一開始的立場，和想走向的立場
做：讓他走過四個立場：原始→目標→過頭→修正。先拉出變化的兩端，再找過頭和修正。問：
- 目標立場再往前走，壞的效果是什麼？
- 第四個立場和第二個差在哪？第二個立場缺了什麼，或藏著什麼未爆彈？
- 每次轉換由什麼事件觸發？能不能各由一個角色推他一把？

不一定要走滿，三個立場也可以。這是檢查故事線會不會太單調的工具，已經寫完的故事也能拿來看。
吐：2–3 組四個立場，各附觸發事件和推他的人
例：
- 貪生怕死→勇敢正義→正義到走火入魔→在兩者間取得平衡。
- 《痞子英雄》的主角吊兒郎當，受熱血警察影響變積極；身世揭開、心上人死去，又被局長煽動，變得偏激；最後在女主角的支持下接受自己。
