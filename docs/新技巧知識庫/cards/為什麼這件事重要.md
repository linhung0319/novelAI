# 為什麼這件事重要

適用：事情一件接一件，主角打來打去，看的人不痛不癢
吃：一個事件，或主角正在追的目標
做：用這些問題找：
- 主角為什麼非做這件事不可？背後有什麼讀者還不知道的原因？
- 這個原因對得上多數讀者也碰過的處境嗎？「只有打鬥才能生存」很少人經歷過；「為了保護珍惜的東西，不想打也得打」很多人有過類似的時刻。
- 加上這個原因後，同一件事看起來有什麼不同？事件本身要不要改？

吐：2–3 個原因，各說它對上什麼處境、讓這件事多了什麼感受
例：一個男人在暴風雨中獨自爬山，最後被直升機救走，這只是紀錄。但他是為了十年前山難的女友，每年這天都上山獻一束她最愛的百合，同一件事就成了故事。
