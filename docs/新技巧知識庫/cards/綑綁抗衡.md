# 綑綁抗衡

適用：衝突不痛不癢，雙方隨時能走開；或只是好與壞、愛與不愛的二選一
吃：現有的衝突和相關角色或勢力
做：
1. 綑綁：把製造衝突的人綁在一起，讓他們無法抽身。問：他們為什麼不能一走了之？綁的東西可以是環境（同一間牢房）、組織（公司）、活動（五天四夜旅行）、形式（假結婚）、心靈（相愛）或血緣（家庭）。雙方各有走不開的理由，或同時有幾條綑綁互相牴觸更好。
2. 抗衡：別停在兩方對立，多加一個角。兩個觀念之外，再加「兩者都要」「兩者都錯」或「其中一方走過頭」，讓不同角色代表不同觀念。

吐：2–3 個改法，各說綁住誰、用什麼綁，以及多出來的那一角是誰
例：
- 學生之間的戀愛可以分手；同住一個屋簷下的兄妹，不管愛不愛都走不開。
- 室友天天吵架，一方搬走就沒戲了。如果她是房東的姪女，有義務住在這裡管理；他預繳了一年房租，也沒錢再搬，兩人只能吵滿一年。
- 令狐沖對邪派朋友的義、對師門的忠、對任盈盈的情，三者都鎖著他，又彼此牴觸。
- 「維護正義」和「追求金錢」，可以再加「追求金錢但維護正義」或「正義和金錢都是虛無的」。
