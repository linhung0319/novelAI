# 先升後跌

適用：主角的挫折不夠痛；或中段一路順、一路慘，沒有起落
吃：主角的目標，和目前的中段事件
做：
1. 升：跌之前他得到了什麼？還能多給他什麼，讓他覺得勝券在握？順境裡有什麼是後面會反咬他的，例如輕敵、故態復萌、其實在演戲的朋友？
2. 反轉：哪個事件讓順境轉成逆境？這之後賭注變大了什麼？
3. 跌：他失去的東西，是讀者也怕失去的嗎，例如家人、朋友、感情、安穩的生活、身體、性命？如果只對他特別重要，前面有鋪過為什麼嗎？
4. 反彈：什麼事讓他觸底回升？可以是內心的迷霧散了，也可以是外面出現一線曙光。
5. 重整：他只是重新振作，還是檢討了順境時的得意和逆境時的低落，認了自己的錯？之後他會用什麼和以前不同的做法？

升跌次數和順序都可以改，悲劇的反彈也可以只是一點感悟。
吐：2–3 條升跌設計，各說升到哪裡、用什麼事件跌、跌掉什麼，以及他重整後會變成怎樣
例：
- 只有跌：富少的財產一夜歸零。先升後跌：富少意外得到加倍的財產，轉眼被奪走，還背上鉅額負債。
- 《食神》：靠瀨尿牛丸重振聲勢，又變回囂張的自己（升）；學院找不到，雞姐中槍，自己身中劇毒被關進少林寺（跌）；回想種種錯誤，一夜白髮，帶著新廚藝回來決戰（重整）。
- 被欺負的學生終於交到朋友，生活一帆風順，原來朋友都是在演戲，他的蠢樣被傳上網路；低潮時他才發現，自己根本不懂怎麼交朋友。
