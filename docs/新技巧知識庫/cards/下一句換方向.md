# 下一句換方向

適用：對話寫到這裡接不下去，或下一句太好猜
吃：作者選的一段對白，停在卡住的那句
做：同一句起手，下一句可以把這場戲帶去不同的地方。每個候選走不同的方向，不要都走最順的那條：
- 讓這個人變得更清楚
- 冒出一個摩擦
- 劇情轉彎
- 漏出一個訊息
- 改變整場的調性
- 碰到這個故事在談的事

吐：3 個下一句，各說走哪個方向、之後會鎖死什麼。作者選了才往下接
例：「老大，這小女孩怎麼處置？」
- 「留她自生自滅。」（人物）
- 「還用問，砍了。」「老大，高抬貴手吧……其實我一眼就認出來了，她是我失散多年的女兒。」（轉彎）
- 「慢著！她手上有印記，她是那個幫派的人。」（訊息）
- 「掃描她的 DNA，由轉化儀培育一個分身。」（調性，這下是科幻）
- 「我當年也是個可憐的小男孩，多虧有強盜救了我。」（主題）
