# 該演還是帶過

適用：這段寫得很長卻無聊；重要的事一句話就過去了；這段過程寫出來反而普通；或想讓角色顯得很強，一寫細節就破功
吃：作者選的一段，它和主線的關係
做：問：
- 拿掉這段，讀者會少什麼？可以先考慮刪，刪不掉才帶過。
- 讀者想看角色經歷這件事，還是知道結果就夠了？
- 角色在這裡要做選擇，或情緒很複雜嗎？這是讀者第一次接觸的重要資訊嗎？
- 讀者想像的版本，會不會比寫出來的更厲害？能不能只留起因和結果，開頭先立期待，再用一個具體的東西證明結果？這比較適合立形象或處理次要事件，讀者一路等著看的那場通常還是要演。

帶過只是交代事情，不用解釋意義。

吐：同一段的演出版和帶過版（或跳法）各一小段，各說換來和失去什麼；可以刪的話也說
例：
- 帶過：「他在過去的一場雪崩中失去了她，至今走不出來。」
- 演出：雪崩來時她拉著他的手臂，他在她耳邊大吼「我愛——」，雪浪淹過來。最後那個字折磨了唯一的倖存者很多年。
- 帶過過場：「談好價錢，招了部車，一直到兩人洗好澡都沒有說話。」
- 跳過：關羽溫酒斬華雄。酒先放著，他提刀出帳；一陣喊殺聲後提著人頭回來，酒還是溫的。
