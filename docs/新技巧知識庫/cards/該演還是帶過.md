# 該演還是帶過

適用：這段寫得很長卻無聊；或重要的事一句話就過去了，拿不定主意
吃：作者選的一段，它和主線的關係
做：問：
- 拿掉這段，讀者會少什麼？不重要的事可以先考慮刪掉，刪不掉才帶過。
- 讀者想看角色經歷這件事，還是知道結果就夠了？
- 角色在這裡要做選擇，或情緒很複雜嗎？這是讀者第一次接觸的重要資訊嗎？
- 這段是過場、背景，還是支線的收尾？

帶過只是交代事情，不用解釋意義。

吐：同一段的演出版和帶過版各一小段，各說換來和失去什麼；可以刪的話也說。由作者選
例：
- 帶過：「他在過去的一場雪崩中失去了她，至今走不出來。」
- 演出：雪崩來時她拉著他的手臂，他在她耳邊大吼「我愛——」，雪浪淹過來。最後那個字折磨了唯一的倖存者很多年。
- 介紹人物也一樣。帶過：「他是籃球校隊隊長，最怕輸給湘北。」演出：他在場邊大吼「再這麼懶散，今年又要輸給湘北了」，矮個子隊員喘著回嘴「我們又不像你長得那麼高」，一邊偷瞄角落那群盯著他的女生。
- 帶過過場：「談好價錢，招了部車，一直到兩人洗好澡都沒有說話。」
- 帶過支線：「他問起她的近況，她大概說了家裡的債和病。聊了兩個小時，他從皮夾給了她一筆錢，送她回家。」
