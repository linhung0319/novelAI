# 憋與爽的節拍

適用：連載憋太久怕讀者走，或一路順爽沒有張力；每章都平，沒有想點下一章的理由
吃：最近幾章的事件
做：
- 標出每章是憋（危機、受氣）還是爽（解消、痛快）。憋多久了？解消過了嗎？
- 解消不要全部結清。這次的解消，能不能變成更大事件的入口？
- 每章自成一個小起伏嗎？章尾有讓人想點下一章的東西嗎？
- 開頭和常態段懸的東西不同嗎？開頭常懸主角的命運，事件密；進入常態後常懸這一場誰會死、這次怎麼打臉，章末鉤可以輕一點，黏性交給一條貫穿的大謎。搞錯的話，開篇會慢熱到不知發生什麼，常態段會章章硬拗高潮而疲乏。

吐：目前的憋爽走向，以及 2–3 個調整方案，例如哪裡提早解消一次、解消怎麼開新事件
限界：單本出版或文學向，章節可以自然收束，不必每章切斷。
