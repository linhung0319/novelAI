# 這段戲留不留

適用：讀起來拖、很平，說不上哪裡不對；有些戲可有可無；事件接不起來；或很喜歡一段，不確定該不該留
吃：一幕，或照順序列出的事件。前後各一兩幕
做：挑相關的問：
- 幕頭和幕尾，角色的情緒或處境變了嗎？一樣的話通常就是沒事發生。
- 這幕有誰想要什麼、被什麼擋著？如果對手只回一句「好，你去吧」，這幕會怎樣？
- 它對後面有什麼影響？影響很小，前因也可以不要。和主線有關，不代表一定要留。
- 為什麼發生、經過怎樣、結果如何，缺了哪一段？

很喜歡但接不上主線時，可以改它、改主線或先移到備用區。
吐：可刪、可併、要補、可調位的清單，各附理由和 2–3 個改法
例：一個講復仇和愛情的故事。比爾蓋茲給了一百萬，復仇才成，要留。大雄給了二十塊，後面毫無影響，雖然也幫了復仇，仍可刪。
