# 反高潮

適用：不想照常見的方式收尾；或結尾讓人失望，分不清是手法還是爛尾
吃：故事走到的高潮位置、讀者此刻的期待、作者想留下的意味
做：
1. 找出讀者此刻最期待的收尾。
2. 讓這個期待落空。結果好壞都可以，重點是不走常見的方向。
3. 用這些問題檢查：乍看突然，回頭推敲說得通嗎？落空之後，讀者會想什麼？答不出來，這就只是爛尾。

限界：讀者一定會有失望的部分。類型讀者就是為那場高潮來的時候，代價更大。值不值得由作者決定。
吐：2–3 種落空方式，各說落空的是哪個期待、前文憑什麼撐住、想留下什麼意味
例：
- 《少年Pi》靠岸後，老虎默默走了，沒有回頭。
- 《全面啟動》陀螺搖搖欲墜，畫面一黑，兩種期待都落空。
- 《傾城之戀》圓中有缺，說不上圓滿，也說不上不圓滿。
- 反例：壞人突然不想毀滅地球，撤退了，主角也不追，故事結束。說不出意思就是爛尾。
