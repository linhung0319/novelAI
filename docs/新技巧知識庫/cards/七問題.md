# 七問題

適用：寫中短篇或一個段落，有主角和目標，但不知道怎麼走完；或這條線沒有亮點
吃：主角和目標
做：一次問一題，作者選了再往下：
1. 他的目標是什麼？
2. 他的阻礙是什麼？
3. 他如何努力？
4. 結果如何？通常不好。
5. 努力無效之後，有什麼意外能改變這一切？
6. 意外之後，他的目標起了什麼變化？他怎麼逆轉？
7. 最後的結局是什麼？

重點在第 5、6 題。意外最好是因為他的努力才有機會發生，天外飛來的意外會讓前面的努力失去意義。

吐：目前這一題的 2–3 個答案；到第 5 題時，各說這個意外和前面哪個努力有關
例：《武狀元蘇乞兒》
- 目標：考上武狀元，娶如霜。
- 阻礙：被趙無極揭穿不識字，淪為乞丐，又被打斷經脈。
- 努力：練回武功，當上丐幫幫主，趕去阻止趙無極害皇上。
- 結果：只學會十七掌，決戰時功虧一簣。
- 意外：秘笈從懷中掉出，被狂風快速翻頁，頁上的圖連起來，現出第十八掌。
- 轉彎：頓悟第十八掌，逆轉打敗趙無極。
- 結局：抱得美人歸，當個逍遙乞丐。
