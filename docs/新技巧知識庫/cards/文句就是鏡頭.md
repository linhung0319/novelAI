# 文句就是鏡頭

適用：畫面跳來跳去看不清；或想知道這段讀起來是什麼畫面
吃：作者選的一段
做：逐句拆成鏡頭：看到什麼、離多遠、停多久。問：
- 順序是視線會走的順序嗎？
- 遠近切換是故意的嗎？
- 這裡想讓讀者盯多久？盯太久的地方值得嗎？
- 一句帶過的地方，讀者來得及看到嗎？

句子長短沒有固定配法，動作不一定要短，感情戲也不一定要長。

吐：這段的鏡頭序列，和 2–3 種重排或調整停留的方式
例：
- 「在我的後園，可以看見牆外有兩株樹，一株是棗樹，還有一株也是棗樹。」（魯迅〈秋夜〉）寫成「兩株棗樹」，就少了視線移過去的感覺。
- 「他的手指有些粗糙，拳頭指節隆起，小臂上有著一條長疤。」手指、指節、小臂，鏡頭由下往上。
- 「他的食指尖，沾上了血漬。」一秒就過去。「他細細的食指尖上，宛若迷宮的指紋，漩渦般開展，那本來是身分的象徵，現在卻被血漬所覆蓋。」同一件事，鏡頭停在指尖上。
