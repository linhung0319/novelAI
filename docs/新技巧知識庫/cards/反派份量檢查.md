# 反派份量檢查

適用：反派像紙老虎；或最後主角贏得很便宜
吃：反派出場的戲，和最後的對決
做：用這些問題檢查：
- 有沒有一場戲，讓人記得他很強、很壞？
- 他和主角勢均力敵嗎？太強無聊，太弱更無聊。
- 他是衝著主角來的嗎？
- 他贏過嗎？給過主角真正的傷害嗎？
- 最後關頭他有沒有為了主角變笨？例如擁有足以毀滅地球的科技，最後卻用武士刀混戰；或在致命一擊前，先把全盤計畫和弱點講一遍。
- 有沒有人犯規？例如主角最後忽然學會氣功輕鬆獲勝，或虛胖的富商搖身一變成了拳法高手。
- 交手之後他變了嗎？這不是必要的，但會多一層。《火影忍者》的對手戰敗後常被主角的理念感染。

吐：最弱的 1–2 處和改法
