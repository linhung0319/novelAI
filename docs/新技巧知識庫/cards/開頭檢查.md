# 開頭檢查

適用：開頭寫好了，想知道抓不抓得住人；或覺得前幾章很慢
吃：開頭幾章或開頭的幕綱
做：用這些問題檢查。不必每項都中，靠其中幾項抓住讀者就夠了。
- 有事正在發生嗎？有什麼讓人想問為什麼？
- 主角當下的問題是什麼？過去的來由能不能往後放？
- 看得出類型和調性嗎？第一段就在告訴讀者這是什麼書。
- 主角或重要角色出場了嗎？有一件小事讓人記住他嗎？是不是一次上太多人？有些人可以晚點來。
- 讀者知道他要什麼嗎？不知道目標，就無法判斷事件對他的意義。
- 有沒有一件讓人想等到的大事？例如前女友兩個月後嫁人、炸彈三天後爆炸。
- 這本書最吸引人的東西露面或預告了嗎？
- 第一個危機真的威脅到他嗎？還是在為鋪陳讓路？
- 設定是在事件和對話裡帶出來，還是整段倒出來？
- 平凡生活是不是太長，久到察覺不到變化？
- 前幾幕的結尾，有東西把人拉到下一幕嗎？

吐：最弱的 1–2 項，以及 2–3 個改法
