# 群像戲份表

適用：群像寫了一段，有人消失很久、配角搶戲寫不下去，或幾個人同一場都在轉折
吃：章節或場次、角色名單。沒有現成的表就先幫作者列
做：畫一張表，列是章節，行是角色。戲份不用平均，但要是刻意的。用這些問題看表：
- 誰消失了多久？是刻意的嗎？
- 有主角的作品：配角戲份是否蓋過讀者最跟的人？主角有參與配角的故事嗎？配角寫太多常會讓主線塞住。
- 各角色的轉折排在一起，有沒有撞在同一場？是刻意的大事件，還是互相搶？
- 大場面同時有幾個人在行動，讀者盯得住嗎？誰可以退到背景？
- 大事件有沒有兌現前面累積的感情？
- 有沒有人憑空冒出來？視角切換有沒有把劇情切斷？

吐：戲份表、可疑處和改法
