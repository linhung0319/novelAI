# 旁帶

適用：「她美得驚人」「他是鎮上最有錢的人」，直說沒感覺，讀者也不信；或想讓人覺得他很強，但沒有東西可以比
吃：想讓讀者相信的一件事，這個場面有誰在
做：不自己說，讓別人的反應或議論來說。問：
- 誰看到會有反應？不同的人反應哪裡不同？
- 誰會因此有得有失？
- 眾人的說法能不能互相矛盾、越傳越離譜？
- 他出手之前，誰先拚了半天？那些人本身夠強嗎？他比他們高出多少？
- 同一件事，別人怎麼反應，他怎麼反應？

吐：2–3 個場面，各說透過誰來帶
例：
- 轉學生走進教室。男生全靜下來；女生有的轉開頭，有的一臉不是滋味，也有的看呆了；老師看到她，課本摔了一地。
- 派對上人人都在講他：鎮上每棟別墅都是他的；他的司機碰傷我的車，第二天全新的保時捷就停在我家門口；他祖上替政府管黃金；他會點石成金；他是外星人。沒人能證明，只確定他的財產多到神祕。
- 《天龍八部》：慕容復的家臣跟丐幫長老打了老半天，蕭峰露一手擒龍功，全場自嘆不如。
- 可以連著用：先讓旁人說他有錢，再讓人跟他比，連勝三個。這比他直接掏出一顆雞蛋大的鑽石可信。
