# 中段空洞

適用：開頭和結局都有了，中間不知道要演什麼，或演得像在拖
吃：故事的前提（讀者是衝著什麼來的）、主線目標、已有的中段事件
做：從這些方向找：
- 兌現前提：這個設定最好玩的是什麼？讀者拿起這本書最想看到什麼？那些場面演了嗎？
- 小目的地：把大目標切成幾個看得到的中途站，每段只游到下一個島。
- 嘗試和失敗：他試了之後，能不能「成功了，但是…」或「失敗了，而且…」？下一次的嘗試從這裡長出來。
- 解決的同時開門：這次問題解決了，能不能順勢打開一個更大的事件？
- 帶來反方觀念的人：主線上出現一個他過去沒接觸過的人，他的想法和主角相反。這條支線之後能不能幫上主線？
- 敵人進逼：對手這段時間在做什麼？敵人也可以是制度、天候、命運或主角的極限。

每個候選都問：它和主線有什麼關係？少了它後面會變嗎？
吐：2–3 組中段事件，各說走哪個方向、接在現有哪件事後面，以及它帶來什麼後果
例：《鐵達尼號》男女主角熱戀、《少林足球》比賽連勝，都是在兌現讀者衝著來的東西，也墊高了之後的跌落。
