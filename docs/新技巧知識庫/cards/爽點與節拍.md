# 爽點與節拍

適用：翻盤或打臉的場面讀起來不爽；連載憋太久怕讀者走；或一路順爽沒有張力，沒有想點下一章的理由
吃：這段爽點和前面的壓迫，或最近幾章的事件
做：
單一場面看三步：
1. 提出問題：敵人或困境夠強嗎？讀者感到壓迫了嗎？
2. 解決問題：主角靠什麼翻盤？這個東西前面藏過或暗示過嗎？
3. 結算獎勵：敵我雙方有什麼反應？誰被震撼、誰後悔？主角實際得到什麼？很多爽點就是少了這一步。

連續幾章看節拍：
- 標出每章是憋還是爽。憋多久了？這次的解消，能不能變成更大事件的入口？
- 每章自成一個小起伏嗎？章尾有想點下一章的東西嗎？
- 開頭和常態段懸的東西不同嗎？開頭常懸主角的命運，事件密；常態段常懸這一場誰會死、這次怎麼打臉，章末鉤可以輕一點，黏性交給一條貫穿的大謎。

吐：哪一步最弱，或目前的憋爽走向；2–3 個調整，例如哪裡提早解消一次、解消怎麼開新事件
限界：這是連載爽文的工具，用多了會同質。單本出版或文學向，章節可以自然收束，結算可以很輕。
