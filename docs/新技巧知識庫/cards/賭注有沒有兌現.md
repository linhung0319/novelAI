# 賭注有沒有兌現

適用：有人掌握了主角的秘密或放了狠話，下一幕就沒下文；或劍拔弩張的對峙莫名和平收場
吃：一段幕綱或正文
做：列出升起的重大威脅、秘密曝光、底線被踩、關係快破裂的地方，逐條往後找：
- 當場了結了嗎？例如滅口、收買、反制、揭穿、說服。
- 變成持續的威脅了嗎？他一直記掛，對方步步進逼，後面的戲都在這片陰影下。
- 主角按兵不動的話，有給理由嗎？例如能力不足、投鼠忌器或另有盤算。

再問這個處理合不合理：
- 他此刻知道什麼？已知秘密外洩就完蛋，卻毫不在意嗎？
- 他要什麼、怕失去什麼？
- 他能做到什麼？對方又為什麼退縮？

別為了省事把衝突降溫，或讓反派講理、主角大度。類型裡的黑暗選擇可以照寫；要克制就寫出克制的理由。

吐：哪個賭注沒有下文，以及 2–3 個處理方式，由作者選
