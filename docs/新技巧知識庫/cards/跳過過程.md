# 跳過過程

適用：這段過程寫出來反而普通；或想讓角色顯得很強，一寫細節就破功
吃：這段的起因和結果
做：只留起因和結果，中間交給讀者想像。問：

- 讀者想像的版本，會不會比我寫出來的更厲害？
- 開頭能不能先立期待，例如所有人都說不可能？
- 結果能不能用一個具體的東西來證明？

重要的戲通常還是要演，尤其是讀者一路等著看的那一場。這招比較適合用來立角色形象，或處理次要事件。

吐：2–3 個跳法，各說從哪裡切、從哪裡接，以及讀者看不到什麼
例：
- 關羽溫酒斬華雄。酒先放著，他提刀出帳；一陣喊殺聲後提著人頭回來，酒還是溫的。
- 兩人爭論某人有多難抓，第三人一直說沒那麼難，然後拍拍手，那人已被綁著推進來。
