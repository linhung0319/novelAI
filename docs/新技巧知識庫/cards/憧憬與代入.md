# 憧憬與代入

適用：主角太強太完美，讀者有距離；或主角太普通，沒人想變成他
吃：主角的設定和他目前最亮眼的戲
做：魅力常有兩個來源，而且會互相抵銷。憧憬是讀者想變成他，來自能力、性格或立場；代入是讀者能把自己疊上去。憧憬拉太高，讀者可能覺得他跟自己是兩種人。先問作者這本書要偏哪邊，再調：
- 日常的帥：不用華麗，他在困境中下定決心去面對。這可以同時有憧憬和代入。
- 給強者弱點：他在哪件事上和普通人一樣笨拙？
- 配一個和讀者同位置的角色：讓代入有地方落腳，主角就可以繼續往上拉。

吐：目前偏哪邊；2–3 個調法，各說會多出什麼、少掉什麼
例：福爾摩斯本人不好代入，有華生站在讀者的位置。
限界：這是傾向，不是定律。爽文可以把憧憬拉得很高，只要作者要的就是那種樂趣。
