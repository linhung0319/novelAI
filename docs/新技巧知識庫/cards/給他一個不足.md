# 給他一個不足

適用：主角太完美；不知道故事要折騰他什麼；或確定要寫某段戲，不知道該讓誰做、他為什麼難
吃：角色和他的目標，或那段戲和現有角色名單
做：找他缺什麼，再看這個缺口會推出什麼故事。

| 方向 | 問句 | 例 |
|---|---|---|
| 恐懼 | 他最怕什麼？故事能不能逼他面對？ | 《大白鯊》的警長怕水，卻得下海獵鯊 |
| 求而不得 | 他一直要不到什麼？ | 《大亨小傳》蓋茲比千方百計，只換來心碎 |
| 外在阻礙 | 誰或什麼擋住他？ | 《刺激1995》的監獄 |
| 舊傷 | 什麼過去讓他遇到類似情況就退縮？ | 《全面啟動》走不出害死妻子的陰影 |

接著問：難關能不能正好設在他最弱的地方？能不能同時有兩三種不足，讓外在和內在互相牽制？拉得越遠越有張力，但也越要想清楚他怎麼可能做到。

也可以倒過來：戲已經定了，先問它要克服什麼，什麼樣的人做這件事最難？先看現有角色裡誰最不順手。要對全國發表開戰演說：最難的人是從小口吃的國王（《王者之聲》）。

吐：2–3 個不足或人選，用一兩句話說，不列恐懼、傷痕、弧線這些欄位；各說會推出什麼主線，或那段戲會變成什麼樣
