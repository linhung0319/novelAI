# 給他一個不足

適用：主角太完美，沒有成長空間；或有了角色，不知道故事要折騰他什麼
吃：角色，和他的目標（如果有）
做：找他缺什麼，再看這個缺口會推出什麼故事。

| 方向 | 問句 | 例 |
|---|---|---|
| 恐懼 | 他最怕什麼？故事能不能逼他面對？ | 《王者之聲》口吃的國王要公開演說 |
| 求而不得 | 他一直要不到什麼？ | 《大亨小傳》蓋茲比千方百計，只換來心碎 |
| 外在阻礙 | 誰或什麼擋住他？可以是人、自然或社會 | 《刺激1995》的監獄 |
| 舊傷 | 什麼過去讓他遇到類似情況就退縮？ | 《全面啟動》走不出害死妻子的陰影 |

接著問：他最弱的地方在哪裡，難關能不能正好設在那裡？（《破壞之王》手無縛雞之力的何金銀要打斷水流。）能不能同時有兩三種不足，讓外在和內在互相牽制？

也可以讓目標直接撞上他本身的條件：這個目標最需要什麼？他身上最缺什麼？條件可以來自先天或後天的身心，也可以來自環境：不敢與人交談的少年要公開演講；曾誤傷人而不敢拿槍的警探接下大案；從小混幫派的少年想重新做人。拉得越遠越有張力，但也越要想清楚他怎麼可能做到。

吐：2–3 個不足，各說會推出什麼主線，以及他成功或失敗時各是什麼樣子
例：《大白鯊》的警長怕水，卻得下海獵鯊。
