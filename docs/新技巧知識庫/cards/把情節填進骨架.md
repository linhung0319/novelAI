# 把情節填進骨架

適用：想到一堆情節，排不成一個故事；或不知道這本書該用哪種結構
吃：摘要或情節清單，加上大約的長度
做：
1. 挑一副骨架。段數要配長度：短篇段太多，每個事件都沒地方演；長篇段太少，容易平淡鬆散。

| 骨架 | 用在 | 要注意 |
|---|---|---|
| 觸發→衝突→解決 | 短篇，或先把主線拉出來 | 中段只有一團「衝突」，要再分 |
| 觸發→順境→逆境→解決 | 多數長篇的起點 | 順序和次數都能改 |
| 低迷→高昂→低潮→愉悅 | 只有模糊構想，不想管那麼多段。直接想主角的心情怎麼走 | 從低迷開場，主線聚焦得快 |
| 期待→幻想→受挫→噩夢→結局 | 爽文，要更大的落差 | 同質性高 |
| 靜→動→疾走，一路加速 | 戰鬥、運動類 | 難減速 |
| 九段、十五段 | 骨架已經有了，想檢查細部 | 段多容易變成在填空 |

全書用一副、章內用另一副也行。

2. 把作者已有的情節逐條放進去，用這本書的人名和事件，不要只寫階段名。
3. 空著的段，問：這一段在這本書裡會演什麼？每個空段給 2–3 個候選。作者也可以決定它就是空的。
4. 放不進任何一段的情節先移到備用區，不要刪。
5. 同一段擠了太多事件，或整本事件太少，都要提出來。事件不夠時，光靠擴寫細節只會虛胖。

大約位置只作參考：打破現況的事件常落在全書前面約十分之一；進入主線常在前四分之一內，再早一點會更緊湊；順境轉逆境約在中段；最低點約在三分之二到四分之三；反彈後通常很快走向結局。

吐：一張分段表，列出每段的現有情節、空段候選和備用區，並標出這本書和骨架不一樣的地方
限界：追求反結構的作品可以不用，或只拿來看自己偏離了什麼
