# 把情節填進骨架

適用：想到一堆情節，排不成一個故事；不知道這本書該用哪種結構；或有主角和目標，不知道怎麼走完
吃：摘要或情節清單，加上大約的長度
做：
1. 挑一副骨架。段數要配長度：短篇段太多，每個事件都沒地方演；長篇段太少，容易平淡鬆散。常用的有：目標→阻礙→努力→結果→意外→轉彎→結局（中短篇，重點在意外最好因他的努力才有機會發生）；觸發→順境→逆境→解決（多數長篇的起點）；低迷→高昂→低潮→愉悅（只有模糊構想時，直接想主角的心情怎麼走）。
2. 把作者已有的情節逐條放進去，用這本書的人名和事件，不要只寫階段名。
3. 空著的段，每段給 2–3 個候選。作者也可以決定它就是空的。
4. 放不進任何一段的情節先移到備用區，不要刪。
5. 同一段擠了太多事件，或整本事件太少，都要提出來。事件不夠時，光靠擴寫細節只會虛胖。

吐：一張分段表，列出每段的現有情節、空段候選和備用區，並標出這本書和骨架不一樣的地方
限界：追求反結構的作品可以不用，或只拿來看自己偏離了什麼
