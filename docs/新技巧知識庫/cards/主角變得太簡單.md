# 主角變得太簡單

適用：主角的變化只有一步，從軟弱變勇敢就結束了；改變很大，但像突然變了個人，或變了也沒意義；或對手只是用來打的
吃：主角開始和結束的狀態，可以再帶上最大的對手、情人或夥伴
做：
- 多走幾步：原始→目標→過頭→修正。目標立場再往前走，壞的效果是什麼？第四個立場和第二個差在哪？每次轉換由什麼事件觸發，能不能各由一個角色推他一把？不一定要走滿。
- 走回本心：他骨子裡是不是本來就渴望另一端？孤僻的人也想有知心朋友。走向另一端，同時也是走回本心。開頭放什麼小事透露這點？
- 放進別的角色：他最缺的東西，對手身上有嗎？對方又能從他身上學到什麼？

吐：2–3 組設計，各說幾個立場或深處的渴望、觸發事件、推他的人，以及開頭的小事
例：
- 貪生怕死→勇敢正義→正義到走火入魔→在兩者間取得平衡。
- 殺手開頭小心救了一隻受傷的小鳥，下一幕才拿槍殺人。後來他和暗殺目標一起逃亡，其實是做回自己。
- 《火影忍者》鳴人和我愛羅都從小被排擠，一個交到越來越多朋友，一個越來越孤獨。決戰讓他們看見彼此的路。
