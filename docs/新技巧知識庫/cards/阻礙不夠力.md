# 阻礙不夠力

適用：這段的阻礙看起來很大，讀起來卻不緊張；或危機解除時沒什麼爽感
吃：角色的目標、這段的阻礙，和他解決它的方式
做：不要只想著把阻礙加大。先看問題在哪一頭。

- 目標那頭：讀者知道這對他為什麼非要不可嗎？阻礙不夠力，有時是目標沒立好。可以回頭烘托目標，讓讀者先知道它有多重要、失去會怎樣。
- 阻礙那頭：
  - 最簡單的解法是什麼？為什麼不能用？能輕易繞開，阻礙就沒有釘住。
  - 對這個角色來說，這有多痛？強度看他在乎什麼。
  - 讀者有沒有類似的恐懼或經驗？
- 受苦那頭：讀者真的看見他痛了嗎？還是一出事就被解決？苦沒寫夠，後面再驚喜的解決也會不溫不火。

吐：2 個方向，一個回頭烘托目標，一個加強阻礙，各說要改哪裡和代價，由作者選
例：
- 烘托目標：養了兩年的倉鼠老死，聽起來不大。如果先讓讀者知道牠對角色獨一無二，而且有不能死的理由，牠的死就是重大打擊。
- 釘住阻礙：《大白鯊》最簡單的解法是封海灘。市長以海灘是全鎮收入來源為由不准封，警長只能去殺鯊魚。
- 受苦：大雄考零分，少了被嘲笑、被痛罵和回家大哭，直接拿到道具，道具就不好玩了。
