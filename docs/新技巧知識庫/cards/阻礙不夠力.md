# 阻礙不夠力

適用：阻礙看起來很大，讀起來卻不緊張；危機解除時沒什麼爽感；或主角打來打去，看的人不痛不癢
吃：角色的目標、這段的阻礙，和他解決它的方式
做：不要只想著把阻礙加大。先看問題在哪一頭。

- 目標那頭：他為什麼非做不可？背後有什麼讀者還不知道的原因？這個原因對得上多數讀者也碰過的處境嗎？「只有打鬥才能生存」很少人經歷過；「為了保護珍惜的東西，不想打也得打」很多人有過類似的時刻。
- 阻礙那頭：最簡單的解法是什麼？為什麼不能用？能輕易繞開，阻礙就沒有釘住。強度看他在乎什麼。
- 受苦那頭：讀者真的看見他痛了嗎？還是一出事就被解決？

吐：2–3 個方向，各說要改哪裡和代價
例：
- 烘托目標：一個男人在暴風雨中獨自爬山，最後被直升機救走，這只是紀錄。但他是為了十年前山難的女友，每年這天都上山獻一束她最愛的百合，同一件事就成了故事。
- 釘住阻礙：《大白鯊》最簡單的解法是封海灘。市長以海灘是全鎮收入來源為由不准封，警長只能去殺鯊魚。
- 受苦：大雄考零分，少了被嘲笑、被痛罵和回家大哭，直接拿到道具，道具就不好玩了。
