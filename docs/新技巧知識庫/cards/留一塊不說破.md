# 留一塊不說破

適用：什麼都交代清楚了，讀完就結束；或想留點讓人討論的東西，但怕變成沒交代
吃：一個事件或真相，和作者自己知道的答案
做：挑一種留法：

- 各說各話：對同一件事，每個人的說法都不同。問：這個人為什麼要這樣說？他要保住什麼？
- 留一半：給一部分肯定的答案，另一部分完全不給，然後把焦點移開。
- 假結局：給一個表面的結局，再留線索讓讀者自己推翻。
- 有提示的謎：台詞或情節給足提示，但從不公布答案。

不說破和沒交代只有一線之隔。問：讀者手上的線索，夠他拼出至少一種合理解釋嗎？不說破的是作者刻意保留的，還是作者自己也沒想好？通常作者心裡要有數。

哪些要留白，由作者決定。
吐：2–3 種留法，各說明確交代什麼、不交代什麼，以及讀者會拿哪些線索去猜
例：
- 《竹叢中》：妻子、武士和盜賊都說人是自己殺的。三個說法都在保住自己的名聲，真相反而不是重點。
- 假鬧鬼：一夥人裝神弄鬼把學妹嚇進醫院，慶功當晚卻遇上一模一樣的事，崩潰後全招了。警察說只是跳電。害人是真的，鬼則始終沒有答案。
- 台詞：「你到底有沒有愛過我？」「這是個好問題，不是嗎？」
