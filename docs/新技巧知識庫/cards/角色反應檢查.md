# 角色反應檢查

適用：這段他的反應怪怪的；為了劇情，角色做了他不會做的事；或這個轉折很想要，但感覺很扯
吃：這段劇情，和角色之前的表現
做：用這些問題檢查：
- 以他當前的狀態，他真的會這樣嗎？狀態會隨事件變：揮霍的人掉一百元不會變節儉，財產少一半可能變得遲疑，全部失去才可能發瘋。
- 有沒有違背個性、和前文矛盾？反應有沒有過頭或不夠？
- 這是他的反應，還是作者或 AI 自己的反應？
- 他這樣做，是不是只因為劇情要往下走？什麼前因讓它發生？改成或加上什麼原因，他才會這樣做？

說不通時有三條路，由作者決定：

| 路 | 做法 | 代價 |
|---|---|---|
| 改事 | 把這件事改得合理一點 | 轉折可能變弱，結構起伏要再看一次 |
| 改人 | 把角色改成會這樣做的人 | 牽動前面所有戲 |
| 加戲 | 回頭在前面加事件，一點一點推他 | 前面要多寫，也可能拖慢 |

吐：不通的地方，和每條路各一個具體改法及代價
例：
- 膽小的女孩見男孩被流氓圍毆，會挺身而出嗎？改事：改成打電話報警。改人：改成衝動的女孩。加戲：男孩之前救過她；她曾因膽小誤事，至今後悔。
- 福爾摩斯犯下低級的推理錯誤。
- 夜深人靜，獨居的膽小女子獨自去查探詭異的聲響。
