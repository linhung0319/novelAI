# 話中有話

適用：角色把心裡想的直接說出口，對白像在念意圖
吃：作者選的一段對白，說話雙方的處境
做：問：
- 這句真正想要的是什麼？
- 他為什麼不能直說？在場有誰，他怕什麼？
- 他們表面上可以談哪件別的事，其實在爭這件事？
- 手上做的事能不能和嘴上說的相反？

直說不一定錯。角色本來就直，或一路繞到這裡終於說破，直說可能最有力。全場都打啞謎也會假。這句要不要繞，由作者決定。

吐：2–3 個改法，各標真正的意圖和表面在談什麼。只動作者選的句子
例：
- 正要吵架的夫妻對客廳的孩子說：「你功課寫完了沒有？」意思是回房間去。
- 「不知道是巧合還是其他原因，每次我要離開她遠行的時候，天都會下雨，她說是因為她不高興。」（《東邪西毒》）
- 反例：「我愛你，別離開我。」「不，我要找富二代。」
