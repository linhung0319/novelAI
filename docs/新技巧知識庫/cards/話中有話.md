# 話中有話

適用：角色把心裡想的直接說出口，對白像在念意圖；一問一答很死板；或台詞沒把這個人的虛偽、怒氣演出來
吃：作者選的一段對白，說話雙方的處境
做：問：
- 這句真正想要的是什麼？他為什麼不能直說？在場有誰，他怕什麼？
- 他們表面上可以談哪件別的事，其實在爭這件事？
- 手上做的事能不能和嘴上說的相反？

一問一答太平時，找最平的那句回話，挑這個人本來就可能這樣講話的路：

| 路 | 例 |
|---|---|
| 拿對方的話回敬 | 「你要是孝順就乖乖讀書。」「乖乖讀書不一定就是孝順啊。」 |
| 雙方都知道不是真的話 | 「你在這裡（坐牢）還習慣嗎？」「很好啊！世界上還有什麼地方比監獄好嘛！」 |
| 同時指兩件事 | 「妳下午的微積分考得怎樣？」「難過。」 |
| 不接話頭，放相反的東西 | 「真想要有大一點的衣櫃。」「妳需要的是少買一點衣服。」 |

直說不一定錯。角色本來就直，或一路繞到這裡終於說破，直說可能最有力。全場打啞謎也會假，接連耍嘴皮會像在比機智，一段裡有一句接得妙就夠了。

吐：2–3 個改法，各標真正的意圖和表面在談什麼。只動作者選的句子，也可以說這句照答就好
例：
- 正要吵架的夫妻對客廳的孩子說：「你功課寫完了沒有？」意思是回房間去。
- 「不知道是巧合還是其他原因，每次我要離開她遠行的時候，天都會下雨，她說是因為她不高興。」（《東邪西毒》）
- 反例：「我愛你，別離開我。」「不，我要找富二代。」
