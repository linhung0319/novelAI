# 誰來點醒他

適用：主角需要被點醒、得到資訊或拿到東西，但寫出來只是有人來說教或送禮
吃：主角卡住的地方、現有角色和物件
做：
- 誰來給最不尋常？語帶諷刺的對頭、迎頭痛擊的敵人、當頭棒喝的路人、一件象徵物、一個夢、一段被觸發的舊記憶，都可以。
- 敵人來給時：他為什麼給？主角和讀者會擔心他什麼時候反咬。
- 主角要付什麼或通過什麼才拿得到？給的人可以刻意刁難。
- 給的人自己有陰影嗎？主角的成長會不會同時放過他？
- 距離要多遠？偶爾出現的引路人比較超然；長期陪伴的朋友，一句話可能更打動人。

吐：2–3 個候選，各說誰給、給什麼、主角付什麼、之後會帶出什麼
例：哈利和鄧不利多是偶爾指引；令狐沖和風清揚只幫一次；女警探和漢尼拔是敵對中仍給指引。
