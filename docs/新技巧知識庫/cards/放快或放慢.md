# 放快或放慢

適用：這段太趕想展開，或拖太久；想把一瞬間拉長，或把很多年壓短
吃：作者選的一段，作者想要快還是慢
做：先問這段的快慢是哪裡來的，再決定動什麼。
- 放慢：他此刻有什麼念頭、想起什麼、周圍有什麼變了？
- 放快：只留發生的事和對話，念頭和周圍能不能先拿掉？
- 壓長時間：有沒有一樣東西，一路出現在這段時間裡？
- 大事剛過，人物有沒有時間反應？

擴寫時只加這個人此刻真的有的東西，不把演過的意思再講一遍。

吐：2–3 個版本，各說多了或少了什麼。只動作者選的段落
例：壓短：小時候踢的足球上有個笑臉，從小學踢到國中才換球；那顆球踢進全國大賽；爸媽慶祝他進職業隊又買新的；後來小孩不踢了，膝蓋傷了，也不再買球了。整段只講球，五十年過去。
