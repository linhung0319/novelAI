# 放快或放慢

適用：這段太趕想展開，或拖太久；想把一瞬間拉長，或把很多年壓短
吃：作者選的一段，作者想要快還是慢
做：先問這段的快慢是哪裡來的，再決定動什麼。
- 放慢：他此刻有什麼念頭、想起什麼、周圍有什麼變了？一秒鐘的事可以停很久。
- 放快：只留發生的事和對話，念頭和周圍能不能先拿掉？
- 壓長時間：有沒有一樣東西，一路出現在這段時間裡？
- 大事剛過，人物有沒有時間反應？資訊很密的段落之後，有沒有一句人話讓人換氣？

快的寫法只對這段有用，不要變成全書的要求。擴寫時只加這個人此刻真的有的東西，不把演過的意思再講一遍。

吐：2–3 個版本，各說多了或少了什麼。只動作者選的段落
例：
- 快：「一顆子彈從耳邊飛過，她連忙撲倒，右邊又是一聲巨響。」
- 慢：同一顆子彈。她撲倒時想起爹交代的話，有槍聲就趴倒、有敵人就裝死。爹已經三天不見了。每天經過的圍牆塌了，右邊小路上她下雨天踩水的小坑，被炸成一個大洞。然後右邊才一聲巨響。
- 拉長：「他看著扳機彈縮了一下，子彈緩慢的射出，空彈殼飛上空中不住旋轉。他的雙眼都沒眨過，子彈，真的會旋轉。他有點得意，只可惜沒機會跟別人說了。」
- 壓短：小時候踢的足球上有個笑臉，從小學踢到國中才換球；那顆球踢進全國大賽；女朋友送新的，爸媽慶祝他進職業隊又買新的；後來小孩不踢了，膝蓋傷了，也不再買球了。整段只講球，五十年過去。
