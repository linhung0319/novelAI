# 角色會做的事

適用：角色資料有了，人還是活不起來；把他丟進新事件，猜不到他會怎麼做
吃：對這個角色的粗略想法，不需要完整設定
做：先不填資料，想他會做的幾件事。小事也可以，最好之後能出現在故事裡。每件都問：他為什麼這樣做，不選別的做法？這透露他用什麼邏輯判斷事情？

然後丟一個新事件試：現在猜得到他的反應了嗎？猜不到，就換一件更鮮明的事。

吐：2–3 組行為，各說透露出什麼判斷邏輯、可以放在故事哪裡；作者挑了再往下
例：
- 十二月，三個軍人巡邏時要涉過冷溪，士官下令休息十分鐘。第一個先過溪再休息；第二個往上游找淺處，沒冷到，也沒休息到；士官休息到最後才直接過溪。一件小事，就看得出三種面對難題的方式。
- 阿強在路上挨了一拳，會怎麼反應？說他是壯漢、業餘拳擊手，只是暗示。說他曾因為小狗在機車輪胎上尿尿，一腳把狗踢飛，還在旁邊冷笑，就猜得到了。
