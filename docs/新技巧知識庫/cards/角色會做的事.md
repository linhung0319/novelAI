# 角色會做的事

適用：資料有了，人還是活不起來；性格只在設定裡，這段戲換誰演都一樣；猜不到他會怎麼做；或每個人開口都像作者自己
吃：對這個角色的粗略想法或現有資料；有正在寫的事件更好
做：先不填資料，看他做事。挑一條路：
- 想他會做的幾件事。小事也可以，最好之後能出現在故事裡。每件都問：他為什麼這樣做，不選別的做法？這透露他用什麼邏輯判斷事情？
- 在事件裡找他要做選擇的那一刻，列幾個都說得通、方向不同的反應。讀者看到他這樣做，會覺得他是什麼人？之後的戲會怎麼走？事件逼不出選擇，就把它逼緊一點。
- 讓他開口：AI 用他的口吻自述，或作者當記者提問。多問會逼出態度的問題，例如最後悔的瞬間、哪件事絕不讓步。作者聽的是哪句對、哪句不像他，認可的才算數。角色還沒有連貫的核心時先不要用，問出來會很零碎。

已有很多資料時，問每筆資料會在哪場戲用到、讀者怎麼知道。他喜歡紅色：為什麼？什麼事造成的？資料多不一定有害，只是不等於讀者看到的角色。

吐：2–3 組行為、反應或一小段自述，各說透露出什麼判斷邏輯、可以放在故事哪裡；作者挑了再往下
例：
- 十二月，三個軍人巡邏時要涉過冷溪，士官下令休息十分鐘。第一個先過溪再休息；第二個往上游找淺處，沒冷到，也沒休息到；士官休息到最後才直接過溪。一件小事，就看得出三種面對難題的方式。
- 阿強在路上挨了一拳，會怎麼反應？說他是壯漢、業餘拳擊手，只是暗示。說他曾因為小狗在機車輪胎上尿尿，一腳把狗踢飛，還在旁邊冷笑，就猜得到了。
- 曹操誤殺呂伯奢全家，逃亡路上遇到還不知情的呂伯奢。認錯，他是還有良知的人；連呂伯奢也殺，他就是自私又狠的人。
