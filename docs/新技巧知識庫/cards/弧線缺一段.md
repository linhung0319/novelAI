# 弧線缺一段

適用：角色的轉變像突然開竅；或排了很多戲，他的心境卻沒有動
吃：角色一開始追的東西，和已排的幕或劇情
做：先問作者這個角色要不要變。要變的話，沿著這條路問哪一場在演：
- 盲目：他為了想要的東西拚命，哪裡看得出他搞錯了？
- 挫折：他以為會發生的和真正發生的，哪裡對不上？可能是得到了卻不開心，也可能是失去後才發現。
- 醒悟：他的防衛和逃避在哪裡被打垮？這時浮出來的是什麼？
- 滿足：他真正需要的東西什麼時候到手？還是想要和需要最後合而為一？

空的那段就是要補的戲。醒悟要經過外在的折磨和內心的考驗，才不會像突然開竅。一次事件就變，會像作者要他變；連續好幾次類似事件都不變，也不合理。可以排幾次一次比一次強的事件，每次讓他鬆動一點。

這條路不一定要走完。也可以讓想要贏，他被慾望吞噬，變成悲劇；或者他一開始就握有真相，改變的是周圍的人。連載爽文的主角也常不走這條長路。

吐：缺哪一段；每段 2–3 個場面候選，各說他在其中失去或看見什麼
例：《食神》史蒂芬周費盡心思要奪回名利權，失去雞姐之後，才知道他要的是一份溫暖。
