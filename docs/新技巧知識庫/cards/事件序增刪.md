# 事件序增刪

適用：覺得故事拖，有些戲可有可無；或事件之間接不起來、怪怪的
吃：照順序列出的事件或幕
做：逐條用這些問題檢查：
- 主線：它有沿著主線走嗎？
- 後果：它對後面有什麼影響？如果影響很小，前因也可以不要。和主線有關，不代表一定要留。
- 三足：為什麼發生、經過怎樣、結果如何，缺了哪一段？缺前因讀者一頭霧水，缺經過少了最精彩的部分，缺後果懸念沒有被滿足。
- 位置：調到別的地方會更好嗎？
- 缺的：路上是否少了一件事，例如關鍵的貴人相助？
- 改動：改了後面，前面有種下前因嗎？改了前面，後面的後果還合理嗎？

很喜歡某一場但它接不上主線時，可以改它、改主線或移到備用區，由作者決定。

吐：可刪、可併、要補和建議調位的清單，各附理由
例：一個講復仇和愛情的故事。
- 比爾蓋茲給了一百萬，復仇才成，要留。
- 大雄給了二十塊，後面毫無影響，雖然也幫了復仇，仍可刪。
- 和朋友打籃球，和復仇、愛情都無關，除非能讓它接上。
