# 縱橫交會

適用：主線太單薄，想加副線但不知道怎麼接；或想埋伏筆，又不想為了埋而埋
吃：一條主事件。有現成的副事件或角色更好
做：
1. 把事件拆成前因、經過、後果。
2. 縱向接：上一件事的後果能不能變成下一件事的前因？
3. 橫向交會：副事件的哪一段撞上主事件的哪一段？
   - 經過撞經過：他行竊時遇上另一個竊賊。
   - 前因撞經過：他為了老母要行竊，家裡卻先闖進了竊賊。
   - 後果撞經過：他得手後準備銷贓，贓物被女賊偷走。
4. 隔幕交會：讓副事件先露一小段，消失幾幕，再回來把因果串起。當下看似贅戲的片段，就成了伏筆。
5. 穿插：兩條事件的觸發、衝突、解決可以交錯排，例如 A 觸發→A 衝突→Z 觸發→A 解決→Z 衝突→Z 解決。
6. 查副事件的頭尾：讀者最後知道它為什麼發生、結果如何嗎？沒交代就會變成贅戲。

吐：2–3 條副線候選，各說在哪幾幕交會、用哪種撞法、先露什麼、在哪裡補完，以及代價
例：小偷潛入行竊時遇上女賊。他被抓，她消失。押送途中車禍，他昏迷垂死，再次醒來，已被女賊所救。
