# 結尾無力往前找

適用：高潮或結局感覺無力，但怎麼改結尾都不對
吃：結局，以及全書的開頭和主要轉折
做：問題可能在前面。用這些問題檢查：
- 落差：開頭他有多低？可能不是結尾拉得不夠高，而是開頭降得不夠低。
- 中段：情緒有沒有太早爬到頂，留給結尾的空間不夠？
- 先埋：他的缺憾、心願和敵人，前面露面了嗎？最後都有結果嗎？
- 翻盤的關鍵：是不是前面看似無意義的人、事或資訊？支線認識的人能派上用場嗎？
- 第二次面對：他這次為什麼和第一次重挫時不同？他用了什麼新做法，是不是整趟旅程學到的？
- 主題：他在故事裡遇到的相反觀念，最後有沒有和原本的想法碰出新東西？

吐：問題出在哪個位置，以及 2–3 個要往前改的地方，各說改哪幾幕、結尾會多得到什麼
