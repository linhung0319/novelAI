# 我他你切換

適用：感情太難受，一直「我」顯得煩又矯情；或第三人稱隔太遠，想在某一句靠近
吃：作者選的一段，這本書的人稱
做：問：
- 這個人此刻想不想面對自己？抽離時，他會怎麼罵自己？
- 「我」在直接感受，「你」站在對面，「他」不在現場。這一刻他站在哪裡？
- 第三人稱裡，最激動的那一句能不能直接變成「我」？

這會打破一般的人稱一致，先確認作者要這樣做。適合一小段，不適合當常態。

吐：2–3 個改法，標出切換點和為什麼在那裡切
例：
- 近拉遠：「小玲，我是個不合格的男朋友。妳總是這樣溫柔，他這個王八蛋卻只想著自己的事業……那天經紀人通知我快去醫院，你這個大笨蛋還想著生意！……小玲，我不配。」
- 遠拉近：「他抱著她漸漸發冷的身體，身軀顫抖。不是說好要一起環遊世界的嗎？我們現在就去，好不好？妳起來啊！」
