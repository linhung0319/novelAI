# 十大故事類型

適用：沒有靈感想找刺激，或有靈感但不知道往哪種類型發揮
吃：作者的靈感，沒有也可以
做：把同一個靈感放進不同類型，看各會變成什麼故事。一個故事可以同時屬於幾類。分類只是刺激想法的指標，不用替作品定型。

| 類型 | 核心 |
|---|---|
| 怪物牢籠 | 與怪物困在逃不掉的範圍內搏鬥 |
| 尋寶歷程 | 追求想要的東西，途中發現真正需要什麼 |
| 喜從天降 | 突然發生好事，好事伴隨災禍 |
| 飛來橫禍 | 平凡人生突遭巨變，一步步克服 |
| 與眾不同 | 主角一開始就不普通，因此格格不入或要隱藏 |
| 人際感情 | 兩人的交流、對立、理解和共鳴 |
| 人生經驗 | 陪讀者面對或回味人生共通的歷程 |
| 黑暗真實 | 主角代替讀者揭露真相，最後讓讀者反問自己 |
| 大智若愚 | 天真的主角挑戰被嘲笑的目標，以單純勝出 |
| 群體枷鎖 | 群體價值凌駕個人時的衝撞 |

吐：2–3 個類型方向，各說這個靈感會變成什麼故事；如果作者是選不下，再說各方向會鎖死什麼
