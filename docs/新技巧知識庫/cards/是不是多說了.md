# 是不是多說了

適用：有句子在解釋意義、評論角色或預告後面的事，像有人在旁邊講話；對白像在向讀者交代資料，或把演過的事再講一遍；內心戲看著多餘
吃：作者選的一段，前面演過什麼
做：先問這句是誰要講的，再分開看：

敘述：
- 這是角色當下的想法，還是作者的想法？
- 拿掉它，讀者從前面的事讀得出來嗎？讀得出來就是多說了。讀不出來，要補的可能是前面的動作和對白。
- 有些書靠敘述者的評論吃飯。這是這本書的聲音，還是順手寫的？

對白：
- 對方本來就知道這件事嗎？「你師父叫岳不群」是說給令狐沖聽，還是說給讀者聽？
- 讀者剛看過的事，一句「他把剛才的事大略說了」夠不夠？
- 這個角色此刻會談這個嗎？還是作者借他的嘴？
- 讀者一定要知道的事，誰有私心要說？誰不想聽？一個人講太長時，能不能讓人打斷？

內心戲：拿掉這段，讀者會漏掉劇情嗎？
- 不會漏，但少認識這個人一點：他有自己在意的東西，可以留。例如人家在論如來神掌，他在心裡算今天齋飯的油水。
- 不會漏，因為前面才演過：他在替讀者做筆記，可以考慮刪。
- 會漏：這是一件被摘要掉的事，可以考慮演出來。

吐：可疑的句子，每處 2–3 個處理（刪掉、帶過、改成角色當下的念頭、改成有動機的問答、換成讓讀者自己看出來的新細節）
例：粗體是他在想，還是作者在想？

他問起她的近況，她大概說了為了還錢而工作。**雖然她這樣的行為不好，但是非常可憐、值得同情。**他從皮夾給了她一筆錢，**十分大方，這可能也是為了彌補他心中的罪惡感**，然後送她回家。
