# 謎三角

適用：故事靠謎撐著，只反轉一次怕被猜到，想騙讀者兩次
吃：想定的真相（沒有也可以先給幾個候選，由作者定）
做：想好三個答案，再倒著排。

1. 真真相：最後要讓讀者知道的事。
2. 假真相：中後段揭曉、讓讀者以為「果然被我猜中」的答案。
3. 表面答案：前段一路塑造、讀者最先相信或故意不信的答案。

倒著想比較容易：我要甲當真兇，就讓乙當替死鬼，前段再把嫌疑引到丙身上。也可以始終是同一個人翻來翻去：甲壞、甲其實好、甲還是壞。

假真相要給得夠滿足，讀者才會放下戒心。下一次反轉要有前面的線索撐著，否則只會讓人覺得離奇和出戲。兩次通常夠了，要再疊就先問值不值得。

吐：2–3 組三層答案，各附揭曉順序、每層讀者會怎麼想，以及最難讓人信服的一處
例：石內卜。先被塑造成壞人，後來發現他並不壞；系列後段又成了背叛者，結局才再翻回來。
