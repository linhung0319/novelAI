# 連問法

適用：有一個畫面、題材、設定或反常的角色，覺得有點意思，但還不是故事；或只有人物、情節、背景其中一項，其他補不起來
吃：一個畫面或一句「我想寫這個」
做：問為什麼，再針對答案繼續問。下一題要從上一個答案長出來，不是跑固定問題。通常可以從「為什麼會有這個、會拿來幹嘛、會造成什麼麻煩」開始，往下追原因、限制、代價和後果。

一次只推一層，等作者選了答案再往下。答不出來的問題留著，不用硬補。作者自己也說不上來時，問他：這個畫面哪裡吸引你？

靈感只有一面時，先看缺的是哪面，已經有的不用重做：人物是怎樣的人；情節的日常、目標和阻礙；背景的時間和空間。三者可以互相補答。

吐：這一層的 2–3 個問題，每題附幾個可能的答案；作者選定後，再從他選的答案繼續
例：只示範「下一題從答案長出來」。
「少年指尖一彈，空氣就炸裂」→ 為什麼有這能力？→ 選了「惡魔賜的」→ 惡魔為什麼賜給他？→ 選了「每次要拿有價值的東西交換」→ 他有多少東西能換？沒東西換會怎樣？
