# 這幕有沒有變

適用：這幕讀起來很平，說不上哪裡不對；或很喜歡這一段，但不確定該不該留
吃：這一幕，和前後各一兩幕
做：先看情緒，再看其他。用這些問題檢查，不必每幕都全過：

- 角色的情緒有變嗎？可以由好轉壞、由壞轉好，也可以壞上加壞、好上加好。幕頭和幕尾一樣，通常就是沒事發生。
- 情緒連得上嗎？有沒有突然冒出氣氛迥異的一幕？如果是刻意調節就沒問題。
- 情緒有累積嗎？要痛哭的那一幕，前面有沒有幾幕鋪著？
- 這幕的行動，是上一幕的決定引出來的嗎？這幕的結果，有推動下一幕嗎？劇情往前走了，還是原地踏步？
- 這幕有誰想要什麼、被什麼擋著？還是只是在走動和對話？如果對手只回一句「好，你去吧」，這幕會怎樣？
- 整幕都在想事情的話，他的難題是什麼？最後決定了什麼？
- 讀者對某個人物多知道了什麼？有沒有人擺著當花瓶，可以加戲、刪掉或合併？
- 拿掉這幕，主線會少什麼？很喜歡但跟主線無關的話，是要讓它接上主線，還是先剪到別的地方放著？

吐：可疑的地方和原因，以及 2–3 個改法。要刪要留由作者決定
例：關羽斬華雄。諸侯輕視他，他立下輸了就砍頭的話。如果諸侯說「好，你去吧」，關羽說「輸了就輸了」，勝負就都不重要了。
