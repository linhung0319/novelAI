# 結局加力

適用：結局成立，但平淡、沒力，差一口氣
吃：已定的結局、前文出現過的物品動作地點對白、主角的改變
做：先看前文替這個結局累積了什麼。結局沒力常常是前面沒鋪，只改結尾救不回來。再挑一兩項試，不必全上。

| 加法 | 問句 | 例 |
|---|---|---|
| 小意外 | 有什麼小巧思能在最後掀開？不必左右故事 | 《鐵達尼號》老蘿絲從口袋拿出海洋之心，丟入海中 |
| 揭露人物 | 讀者喜歡或討厭的人，真面目可以相反嗎？前文有跡象嗎？ | 岳不群的野心、石內卜並非敵人 |
| 情感 | 就算知道結局，還是會被什麼打動？ | 《大話西遊》至尊寶的真心話，紫霞永遠聽不到 |
| 不說出口 | 哪句話可以換成一個動作？ | 戰士赴死前豎起大拇指 |
| 首尾呼應 | 哪個出現過的物品、動作、地點或對白可以收回來？意思可以變，也可以只是呼應。 | 《食神》畫好愛心的紙卡；《刺激1995》談過的海灘；《無敵破壞王》同一句座右銘，第一次無奈，第二次肯定自己 |
| 未完的暗示 | 故事圓滿了，能不能再留一個小懸念？ | 《奪魂鋸》全片終了才暗示真兇另有其人 |
| 再選一次 | 能不能在結尾再給主角一次同樣的選擇，讓他選得不一樣？ | 《命運遙控器》回到最初，他把遙控器丟進垃圾桶 |

意外要在前文找得到理由。小龍女跳崖沒死，靠崖下深潭說得通；靠上帝神蹟就是作者出老千。

吐：2–3 種加法，各說結局多了什麼，以及前文要補埋什麼
