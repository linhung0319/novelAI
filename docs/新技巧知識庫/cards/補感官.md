# 補感官

適用：這段很空，看不見也摸不著；作者想補感官細節
吃：作者選的一段，誰的視角
做：問：
- 這個人在這裡會先注意到什麼？這由他的經歷決定。
- 這個細節想告訴讀者什麼沒明說的事？說不出來，可能就不用補。
- 這個氣味或聲音會勾起他什麼記憶？想起來之後，能繞回眼前的人或事嗎？
- 念頭有沒有具體到讀者看得懂？「一種充滿懷疑的氛圍」，懷疑什麼？

不用每種感官都有。這裡不用補，也是一種答案。

吐：2–3 處可以插入的候選句，各說傳達什麼。不重寫整段
例：他走過我身邊，我聞到一股淡淡的花香，像我奶奶院前種的小白花。他也跟奶奶一樣愛花嗎？他也是個溫柔的人嗎？這裡從他身上的香，到過去的香，到奶奶，再投回他身上。
