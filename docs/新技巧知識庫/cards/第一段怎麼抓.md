# 第一段怎麼抓

適用：開場的事件定了，第一句或第一段沒有力，平平淡淡
吃：開場的事件、類型和調性、主角當下的問題
做：挑一兩型試寫，不必全跑。推理多半適合提問，純文學多半適合世界一句話；只是傾向，看這本書要什麼。

| 型 | 怎麼做 | 例 |
|---|---|---|
| 提出疑問 | 讓讀者立刻問為什麼 | 那封信送到時，正好是父親死後第十年的早晨。 |
| 丟進場面 | 先動再說明 | 跑。喘不過氣了還在跑。 |
| 世界一句話 | 一句濃縮全書的調性 | 在這座城裡，一下雨，人的記憶就會一點一點溶掉。 |
| 敘事者的聲音 | 一開口就露出口吻和立場 | |
| 日常裡的不對勁 | 平靜的風景裡只放一個異質的東西 | It was a bright cold day in April, and the clocks were striking thirteen. |

低調也行，例如 There was no possibility of taking a walk that day. 開頭用台詞的話要短，也要讀來順口。

鉤子要接得上後面的故事，只有驚奇、後面用不到就算沒抓住。除了好奇也可以放憂慮：「進去的人為什麼叫這麼慘？等一下就輪到我了。」角色不牽掛的事，讀者也很難牽掛。這些開法也可以用在每一幕的開頭。
吐：2–3 個第一段草稿，各說用哪一型、讓讀者想問什麼，由作者挑或改
