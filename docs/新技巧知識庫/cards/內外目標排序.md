# 內外目標排序

適用：幕排出來了，但順序感覺不對；或不知道哪些戲可以砍
吃：主角的外在目標、內在問題、已排的幕
做：
1. 拆成一內一外：表面上他要解決什麼麻煩？底下他要回答什麼問題、過哪一關？
2. 對照常見順序：外在目標遇到阻礙→引出內在問題→一連串衝突→內在問題解決→外在阻礙才解決。這不是規定，內外同時解決或最後沒解決也可以成立，但要看得出它是故意的。
3. 逐幕問：這場外在事件碰到他的內在問題了嗎？
4. 既沒碰到內在問題，也沒推動外在主線的戲，列為可刪候選，由作者決定。

吐：一條幕序骨架、一份可刪候選，並標出內在問題有哪幾段沒有戲在演
例：主角想打倒壞人，可是敵人很強（外在目標與阻礙）；他害怕，也不敢殺人（內在問題）；經過一些事，他變勇敢了（內在解決）；終於打敗壞人（外在解決）。
