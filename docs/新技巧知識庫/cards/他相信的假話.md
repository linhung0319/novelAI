# 他相信的假話

適用：舊傷只是背景故事，和現在的戲沒關係；角色有外在目標，卻沒有內在問題；或反派只能用「他瘋了」來解釋
吃：角色現在的行為或目標
做：從現在的行為往回找：他相信哪句不對勁的話，才會這樣做？接著問：
- 什麼經歷讓他信了這句話？
- 這句話讓他現在做錯什麼？
- 故事裡什麼事最能戳破它？

寫反派時，把這句話推到極端：什麼信念會讓一個人做出這麼糟的事？

這是找靈感的方向，不是每個角色都要有一句，也不要把人塞進型號裡。

吐：2–3 句假話，用一小段話說舊傷、它現在害他做的事，以及哪場戲會戳破它。不列欄位
例：
- 「我即我所做」：自我價值全押在成就上，舊傷可能是某次不夠好就不被愛。
- 「世界是不安全的」：凡事先找靠山、先想最壞的情況，舊傷可能是某次保護失效。
