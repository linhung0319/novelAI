# 他相信的假話

適用：舊傷只是背景，和現在的戲沒關係；角色有外在目標，卻沒有內在問題；或反派只是為作對而作對，只能用「他瘋了」解釋
吃：角色現在的行為或目標；反派再帶上主角的目標
做：從現在的行為往回找：他相信哪句不對勁的話，才會這樣做？接著問：
- 什麼經歷讓他信了這句話？
- 這句話讓他現在做錯什麼？
- 故事裡什麼事最能戳破它？

寫反派時，把這句話推到極端，用他的角度把故事想一遍：他問心無愧的那套想法是什麼？如果他的需求和主角一樣正當，衝突會變成什麼樣？這不必和善惡有關。純粹的邪惡也能撐起故事（佛地魔），作者要灰色反派時才往這裡走。

這是找靈感的方向，不是每個角色都要有一句。

吐：2–3 句假話或理由，用一小段話說舊傷、它現在害他做的事、哪場戲會戳破它；反派再說讀者會在哪裡覺得他有幾分道理。不列欄位
例：
- 「我即我所做」：自我價值全押在成就上，舊傷可能是某次不夠好就不被愛。
- 《姐姐的守護者》：妹妹生來就是姐姐的捐贈者，她拒絕父母決定自己的身體。雙方都對，也都不能退。
- 滅絕師太出手狠辣，心中想的卻都是門派和正義，沒有一己私慾。
