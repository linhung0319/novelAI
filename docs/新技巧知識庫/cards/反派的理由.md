# 反派的理由

適用：反派只是為作對而作對；或故事變成好人打壞人
吃：主角的目標，和反派目前的行為
做：用反派的角度把故事想一遍。問：
- 他為什麼不覺得自己有錯？他問心無愧的那套想法是什麼？
- 這套想法是從他人生的哪一段長出來的？
- 如果他的需求和主角一樣正當，衝突會變成什麼樣？
- 他和主角各自代表什麼相對的觀念？這不必和善惡有關。

不是每個反派都要這樣寫，純粹的邪惡也可以撐起故事（佛地魔）。作者要灰色反派時才往這裡走。

吐：2–3 個理由，各說讀者會在哪裡覺得他有幾分道理，以及這個理由和主角怎麼對撞
例：
- 《姐姐的守護者》：妹妹生來就是姐姐的捐贈者，她拒絕父母決定自己的身體。雙方都對，也都不能退。
- 滅絕師太出手狠辣，心中想的卻都是門派和正義，沒有一己私慾。
