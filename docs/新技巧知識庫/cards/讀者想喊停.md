# 讀者想喊停

適用：主角太乾淨、一路做對的事，讀者沒什麼好揪心的
吃：角色、他在乎的人事物，和目前的主線
做：讓他走一條讀者想喊停的路。幾個方向：

- 越錯越深：他一步步做錯選擇，每一步都比上一步更難回頭。問：每一步他為什麼這樣選？是為了義氣、受人所逼，還是別無選擇？最後他要付什麼代價？
- 死不回頭：他對某人或某個信念堅信不移，別人都勸，他還是不改。問：他信的到底是什麼？誰來勸他？堅持讓他失去什麼？最後是證明他對，還是他為此賠上一切？
- 挫敗：好不容易進步了，就把難度提高，把他打回去。他在最低潮時會露出什麼？
- 灰色：一度不想當好人了。什麼把他推過去？什麼把他拉回來？

做錯事時，通常要保留他讓人喜歡的地方。讀者討厭他以後，就不一定在乎他會不會墜落。也有主角一路壞到底還是迷人的（《華爾街之狼》），那就要靠別的東西撐。

吐：2–3 條路線，各列幾個關鍵選擇、讓讀者還站在他這邊的理由，以及他最後的代價。結局走向由作者定
例：
- 古惑仔電影：愛玩音樂的學生誤入幫派，從義氣相挺到替人砍人，再到出賣兄弟，最後眾叛親離。
- 令狐沖冒著被逐出師門的風險，也不跟邪派朋友絕交。
- 穆念慈明知楊康不是好人，還是堅持跟他在一起。
- 《神鵰俠侶》：楊過一度為了報父仇，和蒙古人站在一起。
- 《喜劇之王》：尹天仇以為苦盡甘來能演主角，卻突然被換角。
- 善良型：被騙、被害後仍相信世人，所有人都勸他醒醒，最後善意得勝時讀者跟著感動。
