# 心念插進動作

適用：一直寫「他想」；內心一大段，和動作脫節；或情緒最高的地方一下就過去了
吃：作者選的一段
做：問：
- 不標「他想」，能不能把念頭直接放在兩個動作之間？
- 事件之後接念頭，念頭之後接反應，接得上嗎？
- 情緒最高的那一刻，能不能走進內心繞一圈（感受、回憶、想像），再回到同一個動作？

一直夾會瑣碎，這裡不用每個動作都配念頭。

吐：2–3 種插法，標出插在哪裡。不改其他句子
例：
- 「他冷眼看著這一切，這可不是我要的結果啊！他苦笑。」
- 外部：「她的臉慢慢朝我靠近，我憋著氣不敢呼吸。」繞一圈：中間想起拉她的手過馬路那次，希望時間停在這一刻，又慌了，這是真實的嗎？然後回到憋著氣不敢呼吸。
