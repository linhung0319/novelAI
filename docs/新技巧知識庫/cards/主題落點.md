# 主題落點

適用：題旨定了，但不知道它怎麼進到故事裡；或主題只能靠角色講出來
吃：一句題旨、目前的大綱
做：替題旨找具體落點。載體可以並存，不同載體也可以放不同層次的意思。

| 載體 | 問句 | 例 |
|---|---|---|
| 結局 | 主角目標的成敗，下了什麼定論？ | 《美人魚》化成泡沫：追逐艱難的愛情招致滅亡。反過來就是真愛克服一切 |
| 對白 | 有沒有一句話，留到最高潮說才有重量？ | 「如果不愛他能長命百歲，那我寧願現在就死。」 |
| 人物 | 誰的性格和行為本身就是這個見解？ | 關羽過五關斬六將：忠義勝過生命和利益 |
| 情節 | 結局曖昧時，高潮的抉擇說了什麼？ | 《全面啟動》不知成功與否，但看見主角選擇回到現實 |
| 意象 | 不解釋，只呈現什麼物、景、事？ | 《梁祝》雙飛蝶：是殉情的悲傷，還是團聚的歡愉？ |

濃度看類型和作者想要的，娛樂向可以很淡。讀者會有自己的解讀，不必也控制不了。

吐：2–3 個落點，各說在哪一段、由誰、用哪句話或哪個物件，以及這樣放會不會太露
