# 修稿從大到小

適用：寫完一段或一本，不知道從哪裡改
吃：寫好的稿子，大綱或幕綱（如果有）
做：先問大的。大的有問題，字句可以先放著：
1. 這個故事在講什麼？傳遞什麼？結局指向的意思是作者要的嗎？
2. 最初想寫的那個有趣的點，現在還在嗎？
3. 成品和幕綱差在哪？轉折還在嗎？多加的戲有沒有把主線推偏？
4. 角色的變化指得出每個節點嗎？這些變化合理嗎？
5. 每個角色每次出場，留給讀者什麼感受？加起來是作者想要的印象嗎？
6. 開頭和結尾。改的時候留著每個版本，方便比較。
7. 中間每段的目的是什麼？哪裡讀了無聊？跟結尾有關嗎？
8. 最後才是字句和錯字。

吐：問題清單，由大到小排，並請作者指定從哪裡開始。這張只診斷，修改等作者點名段落
