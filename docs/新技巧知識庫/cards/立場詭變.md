# 立場詭變

適用：故事寫到後來好像變了一個意思；想說的和寫出來的對不上；或不確定哪些情節離題了
吃：作者想說的那句話、主線或大綱、結局
做：用這些問題檢查：
- 先不看作者的說法，只看結局和角色下場，這個故事實際在說什麼？和他想說的一樣嗎？
- 中途有沒有哪裡說了相反的話？例如某個行為前面被懲罰，後面同樣的行為卻沒有代價。
- 哪些重要場面和角色抉擇，既不支持也不試煉這句話？它們是副主題、純粹好看，還是真的漂掉了？
- 立場有轉變的地方，有足夠的鋪陳讓讀者跟上嗎？

對不上不一定是錯。可以改故事，可以改想說的話，也可以留著兩種立場並存。故事夠精彩、衝突夠完整時，矛盾也可能是效果。由作者決定。
吐：實際呈現的意義和想說的意義各一句，可疑處，以及 2–3 個改法（改故事、改主題、留作並存）
例：想寫「愛情無法戰勝環境，導致毀滅」，職場和童年的段落跟這句無關時，可以刪，也可以問作者它們是不是另一個他在意的主題。
