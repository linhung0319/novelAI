# 由果推因

適用：知道後面要發生什麼，不知道前面怎麼埋；或一想到要埋伏筆就覺得刻意
吃：後面要發生的事，和前面已有的劇情
做：

1. 這件事要發生，需要哪些條件？想讓女主角撿起弓箭射死敵人，前面就要有她會射箭，地上也要有弓箭。
2. 這些條件裡，哪些能藏進本來就需要的劇情？最好一件事同時做兩件工作，讀者才不會察覺它是為了伏筆而寫。
3. 剩下的條件，用什麼方式預示？可以不起眼地帶過，也可以寫一句當下和事後讀來意思不同的話。有些條件不必藏，正面鋪陳反而更有力，例如她的射箭本事。

埋的位置通常離回收遠一點：讀者自己想不起來，但一提就會記起的距離。回收時讓角色的情緒跟著揭曉，不要只是說明原來如此。

吐：2–3 個埋法，各說埋在哪裡、當下讀者以為那是什麼、回收時怎麼串起來。埋點由作者挑
例：《臥底》的銀彈。主角中了卡在心臟的銀彈，瀕死才被咬成吸血鬼；銀彈壓住能力，讓他能在白天現身；最後反派捏碎他的心臟，也被銀彈所傷。一顆子彈同時推動開頭、中段和結局。
