# 替讀者下結論

適用：段落裡有句子在解釋行為的意義、評論角色好壞，或預告後面的事，讀起來像有人在旁邊講話
吃：作者選的一段
做：問：
- 這句是角色當下的想法，還是作者的想法？
- 拿掉它，讀者從前面的事讀得出來嗎？讀得出來就是多說了。
- 讀不出來的話，是前面的動作和對白沒撐住，要補的可能是前面。
- 有些書靠敘述者的評論吃飯。這是這本書的聲音，還是順手寫的？由作者判斷。

吐：可疑的句子，每處 2–3 個處理（刪掉、改成角色當下的念頭、換成一個讓讀者自己看出來的新細節）
例：這段粗體的部分，是他在想，還是作者在想？

他問起她的近況，她大概說了為了還錢而工作。**雖然她這樣的行為不好，但是非常可憐、值得同情。**他從皮夾給了她一筆錢，**十分大方，這可能也是為了彌補他心中的罪惡感**，然後送她回家。
