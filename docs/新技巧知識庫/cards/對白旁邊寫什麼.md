# 對白旁邊寫什麼

適用：「他點點頭說」全都一個樣；每句都掛動作或副詞；或一長串對白分不清誰在說
吃：作者選的一段對白
做：用這些問題看：
- 這個動作或神態拿掉，少了什麼？點頭、笑一下、頓一頓，如果換誰都能用，可能只是在填空。
- 動作有沒有透露話裡沒說的？
- 副詞在替對白講什麼？「他怒道」的怒，台詞本身有沒有？
- 這裡一個「他說」夠不夠？什麼都不加呢？雙方快速來回時可以全省。
- 讀者還認得出誰在說嗎？多人對話可以開頭標一次，之後靠口吻；認不出來再加一個動作。
- 話的位置換過嗎？話在前、話在後、夾在兩頭（中間有動作或停頓）、單獨一行，讀起來不一樣。

吐：可疑處，每處 2–3 個改法（刪掉、換成有內容的動作、換位置）。不重寫整段
例：每句都掛，仔細就變成瑣碎：

「剛那人是誰？」媽媽握著拳頭站在家門口。
「誰？」爸爸一邊脫鞋一邊鬆開領帶。
「剛那人？」媽媽又走進了一步站在爸爸背後。
「什麼人？」爸爸把鞋放好關上鞋櫃。

全部拿掉，一長串「誰」「什麼誰」又分不清是誰在說。只標關鍵的動作，例如她擋住他的路、他把她推開。
