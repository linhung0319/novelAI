# 相反觀念的角色

適用：有想講的觀念，但寫出來像在說教
吃：想講的觀念
做：寫一個觀念和它完全相反的角色，用他的看法講故事。
1. 他憑什麼讓讀者先認同他？他的看法要有道理，不是等著被打臉的稻草人。
2. 哪些事件讓他的看法動搖，一步步改到作者想講的觀念？
3. 讀者是跟著他走到那裡的嗎？還是最後才被告知？

不想用角色時有簡單版：先演相反的情境，讓人在裡面吃苦頭。想賣車險，先演撞車後不知所措。這招單用容易只剩好壞二分。

限界：讀者仍會自己下定論。最後落點讀者很難認同時（好好先生變成強暴犯還逍遙法外），轉變未必說服得了人。要不要這樣賭由作者決定。
吐：2–3 個角色，各說起始看法、怎麼讓讀者認同、改變他的事件、最後落點
例：《侏羅紀公園》的科學家一開始堅信能掌控恐龍，也說服了觀眾。接著失控、死人、計畫放棄，主題才出來：自以為能掌控生命是自取滅亡。
