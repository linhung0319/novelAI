# 自創象徵

適用：想表達的東西太直白，或用的象徵都很老套
吃：想傳達的意思、故事裡已有的物品和行為
做：不用現成的象徵（白鴿、梅花），在故事裡把一個東西和這個意思綁起來。
- 想說的這句話，可以由哪個物品或行為代替？
- 它要先在哪裡出現，讓讀者學會它的意思？
- 它回來時，哪一句話可以不用說了？

讀者可能讀成別的意思，不必控制。
吐：2–3 個候選，各說用什麼東西、在哪裡建立、在哪裡兌現
例：
- 《等一個人咖啡》：男主角遇到真心喜歡的女生就變出烤香腸，對方也愛他才會變出熱豆花。一次次都是烤香腸，結尾女主角頭上終於出現一碗豆花。
- 《食神》：他拒絕在紙卡上畫愛心，片尾交還畫好愛心的紙卡，從沒開口說愛。
