# 大綱拆幕

適用：大綱有了，但一段話變不成一幕一幕
吃：一段大綱
做：
1. 在腦中放映這段：看到什麼？畫面切得過去嗎？切不過去的地方，可能少了一幕或少了情節。
2. 同一段大綱可以有不同幕序。試正敘，也試從最有趣的片段切入、再倒敘或插敘。
3. 每幕一句就好：誰做了什麼。作者看得懂的話，幾個詞也可以。
4. 作者提到畫面或想寫的理由時，順手記在幕旁，例如「從刀尖的血滴落開始寫」。隔一陣子就容易忘記當初為什麼這樣排。
5. 拆完回頭看：哪幕和主線無關？哪幕有因無果？章怎麼分可以之後再決定。

吐：2–3 種拆法，各列幕序，並說它先讓讀者看到什麼
例：
- 大綱：「朱崗烈因孫悟空的惡作劇被貶入凡間，他在凡間認識了女主角。」
- 拆成：① 在凡間受苦，閃回被扁的片段，昏迷。② 回想在天庭的威風，口無遮攔被師兄惡整。③ 惡整引發嚴重後果，被王母貶下凡。④ 醒來，發現被女子救起。
- 第一幕可以簡到：「雪地、掙扎、回想、被救、昏迷。」
- 「他從監獄大門走出」放映出來：走過長廊、領物品、換衣服、走出大門、看著藍天。
