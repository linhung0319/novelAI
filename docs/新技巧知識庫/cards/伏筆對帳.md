# 伏筆對帳

適用：想確認前面埋的有沒有交代；或改了結局、改了開頭，不知道另一頭要跟著動什麼
吃：前後文，或大綱和改動的部分
做：前後各掃一次。

從前往後：
- 前面特別強調過的物件、台詞或事件，後來有下文嗎？
- 沒有下文的話，它有其他用途嗎？例如營造氣氛，或故意把視線引開。都沒有的話，看要補回收、淡化，還是刪掉。

從後往前：
- 後面的關鍵轉折，前面有給因嗎？
- 伏筆是自然藏在必要劇情裡，還是硬插一段，一看就可疑？

改動之後：
- 改了結局，哪些伏筆白埋了？新結局又少了哪些因？
- 改了開頭，後面哪些回收跟著失效？

吐：沒交代的、沒給因的、太可疑的各列出來，每處給補、藏或刪的改法。要不要收由作者決定
