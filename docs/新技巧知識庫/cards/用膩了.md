# 用膩了

適用：這招已經用了好幾次，再用會不會膩；這個角色每次出場都同一套，怕他變成固定段子；或同樣的橋段寫了幾輪，覺得在重複
吃：前幾次的用法，和這次打算怎麼用
做：先列出前幾次哪裡一樣、哪裡不一樣，再問：
- 讀者現在預期會發生什麼？這個預期本身能拿來用嗎？
- 這次能不能失靈？對手學會了、環境變了，或他太依賴它反而出事。
- 這招第一次要他付代價，或第一次傷到不該傷的人？
- 換別人用呢？用在他自己身上呢？
- 角色自己發現自己老是這樣了嗎？
- 重複的這段，有沒有哪一次該整個拿掉，或壓成一句？

重複不一定是問題。讀者可能就是等著看這段，招牌動作和固定橋段也是樂趣。先問作者想留的是哪個部分。

吐：2–3 個變法，各說保留什麼、變了什麼、讀者這次會多得到什麼；也可以說這裡照舊就好
例：
- 招牌：福爾摩斯每次一眼看穿來客的職業，讀者就是等這段。
- 失靈：主角靠裝傻過關三次，第四次對方順著他裝傻，把他套進去。
