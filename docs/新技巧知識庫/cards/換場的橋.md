# 換場的橋

適用：換場太硬，只會空一行或寫「另一邊」
吃：前後兩場
做：問：
- 兩場之間能不能共用一樣東西、一個聲音、一種觸感或氣味？
- 先寫人，再寫物，寫回人時，時空已經換了。這裡可以嗎？
- 從內心回到外面時，插幾句景，能不能順勢換地方？

空一行直接換，也可以是最好的選擇。

吐：2–3 座橋，各寫出銜接的句子，加上直接換的版本
例：
- 觸覺：用餐時，一滴湯水濺到他手上，溫溫黏黏。等那滴湯水乾成一層薄膜時，他正與她在床上。
- 嗅覺：打開鍋蓋，滷豬腳的香味蔓延出來，與十年前一模一樣。媽媽第一次滷豬腳時就對我說……
- 聽覺：他抱著阿星的屍體，沉悶的雷聲自遠而近，轟隆一聲大雨傾瀉。華仔在趕來的路上被淋得濕透，依稀知道自己遲了。
