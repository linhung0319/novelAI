# 起伏檢查

適用：故事好像少了什麼，或讀起來一條直線
吃：大綱或幕綱
做：不看情節內容，只看主角和目標的關係：
- 逐段標出他離目標更近還是更遠、心情在升還是在跌。畫出來是什麼形狀？
- 指得出這三個事件嗎？他從不想進入主線到願意進入；由順境轉逆境；由逆境轉順境。
- 跨過門檻只是被推著走，還是心態也變了？跨過之後，有得到好處嗎？
- 有沒有連續好幾段同一個方向？一路無敵或一路失敗都會平。
- 哪個階段重複了？哪個階段沒有？是故意的嗎？

吐：這本書現在的起伏走向，指出哪裡平或少了轉折，以及 2–3 個改法
例：《少林足球》：師兄弟團結一致（跨越）；魔鬼隊用禁藥又收買裁判（順轉逆）；師兄弟一個個受傷離場，阿梅突然加入（逆轉順）。
