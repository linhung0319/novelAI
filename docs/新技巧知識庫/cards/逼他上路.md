# 逼他上路

適用：主角走上主線的理由很牽強，讀者會覺得他其實不必去；他一開始就太乾脆，沒有抗拒過；或看不出他的決心
吃：主角、他的舊習慣或缺陷、主線目標
做：照這條線往下問，一次問一段，作者選了再往下：
1. 舊解法：他一直靠什麼方式把日子過下去？
2. 失靈：這個方式什麼時候第一次不管用？他可能還覺得只是例外。
3. 提議：誰或什麼指出另一條路？他為什麼聽了也不要？拒絕會帶來什麼小懲罰？
4. 拉鋸：能不能讓他在兩件都對的事之間選，而不是對錯之間？例如只想守住女兒，和為了救更多人把女兒託付他人。
5. 最後一根稻草：什麼事讓他不得不動？可以是人，也可以是事件。
6. 出發前的關：放一道直接按他焦慮的關，可以是人、消息、恐懼或別人的偏見。如果是人守關，他為什麼擋？敵方要打擊他，友方要保護他，中立方只是照規定，戲都不一樣。
7. 回不了頭：他說得出「就算 ○○，我也要 ××」嗎？過關之後他少了哪條退路？守關的人之後可以變成盟友、敵人或立場不明的人。

心境大致是拒絕→無奈→接受。動身不等於想通，他心裡還可以有疑慮。主角一開始就定型、靠他改變別人的故事，可以略過這條線。

吐：目前這一段的 2–3 個候選，各說它怎麼連到上一段
例：

| 舊解法 | 失靈 | 稻草 |
|---|---|---|
| 男孩只敢暗戀 | 暗戀對象在全校面前曝光 | 和她一起被指派當佈置委員 |
| 學生被欺負就屈服 | 這次的欺負危及性命 | 家人也受到威脅 |
| 混混靠打架解決 | 被更會打的人打趴 | 重傷讓家人難過病倒 |
| 富少凡事灑錢 | 遇到不希罕錢的女孩 | 家裡一夜破產 |

小事也能用：乖學生要偷回被沒收的小說，但偷竊犯法。就算犯法，我也要拿回來。
