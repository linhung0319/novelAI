# 幕尾停在哪

適用：這幕或這章的結尾讀起來像在收攤，或沒有讓人想看下一頁
吃：這一幕，和下一幕要接什麼
做：先問下一幕是否緊接同一股張力。如果是，直接切斷，不回顧、不預告、不解釋意義。如果這裡真的告一段落，可以讓讀者喘口氣，再用一個新的具體擾動往前拋，例如來了一個人、一則消息或一句話。

不要用「重述目前處境，再預告接下來」的總結段落收尾。

切的時候，把這一刻之後的東西留到下一幕：

| 停在 | 先不講 | 例 |
|---|---|---|
| 疑問 | 答案 | 到底發生了什麼事？ |
| 高潮 | 後續發展 | 我鼓起勇氣吻了她。 |
| 轉折 | 後續變化 | 我還以為我們會結婚，但我們剛剛分手了。 |
| 大事 | 後果 | 原來他說的是真的，火山爆發了！ |
| 揭密 | 他的反應 | 看著手上的證據，我的心涼了：原來他是臥底。 |
| 決定 | 他的行動 | 考慮了很久，我決定殺了我爸。 |
| 猶豫 | 他的決定 | 我到底要不要放過他？ |

「大事」看的是對這個角色算不算大事。守財奴的銀行倒閉，就是他的大事。

「決定」還有騙人的空間：做了決定不等於做了。下一幕可能反悔，也可能是別的意思，比如只是撕掉爸爸的照片。

不是每一幕都要硬留鉤子。如果題材和劇情本身夠有趣，平實收尾也撐得住；連續用同一種結尾則容易疲乏。

吐：2–3 個收尾位置，各說切在哪一句、什麼留到下一幕
