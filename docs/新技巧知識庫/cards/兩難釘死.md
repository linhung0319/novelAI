# 兩難釘死

適用：角色在糾結，讀者卻沒感覺，甚至覺得他蠢；想給角色一個真正難選的選擇；或讀者一看到他想要什麼，就猜到他會學到什麼
吃：角色、他在乎的東西，和現在的選擇
做：
1. 釘死：兩邊都要有非這樣做不可的理由，而且改不了。他不選這邊，真的會失去什麼？如果有簡單的出路，他為什麼不走？
2. 量他心裡的天平：強度看他在乎什麼，不看客觀後果多大。遙遠的歐洲毀滅，比不上眼前被槍抵著的兒子。對極重操守的人，偷一塊錢也夠他痛苦。
3. 想選項：哪一組選擇最能逼出他是什麼人？他想要的換成什麼，就沒有人能說他錯？它和他需要的為什麼不能兩全？
4. 想選完之後：沒被選的人會怎樣？他選的理由能不能翻轉讀者的看法？這個兩難要有答案，還是不給答案？

AI 可以提選項和各自的後果，不替他選。
吐：哪裡沒釘死，或 2–3 組兩難，各說兩邊的理由、他選了會暴露什麼、選完會發生什麼
例：
- 沒釘死：妹妹為了姐姐要放棄男主角，哭了很久，但姐姐和男主角只是普通朋友。她根本沒有非讓不可的壓力。
- 選完之後：死神要丈夫選一人先死，他選了太太。讀者覺得他自私，他卻說：太太怕孤單，我先死她一個人會很痛苦。
