# 換個管道

適用：角色的性格都是直接講出來的；讀者太快看透他；或想讓讀者誤會他
吃：想讓讀者知道的、關於這個角色的一件事
做：想想這件事要走哪個管道。每個管道讀者相信的程度不同，能藏的東西也不同。

| 管道 | 特點 |
|---|---|
| 直述 | 快，但沒分量，通常要有行為或事蹟撐。想營造虛假或疏離時反而適合 |
| 別人說、過往事蹟 | 比自己說可信。可以用誇張的事蹟留印象，或在他出場前先抬轎 |
| 外觀和物品 | 靠刻板印象，一亮相就有印象（十字架項鍊、袋子裡掉出的手槍） |
| 對話 | 話如其人，但會說謊。利害關係越大越假，獨處時的自言自語接近真心 |
| 行為 | 小動作常比話誠實。越沒有人知道時，越接近真實 |
| 心聲 | 最確定，所以太清楚會減少張力。也可以讓他連自己都搞錯，得到夢寐以求的東西才發現不是他要的 |

想製造落差時，對話和行為不透明，適合藏東西；心聲、事蹟、象徵說服力強，適合讓讀者先相信。

吐：2–3 種帶法，各說讀者會相信到什麼程度、留下什麼懸念
例：
- 「那真是太好了！」他這樣說著，手指卻不經意扯緊了衣角。
- 有人看他走路絆到，笑了一聲，他衝上去打掉對方的門牙。
