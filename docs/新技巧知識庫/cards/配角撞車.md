# 配角撞車

適用：幾個配角像同一個人；配角只是工具人；或角色太多管不動
吃：角色名單、各自做過的事
做：分兩層看。
- 功能：他實際做了什麼？給資訊、逼主角上路、擋路、幫忙、點醒、製造懸念、逗笑。兩個人做同一件事，能不能併掉或換工作？反過來，同一個人可以兼任或隨劇情換功能，一場雨或一種恐懼也能擔任，不必為一個功能新開角色。
- 人：把弱點、需求、慾望、價值觀、地位能力、面對核心難題的方式排在同一張表上比。先比主角和主對手，再比對手和盟友，最後比配角之間。最後這步最常被跳過，也最容易抓到兩個配角其實是同一個人。

功能不重疊還不夠，也要問他有沒有自己要的東西。

吐：撞車的組合和撞在哪一項；2–3 個改法（併掉、換功能、換價值觀），由作者決定
例：女主的三個閨蜜：毒舌的負責吐槽，知心的給情緒支持，理性的出主意。
