# 對白升溫

適用：對白只是在傳話，沒有摩擦；或兩人一開口就吵到頂，沒有過程
吃：作者選的一段對白，雙方各自要什麼
做：問：
- 雙方要的東西或觀念差在哪？沒有這個差，爭吵只會讓人困惑。
- 這段能分幾步往上走？每一步是哪句話逼出來的？
- 走到哪裡停？不一定要走到決裂。

不一定要吵：
- 局勢越緊，某個人可能越靜。讓其他人越講越快，反而突顯他的沉默。
- 摩擦也可以不在兩人之間：說話的人正要做決定、正受威脅，或快失去什麼。

過場的對白可能就該平順，要不要升溫由作者決定。

吐：2–3 條路線，各說從哪句開始轉、停在哪裡
例：
「老大，這小女孩怎麼處置？」
「還用問，砍了。」
「可是……她才八歲呀！」（輕微反抗）
「叫你砍就砍，廢話什麼。」（輕微對立）
「這樣太殘忍了吧！」（明確反抗）
「哼！殘忍？我連你也砍。」（明確對立）
「砍我？那倒要看看是誰砍誰！」（決裂）
