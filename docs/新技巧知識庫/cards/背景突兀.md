# 背景突兀

適用：世界觀或背景太正常，主角待在裡面沒有戲
吃：主角的身分，和目前的背景
做：讓角色和背景格格不入，把他踢出舒適圈。從下面找哪個維度可以錯開；背景也可以是直接束縛主角的規則，看他怎麼對抗。

| 維度 | 例 |
|---|---|
| 時間 | 古代人到現代 |
| 空間 | 轉移到虛擬遊戲或意識世界 |
| 活動 | 男人偽裝參加選美 |
| 地點 | 假太監住進皇宮 |
| 組織 | 內向宅男就讀女校 |
| 社會 | 追求自由的人活在高壓統治下 |
| 自身 | 靈魂換到不同的身體 |

也可以只是抽換背景，看同一件事的意味怎麼變：表哥表妹的禁忌之戀放在現代才有張力；行俠仗義的高手放在現代反而新奇。

吐：2–3 個錯開方式，各說他在那裡會不自在什麼、會因此做出什麼
