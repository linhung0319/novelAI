# 結局題旨互推

適用：故事有了，但說不出它在講什麼；結局選不下；或題旨把故事綁得動不了
吃：主線（主角要什麼、主要衝突是什麼），已有結局或題旨也帶上
做：角色的下場通常就是故事下的註解，所以兩頭可以互推。看作者卡在哪一頭：

**有下場，找見解。** 把故事壓成一句，再問這個下場在替什麼下註解。「愛情」只是主題，「真愛不怕死亡」才有見解。見解常可以寫成「因為 X，導致 Y」，X 是行為或觀念，Y 是結果；也可以問它靠什麼達成，如「愛因自我犧牲而勝出」。句型只是幫忙收斂，作者有別的說法就用他的。找到的見解不是作者想說的，就回去問他到底想說什麼。

**結局未定，換結局。** 同一條主線，依主角目標的下場試幾種，看各自說出什麼見解、讀者帶著什麼感受離開。挑有戲的試，不必全跑。

| 下場 | 怎麼算 | 例 |
|---|---|---|
| 達成 | 可有小遺憾，大致圓滿 | 《唐伯虎點秋香》 |
| 沒達成 | 努力過仍失敗，讀者同情或憤怒 | 《殺人回憶》真兇逍遙法外 |
| 達成部分 | 贏一部分，輸一部分 | 《浩劫餘生》活了下來，愛人已嫁別人 |
| 只暗示 | 有不同可能，但看得出最恰當的讀法，重點移到歷程 | 《少年Pi》兩個版本 |
| 停在分歧 | 揭曉前結束。有人津津樂道，也有人覺得被耍 | 《全面啟動》旋轉的陀螺 |
| 達成才發現不是想要的 | 追表面目標，得到後才醒。可給回頭機會，也可不給 | 《白色巨塔》不給；《命運遙控器》給 |

**題旨綁手綁腳。** 題旨是「仁慈導致滅亡」，仁慈的主角就不能有好下場。好下場更好看的話，可以改題旨。暫時放下題旨，只問：什麼主要衝突、什麼最後結果最有趣？這兩個定了，主線就有了，題旨也會跟著出來。

作者不想現在定題旨也可以。娛樂向的故事題旨可以很淡，下場定了自然讀得出來。

吐：2–3 組「結局—見解—讀者感受」，並說選了哪組，現有主線哪裡要動。不替作者選
例：
- 黑道愛情，兩人死亡：愛情無法戰勝環境，導致毀滅。兩人生存：愛情能戰勝阻礙，所以重獲新生。
- 貪心的主角死了：貪婪導致滅亡。好心的主角死了：仁慈導致滅亡。
- 英雄打倒魔王：正義勝過強大的邪惡。英雄和魔王變朋友：溝通能化敵為友。
