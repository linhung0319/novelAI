# 動力檢查

適用：讀者不在乎主角成不成；故事到中段就鬆了；或讀起來很散，看不出在幹嘛
吃：主角的目標，和目前的劇情
做：用這些問題檢查：
- 看得出主角是誰嗎？他有帶著故事前進，還是常被別的東西搶走？
- 他要的東西具體嗎？讀者看得出他的進度嗎？
- 能用一句話說出讀者在追什麼嗎？
- 他有多想要？哪場戲看得出他死也要達成？
- 是什麼情緒在推他？憤怒、不服輸，還是想守護？
- 他要的東西是不是中段就到手了？要轉換目標可以，下一個接上了嗎？
- 每件事讓他離目標更近還是更遠？有沒有哪一段在原地踏步？
- 開頭讓讀者期待的東西，後面還在供應嗎？
- 目標是不是太多？有沒有一個最強的，讓故事聚焦？

主角如果是刻意沒有動力，就看誰替他推。

吐：最弱的 1–2 處和改法
例：楊過能不能和小龍女在一起？喬峰能不能洗刷冤屈？一句話就是讀者追下去的理由。
