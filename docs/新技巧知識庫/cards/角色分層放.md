# 角色分層放

適用：角色一出場就把身世交代完；或配角出場很多次，讀者還是沒感情
吃：角色的身分、性格、背景，以及他出場的幾場戲
做：把角色資訊分層，各由一個轉折揭開。問：
- 讀者現在對他最好奇什麼？
- 下一層由什麼事揭開？不要靠旁白或自述交代。
- 讓人心疼的那層，放在讀者喜歡上他之前還是之後？
- 這場需要讀者知道多少才看得懂？給到這裡就停。

一種常見順序是身分引起好奇、性格讓人喜歡、背景讓人憐愛。這不是唯一順序，懸疑的書可能倒過來用。

吐：2–3 種排程，各說哪場戲揭哪一層、讀者當下的感受
例：《原神》的胡桃先給怪身分（殯儀館館主），再給有趣可愛的性格，最後才給讓人憐愛的背景。
