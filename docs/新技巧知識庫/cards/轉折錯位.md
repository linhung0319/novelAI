# 轉折錯位

適用：結構太規整，讀者猜得到「差不多要轉壞了」或「快要好轉了」
吃：目前的起伏順序，一串事件或揚抑都可以
做：不換事件，先動起伏本身：
- 改次數：多跌一次，或在逆境中插一次小順境。
- 換順序：從逆境開場；中間一度好轉，最後仍是壞結局。
- 換時間點：讀者這時預期要轉了嗎？提早或延後會怎樣？

動完查一遍：因果還接得上嗎？主角的變化還合理嗎？刻意的急轉如果沒有因果撐著，會變成不知所云。
吐：2–3 個變形後的起伏序列，各說多了什麼驚喜、失去什麼
例：
- 《大英雄天團》：申請上實驗室（揚）→哥哥死於火場（抑）→和哥哥的朋友追查神秘人（揚）→神秘人竟是哥哥拚命救的教授（抑）→重新振作阻止陰謀（揚）→杯麵犧牲自己（抑）→在殘骸手臂中找到晶片，重建杯麵（揚）。
- 《食神》：才介紹完主角的囂張，就馬上跌進逆境。
