# 目標互推

適用：想不到主角要什麼；有目標卻不知道主線是什麼；不知道反派或配角要幹嘛
吃：一段主劇情或一個主角目標，有哪個算哪個
做：缺哪一格補哪一格。
- 有劇情，缺目標：主角從頭到尾在忙什麼？那多半就是他的目標。
- 有目標，缺主線：為了讓他達成目標，要發生哪些事？那些事就是主線的候選。
- 缺反派目標：誰的行為會擋住主角的目標？他為什麼要這樣做？反派不一定是壞人，逼你念書的父母也算。
- 缺配角目標：主角的心態要往哪裡變？要他變壞，誰來洗腦他；要他改過，誰來點醒他；要他冒險，誰來逼他。由主角想配角的任務，再由任務想配角的目標。龍套和功能性角色不用找。
- 主角真的不想動：交給一個動力很強的配角推，再用某種綑綁把主角拖進去。主角最後可以轉變，也可以從頭到尾都是被迫的，那個矛盾就是笑點。

作者如果刻意讓目標模糊，就先問他讀者要靠什麼追下去。

吐：缺的那一格 2–3 個候選，各說會帶出什麼主線或衝突
例：
- 到吸血鬼黑幫臥底的故事：主角打算對黑幫不利。
- 一對戀人在即將沉沒的郵輪上談戀愛：目標是一起活下去。
