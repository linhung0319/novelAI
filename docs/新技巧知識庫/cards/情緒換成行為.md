# 情緒換成行為

適用：「他很傷心」一句過去沒感覺；或動作寫了一堆，看不出他在想什麼
吃：作者選的一段，這個人此刻在意什麼
做：問：
- 他此刻想藏什麼？藏不住的是哪裡？
- 他手邊正在做的事，會被這個情緒怎麼改變？
- 這個動作換別的角色也能用嗎？手心冒汗、指節發白這種誰都能用的先放一邊。
- 讀者看完，猜得到他在想什麼嗎？

標籤不一定錯。不重要的人物、想要冷感或疏離時，「他是個孝順的孩子」一句就夠。

吐：2–3 個改法，各說讀者會由此讀到什麼。也可以建議標籤留著
例：
- 「他摸了摸旁邊沒有人躺的枕頭，不能自制地發出一聲怪叫，那是太用力換氣才會發出的聲音，他自己都嚇到了。」
- 反例：「失去她一個禮拜了。他去打了幾次籃球，每天早上煎一顆蛋，晚上看電視，還對著鏡子畫了一幅自畫像。」動作很多，讀者不知道它們要說什麼，除非後面接得上。
