# 筆調漂移

適用：這段的語氣和前面不像；或說好的基調（例如喜劇）寫著寫著不見了
吃：作者選的一段，這本書前段的片段或基調
做：問：
- 和前段比，說故事的態度變了嗎？
- 是故意的，還是寫著寫著就變了？類型有沒有跟著轉？
- 對白的調性呢？同一句話，文藝、科幻、驚悚的人物會講得不一樣。
- 每段單看都沒事，但連起來比前面少了什麼？
- 基調少了，是這段真的不適合，還是少了原本帶它的東西？例如喜劇沒有人接梗時，主角極小極俗的念頭撞上極大的場面，一個人也做得到。

不要用「這段比較沉」一路打發，也不要一看到變化就拉回去，轉過去可能更好。

吐：可疑處和前段的對照；再給作者選：拉回來怎麼改、接受轉調並列出前面要統一的地方、換一個東西帶基調
例：
- 「事已至此，無需多言。」語畢反手一劍，如流星追月……「救……救命啊！」對手嚇到快尿褲子。
- 「岳不群，看劍！」「唉喲！你幹嘛刺人家啦！」
