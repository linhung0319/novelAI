# 角色各帶主題

適用：人物很多，故事卻只有一層意思，看起來單調
吃：主題、重要角色和他們的經歷
做：不從主題往下推，反過來看每個重要角色的人生縮影在說什麼。
- 他的選擇和下場，替什麼下註解？
- 這個見解和主線的主題是呼應還是衝突？
- 它要顯眼，還是若有似無就好？
- 放在一起，是互相映照，還是互相抵銷、讓故事自打嘴巴？

不是每個故事都需要多主題，單一主題寫透也可以。作者想要單純就停。

吐：2–3 個角色的副主題，各說它和主線是呼應還是衝突、在哪裡露出
例：
- 大方向是邪不勝正。反派寫得有血有肉，多了「壞人也有苦衷」；好人為了制服壞人也做了壞事，又多了「正義和犯罪只有一線之隔」。
- 《三國演義》的關羽和曹操，各自承載不同的東西。
