# 打鬥

適用：打鬥寫成招式清單，看得累，也不在乎誰贏；或直接開打沒感覺，想讓這一戰讓人期待
吃：這場戰鬥、雙方各要什麼、前後的段落
做：問：
- 這場打，誰要什麼？輸了會失去什麼？打完兩人的關係或處境變了什麼？
- 讀者透過誰的身體和心思經歷這場打？
- 哪一瞬間值得停下來？其他招能不能帶過？比較長的念頭，能不能放到打完之後？
- 讀者知道這一招的規則嗎？放在動作中哪裡說？
- 打之前和打之後也能加戲：誰在看？誰押了什麼？

鋪墊的兩種形狀，太熟的話哪一步可以顛倒：
- 比賽框架：對手約戰 → 主角準備 → 對手出場獲得稱讚 → 主角平淡出場遭噓 → 大人物打賭 → 主角勝出，眾人震驚。
- 反差傳說：主角被貶低，對手很強；主角用普通的直拳解決；這一戰被傳成神話。

吐：可疑處和 2–3 個改法或鋪墊安排。要動到選段以外時，列出要動的位置
例：「劍鋒劃過耳際，斷開幾絲髮線，在空中飛散，半黑半白。」寫得少，焦點集中。
