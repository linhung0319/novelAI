# 立場曖昧的人

適用：想要一個讓人猜不透的角色；或角色忽敵忽友，看起來只是作者想轉就轉
吃：主角目標、這個角色和主角的關係
做：
- 他每次幫或害，有沒有讓主角靠近或遠離目標？和目標無關的善惡變化只是換個性。由善變惡後就定型，也不算曖昧。
- 怎麼進入曖昧？一直幫忙的人，關鍵時刻總是有意無意壞事；一直刁難的人，關鍵時刻總是有意無意幫忙。
- 什麼隱藏動機能同時解釋每一次搖擺？這個理由最好揭開時讓人動容，先給作者選。
- 結局時他最後一個行為是幫還是害？那就決定了立場。他可以不甘願，也可以不明說。
- 選邊之後，主角還敢百分百信他嗎？如果想讓疑雲留到最後，這裡還能再用一次。

吐：2–3 個隱藏動機，各說能解釋哪幾次搖擺、何時揭開、最後一個行為是什麼
例：
- 總在關鍵時刻阻止主角復仇的愛人，其實是仇人的女兒，最後要在愛人和親人之間選。
- 嘴上說絕不幫忙，又說與其讓那傢伙贏，不如讓你贏，然後不甘願地給出關鍵指引。
