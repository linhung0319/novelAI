# 岔路定性格

適用：性格都寫在設定裡，故事裡看不出來；或這段戲換誰來演都一樣
吃：一個事件，和身在其中的角色
做：在事件裡找他要做選擇的那一刻。列出幾個都說得通、方向不同的反應，逐一問：讀者看到他這樣做，會覺得他是什麼人？之後的戲會怎麼走？

事件逼不出選擇，就把它逼緊一點。人在低潮或受迫時最藏不住：是在槍口下投降，還是照樣衝上去？

也可以倒過來用：想讓讀者覺得他是某種人，什麼事件能逼他做出那個選擇？

選哪個由作者決定。
吐：2–3 個反應，各說它塑造出什麼形象、之後往哪裡走
例：曹操誤殺呂伯奢全家，逃亡路上遇到還不知情的呂伯奢。認錯，他是還有良知的人；連呂伯奢也殺，他就是自私又狠的人。
