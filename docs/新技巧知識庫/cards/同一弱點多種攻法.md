# 同一弱點多種攻法

適用：敵人一個接一個都差不多，打完就換下一個；或對立只剩善惡兩邊
吃：主角最大的弱點、現有的對手群；有想探討的道德難題更好
做：用這些問題重排對手。人數不用湊，有兩個也能問。
- 每個對手怎麼按同一個弱點？手法哪裡不同？
- 面對同一個道德難題，每個人的回答是什麼？
- 對手之間有什麼衝突？不要全部只對著主角。
- 長篇要排先後時：哪個練手、哪個多次交鋒、哪個貫穿全書？每打完一層，弱點被按得更深了嗎？

吐：2–3 種配置，各說每個對手的攻法和他代表的回答
例：《窈窕淑男》的難題是男人怎麼對待女人。Ron 為保護女人合理化欺騙；Julie 有才華卻容忍被虧待；John 用權力換性好處；Michael 假扮 Dorothy 後反而替女人爭尊重。
