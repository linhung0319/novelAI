# 索引

每招一行，卡片在 `cards/`。先選領域再看症狀，只讀選定的 1–2 張。沒有合適的招就直說，照自己的想法回答。

卡片是材料，不必照步驟；例子只示範形狀，不要搬進候選。該由作者決定的事給候選，不表態，作者問了才說。正文類的卡不放進落筆的寫手 context。

## 構想

- 無關組合：靈感單獨看都不夠好，不知道要寫什麼
- 十大故事類型：完全沒靈感想找刺激，或不知道這個靈感往哪種類型發揮
- 連問法：有個畫面或題材，但還不是故事；或只有人物、情節、背景其中一項
- 主題三角：有想講的主題，不知道要寫哪些戲；主題只演得出好壞兩邊；或被主題綁死
- 相異錯配：角色、設定或點子太平凡、太老套，或想不到更好玩的變法
- 三十六劇：想不到要放哪些梗，或這段還能變出什麼戲
- 結局題旨互推：結局選不下；說不出故事在講什麼；或題旨把故事綁得動不了
- 壓縮成摘要：想確認自己想清楚了，或想法很多、故事開始散掉
- 故事設定健檢：設定有雛形，想知道吸不吸引人、哪裡撐不住；或什麼都想放，不知道砍哪個

## 世界觀

- 這條規則該有誰：有世界規則，但沒有人物或勢力在裡面活動
- 能力太萬能：能力、魔法或金手指太萬能；主角只要靠它就好；或撐不撐得到後期
- 綑綁抗衡：衝突不痛不癢，雙方隨時能走開，或只是二選一
- 自訂規則：誇張的設定要不要解釋、什麼時候交代
- 抽掉就垮：設定很多，但感覺只是裝飾，或不確定該不該留
- 解圍太便宜：靠能力、外力或巧合解決危機，感覺很便宜
- 設定怎麼帶出來：有一批設定要讓讀者知道；設定突然蹦出來，或像在念說明書、念課文

## 角色

- 給他一個不足：主角太完美；不知道故事要折騰他什麼；或某段戲不知道該讓誰做
- 角色會做的事：這個角色很空；資料有了，人活不起來；換誰演都一樣；或每個人開口都像作者
- 目標互推：想不到主角、反派或配角要幹嘛，或有目標卻沒有主線
- 臨摹混搭：想不出這個人，腦中只有「有點像某某」
- 弧線缺一段：轉變像突然開竅，或心境一直沒動
- 主角變得太簡單：主角的變化只有一步，或變很大卻像換了個人
- 缺一個反對的人：這段衝突很弱，只剩主角在想事情；或對手是天災、恐懼，沒有具體的人可恨
- 關係網缺線：角色都只跟主角有關係，配角之間沒戲
- 群像：角色一多就各演各的；有人消失很久；或配角搶戲
- 改一個條件滾下去：角色很通用，或兩個角色太像
- 核心情緒：行為合理但沒勁，或要做反常的事怕讀者不接受
- 他相信的假話：舊傷只是背景；反派只是為作對而作對，只能用「他瘋了」解釋
- 同一弱點多種攻法：敵人一個接一個都差不多，或對立只剩善惡
- 立場曖昧的人：想要猜不透的角色，或忽敵忽友看起來很隨意
- 誰來點醒他：主角需要被點醒，但寫出來只是有人說教或送禮
- 反差要收：角色表裡如一太單調，或有反差但只是噱頭
- 相反觀念的角色：想講的觀念寫出來像在說教
- 鏡像與對照：配角只是襯托主角，沒對他造成壓力
- 憧憬與代入：主角太強讀者有距離，或太普通沒人想變成他
- 讀者不在乎他：這個角色很討厭，或讀者不會在乎他，會不會不想跟他走
- 配角撞車：幾個配角像同一個人；配角可有可無；或角色越開越多
- 角色反應檢查：他的反應怪怪的；為了劇情做了他不會做的事；或轉折很想要但感覺很扯
- 反派份量檢查：反派像紙老虎，或主角贏得太便宜
- 動力檢查：讀者不在乎主角成不成，中段鬆了，或看不出在幹嘛
- 用膩了：這招或這個角色的段子已經用了好幾次，怕變成固定套路、讀者會膩

## 劇情

- 把情節填進骨架：想到一堆情節排不成故事；不知道用哪種結構；或有主角和目標不知道怎麼走完
- 縱橫交會：主線太單薄想加副線，不知道怎麼接
- 中段空洞：頭尾都有了，中間不知道要演什麼
- 下一步從結果長：上一幕寫完，不知道下一幕要做什麼；這件事之後要怎麼接
- 大綱拆幕：大綱有了，一段話變不成一幕一幕
- 特質要有展場：特質或關係定好了，但沒有一場戲在演它
- 由果推因：知道後面要發生什麼，不知道前面怎麼埋；想埋伏筆又怕太明顯；或現在要一個轉折，又不想憑空冒出來
- 主題落點：題旨定了，不知道怎麼進到故事裡；或故事只有一層意思
- 逼他上路：主角走上主線的理由很牽強，或他太乾脆
- 起伏怎麼走：挫折不夠痛；一路順或一路慘；猜得到要轉了；或讀起來一條直線
- 爽點與節拍：翻盤打臉讀起來不爽；連載憋太久；或一路順爽沒有想點下一章的理由
- 先笑後哭：這場死亡或背叛應該不會痛，或故事一路沉重
- 誤導佈局：真相想好了，但讀者猜得到；或想騙讀者兩次
- 第三條路：一路在 A 和 B 之間拉扯，怎麼選都猜得到
- 兩難釘死：想給角色真正難選的選擇；或他在糾結，讀者卻沒感覺，甚至覺得他蠢
- 阻礙不夠力：阻礙看起來很大，讀起來不緊張；主角打來打去，看的人不痛不癢
- 讀者想喊停：主角太乾淨、一路做對的事，讀者沒什麼好揪心的
- 資訊差：事件都對，卻不緊張；所有人知道的都一樣；或不知道該讓誰先知道答案
- 留一塊不說破：什麼都交代清楚了，讀完就結束；一條線想拖著，又怕變成沒交代；或想讓每個人的說法都不一樣
- 結局沒力：結局成立但平淡；高潮無力，怎麼改結尾都不對
- 反高潮：不想照常見的方式收尾；或結尾讓人失望，分不清是手法還是爛尾
- 內外目標排序：幕排出來順序不對，或表面在忙，看不到他心裡的問題
- 開始與開場：不知道第一章從哪寫、要不要楔子，或一直在交代前史
- 爽與深的鈕：這段該快還是慢、該爽還是深
- 角色分層放：角色資訊一出場就交代完，或配角出場很多次讀者還是沒感情
- 開頭檢查：想知道開頭抓不抓得住人，或前幾章很慢
- 這段戲留不留：讀起來拖、很平；有些戲可有可無；或很喜歡一段，不確定該不該留
- 整段碎掉：發生很多事，每件都獨立，讀完不記得；每章都等長等速
- 賭注有沒有兌現：有人放了狠話或握著秘密，下一幕就沒下文
- 假象對帳：有反轉或揭曉，怕讀者不服，或怕太早被猜到
- 伏筆對帳：埋的東西有沒有交代；或改了結局，不知道另一頭要動什麼
- 立場詭變：寫到後來變了一個意思，想說的和寫出來的對不上

## 正文

- 下一句換方向：對話寫到這裡接不下去，或下一句太好猜
- 一件東西頂一段描寫：描寫很長卻沒感覺；不知道該描寫什麼；或這段很空，看不見也摸不著
- 換場的橋：換場太硬，只會空一行
- 話中有話：角色把心裡想的直接說出口；一問一答很死板；或台詞沒把他的虛偽、怒氣演出來
- 對白升溫：對白只是傳話，或一開口就吵到頂
- 認得出是誰：角色講話都一個樣，或配角多了記不住
- 情緒換成行為：情緒一句過去沒感覺；像旁白在總結；動作很多看不出在想什麼；或痛寫得像說明書
- 換個管道：性格都是講出來的，或讀者太快看透他
- 旁帶：「她很美」「他很有錢」直說，讀者不信；或想讓人覺得他很強但沒東西可比
- 複沓與反常：這段達成得太容易，或情緒推不上去
- 情景相襯或反差：景只是布景，或傷心就下雨
- 一句話幾種寫法：這句就是不對，想看別的寫法
- 心念插進動作：一直寫「他想」，或內心和動作脫節
- 我他你切換：感情太難受，一直「我」顯得矯情，或第三人稱隔太遠
- 角色怎麼登場：第一次出場很平淡，像在填資料
- 第一段怎麼抓：第一句或第一段沒有力
- 幕尾停在哪：結尾像在收攤，沒有讓人想看下一頁
- 自創象徵：想表達的東西太直白，或象徵都很老套
- 該演還是帶過：這段該寫滿還是一句帶過；過程寫出來反而普通
- 放快或放慢：這段太趕或太拖，想拉長一瞬或壓短很多年
- 換一雙眼睛：不知道這段該由誰來看
- 貼近或拉遠：和角色隔了一層，或太黏想拉開
- 這段回憶該不該插：想插回憶或支線，怕打斷
- 幕裡寫了什麼：某一幕怪怪的，說不出哪裡怪
- 對白旁邊寫什麼：「他點點頭說」全一個樣，或每句都掛動作，或分不清誰在說
- 是不是多說了：有句子在解釋意義、像旁白；對白像在交代資料、講給讀者聽；或內心戲看著多餘
- 文句就是鏡頭：畫面跳來跳去，或想知道這段讀起來是什麼畫面
- 重音放哪：讀起來一直煞車，短句、破折號或留白很多；同一個句型一直疊
- 唸起來卡：句子拗口、像翻譯，或換不了氣
- 視角跳了嗎：不知道這段是誰的眼睛
- 筆調漂移：語氣和前面不像；基調不見了；或這個用詞放在這裡出戲
- 跟範文比語感：語感不是我要的，但說不上差在哪
- 打鬥：打鬥寫成招式清單，或直接開打沒感覺
- 修稿從大到小：寫完了，不知道從哪裡改
